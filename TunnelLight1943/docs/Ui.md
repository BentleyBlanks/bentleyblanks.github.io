## 阅读层那张纸是**程序化画的**（2026-08-15 用户定：「界面里只有一张纸，程序化的在纸上写上文字内容」）

- **征夫告示的阅读层是 `Art.DrawNoticeSheet` 现画的一张纸，连纸上的字一起**（文案＝
  `Core.ZHENGFU_NOTICE`，存告示原文不存简体转录）。`#noticeSheet` 是张 DOM canvas，
  `Main.PaintNoticeSheet` 只在**打开时与画框变了时**重画。
- **繁体、竖排、自右向左（全作铁律），标题也走竖排**（横排四字今人读成「示告夫徵」像 bug；
  与墙上那张小告示 `DrawNoticeWall` 同款）。
- **每次 `clip` 之前把轮廓重走一遍**：canvas 的「当前路径」不进 `save`/`restore`，
  `ctx.save(); ctx.clip();` 裁的是上一句 `beginPath` 的路径——裁没了看着像"纸太干净"。
- **字号要搜，起点得给到铁定装不下**：从大往小收到刚塞进版心＝装得下的最大一档；起点一给就过等于没搜。
- **纸形按画高走，判据用画高不用画宽**（同「拇指落点」那条）：画高够就竖长优先，矮画高那档摊到
  跟画框同形。守着它的：`Script_RenderHealthTest`「告示的字每档画高都认得出」（下限 12px）。
- **做旧的上限由字定**（盖章是气氛、日期是信息）。印章骑着落款盖，但上沿**刚咬住**署名末字就够，
  不许整个骑上去、不许往左吃掉日期列。
- 外部成图流水线（`Script_TypesetNotice.py` + `Script_TextureKey.py`）与
  `Texture/Texture_NoticeZhengfu.webp` **都还在、没人引用**——要清理另说，别顺手删。

## 主菜单与存档（2026-08-17 用户定：「这开始菜单还弄个两层是干什么？」）

- **标题页只有一列条目**：继续（有存档才出，主位）／新游戏／操作说明／设置。条目自带一行小注
  （「第一章 · 第 13 幕 · 把水带回家」「从头再来一遍」），**代价写在脸上**。
- **选关只在调试面板**（设置 → 调试，`` ` ``/F2 也开）：线性剧情不给玩家跳关；做的人从标题页的「设置」进。
- **存档＝一个自动存档位，按幕存**（`Script_Main` 的 `SAVE_KEY`）：写「哪一章 · 哪一幕 · 旗标」，
  恢复走 `Core.DebugJump` 按脚本结算前序。① **认 id 不认序号**（往章里插一拍，序号就指到别人家）；
  ② **旗标合并回来**（结算只跑得出默认分支）；③ `BAG_KEY` 与 `SOUND_KEY`/`VOL_KEY` 各存各的，
  不在存档里再抄。守着它的：`Script_DebugJumpTest` 末尾（换幕落盘 → 刷新 → 继续 → 同一幕、旗标还在）。
- **设置面板在游戏里就是暂停菜单**：世界停住（`MenuFrozen`，跟实拍的 `Freeze` 同一条路：游戏钟停、
  渲染照跑）并压暗画布（`body.paused`）——不停的话，在车铃那一拍（全章唯一会失败的）点开设置
  就等于站在伪军跟前发呆。面板里有「操作说明」「回到标题」；**回到标题在标题页上整条不出**
  （按了没反应的钮比没有更糟）。
- **Esc 一层一层地收**（确认框 > 操作说明 > 设置 > 标题页）。菜单里键盘归 `MenuKey`：玩法那句
  「空格/回车 → advance + preventDefault」会吃掉回车，而按钮靠 keydown 激活。
- 改完**必须看图**（`node Script_Cli.mjs menu`，菜单类界面一条命令全拍）：菜单的毛病测试基本抓不住。

## 世界内提示（HUD）清晰度

- 屏幕像素密度已是贴图标尺 PPM 的近三倍，特写还推近——**会被玩家盯着看的 canvas 纹理必须超采样**：
  提示类 `HINT_SS`，道具 `PROP_SS`，小件 `DETAIL_SS`；逐帧重画的 canvas 用 `setTransform(SS,…)`。
- DOM HUD 的字体规矩见 `Style_Game.css` 顶部注释：居中走布局不走 transform、text-shadow 收贴身、
  字体必须真的加载（index.html 的 Google Fonts 四档字重）。

### 拇指落点上不许压着别的东西（2026-08-13 用户报「按钮触发位置偏移」）

DOM 按钮的**画**和**点**是同一个盒子，不可能真的错位——"触发位置偏了"只有一个来源：
**被别的元素盖住了一半**，剩下那弯月牙还能按。三条：

1. **判据用画高不用画宽**：竖着的 HUD 撞的是高度，只在手机上才叠——这类 bug 一律是
   `@media (max-height:)`。包袱条在 ≤520px 画高下改成右上角 3×3 的方格（九件不用滚）。
2. **通知不许吃触摸**：滑出来"探头"的是通知不是控件，`#bagPanel` 默认 `pointer-events: none`，
   只有玩家真打开（`.open`，世界冻结）才接管拇指。`show`（滑进来了）与 `open` 是两个类，别混。
3. **底边也要让开安全区**：`env(safe-area-inset-*)` 左右底都得写——横屏 iPhone 的 home 指示条
   那一条的触摸系统先当上滑手势收走，同样读作"偏移"。

守着它的：`Script_RenderHealthTest` 的「拇指控件三态无遮挡」——三档横屏手机（667/844/932）
× 三种状态（玩法 / 包袱探头 / 包袱打开），按圆形按钮的**有效面积**逐点验，摇杆与两颗钮一格
都不许缺。设置面板不在此列——玩家自己打开的模态面板，点面板外面本来就是关掉它。

### 画框边缘的「下一件事」（2026-08-10 用户定，参考勇敢的心）

目标出了画框时，边上立的**不是一个方向键**，是一枚带图的牌（`Art.DrawEdgeHud`）：**箭头说往哪走，
图说去干嘛**，一支箭头说不了两件事；不同任务、不同人提示不一样。

- 牌面由 `Core.BeatHintIcon` 推出来，跟着 `GetBeatTarget` 那张表走：目标是谁就画谁（侧脸＋衣色），
  是什么东西就画小样，上手的活画手势。**挑人的条件必须和 `GetBeatTarget` 一模一样**，否则牌上是甲、
  路却通往乙。剧本可在节拍或链上某一步写 `hintIcon` 覆盖推导。
- 种类是封闭的一张表（`HINT_ICON_KINDS` ↔ `Art.HudGlyph` 的 switch）：新加一种词就得同时给一张画法。
  守着它的：SmokeTest「边缘 HUD 牌面」扫全八章逐拍——每拍都推得出、种类都有画法、找人带得上 who、
  拿东西带得上 item，全场不许退化成一种图。
- 借世界里的画笔时**照实际尺寸倒推缩放**：`DrawCarry` 按真家伙画，原样缩到牌上是一根牙签；
  `DrawCharacter` 从脚到发顶是 64×S 而不是 bodyH 的 62×S，照 bodyH 给会把脑袋切在裁剪圈外。
  牌面一律加圆形裁剪兜底，但裁剪是保险不是版面。
- 摆位在 `Script_World.js` 的 `UpdateEdgeHud`：牌贴在 `EDGE_HUD_Z`，**那一层的画框比 `viewW` 窄一档**
  （×(dist−z)/dist），不折算箭头尖就被切掉。牌面按 icon 烘一次存进 `edgeHudTex`（每帧重画一张
  `HINT_SS` 的大图太贵），一探一探的怂靠挪网格。
- 目标还在画框里时仍是那枚小人字标（`DrawMarker`），两者互斥。

### 角上那枚「下一件事」＝目标 HUD 的唯一一处（2026-08-13 加，2026-08-17 合并）

目标 HUD 只有左上角这一枚牌（`#objectiveTab`）；屏幕正中那条（`#objectivePanel`）已整个撤了
——换目标那一刻不许两处同时说同一句。这枚牌把「变化时说一遍」「常驻一枚图」都接过来：

- 图与画框边那张牌**同源同画笔**——`Core.BeatHintIcon` 推种类，`Art.DrawHudBadge` 画（＝`DrawEdgeHud`
  去掉箭头：角上的牌不指方向，方向只在目标出框时才有），玩家只用学一套。新加 icon 种类照旧只改
  `HINT_ICON_KINDS` ↔ `HudGlyph` 那一对，这枚牌自动跟着长。
- **换了目标，牌自己张开把字说一遍**（`objFresh` → `SetObjTabOpen(true)`，`OBJ_TAB_HOLD` 后收回图），
  换了图顶一下（`.bump`）；之后悬停（CSS）/ 点一下再看（同一个 `SetObjTabOpen`、同一个时长）。
  目标在过场里换的（牌藏着）先欠着，牌露面那一帧补说——不然那句就没人说过。
- 过场里整枚藏起来（`inCinematic`），没有 `objective` 的拍也不出。
- 展开走 `grid-template-columns: 0fr → 1fr`，**裁剪壳必须是网格的直接子项**（`.clip` 自己
  `overflow:hidden`，自动最小尺寸才归零）——固定宽度写在直接子项上，收起来的牌照样是隐形板子还吃点击。
  字的宽度钉死在里层，不然展开过渡里中文会一路重排行。
- 左上角还住着跳过序章那颗钮（现在没有 prologue 拍，机制留着）：两枚同时亮时牌让到它下面（`.lower`）。
  守着它的：`Script_RenderHealthTest`「拇指控件三态无遮挡」顺带验——牌自己按得着、跟跳过键不叠。
