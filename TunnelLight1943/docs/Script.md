## 剧本口径（2026-08-11 起；c1 2026-08-13 按 Notion **第八稿**整章重排）

**剧本代码按章在 `Data_ScriptC1..C8.mjs`**（一章一个文件，工厂＋Core 末尾的

新增章文件要登进 index.html 的 import map（`TestModuleGraphIsCacheBusted` 盯着）。

- **章名与稿源**：c1「**蓝底白花**」（第八稿：Notion《第一章 · 善意的谎言》＋独立的
  《序 · 那天》两页为准；章名按布的暗线取）、c2「地洞里的眼睛」（梳篦扫荡：下窖/
  捂嘴听声/伤员两难抉择/挖开祖辈防兵洞爬出去）。

  c1（含序）28 拍已分好，Notion 两页剧本已逐行标注（〔镜〕〔演〕〔音〕〔说明〕〔字卡〕

- **视频序章已删**（替代品是第八稿「序 · 那天」）。机制现状：`PROLOGUE_CLIPS` 从全
  剧本派生（现为空表，再有拍写 `cam.kind:"insertVideo"` 它自己长回来）；`SkipPrologue`
  读节拍的 `prologue: true`（现在没有这样的拍，跳过键不亮）。`Video/`、`Script_Art` 的
  `proN` 定格卡、`Audio/Voice` 旧旁白都是无引用遗产——**别顺手删**（VideoBoard 还在用
  `Pro_All.mp4`）；始末见 `Data_DesignHistory.md`。
- **新加活卡，清卡三处要同步**：每帧清、DebugJump 重置、Main 的 SetLiveCard 分派；
  判定与作画共用同一份版面（Core 导出、Art 照着画），驱动器走通用的 `CardSeqDrive`
  （`TEAR_CARD`/`SEW_CARD` 是样板）。
- **打进来的光**：盖板合上（`flags.lidShut`）/ 夜里（`state.hatchMoon`）时从板缝打进
  窖里的三束光，`Script_Light.CreateLightShafts` 按 **SDF** 现算——是**空气里的一束
  光**（不烘在井壁贴图上，窖底那间屋也得有）：柔边、沿程张开、按遮挡掩码被土层
  吃掉、**被人挡断**（uBlockers 与灯共用）、浮尘、落地一摊亮斑。`state.beamSlant`
  只转 uDir，不烘直/斜两份贴图。规矩：
  ① **绘制序走 `FixOrder` 排在压暗罩（ORDER_DARK）之后**——加色的光排在罩子前面就被
  一起压掉；裸 `renderOrder` 会被 `ApplyDepthOrder` 按 z 重新派号盖掉。
  ② **张开要给得很省**：一条缝才几毫米，打到三米六外也就一拃宽。
  ③ **亮度按外头的天光给，不按窖里的暗给**（窖里越黑只说明板压得越严）；夜里
  （hatchMoon）才只剩月色。上限**按没压暗的那间窖定**（c2 的窖是亮的）。
  ④ **走 `CustomBlending` One/One 真加法，alpha 写 1.0**：`AdditiveBlending` 是
  `src.rgb × src.a + dst`，浓度同时写进 rgb 与 a 就被平方掉，淡层全没、只剩亮芯
  "三根棍子"。灯那一路 `CreateOccludedLight` 没动，它的数值是照老混合调的。
  ⑤ **沿程亮度、宽度都不变的光带柔边再软也是圆筒**，三件一起做：亮芯按张开量变淡
  （能量守恒 `s.y/hw`）、外面套一层张得快得多的散射（`gw`，"光柱"的形全在这一层，
  芯子只是里头那根亮线）、沿程有浓淡（`sin×cos` 低频起伏）。
  ⑥ **三根一模一样还严格平行＝三根管子**：宽/亮/歪（`tilt` 每米偏多少）/噪声相位
  各走各的，中间那条当主光。
  ⑦ **有直射就得有间接光**：落地亮斑本身是一盏很软的面光源，把窖底、身上和四壁下
  半截提一档，颜色**暖一档、脏一档**（`uBounceColor`）；**主要照下半截**（窖顶留黑）；
  遮挡走**软透射**（`exp(-Σsolid·k)`），一撞土就归零会留下掩码方盒子的刀切直边。
  ⑧ **落地亮斑的遮挡在光轴上算一次，不许逐片元竖着回溯**（它是地上的一块光，不是
  空气里的一段）。掩码把地面往下一截也算空气（走廊 air 矩形从 `UNDER_Y−0.2` 起），
  亮斑与间接光都要**夹在窖底以上**。
  ⑨ **人挡光不许挂在步进上算**（步长跟着片元 dist 走就是 dist 的锯齿函数）。走
  `BlockedSeg`：挡光的是几个轴对齐方盒，**线段到盒子的距离直接解析算**（夹在段上取
  离盒心最近的一点 → 盒的 SDF → softstep），光柱本体 / 落地亮斑 / 间接光三处各调一次。
  配套：半影给得很省（`0.05 + 0.03·tc`，板缝近乎点光源，那点软只为抗锯齿）；越远
  的遮挡物越软；**土层那一路照旧步进**（掩码是贴图只能采样，但它不动不会闪）。灯那
  一路 `CreateOccludedLight` 仍是步进结构，暂未动。
  **判据**：`shot "c2_hush@hold=e,dur=1.2" --eval "…把 srch1 停到 29.0…"` 对照兵在
  远处那张——光柱上有等距横杠就是这条犯了。
  ⑫ **能量要放在"被照亮的东西"上，不是空气里**（2026-08-18 用户贴《勇敢的心》
  地堡那一幕：「参考一下勇敢的心怎么做的，然后做好」）。把那张图逐块读一遍，
  能看见光的地方**没有一处是空气**：洞口过曝的白、梯子一节节发亮的横档、井壁上
  一大片软亮斑、梁在墙上的斜影、地上一摊；空气里那点雾很弱，只在洞口下面一小截。
  前两版正好反过来，所以永远是"黑屋里插着几根发光的棍子"。现在分四层，
  **面光 `wash` 占七成**（以洞口为心、横向随深度张开、纵向 `1/(1+(t/d0)²)`）
  ＋洞口过曝一团＋细光柱（只剩一成多，`exp(-t·1.1)` 一米开外就散）＋亮斑/间接光
  照旧。**2D 剖面里"空气"就是后墙**，所以给空气加色 ＝ 把墙照亮，正是要的那件事。
  四条：
  · **等宽带 + 指数衰减怎么调都是柱子**：横向高斯的拖尾把光泼得满屋都是，纵向又
    掉得太慢。形状必须是"以洞口为心的衰减"。
  · **有黑才有光**：`LIGHT_MOOD` 的 `tunnel` 0.42→0.58、`dark` 0.52→0.74，
    c2 窖里那七拍从 `day` 改成 `tunnel`（原来窖里跟外头一样亮，光再怎么调都是
    "亮墙上又亮了一块"；而且 c2_out「天光晃得人睁不开眼」本来就要这个反差）。
  · **遮挡一律软透射 `Transmit`，不许再 break**：面光铺满整间窖，硬阈值会把掩码
    那些 6 像素/米方盒子的直边整条画在墙上。
  · **窖底以下一点光都不许有**（`aboveFloor`）：那底下是剖面近侧那条黑土，而光柱
    排在 ORDER_GLOW 上画在它之后，泼过去就是"地上贴了张亮纸"；掩码指望不上，
    它把地面往下 0.2m 也算空气。
  四个可调量做成 uniform（`uWash`/`uHead`），配 `world.__shaftLight()` 现调现看：
  `shot --eval "tl.world.__shaftLight().uWash.value.set(…)"`。打光是看着调的活，
  别再改一个数重编译一次。
  · **亮度按"最亮处不过曝"给，别按"看得见"给**（首版给到 1.25/2.0，用户一句
    「有那么亮？搞笑呢？」退回）。参考图里最亮的只有洞口那一小块，梯子是**被照亮
    的木头**、还读得出木色，不是一片白。现在 `uWash.x=0.38`、洞口 0.85。
  ⑬ **人挡光要照真剪影，不许拿方盒子**（2026-08-18 用户："你角色过去怎么遮挡的
  形状是个方块而不是角色的边缘啊"）。老的 `BlockedSeg` 拿半宽 0.20m 的躯干柱做
  遮挡体，人一进光柱，画面上断掉的就是一个方块。现在宿主每帧把演员**单独渲进
  一张小离屏靶**（`Script_World` 的 `BLOCK_LAYER=3`，画布三分之一分辨率，
  `RenderBlockMask` 排在所有正式渲染之前——它要动 `camera.layers` 和清屏色），
  着色器沿光线累加它的 alpha（`MaskAt`/`Blocked`）。头发、袖子、抱在怀里的孩子，
  什么形状挡出来就是什么形状。三条：
  · **世界→靶 uv 用渲那一遍的相机矩阵**（`uBlockVP`），所以长焦 DOF 相机、
    小窗相机来画光柱时采样照样对得上；
  · **要多走一米**：光源是地表那条板缝，踩在板上的人整个在原点上头，只走到原点
    一根头发也采不到（方盒子那版是靠"线段到盒的距离"才蒙对的）；
  · 累加而不是 min/break——随深度连续，不会重蹈⑪那道横杠。
  方盒子那条留着当兜底（`uBlockOn=0`，靶还没渲出第一帧时）。
  **拍对照**：`--eval "…s.uBlockOn.value=0; s.__mesh.userData.SetBlockMask=()=>{}"`
  就退回方盒子，两张一比就知道剪影有没有真生效。
- **井壁贴片的下沿要淡出，不许齐齐切断**（2026-08-18 用户报「还有点bug」，画面上
  是一块四角笔直的淡色板）：`yWallBot` 把井壁切到走廊洞顶就收笔、指望走廊自己的
  后壁接手，可两张贴图的调子对不齐，于是井筒底下横着一条贯穿的直边。现在最后
  0.5m 走 `destination-out` 渐变淡成透明。
  **"是光还是几何"的排查配方**（这一轮走通的）：先把两层光的 `uColor`/`uBounceColor`
  分别染成纯红/纯蓝实拍一张，一眼分得出是哪一层；再把两个颜色全调 0 拍一张
  "光全关"的对照，硬边还在就是几何；最后按 `world.debugLayers()` 把嫌疑网格
  `material.color.setRGB(0,0,3)` 染色点名。
- **有光就得有黑给它打进来**：序的窖底几拍走 `timeOfDay: "dark"`（c1_hide 与 c1_open
  头一句；c1_descend 在"翻板合上"那一行的 `on()` 里拨 `state.lightOverride = "dark"`，
  罩子顺曲线压下来跟那声闷响同拍）。`tunnel`/`dark` 两档在 `Data_DayCycle` 里；
  `LightPath` 对不在昼夜环上的档直接过，不会绕出个日出。
- **院外那团混杂的动静**：全在墙外头顶、画面里没有，所以不能是几行零散的 `Cue`
  （那是"三个音效"，不是"外面出事了"）。走调度器 `SetDin/StopDin`（Core，`StepDin`
  每帧走）：一个 `near`（0=村外 1=头顶）同时管密度/音量/rate（远的闷近的脆）/左右，
  自己往 target 爬；底噪 `raidRumble` 一直垫着；**挂在 state 上跨拍连着走**。随机走
  自带 LCG 不用 `Math.random`，无头要能复现。
  `dogBark` / `shout`（**不给词**，只给喊的轮廓）/ `raidRumble` **照老办法本地烘**
  （`Script_SfxBake.mjs` → 本机 MiniMax Hub 的 music-3.0 拟音 → 切 → MP3），合成器
  那版留着当兜底。① **一个 cue 可以有多个变体**（`variants: N`，清单里 `files: [...]`，
  `PlaySample` 每次随机挑）——常响的东西单样本循环就是机关枪；② **持续型素材走
  `window: true`**（没有起音特征，改扫滑窗取能量最高的一段）。采样的 `rate` **连音高
  一起变**，狗/喊在 `DIN_LAYERS` 里的 rate 区间要窄，远近主要交给音量、密度和左右。
  **改完用 `state <id> --cues` 验**，别靠听。
- **微过场行上的 `on()` 行首触发一次**（与 StepCinematic 的 lineFired 同款）；跳幕结算
  只跑 effect 不跑 on()，所以**旗标必须落在 effect 里、on() 只做画面**。
- **一整段戏只长在微过场里时，那一拍要写 `settle`**（`SettleBeat` 末尾对**每一种 kind**
  都调 `def.settle?.(state)`）：effect 只能起微过场，**结算并不播它**，行内 `on()` 里
  改的世界整段作废。`settle` **只写状态不写画面**（落点归 SettleDest），而且**跟 on()
  调同一个函数**（c1_open 的 `DayThreeWorld` 是样板）——抄两份迟早分家。判据：这一拍
  改了世界，而改世界那几行在 `on()` 里？那就欠一个 `settle`。
- **cinematic 不跑 onStart**：过场拍的布景一律写在**第一行的 on() 里**（c1_rescue/
  c1_mend 是样板）；onStart 只有 chain/scribe/hold(onEnter)/doomedHold 认。
- **c3 起仍是旧线**（救妹妹/沙河庄地道），与新一二章的叙事**尚未接上**，待按剧本
  新生逐章翻新；`PLAYABLE_CHAPTERS = 2`，玩家只见前两章。
- 抉择节拍支持 `flagKey`（落进哪面旗）与 `when`（分支拍整拍跳过），第二章舀水/忍着
  两支就是样板。
- three.js 已收进 `vendor/three/`（不吃 jsdelivr CDN——断网/被墙就是黑屏）。
- 新台词的配音还没烘（Voice_Manifest 里没有的行静默出字幕）；在有 TTS 环境的机器上
  跑 `Script_VoiceExtract` + Qwen 烘焙流程补齐。

## 历史与叙事铁律（改玩法/文案前过一遍）

- 每个玩法元素过「1942-43 华北敌后穷苦农村会有这个吗」检查。
- **画面里出现的一切汉字都按 1942 年的写法**：① **繁体**（简化方案是 1956 年的；
  「征召」的征那时写作**徵**——徵夫告示、徵糧）；② **竖排，或横排自右向左**（横排左起
  是 1955-56 年后的规范）——横写的标语要**倒着码**，第一个字落在最右边
  （`Art.DrawWallSlogan` 就是这么画的）；③ 告示是**印/写在纸上贴**的，标语是**石灰水
  刷在墙上**的，两种质感别混。外部生成的成图尤其要盯：扩散模型排繁体竖排必出乱码，
  告示那张纸是**模型只出空白纸、`Script_TypesetNotice.py` 自己逐字排**（排不下就抛）。
- **墙上有字是这个年代的村庄该有的样子**：新民会宣抚班拿石灰水刷日伪口号（共存共榮／
  愛護皇軍／剿共安民，治安强化运动 1941-42 那几次刷得最勤），抗日标语被白灰盖掉只剩
  透出来的影子（`slogan: { ghost: true }`）。摆位在 `Data_Scenes.json` 的 house/yardWall
  上挂 `slogan` 字段，不新增 kind。
- **派差事必须有前因后果**：谁要的、为什么缺、干完去处在哪——三样都得交代，而且优先
  用**画面**交代：爹亲口派活（micro-cine 一句话）、完工后工作台边立起半成的门扇
  （doorLeafWip）。目标文本只复述，不补锅。
- **新地点/新人物先在画面里出现过，再让玩家去找**（c1 的妹妹在「去老槐树找她」之前，
  先在搬料那一拍从家门跑过整条街，娘一嗓子「就在老槐树底下玩」把地点钉死）。
- 旁白不实况复述画面动作；惊变时刻旁白闭嘴走同期声；日军讲日语无字幕。
- 妹妹等被护送者永不成为失败原因；首败无文字；重试 ≤15 秒。
- 潜行重置点不得落在任何敌人视线里，撤退方向必须是空的。
