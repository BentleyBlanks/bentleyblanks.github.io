## 镜头规范（2026-08-08 用户定，参考勇敢的心）

**全作只有一个景别档：玩法景别。** 变化只许来自镜头动画（横移 `pan`、换机位、
推特写做功那一拍），不许来自"把镜头拉远看全局"。

- **景别只有一张表：`Script_Main.js` 的 `PLAY_HW`**（地表／夜／地道村／据点地道各一档），
  `BaseShot` 从它取数，别在别处另写 hw。
- **尺子是「人占画高多少」，不是"看得见多少米"**：参照《勇敢的心》截图（大人占画高两成
  出头），本作按柱子约 22%、大人约 27% 收。**要改景别就改这个比例，别照"这一屏想装下
  什么"去配 hw**——后者每次都往宽了走。
- **中远景的定点镜跟着同一把尺子收**：`HintShot` 里 `wide`/`shot`/`close` 的 dist 一律过
  `TightenHw`（系数 `HW_TIGHTEN`，下限 `HW_CLOSE`＝本作最宽的特写档，封顶 `HW_WIDE_MAX`）。
  剧本里成百处 `dist:` **别逐个改**：改尺子改 `HW_TIGHTEN`，某一镜要例外就把 dist 写到
  `HW_CLOSE` 以下（特写原样过）。`insert` 与 `free` 不在此列——那两档是照卡面与三维走位量的。
- **`hw` 是按 16:9 调的**，`ApplyCamera` 对比 16:9 更宽的屏幕**保画高、往两边加宽**（`hw`
  按 `aspect / (16/9)` 放大；照画宽走会把上下裁掉、读成"拉扁"）；比 16:9 窄的不动（保画宽，
  上下多出的是天和地）。与「不许拉远」不冲突——人在屏幕上的大小与桌面一样。守着它的：
  RenderHealthTest 逐比例量，一米见方投出来必须还是正方，超宽档画高必须与 16:9 相等。
- `wide` 在本作里**不是全景**，只是"比玩法机位退一档"：写多大都在 `HintShot` 里封顶到
  `HW_WIDE_MAX`。
- **绝对不许出现俯瞰全村的机位。** 一屏摆完村街、露出地道剖面和地窖，等于把地图和
  「命藏在脚底下」这个题眼一起剧透。
- 交代世界靠**一次一处地走过去**：每一镜只给一件东西（一段村街、村口的地平线、一副碾子），
  横移串起来，而不是一镜看完。
- 画面外的后果由角落的照片小窗（pip）兜着——这正是不必把镜头拉远的原因。**小窗还有第二个
  用处：去主相机去不了的地方**（井筒里、地面以下），见「地表场景看不到地平线以下」那一节。
  它同时是这一拍的提示。
- **镜头不自己动**（2026-08-10 用户定）：玩法段镜头只跟着人走。想让玩家看见什么，用**固定
  机位的一拍**或过场去交代，不要做"走到某处画面自己摇过去"。窖口自动下沉的机制还在
  （`Core.CAM_CELLAR_PEEK` 总开关 + `state.cellarPeek` + `BaseShot`），**默认 false**。真要
  再开自动镜头，两条一起做：① 挂到 `state.steadyCam` 这一个让位判据上（推车 / 被盯上 /
  节拍声明 `steadyCam: true` 时一律不动），别各写各的；② 位移量按**画高**
  （`world.viewSize.h`）反算，不许写死米数——宽屏手机画高只有 16:9 的八成。
- **戏在屋里演，立面必须半隐**（节拍上声明 `indoorScene: true`，或过场里
  `state.beat.indoorScene = true`），否则墙合着屋里的人只剩一双脚。**半隐＝让开，不是变成
  一层膜**：墙一淡到不再挡人（与 `IndoorHidden` 同一条 0.5 线），`UpdateProps` 就把它的
  **绘制序**挪到演员之后（`nearBack`）——位置不动（摆位归 `PlaceZ`、绘制序归 `SetPlayOrder`），
  墙还在，人/门扇/工作台却全是实的。**凡是"盖在玩法层前面的半透明大片"都先问：该让开，
  还是该更透？** 让开永远比更透好——更透只会让整幅画一起发灰。
- **屋子的两头要有山墙内侧**（2026-08-14 加，`Art.DrawRoomWing`）。后墙比演员远，画框往
  两头一开就越过它望见野地——**这是视差，不是"后墙画短了"**。东西两头各挂一片 `roomWing`
  （Data_PropArt 的 `variants.interior.wingSpan`＝从墙角往外铺多少米）。
  · **两条闸缺一不可**（`UpdateProps`）：① 只在 `filmic` 那一档现身——玩法景别下一露就是
    "院子里凭空立着两堵墙"；② **镜头得在屋子足迹±1m 之内**——`state.beat.indoorScene`
    是行内 `on()` 拨的、一拍之内不会自己撤，而同一拍里插得进屋外的镜。**不做渐变**：过场
    是硬切进来的，跟着立面的淡入曲线等于每场屋内戏开头闪一下野地。
  · **摆在 building 带、绘制序挪到 `nearBack`**：压过 yard 带院里的东西，又低于行走线与
    演员。**院里 walk 带的杂物（石碾、掩体）压不住**，那是这一档的边界。
  · **宽度是量出来的不是估的**：`shot ... --eval` 里把 NDC±1 二分回墙面深度上的世界 x，
    逐镜取最大。**定宽贴图由最宽的那一镜说了算**，最远几镜里墙比屋子长是已知取舍。
- **屋里地面上的固定物（地窖口、下窖的梯子）不要做隐现**：它们在 `loose` 带、立面在
  `facade` 带，墙本来就排在前面——合着时地面以上被墙挡、地下那截照常露着，读出来就是
  「地窖在屋子底下」。读错位置**九成是坐标不在屋子足迹内**，别拿透明度去治：加隐现会把
  地下那截也灭掉，玩家在院里就找不着自家窖口。
- **地表与地下在同一个场景里，"摆到画框外"必须指明是哪个画框**：地表机位下压在画框下缘外
  的东西，镜头一沉进地窖就正对画面正中。前景框景层（`fore`）现在留空，闸门是
  `dist > 7 && camY > SURFACE_Y`。以后真要做勇敢的心式的框景：**摆位跟着镜头所在那一层的
  地平线走**，别写死 `SURFACE_Y`。守着它的：`Script_RenderHealthTest`「地下机位无前景层」。
- **过肩（`ots`）只用在两个人都露脸、面对面的场合**。被越过的人由前景剪影代表，必须**被
  画框下缘切掉**才读得成"贴着镜头的那个人"，浮在半空就是一坨椭球。主体被墙挡着时过肩没有
  意义——改普通双人镜。剪影尺寸按实拍标定（层缩放 comp 会再吃掉一档），别信纸面上的百分比。
- **路过的注视不许接管镜头**：走路途中的 goto 触发点**不许起 `StartMicroCine`**——过场首镜
  默认 iris 收黑，玩家读到的就是"切黑屏+夺操控"。路过要交代的东西：道具画在路边自己会
  说话，链步骤挂 `note:` 出一条手记 toast，脚不停。过场只留给**事件**和**玩家自己按 E
  换来的**那种——会打断走路的镜头必须由玩家自己按出来。**手记也有下限**：toast 一次只挂
  一条，后一条顶掉前一条，两个触发点隔得比一句话的阅读时间还近就合成一条或删掉步骤。
- **过场可以自由运镜（2026-08-13 用户定：序章要「勇敢的心」过场动画的形式，不拘泥 2D
  视角）**：cinematic 行的 `cam` 用 `kind:"free"`——`{from:[x,y,z], to:[x,y,z], at:[x,y],
  atTo:[x,y], roll}`，机位与注视点按本行时长 smoothstep 插值（VO 拖长行时钉在终点），Main
  每帧直设、World 走 `ApplyCineCamera`。**只许过场行用**：玩法段的「跟随、永不旋转」一个字
  不动。四条尺度（世界全是面朝 +z 的立牌——纸戏台可以斜着看，不能绕到侧面去）：
  ① 偏航/俯仰 ≲25°，roll 只做小幅荷兰角；
  ② FOV 30° 下**画宽 ≈ 机位到注视点的距离**（＝旧 hint 的 dist×2）；
  ③ 室内镜头画框顶别越过屋高 2.4m——超了就是把天和远景带进屋里，读成「屋里起雾」；
  ④ 门是画在立面上的，而**室内过场第四堵墙整个不画**（World 的 filmic：cinematic+
     indoorScene → 立面透明度 0；玩法段照旧半隐）——所以门不能给正脸，撞门用声音演。
  范例：序·那天（c1_thatday）整场——分屏显影、低机位追人、缓推怀抱、俯角掀翻板、低机位
  收尾，转场全是硬切+首镜 iris。

### 框景板（`fg`）的两条硬账（2026-08-17 掀盖那一镜查出来的）

1. **`dim` 不许省。** 省了就是 `dim:1`＝按原色画，而框景板要当画面里最暗的那一块——漏了
   就是一大片发白的灰饼。手写 fg 照 `Data_ScriptC1` 顶上那张 `FG` 表给。
2. **框景是用来吃空画框的，不是用来挡主角的。** 摆位先问这一镜的主体落在 u/v 哪儿，板子往
   **另一边**的角上塞；主体挪了，板子跟着挪。
3. **梁（`beam`）的画法**（2026-08-17 重做）：
   · **椽子头不该长在梁底下**——那是檐口的东西；梁上头才是檩和椽、朝屋里走（在这个框景里
     全在画框外）。**先问"现实里这儿有什么"，再问怎么画。**
   · **等距 ＋ 同宽 ＋ 各描一圈墨线 ＝ 一排零件**（同 strawEdge 那把梳子、同「等距的横杠是
     梯子不是炭裂」、同「小形体配全圈墨线＝一坨」）。
   · **梁底不许是一条直线**：这条边贴着过场的黑边，平行的直边跟黑边并成一条就读成"多了
     一道 UI"——底沿要起伏＋中间下垂。
   认出"圆木"靠**底面一条柱面高光**（同 `DrawLimb`：光从底下打上来，贴着底沿最亮、往上很快
   收掉），**而且必须一笔铺完**——**分段画连续的东西，接缝本身就成了内容**。别为"两头暗当中
   亮"往上叠一层暗：屋里是一大片漫射光，沿梁长匀着才对。
4. **过场里那枚心情气泡要排在框景之后**：它是漫画式的状态提示（照《勇敢的心》），不该被
   贴在镜头跟前的板子吃掉——排 `LAYER_ORDER.cine + 40`，仍压在昼夜罩（`ORDER_DARK`）之前。
   **凡是"贴在世界里的 UI"都要问一遍：谁会挡住它？**
5. `Art.DrawCineFore` 的 `strawEdge`：几乎等距、几乎竖直、长短相近的细线＝**一把梳子**。
   柴火是横七竖八堆的——歪得开（±50°）、长短差得开、成簇留缝，还得有几根**横着压在上头**
   （柴堆的轮廓靠交叉咬出来，不是一排竖线的顶端）。

### 过场三件套（2026-08-14 用户拿勇敢的心截图定的：「做成真正的过场动画」「也有这种左右分的镜头」）

过场与"游戏截图换了个角度"的差距不在运镜，在**画**。三件：

1. **全局分级**（World 的全屏后期）。贴图全是没声明 colorSpace 的 CanvasTexture，上屏被当
   线性值提亮——单张能靠压色号救，**整幅画的调子救不回来**，分级把这一档还回来。
   · **常开，过场与玩法同一条曲线**（2026-08-17 起）：**只要这遍后期有开关，开关两边就必然
     是两张脸**，调得再近也只是把接缝做窄。节拍级 `grade:` 字段与 Main 里那段吸附已删；小窗
     （pip）也在同一遍后期里（`world.Render(pipRect)`）。
   · **这遍后期九成的效果是一道 gamma，不是那条曲线**：离屏靶声明了 `SRGBColorSpace`，
     而那块四边形是裸 ShaderMaterial、three 不补输出编码——**一解一不编 ＝ 全屏乘一道
     ^2.2**，正好是 CanvasTexture 那笔老账的反函数。由此：① **统一只能往"两边都还"走**——
     往"都不还"走全作的黑就没了（墨线、逆光门洞、框景板全靠这一档压下去）；② 还多少要能拨：
     **`GRADE_GAMMA` 就是这个把手**（显示值上的指数，1.0＝老玩法段的 washed 脸，2.2＝老过场
     那档全压）。改它就是改全作的调子，**改之前先拿实拍逐像素量**。
   · 那段 GLSL 是 JS 模板字符串，**注释里一个反引号都不许有**——整份 World 当场 SyntaxError。
   · **只许动明度，不许动色相**（2026-08-15 用户退回）。分离色调**已整个删掉**。**对比曲线
     打在明度上、原色按比例缩回去**，别逐通道各跑——逐通道会拉开偏暖的色，那也是变色。
     剩下四件都是各通道等量的：S 曲线对比（**不走直线**，直线把暗部整段压成 0）、黑位、
     晕影、纸纹颗粒；唯一动颜色的是 `uSat`，只往灰里收——`SetCineGrade(k, sat)` 第二参，
     0＝彩色转黑白（用户明说可以）。再加风格化只加在明度或饱和上，**不许再引入通道差**。
   · 常开之后四件都收了一档：玩法段也要走，画框边上正是找路要看的地方。**要再往"电影感"
     上加，加在只有过场才有的东西上**（黑边、DOF、框景板 fg、运镜），别再往这条曲线上加。
2. **过场框景 `fg: [...]`**（剧本行上声明，画笔 `Art.DrawCineFore`）：一块压得很暗、被画框
   切掉的近景（门框柱、房梁、炕沿、瓮肩、梯子帮、草茬），吃掉空画框、给出很近的深度、是画面
   里唯一真正黑的地方。**摆位按画框给**：`{art,u,v,z,w,h,flip,dim,side}`——z 是离行走线多近，
   u/v 是板心在**它自己那个深度上的画框**里的位置（−1..1；贴镜头那个平面上整个画框才三四十
   厘米宽，世界坐标摆不准）。u/v 只在换镜头那一下折算一次，之后钉死在世界里。
   画法三条：**不许糊**（读成"镜头脏了"）、**背光那条边要留亮边**（全黑的一块是贴纸）、
   **里头要有纹理**。色号是跟分级一起算的。**改 `GRADE_GAMMA` 就要回来看这几块板**——`dim`
   （`FG` 表）是照着分级配的，分级一松它们就退成灰饼。
3. **左右分屏 `cam:{kind:"split", left, right, gap, fg}`**：两台过场相机各渲半屏（scissor），
   中间一道手绘撕口白缝（`Art.DrawSplitSeam`，比空当略宽，要咬进两边的画里才像同一张纸）。
   半屏画幅是竖的，**同一机距下人物比整屏大一圈**，两侧机位要各按"这一格装什么"给。
   **两格的画框绝不许互相看见对方**，否则同一个人在两边各出现一次。框景按
   `side:"left"|"right"` 挑相机折算。

**机位不许沉到地平线以下**：窖顶与地表之间是**实心土**（近侧剖面 NEAR_Z 那刀只在窖室那块
掏了洞），机位摆进去满屏是土。地表机位同理：注视点压到 y<0.5 会把近景地面带（z=3.3）
整个涨进画框，下半屏一片灰。窖底那间屋自己可以拍（那儿掏空了）。

**微过场也算过场**：立面全隐的判据是「节拍 kind 是 cinematic **或** `state.microCine`
在跑」——链的 effect 里起的 micro-cine 节拍 kind 是 chain，照样按过场处理。是不是过场
看的是**这会儿谁在掌镜**，不是这一拍挂在哪个 kind 上。

**配乐可以按拍/按行关掉**（`bgm: null` / `state.bgmOverride`，见 `Data_BgmConfig.EXTRA_BGM`）：
BGM 默认按 `CHAPTER_BGM[chapterIndex]` 无条件铺；序的三拍静音，音乐只在收尾「没人来叫。」
进来，托过章名卡，画面一回来就交还给章 BGM。守着它的：`Script_BgmTest` 断言序不许有配乐。

### 黑屏（`cam:{kind:"dark"}`）：黑要黑到底，长要短（2026-08-14 用户退回）

1. **黑不到底的真凶是层级，不是数值。** `#fadeOverlay` 罩子 `z-index: 26`（世界、HUD、小窗
   24 在下），字幕 28 / 章名字样 28 / 跳过键 30 / 章节卡·抉择·结束屏 32 在上，fade 给满 `1`，
   背景色 `#000`。**压在罩子之上的那几层不许带暖调**（全黑画面下缘会留一条更亮的带子）。
2. **指数吸附永远到不了终点**：fadeLevel 走 6.5/s ＋ 贴近终点（<0.01）就**吸住**。
3. **空黑屏是标点，不是一场戏。** 尺子：**没有字的黑 ≤1.5s，一句短旁白 1.5~2s，章名卡只留它
   自己淡入淡出要的那点**；titleCard 的 `dur` 要跟着行的 `d` 一起改（差值留 0.2s）。
   **开场是这条尺子的例外（2026-08-17 用户重排分镜定的「刺刀一帧版」）**：黑→**硬切一帧**
   （活动插卡 `bayonet`）→黑，黑里全是戏——那条尺子量的是空黑。硬切靠行上的 `cut: true`
   （HintShot 的 insertCard/dark 都认，Main 的 `fadeSnap` 当帧把罩子钉到目标）：半秒的一格走
   吸附会从头到尾蒙灰。**拍它用 `shot "c1_thatday@line=2,at=0.25"`**——钉格当场冻帧。
4. **实拍量黑屏要先推 HUD 这一侧。** 收黑的不透明度长在 `SyncHud` 里，只在 rAF 里走；`Settle`
   把 `SyncHud` 一起推。再遇到"数值明明改了、图上没变"，先问是不是这一侧没推够。`shot --eval`
   在 `Settle` **之前**跑，读渐变中的量会偏早——判黑屏黑没黑得看图（或对 PNG 逐像素量）。

## 过场要正脸/手势：活动插卡（2026-08-10 太君那一镜立的）

全作是侧视骨架，**正脸给不出来**。过场里要"冲着镜头"的画面（横摇到军官、挥手、交头接耳），
走**活动插卡**：

- 画笔在 `Script_Art.mjs` 写 `Draw<名>Card(ctx, W, H, seg, t)`，登记进 `Art.INSERT_LIVE`；
  剧本行写 `cam: { kind: "insertCard", card: 名, seg: n }`。
- World.SetInsertCard 见到登记过的名字就每帧重画（同一块定格卡画框）；动画完全由
  `(seg, 本行已走秒数)` 驱动——游戏时钟给的，无头实拍逐帧对得上。
- 一段连续演出拆成几个 seg 挂在相邻几行上，行的 `d` 就是该段时长；音效照旧在行的 `on()`
  里 Cue。日军讲日语无字幕，这类段落只给同期声（引擎/风/乌鸦）。
- 实拍对时：`shot --dur --phases` 的 **dur 量的是游戏钟**——没按键的拍用 StepFrames 推够
  游戏时间，按着键的拍盯 `state.time`；别按墙钟折算（无头合成器上墙钟慢 3~4 倍）。
  `beat <id>` 逐句打出 `[起点s +时长]`，dur 照它给：总时长再留半秒余量。
- **人脸只能走插卡**（2026-08-14）：几米外一颗脑袋在屏幕上二十来个像素——骨架给不出
  "一张脸"。§9 那声「水。」挂在 `strangerFace` 卡上（seg 0 脸／seg 1 张嘴）。画脸三条账：
  ① **画布 y 朝下**，"脸朝上"的局部坐标 v 要取负号；② 脸读不读得出全在**外轮廓**（额→眉骨→
  鼻根的凹→鼻尖→人中→上下唇→颏唇沟→下巴），椭圆里贴五官出来是块石头；③ 轮廓的起伏**要大过
  笔迹的抖**（InkFill 的 amp），否则是一条毛边。整条脸照一条"脸线"算：沿线走 s、沿法线推 o，
  鼻尖 o = 0.10 个头长。五官**明暗两遍都要画**（暗的一遍压到 0.45），光条压不到的脸才有五官。
- **改卡的版面用 `Script_ArtPreview.mjs card:<名字>`**：两段并排渲一张 PNG，比整拍实拍快
  两档，卡要改十几轮。
- 画里的经验：正面剪影的兵**两条腿必须分开画**（连成一片读成披袍的）；斜背的步枪是一道短
  斜线加一点刺刀尖，竖着画就成了长矛；骑车的人身下要有发动机的黑铁块和踩踏板的脚，否则人
  浮在半空；挎斗必须贴着车再加两根连杆。

## 地表场景看不到地平线以下——想演井底，用小窗那台相机（2026-08-10）

**主相机永远看不到地平线以下。** 地表场景的画面底下压着一条**近景地面带**（z=3.3，
renderOrder 8500）——它就是"镜头正前方三米的地面"，物理上就该挡住地平线以下的一切；
镜头往下降它跟着涨上来。

**但小窗（pip）是第二台相机，它能去主相机去不了的地方**（用户出的主意）：pip 机位按 `hw`
反算 z，小景别下落在**那条地面带后面、井筒里面**——井底那点事有地方演。

怎么用（打水的二三道手是样板）：

- `Core.PinPip(state, { at:{x,y}, hw, kind })` **钉在一个死点位上**（不跟人），`t: null` =
  不自动收，由玩法每帧立、每帧撤。`Main.SyncPip` 认 `spec.at`。
- **只给小窗看的东西放 `PIP_LAYER`**（`mesh.layers.set(PIP_LAYER)`，主相机只开 0 号、
  `pipCamera` 额外开 1 号）。别靠"摆得够低"来藏——主相机在特写下会探到地面以下一点点，
  混在 0 号里迟早露出一角黑方块。
- **绘制序要压过那张土路贴图**（它在 `walk−4`）：排到 `nearBack` 小窗里只剩一片黄土。井筒
  用的是 `loose−1`。
- 坑：`BakeSprite` 的锚点偏移存在 `userData.offset` 里，**手动 `position.set` 的 mesh 不会
  自动吃这个偏移**——整条贴图就浮到别处去了。

**小窗顺带就是提示**：玩家在小窗里看见空桶口朝上浮着、拽一把就栽下去，不用一句说明。提示
长在被操作的那件东西上，比在 HUD 上写字强（同"抽象手势图标已整体拆除"那条）。

静态贴图上画着的东西，玩法接管时必须让位：井绳跟摇把一样走 `DrawWell` 的
`rope:false`/`crank:false`——不然桶拽到井沿上了，井口里还挂着另一根不动的绳。

## 过场机位的尺子要算黑边（2026-08-18 从项目记忆并入）

- 【规矩】`#cineBars` 是盖在整幅 16:9 上头的，可见画高只剩七成多，先吃掉的正是头顶和脚下——配景别按**可见画高**算，工具在 `Data_ScriptC1.mjs` 顶部：`CINE(x, y, 画宽, [框景])` + `FG.*`；身高按**实测姿势**取（站/坐/跪各不同），不按站姿。【为什么】给到成人视平线那么高，地平线钉在画框下沿、上半屏空墙；照站姿配跪姿的机距会松一整档。
- 【规矩】站在地上的主体注视点略高于脚线（腰线居中、脚下留一成半），不是视平线。
- 【规矩】框景 `fg` 的 u/v 折算：`free`/`split` 自带相机，定点镜（insert/shot/close/ots）由 `Script_Main.UpdateCamera` 反推机位；玩法段 `def.fg` 只能写世界坐标；`free` 不许用到玩法段。
- 【规矩】`ForeMix` 是 `k = 1/dim`，dim 小只压两成，框景要真的黑（照 `FG` 表）；`beam` 的 v 不许过高，否则整根缩进上黑边只剩一排黑齿。
- 【规矩】微过场相机别用 `kind:"wide"`，用 `kind:"shot"` + dist。
