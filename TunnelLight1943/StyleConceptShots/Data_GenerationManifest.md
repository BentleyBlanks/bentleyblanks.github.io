## Shared prompt

Create a polished 16:9 in-game screenshot concept for the historical side-view game “Tunnel Light 1943”. Use the online screenshot for scene content, spatial logic, characters, gameplay moment, and camera. Use the supplied reference images only for visual language. Render a unified minimalist editorial paper-cut illustration with a warm ivory or dark matte-paper ground, flat geometric silhouettes, delicate charcoal linework, subtle fiber texture, large calm negative space, and restrained poster-like hierarchy. Use chalky white, taupe, charcoal, desaturated olive/sage/indigo, mustard-gold for the boy, dusty rose for the sister, and only small amber or brick-red accents. Preserve readable side-scrolling gameplay staging and a few tiny geometric HUD indicators, with no readable text.

Historical constraints: 1940s rural North China, earthen villages, rough timber, period clothing and equipment, no modern objects.

Exclude phone frames, Douyin/TikTok interface elements, social icons, counters, dates, location tags, usernames, watermarks, logos, subtitles, garbled typography, photorealism, 3D rendering, anime, glossy gradients, neon colors, thick comic outlines, and unnecessary characters.
