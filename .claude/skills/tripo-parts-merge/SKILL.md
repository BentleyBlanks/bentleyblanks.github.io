# Tripo 部件合并

做过：罗班长（V13）、日兵甲、日军士兵A（V7）、何有田、顺子、日兵乙。每个人物都返工了 5–13 轮，几乎全是「没对参考图就导出」。

## 脚本

`OneDrive\AI\Models\Blender\Taierzhuang1938\<Name>PartsMerge_<日期>\Scripts\`，新人物**拷最新一份**（现在是 `YiPartsMerge_20261104`，底子是何有田/日兵甲）改路径和参数：

`01_import` → `02_look`（看原件）→ `03_prep`（转向、自动扳正手脚、另存法线）→ `04_assemble`（拼装、收身、帽子、脖子、小臂）→ `04b_legs_and_scale` → `06_mirror`（镜像手脚）→ `08_single_material`（4K 单材质烘焙导出）→ `09_check_glb` / `09b_closeups`（回导检查、特写）→ `14_render_vs_ref`（和参考图叠图）。

Blender 从本 worktree 根起：`node scripts/Script_BlenderMcp.mjs start|exec --file|stop`，用完 `stop` 并附 `status --scan`。中文路径的部件先拷到 ASCII 目录。

## 硬规矩

1. **导出前自己对完参考图**：渲同像素比例（参考图 px/m、头顶 1.809 m）的正/侧平光图，和 T-Pose 参考图半透明叠，画帽顶/眉/下巴/领口/腰带/裆/绑腿上沿/地面线；**按行比剪影边界**定量，别凭眼看。问题处拍特写和原图同部位并排。
2. **导出后用回导的 GLB 再比一遍**，读 GLB 头断言 1 mesh / 1 material（检查场景会把旧成品一起导出去）。
3. 版本递增 `<Name>_Merged_V<n>.glb/.fbx`，不覆盖旧版；并排图发给用户。
4. **单材质**：Tripo 上传只认第一个材质，多材质头上会贴身体贴图。图集按 sqrt(表面积/UV 面积) 分，脸 ×2.5、手 ×1.5；`pack_islands(margin_method='FRACTION', margin=0.001)`。

## 必修的坑

- **法线**：Tripo 光滑全靠自带法线，bmesh 焊点会打乱 → 03 另存 `nrm` 角点属性，旋转/镜像/缩放跟着改，08 用 `normals_split_custom_set` 写回。表现是打光下脸上一块块灰斑。
- **金属度**：Tripo 不写 metallicFactor = 1，导出归 0；胸像头粗糙度偏低发塑料光，+0.4。改过像素的贴图副本要 `pack()`，否则烘焙读回原图。
- **减面/改形前 remove_doubles**，否则 UV 接缝撕开；Tripo 有时每个面角一个点（15 万→5 万）。
- **比例对参考图，不只对身高**：头（下巴到头顶约 22–28 cm，用户嫌过头小）、脖子长、腿长、手长都量；Tripo 衣服偏胖（正面宽约 8%、腿 16%、前后 25–30%）→ 04「收身」。最后整体等比回头顶 1.809 m。
- **手**：按四指平面主轴自动扳平（歪过 18°–31°，「手是歪的」被提了每个人物），再把手腕→中指尖对到袖管轴线；手腕放在袖口边、贴上半部；手比袖口宽就把袖内顶点沿袖轴收回，不要逐点压扁。
- **小臂**（挽袖人物）：别拉长手模型的小臂（像管子、纹理糊）。手腕后 1.2 cm 平切，自己放样一段，中心慢慢挪到**袖口内壁实测中心**（和手轴偏 ~1 cm），袖口外不收；袖口太紧就把布往外撑 3 mm。罗班长式短袖口：小臂只粗 15%、贴图由手腕色渐暗，别塞满袖碗成「圆饼」。
- **帽子/钢盔**：按参考图量的高度放死，**不抬帽子**；戳出帽子的头顶顶点往下压进帽壳。Tripo 帽子是实心的，别把头皮往里收（拉丝）；帽外层不够盖头皮就分方向格往外推。帽檐朝向用最低点自动转正。帽子高低用户能看出 1 cm。
- **脖子/领口**：首选光头胸像头（带锁骨），只修穿帮不自己长脖子；V 领井里露胸像自己的胸口，井底压到胸口下 6 mm，**别删井底**（军装实心，删了看穿）。不得不补脖子时补片要和头连成一块（分开的部件 Tripo 绑骨后接缝裂），新皮肤取后脑光头区（八方向腐蚀取块）镜像平铺 + 淡噪声，不能纯色。
- **脚**：左脚镜像成右脚，按鞋底长轴转正，内八改外八约 10°；脚长 29–30 cm；绑腿逐层收到裤腿里，颜色换成身体绑腿色。
- 排查：按平面切片画轮廓看谁穿谁；从相机像素打射线分辨洞/翻面/贴图；单色 + STUDIO 打光看几何（后颈斜线那类是几何不是贴图）。
