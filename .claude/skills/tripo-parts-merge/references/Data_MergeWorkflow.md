# 制作与验收细则

## 比例与参考图配准

1. 每件原模型先读包围盒、变换、材质、贴图及拓扑。统一单位、上下轴和正前方，保留原件与变换记录。需要 ASCII 输入副本时保存原路径映射。
2. 以原始三视图和角色身体为比例依据，单件优先整体平移、旋转、等比缩放。局部修形限于任务所需区域，保留脸、手指、鞋底和装饰件的结构。
3. 先确定地面、眼线、下巴、肩线、领口、腰带、衣摆、裆、裤脚或靴口、腕心，再检查整体轮廓。分别标注裸头、含发、含帽高度。角色自然身高与标尺的选择写进参数记录。
4. 正侧背使用一致的世界尺度和相机定义，记录正交尺度、模型姿态与图片变换。先用全身同尺度图检验位置，再用眼线配准局部图检验脸型。每张图独立拉伸会掩盖比例偏差。
5. 原尺寸图用于计算像素差、按行轮廓、截面和部位尺寸，缩略图用于观察。头发遮挡、手指展开角和姿态差异应在测量中标记。剪影重合度结合局部检查使用。

## 头颈、领口与皮肤

- 优先保留胸像头自身的连续颈部、斜方肌和锁骨。整理伸入衣服的胸肩余量时保留支撑领口所需的皮肤，检查前后左右及俯视的实际遮挡关系。
- 先诊断颈长来源。头位偏高、下巴前伸、后领偏低和颈段拉长分别处理，同时复检眼线与肩线。领口局部形变使用平滑衰减，并检查肩部、肩章、领章、衣褶及纹理形变。
- 补颈与原皮肤连接，检查可见区域与补段底部的开边、翻面和重叠。封底位于衣内并保持动态转头时的覆盖余量。检查记录明确选择区域、焊点容差及边界含义，避免把 UV 分裂顶点误算成几何洞。
- 保留服装设计中的领井、内壁和遮挡面，先识别其作用再裁切。局部封口检查独立于整件衣服的设计开口。
- 新皮肤采用原皮肤纹理重投影或重新展开后的连续烘焙，匹配脸、后颈、小臂和踝部的色调、粗糙度及法线。检查纯色色块、错区取样、拉伸条带、黑边和高光接缝。
- 隐藏补面的材质可按遮挡用途简化，可见皮肤需要保留纹理。发现补面暴露时连同 UV 与材质一起修复。

## 手、腕与袖内小臂

- 用解剖学左右、拇指位置及手掌朝向确认手别。镜像后检查绕序、法线和左右命名。
- 以腕心至中指方向、四指平面及小臂轴线对齐 T-Pose，结合顶视与侧视检查。优先刚性转平和等比放置，保留手掌宽厚与指长比例。
- 袖口尺寸与手臂几何分别诊断。查看去衣服或剖切图，确认小臂实际连续延伸至袖内，腕根及肘部位置自然。
- 缺小臂时沿实测轴线放样连接，逐截面平滑改变中心和粗细，纹理随之重建。袖内顶点可在遮挡区收束，检查局部压扭和截面突变。
- 修袖口后复检腕到肘的形状，修手臂后复检袖内覆盖与动作余量。

## 腿、脚踝与鞋

- 用大脚趾内侧、足弓与鞋底判断足别。已有单侧脚可以镜像，确认真正的左右映射后再摆位。外张角、脚长与站距来自当前参考图和原件。
- 从小腿下段到踝心、脚跟、足轴进行连续截面检查。截面中心、边界及面积由完整面与切平面相交得到，配合正、侧、后和局部斜视确认。
- 区分腿轴倾斜、鞋筒偏转、重叠绑腿、局部接缝折角和脚掌朝向错误，再修对应几何。单截面或稀疏点拟合的轴线需用整段轮廓复核。
- 保留原鞋底厚度、足弓、脚趾、后跟与绑带。身高调整优先整体等比定标，接口长度优先在裤腿或隐藏区处理。
- 清除互相覆盖的上段绑腿或鞋筒余量后，修平接口并复查皮肤、布料的 UV 和法线。长筒靴保留从靴口到鞋底的完整结构，结合裤腿与靴口关系摆放。
- 裸趾或草鞋检查五趾及绑带。新部件有明显多趾等源错误时，根据本次范围选择局部修模或重新生成，并保留替换来源。

## 帽子、后脑与服装装饰

- 对照正、侧、背图分别校准帽檐朝向、倾角、帽冠、帽带和前后沿。几何最低点只能辅助判断朝向，结合帽徽与原图确认。
- 沿额头、太阳穴、耳上方、后脑、帽沿下缘检查一整圈贴合。用帽壳与头的截面、相交查询定位问题，记录检查覆盖的区域。
- 帽带需要适合前额与后脑不同轮廓。局部帽壳修形同步检查帽檐弧线、帽冠折角、接缝和下缘漏点。补片与原帽的布纹、粗糙度和法线一起衔接。
- 肩章、领章、帽徽、星徽等作为受保护的局部结构。领口、肩部或帽壳改变后检查它们的长宽比、倾角和纹理，源件本身变形时按参考图做相应局部修复。

## 法线、拓扑与单材质图集

- 读取并保存原件的角点自定义法线。既有脚本用 `nrm` CORNER 属性暂存，旋转与镜像跟随变换，非均匀缩放按逆转置处理并归一化。拓扑操作后核对属性对应关系，再用 `normals_split_custom_set` 或当前 Blender 等价 API 恢复。
- 先检查 Tripo 是否因 UV 接缝而重复顶点。确需焊接或减面时使用符合角色尺度的容差，保存 UV、材质和角点属性。查退化面、翻面、尖刺及新接缝，复核脸部平光和斜光表现。
- 该工作流以单网格、单材质图集交付，来自老耿在 Tripo 导入时发生贴图串用的经历。源场景可保留分件和多材质，最终导出仅选择目标人物。
- 图集按表面积、原 UV 密度和用途分配，脸手优先保证细节。旧脚本脸 ×2.5、手 ×1.5 是可调起点。4K 起步，老耿修复曾采用 8K，应按当前实际质量和目标用途决定。
- 旧脚本的 `pack_islands(margin_method='FRACTION', margin=0.001)` 可作起点，按分辨率、扩边和 mip 需求检查边距。保留源 UV 与目标 UV 的明确映射。
- 分别烘焙颜色、粗糙度与法线等实际使用通道，核对色彩空间。金属与皮肤根据源材质和效果校准，对非金属皮肤明确设置合适的 metallic 与 roughness。
- 改写图像像素后更新并打包或保存正确副本，验证烘焙实际读取该版本。检查空白图集、跨岛串色、法线方向和 UV 越界。
- FBX 可保留原四边面为主的拓扑，GLB 按导出三角面报告。Join 后继续检查接口几何连通性及蒙皮风险。

## 导出与局部修复的最终复检

| 项目 | 可核查证据 |
| --- | --- |
| 正侧背比例 | 同尺度并排或叠图、配准点、局部偏差和测量误差 |
| 脖子与领口 | 皮肤连续性、所选补段开边统计、前后与俯视近景 |
| 手腕与小臂 | 顶视及侧视轴线、去衣服或剖切图、连续截面 |
| 脚与脚踝 | 足别、鞋底、整段小腿截面及同视角前后对照 |
| 帽子 | 前后左右贴合、帽沿下缘和俯视边缘，记录相交检测范围 |
| 材质 | 实际图像与尺寸、UV、平光颜色及斜光高光接缝 |
| 导出完整性 | 干净场景分别回导两格式，模型数量、尺寸、贴图和法线核对 |
| 版本与重建 | 来源映射、参数、重建入口、递增版本及本任务 Blender 退出状态 |

按问题覆盖必要视角。已有检查足够、相关几何未变时复用其结果，并标明沿用版本。页面验收使用仓库本地预览入口并静音，后台浏览器显式带 `--mute-audio`。

## 可复用脚本的选择

先查看 [案例记录](Data_CaseHistory.md) 中匹配故障的工程与脚本。读取其输入、坐标约定、区域选择、变换和导出逻辑后，提取适合本角色的部分。把参数、文件和对象名称改为当前任务值，并从原件或选定基线重建以验证可复现性。

旧 `YiPartsMerge_20261104` 的阶段包含 import、look、prep、assemble、legs_and_scale、mirror、single_material、check_glb、closeups、render_vs_ref，可用于理解制作顺序。后续角色的颈部、手臂和鞋底修复已经替换部分早期做法，选择时优先核对对应故障的最终修复。
