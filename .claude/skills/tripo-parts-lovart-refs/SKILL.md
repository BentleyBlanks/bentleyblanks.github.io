## 步骤

1. **先看三视图是不是干净 T 字**。带挂件（背囊、步枪、水壶、布巾）或 A 字时，先出 T-Pose 三视图：正面用原图 + 脸部放大改图（GPT Image 2），侧面、背面拿正面做附图1保证帽顶/鞋底同高。漏了东西就**在那张图上改图**补，不重画。
2. **裁脸**：从正面、侧面图把脸裁出来放大 4 倍（`FaceCrop_Front/Side.png`），头部两张都拿它做附图1。
3. **上传**附图拿网址写进 `urls.txt`：`agent_skill.py upload --file`。
4. **跑**：`MODEL=... run.sh <名字> <提示词文件> <附图网址...>`，内部是
   `PYTHONUTF8=1 python ~/.claude/skills/lovart/scripts/agent_skill.py chat --prompt "$(cat p.txt)" --attachments ... --prefer-models '{"IMAGE":["generate_image_nano_banana_pro"]}' --json --download --output-dir ...`。
   有并发上限（报 Concurrent task limit 就分批）。
5. **自己逐张验收**再交：对照下面的雷区，不合格的挪 `_lovart/_rejected/` 重出。挑好的拷成 `Ref_*` 改名。

## 提示词写法

- 通用开头：「附图三张是同一个角色的正面、侧面、背面 T 字三视图。只生成他身上的一个部件，用于 3D 建模参考：颜色、磨损、肤色、比例与附图完全一致，写实照片风格，纯白背景，无阴影，均匀柔和棚拍光，部件完整居中、四周留白，无文字。只出一张图。」再写部件段和输出分辨率。
- 「左手/左脚」要注明「正面图里画面右边那只」。
- 头部写成**改图**：「这是改图不是重画，脸一点都不能换」，逐项点名脸型、眉、眼、鼻、嘴、耳、肤色；只列要做的几件事（摘帽、剃光、刮胡、去布巾）。
- 身体写「像一件被隐形人穿着的衣服」「袖子水平伸直与躯干成 90 度，绝对不能下垂成 A 字」。
- 装饰件的朝向写死在图上：如肩章「平放在肩顶，从领口根沿肩线伸到袖缝」（日军士兵A 因为没写死重出过一版）。

## 雷区（都被打回过）

- **脸不像原人**：罗班长头部第一版直接重画，用户「和原版的脸有一毛钱关系吗」。必须拿脸部裁切改图。
- **手不是俯视**：要正上方垂直俯视；小臂出框、拇指看不见也算废。
- **头只出到脖子**：Tripo 头会变成短粗脖子、合并时补不齐。罗班长后来改出**带脖子、斜方肌、锁骨的光头胸像**（`HeadBaldBust`）才解决。新人物光头图建议直接出胸像：「脖子以下带一部分上身（斜方肌、锁骨、上胸），在锁骨下方平切」。
- nano banana pro 出全身易成 A 字、偏黄；左右肩章星数会不对称。全身和身体用 GPT Image 2。
- 已知可接受的偏差，写进说明不必重出：帽子背景浅灰渐变、绑腿比要求长、袖子略下垂。
- 内容审核拦血腥词时换成中性描述（stain already on the wall）。
