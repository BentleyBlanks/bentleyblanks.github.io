# 视频转骨骼 · 动捕分镜与 AI 视频提示词规范

本 Skill 沉淀已验证的「电影分镜 → AI 视频（Seedance / MiniMax-H3）→ 单目 77 骨提取（GEM-X / GVHMR）」提示词铁律。代码真源位于 `MotionWorkbench/server/Data_Level01Scene01Catalog.mjs`（`STUDIO_BG_RULE` 与 `LIMB_COLOR_SUIT_RULE`），项目资产目录与提骨验收规范见 `Taierzhuang1938/docs/Data_VideoToSkeletonStandard.md`。

## 1. 动捕服着装规则（唯一定义源，防串色/翻色）

采用**「中灰哑光躯干 + 解剖同侧蓝/橙高对比紧身服 + 真肤色裸手 + 深色鞋」**（相比对角/四色更不易在 AI 视频转身中跳色）：

- **躯干边界**：躯干前后正反面均为完整纯中灰色，四肢颜色**严格止于肩缝与髋缝**，严禁溢入胸口、锁骨或后背。
- **解剖学左右（严禁按画面左右写）**：
  - **人物自身解剖左侧（自身左臂 + 左裤腿）**：深钴蓝色
  - **人物自身解剖右侧（自身右臂 + 右裤腿）**：亮橙色
  - 提示词必须显式声明：**转身、侧身或背对镜头时，颜色严格跟随人物自身左右肢体，绝不随画面左右互换**。
- **裸手与鞋底**：双手必须保持真实肤色裸手无手套（保障 ViTPose / WiLoR 识别十指）；穿深色防滑鞋（保障接地检测）。
- **禁止服装词打架**：角色描述 `characterDesc` 与单格分镜 `prompt` 中**只写年龄、体型、发型及必要道具**（如胸前帆布背包带），**严禁出现任何日常衣裤词**（如「灰绿短袖」「军绿上衣」「深色长裤」等），所有服装描述只由 `LIMB_COLOR_SUIT_RULE` 单一定义。

## 2. 棚拍背景与机位规则

- **背景色**：使用**极浅哑光冷灰无缝摄影棚（约 `#e6e8eb`）**并保留**柔和自然的地面接触影**。不要用纯白背景（纯白容易在撑地/贴地动作下吃掉浅肤色手指边缘，也会削弱鞋底接地参照）。
- **固定机位**：三脚架绝对静止，**约 45° 斜向、向下俯角 35°–45° 半俯视中远景**，严禁推拉摇移切镜。
- **完整入画与真实位移**：
  - 人物身高占画面约 60%，头顶与双脚鞋底留白充足；冲刺、前扑、倒地动作须为全程运动范围预留前后空间。
  - 前进/急刹/猫腰冲刺等带根位移的动作，必须相对固定地面真实位移，不得改成原地踏步或靠镜头平移伪造位移。
- **单人无杂物**：画面内仅一名人物，无场景家具/多余道具/文字/水印。

## 3. 分镜三格与视频提示词拼装检查清单

新增或修改 `Data_Level01Scene01Catalog.mjs` 动作条目时，逐条核对：

1. `characterDesc` 不含任何日常衣物/颜色词（仅年龄、体型、发型、必要随身带具）。
2. `videoPrompt` 统一通过 `makeCameraPrompt(characterDesc, actionDesc)` 生成，自动注入 `STUDIO_BG_RULE` + `LIMB_COLOR_SUIT_RULE`。
3. `storyboard.shots`（S1 起势 / S2 核心 / S3 收势）每格都用 `极浅哑光冷灰无缝摄影棚(#e6e8eb)带柔和地面接触影`，且不含日常衣物词；后端 `Script_WorkbenchServer.mjs` 在生图时自动补全 `LIMB_COLOR_SUIT_RULE`。
4. 出图后人工复核三件事再送 Stage 03 视频生成：
   - 胸口/后背是否纯中灰无橙蓝串色；
   - 转身/背身格（如 S3）的蓝/橙是否仍贴在人物自身左/右肢，未随画面左右翻色；
   - 裸手十指与深色鞋底在 `#e6e8eb` 地面接触影上是否边缘清晰。
