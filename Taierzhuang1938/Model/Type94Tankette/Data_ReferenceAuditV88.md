# Type94 2014 后缘点位更正 V88

V86 记录的 2014 远侧交界 `(1890,1373)` 取错了位置：它在后缘线中段，不是后缘与侧缘的交界。原生局部复核后，使用两条已复核的侧缘候选线与后缘候选线求交，得到约 `(1805.78,1380.12)`。交点计算不使用模型或相机；选线发生在看过旧预测之后，因此不是盲测，原 12 像素不确定度也不降低。

旧点与原记录文件保留，不原地覆盖。V87 在更正数据下的 2014 RMS 由旧约 74.55 降至约 15.31 像素；旧残差不能继续用作结构变化或机位错误的证据。三图联合的局部参数结果约为 6.15／10.64／2.76 像素 RMS，均在这批粗略交界点采用的不确定度范围内，但不确立物理标定或精密尺寸。

另外从实际源网格提取后缘外皮直段，区分圆角／倒角后的皮肤边缘与虚拟尖角交界。该过程按世界坐标选择边缘，并检查 Y 位置与当前参数一致；不把合并网格的局部轴误当成车体轴。模型仍只作毫米级局部参数更新，不改相机。

更正的来源、后验检查限制、旧结论撤回和新试件见 [Data_ReferenceAuditV88.json](Data_ReferenceAuditV88.json)、[Data_GrayTrialV89.json](Data_GrayTrialV89.json)。
