# Type94 罩体后缘与交界约束 V86

在 2017、2014、TourGuide 原图中分别记录罩体后缘的直段及与侧缘的表观交界。边缘由厚漆、圆角和光照影响，观察点是近似交界，不是已测得的尖角顶点。点位先记录，随后试算，机位保持原值。

只看主参考的直线会触及后部高差下界，显示深度／高度耦合。加入有限后缘两端才能约束横向中心与宽度。在当前机位族下，2017 与 TourGuide 的交界可得到约 2.03／2.69 像素 RMS 的局部一致结果，但同组参数在 2014 年照片约 74.55 像素。将三图全部联合也没有同时贴合，不能因此宣称相机、点位或结构状态已确定。

V87 仅保留主参考／高机位支持的局部候选供比较；2014 继续作为未参与该候选拟合的冲突记录。没有据此认定旧照片结构不同，也没有移动相机去消除差异。直线单独拟合的前一试件另存为未采纳版本。
