# Type94 传动罩与前装甲约束 V82

从实际 V81 源工程分离左右传动罩的小型独立表面，得到每侧 5 个旧规则头形的实际冠面位置和投影。按现有主／2014 机位，近侧 5 枚都被当前模型遮挡；远侧上两枚被车体遮挡，下三枚可见。这是模型几何的可见性结果，不能把投影点直接认作照片中的头部，也不证明某个机械轴或零件归属。

新增复核 2014 年照片中 5 个可辨认的前装甲头形足迹。位置不确定度暂取 4–6 原图像素；选区受旧预测引导，未根据拟合回改点位，不作为完全未触碰的整图验证。对保留的 V75 假设只做新数据评估，没有重跑原来的拟合。

在固定 2014 机位下，保留平面约 8.85 像素 RMS；前移平面方案约 30.31，联合相机／平面方案约 51.57。新点不足以证明旧机位或平面精确，却明确不支持直接采用这些前移方案。远近传动罩、前角紧固件和履带包络仍需实体对应核对。

原始数据、哈希、可见性与评估入口见 [Data_ReferenceAuditV82.json](Data_ReferenceAuditV82.json)。源模型没有改变。
