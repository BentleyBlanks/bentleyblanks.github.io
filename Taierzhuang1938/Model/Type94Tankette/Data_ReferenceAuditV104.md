# Type94 固定前装甲复核 V104

直接观察 2017／2014 同车原图，新增八个前装甲固定紧固件的候选对应，保留原图哈希、裁切矩形、640 像素观察图上的手工中心与反算原生坐标。被栏杆或传动罩遮住、身份不清的下部及远侧紧固件不补齐。区域选择参考了既有预测，因此这些点不是盲测；中心是照片冠面中心，不是测绘轴心。

七点训练和一个仅从拟合中留出的点，均按六原生像素粗标不确定度处理。沿用主图条件前平面和既有内参，只改 2014 相机六自由度时，训练 RMS 从 3.93 降至 2.71 像素，留出点从 12.37 降至 8.43 像素；但未参与拟合的后侧罩实表面边缘 RMS 从 11.99 增至 20.09 像素。训练点原本已在粗标不确定度内，这次局部改善不足以支持采用约 1.515° 的相机变动。

保留该条件试验并不改相机或几何。它只说明这一个固定内参、条件前平面下的前部拟合不能同时改善另一深度的后部控制；不证明所有相机方案无效，不把剩余误差解释成某一轮轴或传动罩的已测偏移。平面单应性也单独记录，不能代替真实三维标定。
