# Type94 车首拖钩图像核对 V93

在 2017 主参考和同车 TourGuide 照片中，可辨认车首向前开口的厚钩身、上方横销、独立锁闩和横销附近的线圈。此前模型把它做成平行前装甲的双耳 U 形环，并让整圈绕横销摆动；这项结构识别被否决。它不能继续作为固定车体光学对应或机械运动的依据。

原图哈希、原生裁切范围、粗略标点和源工程独立组件审计保存在外置 `ReferenceV93`。主图旧销轴预测与粗标的图像中心约差 105 原生像素；该数值只说明旧部件的条件投影偏差，不能当成实车尺寸误差。粗标在旧模型观察之后取得，不是未触碰的独立留出点。

保留相机并假定中心平面 X=0，可得到一个新的条件销轴位置。主图钩尖、钩底和锁闩末端是可见轮廓，不能直接冒充钩身中心线；它们只用于外观复核。四个隐藏安装头、钩身截面、弹簧圈数、轴承结构和锁闩演示行程仍为推定，不宣称承载或史实止挡。

后续局部试件见 [V94](Data_GrayTrialV94.md)。本审计不接受整车参考、不改变相机或覆盖材质候选。记录与输入身份见 [Data_ReferenceAuditV93.json](Data_ReferenceAuditV93.json)。
