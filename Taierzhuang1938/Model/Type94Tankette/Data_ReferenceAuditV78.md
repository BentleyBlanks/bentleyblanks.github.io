# Type94 前角观察 V78

2017 主参考与 2014 原图近景都能辨认远侧前角的窄条凸起安装部位和上部头形。原 V64／V74 传动罩在对应处是连续圆弧，V73 的 `FarUpperEdge` 不能简单作为平面前装甲上的普通头部放置。另一个下部凸起的身份和位置尚未确认，安装部位的真实截面、深度和与壳体的连接方式均未证实。

从实际 V74 源网格发射主参考观察射线：`FarUpperEdge` 首先击中右传动罩，比原条件平面头部位置提前约 10.6 mm；`NearMiddleEdge` 首先击中左传动罩，提前约 70.1 mm；`NearBottomEdge` 首先击中左履带第 41 节，提前约 148.3 mm。这些是当前模型的遮挡事实，不是照片中结构归属的证明，也不能据此直接把全部头部搬到击中物体上。

此轮由远侧安装部位建立 [V79 局部灰模试件](Data_GrayTrialV79.json)，没有采用 V75 的前装甲面或相机改动。第三张照片的对应／相机冲突仍未解决，不作为已认证的独立几何验收机位。机器匹配的重复螺栓／铰链误配已有 V40 记录，本轮没有重跑该匹配来替代实体身份核对。

来源哈希、原始坐标、实际射线结果及剩余范围见 [Data_ReferenceAuditV78.json](Data_ReferenceAuditV78.json)。本轮只增加局部证据和试件，不构成整车参考验收。
