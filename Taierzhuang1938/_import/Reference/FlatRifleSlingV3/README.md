# Flat rifle sling source

The user clarified that hemp rope described the desired low rebound, not the strap's appearance. The runtime asset is a flat brown strap; the rejected round rope version is withdrawn.

Built-in imagegen (tier 1) supplied one fine brown leather base-colour tile, preserved here as a 1024px WebP derivative. The full PNG and editable Blender project are in `C:/Users/Bentl/OneDrive/AI/Models/Blender/Taierzhuang1938/FlatRifleSlingV3_20261105/`.

`_blender/Script_FlatRifleSlingBakeV3.py` builds the 25 mm wide, 2 mm thick strap, tapered 16 mm ends, folded loops, short return tabs and stitches, then bakes the fine normal map in BlenderMCP. The GLB has 63 skinning bones driven by 32 simulation points; the physics does not gain elasticity from the extra spatial interpolation frames. Surface and stitching are creative reconstruction, not evidence of standardized 1938 issue.
