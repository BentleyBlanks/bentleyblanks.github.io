# Hemp rifle sling fibre source

`Texture_HempFiberSourceV2.webp` is the 1024px production derivative of one image made with built-in imagegen (tier 1), 2026-11-05. `Prompt_HempFiberV2.txt` preserves the prompt. No paid fallback was used.

The image supplies fine, lengthwise dry hemp fibres. The three helical strands, closed swivel eye, whipping and stock lashings are actual Blender geometry, rebuilt by `_blender/Script_HempRifleSlingBakeV2.py`. The fibre normal is baked in Blender at physical scale; the GLB embeds Base and OpenGL Normal as WebP.

The full generated PNG and editable Blender project remain in `C:/Users/Bentl/OneDrive/AI/Models/Blender/Taierzhuang1938/HempRifleSlingV2_20261105/`. The game asset is `Model/HempRifleSlingV2/Model_RifleSlingHempV2.glb`. These material and binding choices are creative design, not evidence of an issued 1938 sling.
