### 为什么传单/报纸是繁体、家信是简体

传单和报纸是 1938 年的**铅印品**，简体字在那时候是明确的年代穿帮。
家信是**顺子代笔的手写**（罗班长口述），一个被绳子捆来的农民写的俗字体，
而且策划案给的四句原文就是简体，要能逐字对上，所以照原文写。

## 生成链路

按 `AGENTS.md`「Generated Images / 生图（三级回退）」走，**第 1 级就成了**：

1. **Codex CLI 内置 `image_gen__imagegen`（本批全部走这条）**
   `codex exec -m gpt-5.6-sol --skip-git-repo-check -s workspace-write -C <临时目录> -c model_reasoning_effort="low"`
   四条并行，各出一张**纯空白做旧纸底**（`base_leaflet` / `base_news` / `base_letter` / `base_map`），
   约 2 分钟出齐，四张全都干净、一个字都没有，不需要降级到 Lovart 或即梦。
2. Lovart —— 没用上。
3. 即梦 Seedream 5.0Pro —— 没用上。

### 关键：文字不是生出来的，是排上去的

AI 生图写汉字必出乱码，所以**分层合成**：

- **AI 只出纸底**（提示词里把 "NO text / NO Chinese characters / NO markings" 写死到啰嗦为止）；
- **所有文字由 `Script_MakePaperProps.mjs` 用系统字体逐字绝对定位排版**，
  再用无头浏览器整页截图。浏览器走仓库既有的
  `PrairieFire1937/Script_BrowserTestKit.mjs` 的 `LaunchBrowser` ＋
  `Taierzhuang1938/Script_DevServer.mjs` 的 `ServeRoot`，没有裸写 puppeteer。

重跑：

```bash
node Taierzhuang1938/Texture/Script_MakePaperProps.mjs --bases=<放 base_*.png 的目录>
node Taierzhuang1938/Texture/Script_MakePaperProps.mjs --only=letter --keep   # 只重出一张并保留中间页
```

`--bases` 缺省或目录里没图时，整张走**纯程序化做旧**（噪声/纤维/霉斑/污渍/折痕/磨边），
不会失败，只是纸感差一档。脚本自带确定性随机种子，同参数重跑结果一致。

## 三个踩过的坑（重出图前先看）

1. **纤维不能画长**。第一版纸浆纤维长 30–190 px，出来是一层划痕，整张纸像被刀刮过。
   纤维就是短（3–14 px）、多、淡。
2. **半调网点要一颗颗画**。用 CSS `repeating-radial-gradient` 做的网点是从单个圆心发散的
   同心弧，出图一片摩尔纹，一眼渲染事故。现在是 canvas 按明暗场逐点画，而且明暗必须有大结构
   （上淡下重＋一处高光），否则等密度网点只是个黑方块。
3. **字体自查不能拿汉字量宽**。全角字在任何中文字体里都是同一个前进宽度，量出来永远相等，
   会把装着的字体全报成「缺失」。必须用拉丁串量。

另外：AI 出的扫描件四周留了白底投影，`cover` 之后还得再往里推 14 % 才裁得掉白边（地图那张是
edge-to-edge，不用推）；AI 纸底自带折痕，程序化折痕要减到 45 % 强度，否则同位置叠出双重棱线。

## 交付边界

- 本批**只**新增 `Texture/` 下的 4 张 PNG ＋ 本文件 ＋ `Script_MakePaperProps.mjs`，没改别的文件，没提交。
- 贴图**还没接进引擎**：挂点、材质（建议 `MeshBasicMaterial` 或低粗糙度 `MeshStandardMaterial`，
  纸张不吃高光）、是否需要 alpha 裁边，都留给后续章节批。
- 四张都是**不透明整幅**，纸铺满画面、边缘用压暗和缺口表现磨损，没有做 alpha 抠边 ——
  这样不论引擎按不透明贴图还是按透明片使用都不会露黑边。要真·撕边轮廓的话得另出一张 alpha。
- `Script_MakePaperProps.mjs` 按「不越出 `Texture/`」的交付边界放在了本目录；
  仓库惯例是 `Script_*` 放项目根，集成时可以平移到 `Taierzhuang1938/`（它只依赖
  `../Script_DevServer.mjs` 与 `../../PrairieFire1937/Script_BrowserTestKit.mjs`，
  移动时改这两行相对路径即可）。
