# 03｜夺取右侧阵位，接回第一批守军
目标：**跟随班长推进并夺取右侧机枪阵位，打退直接阻拦撤退的进攻组，掩护第一批守军实际撤入后交通壕。**
**阶段进展：**辨认守军与封锁火力 → 跟随班长沿右侧低沟推进 → 清除阵位守卫并夺点 → 利用新阵位压退指定进攻组 → 第一批守军通过缺口、进入安全区 → 何有田接替老周，战车在道路远段露面。
**任务提示：**先显示“跟随班长，夺取右侧机枪阵位”，夺点后更新为“掩护第一批守军撤入交通壕”。不把全阶段压缩为一个击杀计数任务。
**玩家与班长路线：**后交通壕 → 右侧接近低沟 → 破墙阵位侧入口 → 夺下的射位。不是在后沟站桩射击，也不是跑到守军身边领人。
**守军空间位置：**待撤守军在前沿土坎的背坡遮挡内；撤退缺口是背坡通向后交通壕途中被炸塌、炸浅的暴露沟段，不是要求守军翻过土坎、冲进北侧敌军再撤回。03—05围绕这个同一缺口连续展开。
### 接应位置与伤情铺垫
承接02，小队经过背坡伤员集结处，进入仍由我方掌握的后交通壕。玩家先辨认三处位置：前方土坎后被困的守军、通往后交通壕的撤退缺口、右侧破墙内封锁缺口的敌军机枪阵位。后续守军也已在同一片前沿作战，不到04才凭空出现；第一批是距离撤口较近、先具备撤离条件的人。
正面日军从北侧既有弹坑、土埂和破墙之间逐段接近前沿，不是整排站着射击。老周在左前侧枪位阻止其越过前沿；守军退到土坎背面后可避开正面的直接射线，但经过塌浅沟段形成的撤退缺口时，仍会暴露给右侧机枪。玩家看到一名守军尝试通过又被打回遮挡，先理解“人就在前面，但缺口过不去”。
老周腿上已有临时包扎，挪动吃力，仍在操作机枪。此处提前交代伤情，04不再突然新增一次受伤。
> 老周：“右边破墙！冒火那个口子！把路封死了！”
> 罗班长：“周哥，顶一下！我们去拿右边！”
> 罗班长：“顺子，跟紧！莫走外头！”
### 随班长接近并夺点
玩家与班长从后交通壕右侧接入低沟，利用土坡和残墙逐步接近阵位侧面。沿途敌人是守卫该阵位、看守连接口的同一支分队；不在无关空地随机堆敌。班长在转折处停下指路、协助掩护，玩家完成主要交战，不是留在后方远距离打靶，也不是跟着班长走完一条已清空的路。
接近途中能看见右侧道路、阵位背面的支沟岔口，以及外侧旧院落的屋顶，为后续战车来路和取弹路线留下空间印象。
> 罗班长：“贴这道墙！前头有人！”
> 罗班长：“口子压住了，进！”
清除阵位内的直接威胁后，占领成立。这里保留面向撤口和正面来敌的可用射界；玩家可以操作夺下的机枪，也可以使用自己的步枪，不把上机枪作为唯一推进方式。
### 从夺点转为掩护撤退
班长指向正面正要接近缺口的那一股敌军。玩家从右侧阵位协助老周，迫使这股敌军退入遮挡、暂时停止推进。正面压力仍在，但眼前通路出现撤离窗口。
> 罗班长：“土坎前头那一伙！莫让他们压到口子上！”
> 罗班长：“压下去了！前头的，下来！往沟里走！”
白盒采用“指定进攻组击杀阈值＋撤路直接火力解除”触发开始撤退；玩家和NPC的有效击杀都计入，阈值随测试调整，不要求全场清敌。达到数量时，仍能有效扫射缺口的敌方射手必须先被处理；不能只因计数够了，就让守军顶着封锁火力跑。
第一批守军从原有位置沿土坎背面移动，穿过缺口，进入后交通壕并转过折角。玩家在夺下的阵位继续掩护，能看见救援结果。若撤路重新受威胁，尚未出发者留在遮挡后，已出发者奔向最近遮挡，不站在空地等触发。
### 第一批归队，威胁提前露面
第一批过口后，班长安排何有田沿己方后交通壕接替老周的左侧枪位；幺娃与搬运人员扶老周向背坡集结处撤。玩家留在右侧阵位，不再回左侧重复接枪。
> 罗班长：“何有田，接周哥那边！幺娃，扶他下去！”
> 老周：“外头还有人！”
> 罗班长：“看到了！这边有人接，你先下去！”
第一批撤退尾声，右前方道路远段传来发动机和履带声，玩家可短暂看见车影经过残墙后方。它尚未获得封锁缺口的射界，先建立“同一条路上有重威胁正在过来”的预期。
**通过条件：**右侧阵位由我方实际控制；第一批所有仍存活守军进入后交通壕折角后的安全区，且至少一人活着接回。开始奔跑、击杀达标或全员阵亡均不能当作接回成功；第一批全部阵亡则接应失败。

# 04｜战车沿路压进，右侧射位失效
目标：**继续掩护后续守军，辨认战车如何重新封住撤口；从受压制的正面射位退到阵位后侧，随班长转入取弹行动。**
**阶段进展：**留在已夺下的右侧阵位掩护余队 → 战车从已露面的道路远段驶出路弯 → 正面射位受压制 → 班长带玩家短撤至阵位后墙 → 战车继续前移、封住撤口，余队停入遮挡 → 明确弹药屋位置与分工，进入后侧支沟。
**任务提示：**“掩护后续守军” → “跟随班长，退到阵位后侧” → “沿后侧支沟前往旧弹药屋”。战车出现不直接跳过玩家的应对与短撤过程。
**玩家与班长路线：**03夺下的右侧阵位正面射位 → 同一阵位后墙 → 后侧下沉支沟岔口。这里是一段从暴露射位缩回实遮挡的短后撤，不回02起点，不横穿守军撤退缺口，也不离开原战区。
### 同一阵位，同一路口
03结束后不切换场景、不把玩家重置到后交通壕。玩家与班长仍在刚夺下的右侧阵位，何有田已接替左侧枪位，文财守后交通壕入口，幺娃护送老周撤向06集结处。
后续守军从先前已存在的前沿位置沿背坡向缺口收拢。正面日军继续从原来的弹坑和土埂推进，部分留在遮挡内射击，部分试图向前沿侧端接近；何有田阻止其逼近，玩家从右侧协助。击退上一股敌人只是争取了窗口，不代表整个正面已被清空。
### 战车先压制阵位，再封住撤口
03尾声出现过的战车，沿东北方向道路继续向南驶出路弯，伴随步兵沿道路边缘跟进。战车先取得对右侧阵位正面射位的射界，随后绕过前沿土坎侧端，逐步取得对撤退缺口的射界。来路、行进和开火位置连续，不在玩家附近突然生成，也不跨阶段倒退回远处。
> 何有田：“右边路上！战车出来了！”
> 罗班长：“先看住跟车的！前头还有人没下来！”
玩家可继续用机枪或步枪处理伴随步兵，但普通枪火不能使游戏中的战车停止推进。战车向正在开火的阵位施压，正面射口周围落弹、碎屑飞溅，玩家难以继续露头。
> 罗班长：“下来！莫站枪口上！退后墙！”
**战车不是把右侧阵位夷为平地。** 可有正面局部受损，但阵位后墙、土坡和下沉支沟仍提供实遮挡。班长先退向后侧并招呼顺子跟上，玩家完成一段短后撤，不强制演成整座阵地被炸没。
战车继续向压口位置挪动，缺口遭火力封锁。后续守军停在缺口前最后遮挡后，不顶着火力冲，不消失回原位。玩家能把新局面与刚才的成功对上：右侧阵位已经夺下，但刚打开的撤路又被战车封住。
### 班长判断并组织取弹
退到阵位后侧，班长确认继续守着原射位不能解决战车。已撤下的守军在后沟喊明旧弹药屋仍有集束弹；该屋位于右侧阵位东南后侧的旧院内，院墙、土坡和支沟将其与道路隔开，位置与取弹路线保持一致，不再写成另一个北侧目的地。
> 守军：“外边旧弹药屋还有集束弹！后沟能过去！”
> 罗班长：“文财，看住沟口！何有田，前头交给你！”
> 罗班长：“顺子，跟我走后沟，去拿弹！”
> 顺子：“前头还咋个过？”
> 罗班长：“莫走路上！跟到老子！”
何有田负责压住正面与逼近的敌方步兵，不是开枪就能让战车无限转头的诱饵。班长和玩家主要依靠后墙、土坡、沟深脱离直射。
**通过条件：**战车已沿可辨认的道路进入压口位置并形成实际封锁；后续守军收拢在最后遮挡；玩家与班长抵达右侧阵位后侧遮挡；取弹位置、路线和留守分工明确，进入05。

# 05｜班长带路取弹，解除战车封锁
目标：**从右侧阵位后侧沿支沟取得集束弹，返回道路旁的攻击位置，由玩家完成攻击，重新打开撤口并接回剩余守军。**
**阶段进展：**阵位后墙出发 → 沿支沟接近旧弹药屋并处理切入敌兵 → 取得集束弹 → 沿原支沟返回已知岔口 → 随班长转入道路旁的遮蔽攻击位置 → 玩家攻击后退回遮挡 → 撤口封锁解除、余队实际通过 → 玩家与班长沿支沟撤回后交通壕，接防后返回06集结处。
**任务提示：**“取得集束弹” → “跟随班长，接近战车” → “解除战车对撤口的封锁” → “掩护剩余守军撤回” → “随班长返回伤员集结处”。取弹、攻击、接人和自身撤离分别确认，不用一次投掷直接结束整个阶段。
**玩家与班长路线：**04结束的阵位后侧岔口 → 旧弹药屋后门 → 沿原支沟返回岔口 → 道路侧攻击位置 → 退回岔口 → 己方后交通壕 → 06背坡集结处。取弹往返、最后接近和完成后的脱离是三段连续动作，不把投掷方向当作人物行进路线，也不让玩家在爆炸后穿过敌军正面撤走。
### 沿阵位后侧支沟取弹
起点就是04结束时的右侧阵位后墙，不把玩家送回后交通壕起点重走03。班长先进入已在03接近途中露过面的支沟岔口，带玩家绕到旧弹药屋背面。
路线只保留有功能的转折：离开阵位正面射界、贴墙或土坡经过受损沟段、从旧院后侧入屋。取弹支沟在己方这一侧，不直接连接被困守军的前沿遮挡，不能成为无需解决战车即可把守军全部绕出的捷径。
> 何有田：“班长，快点！这边老子顶到！”
> 罗班长：“顺子，下沟！屋在墙后头！”
中途一处沟沿受损，玩家短暂看到同一条道路：战车比04更靠近撤口，伴随步兵也在移动。这里需要降低姿态是因为沟沿遮挡不足、外面存在直射威胁，不设置没有作用的强制匍匐段。
> 罗班长：“低点！上头看得到！”
> 罗班长：“前头岔口！有人下沟了！”
少量敌兵从已经看见的道路连接口切入支沟，构成近处交战；不是把敌人刷新在玩家脸上。班长指路并掩护一侧，玩家清除拦路者。正面进攻仍由何有田和留守人员应对，枪声、喊话与道路观察口保持原战场的存在感。
### 取得弹药，原支沟返回岔口
旧弹药屋是此前前沿使用的补给位置，正门方向危险，后侧通道尚未被占。留守兵或搬运人员仍在整理余下物资，不做孤立于战场之外的新补给站。
> 留守兵：“里头那个箱子！就剩这些！”
> 罗班长：“拿起！沿刚才的沟回！”
玩家拾取游戏内集束弹后，沿刚走过的支沟返回已知岔口。返程不复活去程敌人；变化来自道路上战车的前移、伴随步兵的重新占位和局部沟沿受损。战车始终沿原道路连续移动或停留射击，不瞬移到另一个方向。
> 何有田（远处）：“它又往前挤了！前头的人还卡到起！”
> 罗班长：“听到了！顺子，跟紧！”
### 从岔口转入道路旁的攻击位置
回到阵位后侧岔口后，班长带玩家转入道路旁低沟或残墙后的攻击位置。这条短支路在去程已可辨认，不拿到弹后凭空开门；它与右侧阵位相邻，但不是回原机枪射口远距离投掷，也不是沿道路正面追车。
班长停在最后遮挡处，确认位置并照应近处敌兵。玩家处理眼前直接威胁，完成集束弹的游戏内投掷，再退回遮挡。保留玩家的关键操作，不把高潮交给NPC代办。
> 罗班长：“就这边！莫上大路！”
> 罗班长：“顺子，拿弹！旁边的人我看到！”
> 罗班长（投掷后）：“回来！低头！”
### 缺口重新开放，接回余队
有效攻击后，战车进入受损停驶状态，同时中断原先封锁缺口的有效火力。**仅仅履带停转、武器仍能扫射撤路，不算已经解围。** 若伴随步兵仍直接控制缺口，玩家与友军继续处理这些威胁，不要求把整个战场清空。
正面日军不会因战车受损而全体消失。何有田继续阻止近处敌兵越过前沿，剩余守军利用背坡和撤离窗口移动；正面敌军的推进企图、实际到达位置和当前射界必须区分：前出的敌兵仍受土坎、侧射火力和自身遮挡约束，不能在战车停驶后自动获得对整条撤路的无遮挡射界。若有敌兵实际越过土坎或绕到侧端并重新封路，必须先打断这处直接威胁，再放行尚未出发的守军。
> 何有田：“停了！口子能过！”
> 罗班长：“前头的，下来！莫堵沟口！”
> 刘文财：“还有人！后头跟上！”
剩余存活守军从原遮挡位置出发，实际通过同一个缺口，进入后交通壕折角后的安全区。玩家与班长沿道路旁支沟退回右侧阵位后侧，再接回己方后交通壕；不横穿仍受威胁的正面空地。接防人员从己方后方沿沟进入现有阵位，接住何有田和文财的位置，小队才脱离。
> 刘文财：“这批过了！”
> 接防兵：“这里我们接！你们先下！”
> 罗班长：“走！回伤员那边！”
回到02经过的背坡集结处，玩家看见老周已经等候后送，顺接06的命令与借火对话，不另加一次受伤演出。
**通过条件：**取得并使用集束弹；战车失去推进能力且撤口有效封锁解除；剩余所有存活守军实际进入安全区，且这一批至少一人活着接回；玩家与班长撤入己方后交通壕；接防人员到位，小队回到06集结处。整批阵亡不能判定接回成功。
