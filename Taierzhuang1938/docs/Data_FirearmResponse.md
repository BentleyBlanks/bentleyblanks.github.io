# 枪械输入、射击与装填同步

2026-10-15 的用户授权范围为枪声、输入响应、连射/后坐、装填同步与轻机枪瞄准。伤害、敌军受击打断及第七项的全面视觉迭代不属于这次玩法改动。

- 玩家各枪通过 `WEAPONS.shotCue` 选择音效。随身、架设、AI及车载机枪的逐发弹道事件均传 `burst: 1`，批量环境声保留自己的点射配方；玩家架设射击同样走 `PlayGunshot` 的第一人称分层。
- `Script_FirearmActions.FirearmCadence` 保留连续射击的帧内时间余量；中断、换枪与新扣扳机没有历史欠发。纯规则与浏览器验收覆盖不同时间步。
- 举枪过程允许按当前插值散布射击。动作尾段与短射击冷却使用 150 ms 输入缓冲；R 在拉栓期间保留到该次拉栓结束。换槽、死亡、暂停和不兼容动作取消排队输入。冲刺恢复只用一次 220 ms 窗口，与收枪回位并行。
- `GunReadyFromCover` 为开火和准星提供同一掩体就绪判据。几何探测与视模回位都满足后才能开火，转身离开掩体后恢复。
- 自动武器的反向鼠标输入消耗已经压回的待恢复后坐；达到累计上限后压枪，下一发仍会产生新的相机后坐。没有手动压枪时保留原有完整恢复与上限。
- 捷克式、十一年式均可站立瞄准，两脚架保留稳定与转向代价；移动或离地自动收起，不能带着支撑加成奔跑。靶场和正片同规则。

## 装填事件契约

`Data_Tuning_FirearmActions.RELOAD_EVENTS` 按 `reloadKind` 给出归一化机械节点。`FirearmReloadTimeline.Advance` 保证跨帧不漏事件、重复求值不重复播放或加弹。视模在 `TriggerReload` 创建时间轴，向 `onReloadEvent(event, action)` 发事件；正常结束与剧本强制完成会收齐剩余节点。取消动作不会发未来事件。

`loaded` 节点才把弹药放进枪内并扣备弹，之前弹药读数保留实际余量；插入前取消不花弹，插入后取消保留已经装入的弹。第一关旧领械夹具的手动装填完成凭据仍在整段动画真正完成时授予。架设机枪同样以事件更新弹板读数，换板动作结束前仍禁止开火。

声音使用现有录音的 `offset/maxDuration` 片段，以对应开栓、插入和闭锁；普通未指定片段的音效行为不变。汉阳造实物结构和三步枪动作由并行换弹动画任务继续校正，最终曲线变化须同步此表，不得仅移动手而保留旧声音与弹药时间。

九二式使用独立 `stripFeed` 动作及横向30发保弹板，随弹药消耗横向进给，不再调用十一年式的六桥夹漏斗动作。静态掌位、枪械瞄具和世界枪模不改。

## 验收

`Script_FirearmActionsTest`：射速相位、阻塞恢复、事件单次性、压枪及掩体就绪。

`Script_FirearmResponseBrowserTest`：正式鼠标/键盘链、真实解码单发采样、逐枪装填时间、取消前后库存、拉栓排队、最后一发留栓、30/60/120 FPS 连射、压枪、冲刺、两种机枪肩射/架枪和掩体恢复。产物在忽略目录 `_shots/FirearmResponse/`，截图不能代替动作与账目的断言。

既有门禁继续使用 WeaponRange、FirearmHandlingBrowser、Emplacement、FpsArm、AdsSight、MotionVectorContract 与第一关领械凭据检查。
