# 翻车后的黑视与炮震恢复

2026-09-12：用户指出开场眨眼、发晕表现虚假，要求联网对标 COD。范围是第一关玩家车厢翻覆后的感官表现。

## 查证与采用范围

- [COD 官方 BO6 装备说明](https://www.callofduty.com/blog/2024/10/call-of-duty-black-ops-6-launch-comms-equipment-perks-scorestreaks-intel)分别定义震撼弹的移动／瞄准迟滞与闪光弹的致盲；不能把所有受冲击表现都归成闪屏。
- [Treyarch 官方音频设计](https://www.callofduty.com/blog/2024/10/call-of-duty-black-ops-6-dynamic-soundscape-audio-intel)明确提到 concussion / flash shellshock 的耳鸣，并提供独立减弱耳鸣的选项。
- [COD: Advanced Warfare 后处理作者 Jorge Jimenez 的 SIGGRAPH 2014 说明](https://www.iryoku.com/next-generation-post-processing-in-call-of-duty-advanced-warfare/)强调时间稳定性、滤波质量和轮廓过渡对自然观感的作用，说明景深与运动模糊的分工。这是通用后处理依据，不是炮震专用着色器的公开实现。

以上资料支持分层感官反馈与稳定的光学过渡，没有公开本场景的眨眼曲线或专用炮震参数。下面的镜头曲线、失焦半径与持续时间是本项目设计，不宣称复制 COD 源码或逐帧还原某段战役。

## 本次对标结果

| 通道 | 原实现的问题 | 本次实现 |
| --- | --- | --- |
| 眼睑 | 多次近乎闭合，拉长后像重复拉幕布 | 一次快速闭眼、保留黑视，然后连续睁开；上眼睑运动较多，边缘宽羽化 |
| 发晕 | 两组固定频率正弦摆动，类似规律摇头 | 有限、错峰的回稳关键帧；不循环，恢复时不重置相位 |
| 失焦 | 睁眼后立即清晰，主要依赖摇屏表达发晕 | 中心较轻、周边较重的柔化和低权重偏像；一次小幅聚焦回退，不再遮断视野 |
| 色彩 | 缺少独立恢复通道 | 轻微去色、外围压暗随任务时钟退去，普通画面回到原值 |
| 声音 | 已有独立低通、耳鸣和急喘 | 沿用既有音频链及拉长的恢复时长；视觉恢复不等于声音立刻恢复 |

眼睑、失焦、镜头与听觉共享任务时钟，但各用独立包络。原有 `openingRecoveryScale` 仍有效；此次感官专项未调整当时的翻车、拖扶、玩家控制权、伤害和剧情时间轴。后续 2026-09-12 车厢对白迭代已延长人物恢复：眼睑遮挡量降至 0.45 以下才播放班长完整 4.8 秒失败起身，站稳后才进入援手；具体见[车厢对白](Data_CarriageDialogue.md)。恢复操作后保留原有最长八秒的镜头回稳窗口，画面与听觉的余效按撞击时钟继续完成。

## 接入与验收

`Data_FirstLevelOpening.blinks` 只管一次闭眼／睁眼。`Data_Tuning_FirstLevel.OPENING_PERCEPTION` 管光学和镜头曲线。`SampleOpeningPerception` 为纯函数，暂停／重复渲染不推进恢复。`FirstLevelOpening.Dispose` 清掉暂态视效并恢复听觉。

`Script_Main` 透传 `concussion`；`Script_PostComposite` 在既有采样段完成小半径九点柔化和轻微偏像，在 lens 段去色、压暗、合成眼睑。只采当前 HDR 图，不回灌 TAA，不新增 pass、纹理或 sampler。像素半径与输入分辨率一起缩放，保持相同视野比例。HUD 与字幕仍清晰。系统减少动态效果开启时，额外镜头摆动与偏像归零。

- `Script_FirstLevelMissionTest`：一次闭眼、长尾恢复、有限幅度、完全归零；合入车厢演出后增加实际眼睑门槛、完整可见起身和暂停期间不推进的回归。
- `Script_PostTest`：GPU 实际滤波、闭眼全黑、归零后逐像素一致。
- 现有开局输入、受击反馈、帧图、运动矢量、车厢前景与七切片开机门禁按影响范围执行。
- 对比截图、诊断脚本与过程日志只保留在本地 `_shots/OpeningShellshock`。逐帧推进的对比截图是视觉专项证据，不作为实时正常通关证明。
