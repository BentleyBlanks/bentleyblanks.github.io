## 动作接口

GLB 使用米制 Y-up，鼻端与车头为局部 -Z。`DonkeyWalk` 是原地循环，步幅与周期存于骨架 extras；运行时按路程推进整个车组。`CartRoll` 一圈完整转动，以实际轮周长换算时间，不能直接拿行走相位代替轮相位。`DonkeyIdle` 使用独立时钟；停车时保持累计轮程。

最终骨骼与片段名称不依赖 Blender 导入时生成的显示骨形状。重新导入的 Action 从第 0 帧开始、NLA 条带通常从第 1 帧开始；验证按实际 Action 范围取样，防止错一帧误报接地。
