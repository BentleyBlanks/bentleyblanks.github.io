## 旧骨骼复用

只读调查了「修复牛马车走路动画腿部」的历史和三份复制件。已发布版与 WalkRepair 版为动物 20 骨、车 4 骨；后期候选的马扩至 116 骨，包含胸颈、骨盆、耳朵和大量套具分支。它们没有 Blender 常驻 IK 约束，主要由解析解算烘成关键帧。旧文档明确写着真实感验收未完成，候选没有被当成通过版本。

复用层级与解算约定，重建驴的关节位置、蒙皮、步幅、行走与静止。皮肤的 CC0 拓扑与雕刻法线保留并按驴的头颈、窄体、四肢比例重塑；耳、短鬃、细尾、面部细节、车和套具新建。没有直接缩小整匹马，也没有接入旧候选动作、发片或未验收的脱套具动态。

## 动作接口

GLB 使用米制 Y-up，鼻端与车头为局部 -Z。`DonkeyWalk` 是原地循环，步幅与周期存于骨架 extras；运行时按路程推进整个车组。`CartRoll` 一圈完整转动，以实际轮周长换算时间，不能直接拿行走相位代替轮相位。`DonkeyIdle` 使用独立时钟；停车时保持累计轮程。

最终骨骼与片段名称不依赖 Blender 导入时生成的显示骨形状。重新导入的 Action 从第 0 帧开始、NLA 条带通常从第 1 帧开始；验证按实际 Action 范围取样，防止错一帧误报接地。

## 验证与史料范围

保留正、左侧、背、斜侧及头部近景，完整行走周期检查实际蒙皮蹄面、根部连续、套具接点和距离轮动。导出后重新导入同一份打包 GLB，浏览器也载入该文件核对字节哈希、材质、两只运行时网格及动作。验收图片、视频和 HTML 不提交。

表面通过独立 GameUV 烘成两套图集，分区和分辨率按上方 V3 规则。基色只烘颜色，不烘场景光照；数据图线性、法线为 OpenGL +Y。WebP 打包逐像素无损，非图像缓冲的几何、蒙皮和动作字节保持不变。只有超出 80,000 三角预算时才精简运行时木车，保留动物和编辑源，并量测双向表面误差。

外形、毛色、旧损和套具做法属于按参考图的创作复原，未据特定历史实物复刻。Notion「史实与创作对照表」与资料馆同轮补充该范围，不用 CC0 模型许可证明历史真实性。
