# 白刃战系统｜大刀与刺刀

当前规则依据 [Notion 融合修订版](https://app.notion.com/p/3d160335331c811e84dadd826f089013)（页面更新 2026-09-05 18:20 UTC，2026-09-06 读取）。本轮用户额外要求 1v3 与实体场景靠近／交互触发。旧版历史验收不等同于本轮通过，证据见 [融合版验收](Data_MeleeFusionAcceptance.md)。

## 输入与连续交锋

- 大刀及步枪白刃架势：左键轻点短斩／短刺，按住后释放重劈／长刺；按下即开始可见准备，释放接续剩余起手，不重播完整前摇。
- V 切换已装刺刀步枪的射击／白刃架势；X 只装卸刺刀。射击架势保留左键射击、右键瞄准。架势有持枪姿态及 HUD 提示，不按距离自动切换。
- 右键是瞬时拨挡，长按不延长。有效武器接触范围内可主动拨枪，左右动作根据移动意图和接触方位选择；拨空、隔空或对方撤枪无奖励。主动拨枪的恢复差较短，精确拨挡收益更大。
- 成功拨挡和攻击收招尾段允许一个短输入缓存；QTE、受击、换武器及失焦均清空，避免恢复后自行攻击。
- WASD 保持移动，鼠标保持自由观察。敌人在起手中追踪，接触阶段武器方向只允许有限修正；及时侧移可以让刺击实际落空。
- 大刀贴身使用紧凑斩击。**玩家的 F 近身推架 2026-11-23 撤了**（用户）：F 不再归白刃（只剩卡刀实验的补刀），交回通用交互。推架规则（`Push`）仍在，只给对手用：贴身时日军照样会侧压 / 横推把玩家顶开，零生命伤害，有体力、恢复和抗连续硬直间隔，不能打断已进入有效阶段的重击。
- 轻／重每次只结算一个目标。中心距离用于初筛，再检查有限刀刃／枪尖扫掠；身体、武器、环境和挥空分别给出受击、碰枪、受阻回弹与惯性收招。武器绕转限制不锁镜头。
- 玩家近距离白刃造成日军死亡时，屏幕边缘短促飞溅一层镜头血迹：中央准星区保持清楚，约 0.82 秒自行淡出。它是砍出去的击杀回执，不读玩家血量、不触发濒死搏动；推架、QTE、枪击、友军误伤及玩家受伤均不触发。

## 多敌与可读机会

统一规则负责敌友双方，不另建测试场伤害。近距离一人牵制、其余寻找侧角；可见前摇之后出刺，身体与障碍挡住线路时要换位或收枪。出招前错开过近的接触时间，但允许前摇重叠，不在发出后取消本应命中的攻击。拨开甲只影响甲，乙仍是威胁；玩家可以在甲活着时转向乙，不要求先退远拆成单挑。

AI 从动作状态与反应延迟判断，不直接读取按键。命中显著改变受击者姿态并中断当前攻击，反复轻击／F 不无限刷新完整失衡。距离、损伤、窗口与调度参数统一位于 `Data_MeleeCombat.mjs`，是游戏原型参数，不是历史物理定律。

## 两种抵抗

站立 QTE 只在近距离存在武器接触、双方确实受阻后进入；先有短促刀枪硬架，随后才出现抵抗提示。**倒地 QTE 不再是通用功能**（2026-11-23 用户：改成特定关卡 / 剧情触发）：白刃战里被撞倒、炸倒只是倒地再起身，对手上前候着，不自动开 QTE；唯一入口是剧本的 `BeginScriptedGround`（第一关屋内伏击等），实验场只在取证口 `Debug.MeleeCombat.ScriptedGround()` 走同一入口做回归。

QTE 输入阶段最长 4.8 秒，结束后按结果恢复操作；冷却从释放后重新计算，并覆盖起身时间。连续受击照常扣血，但不重置正在进行的倒地／起身动作；存活玩家起身后有 1 秒不被再次打断或击倒的操作窗口。无敌模式同样按时起身。按键卡位于准星下方，输入阶段突出闪动 F，显示剩余时间；结算后停止闪动，退出后隐藏。

两种均使用真实 F 按下事件；系统按键重复无效。条左是我方挣脱，右是敌方压制；连按使标记向左，不按向右。约 5 次／秒可正常推进，约 7 次／秒封顶；低体力仍有可赢路径。保留长按和自动辅助。连续输入、武器压力与声音同步。

成功不杀敌、不自动接终结：站立恢复自由操作，倒地先起身，奖励恢复差从重新可操作时计算。失败通过原生命／出血规则受伤；普通站立失败不再自动接一轮倒地抵抗。本轮测试场死亡后手动重开，未引入全章节阵亡接替。

**剧本一次性按键（2026-09-28）**：`BeginScriptedGround(..., { input: "press" })` 开的倒地僵持不连按——窗口里按**一下** F 就赢，窗口漏完才输，进度不衰减，`progress` 读作「窗口还剩多少」（HUD 画成漏完的弧）；辅助档「自动」在 `MELEE_QTE_RULES.pressAutoS` 后替玩家按下。成败之后的姿势、失败伤害与起身仍走共用结算；输了压在上面的人保持 `Pressure`（捅下去），不再画成被推开。赢下来之后对方死在结算里不算「人没了」，结算与起身照常走完。只给第一关 09 进门遭伏击用（照 COD5 万岁冲锋），杀招由任务在结算那一刻自己下，共用层「成功不自动杀敌」不变；口径见 [Mid 册 09](Data_FirstLevelMid20260919.md)。

单敌限次和交锋冷却限制重复 QTE。第二名敌人已具备直接威胁时不开始长僵持；QTE 中旁敌保持世界状态，重新获得直接线路时提前脱离并给回操作，再显示新的攻击起手。提前脱离不是获胜，不击退、不发放攻击奖励。

### 玩法变体（2026-11-23）

面板换成其他测试场同一套样式（`.shellImpactLab`），同日第二轮按用户要求只留最基本的布局：「玩法 / 项目 / 操作 / 读数」四组，说明性长句、QTE 输入、动作检查、最近交锋都撤了。「玩法」两排按钮随时切换，切了立即重开当前项目；网址 `?meleeControl=drag&meleeImpact=lodge` 也能直接指定。变体只在实验场里设（`MeleeCombatDirector.SetVariant`），**正片白刃层永远是 classic**。数在 `Data_MeleeCombat` 的 `MELEE_VARIANTS` / `MELEE_LODGE` / `MELEE_DRAG`。

| 操控 \ 命中反馈 | 原版 · 砍中即退 | 卡刀 · 拔刀 · 补刀 |
|---|---|---|
| 原版 · 按住蓄力 | 改造前的行为 | 原版出刀 + 卡刀 |
| 拖拽挥砍 | 按住左键甩刀（视角跟一部分） | 两者叠加 |

- **卡刀（impact `lodge`，只对玩家的大刀）**：**刀真砍进身体里才卡**（用户第二轮：「没砍进去是不需要拔刀的」）。卡不卡看两样：刀刃吃进去的深度（这一刀够得着的长度 − 到对方体表的距离）≥ `minDepthM` 0.42 m（轻击再深 0.06 m），且对方在这一刀正中线 ±0.42 rad 以内；刀尖擦过、砍在弧线边上的只是一道口子（记 `shallowCut`），照常让对方失衡、不用拔。卡住后双方进 `lodged`：人走不动、视角被拽回对方（`tetherRate`），第一人称刀定在砍进去那一帧发抖，**刀尖钉在对方身上那一点**（第四轮，用户：「固定在某一个点，例如肩膀，可以转视角，但刀砍的位置不动」）：卡住时在对方肩膀（上撩落在腰腹）、偏向刀来的那一侧记一个世界点（`lodge.anchor`），第一人称每帧把整副手臂连刀绕相机转到刀尖对准这一点（`Viewmodel._LockLodgeToWorld`，在刀架父节点局部空间里对齐方向，避开视图模型根节点的非等比缩放），视角不再被拽回，随便转头刀都扎在原处，直到 F 拔出来。**拔刀不是 QTE**（用户第三轮）：屏幕中间一个圈（HUD 的按键提示环，与屋内伏击同一个，`MeleeCombatDirector.PromptView()` → `Script_FrameStepsPresent`），中间写 F；长按 F `holdS` 0.8 s 把圈走满就拔出来，中途松手按 `decayPerS` 往回退；左键、S、晃鼠标都不算。没有时限 —— 对方挨了这一刀动不了，刀不拔就一直卡着。拔出来（`yank`，0.36 s 顺着刀路往回抽、甩一蓬血）→ 对方 `reel` 踉跄 2.4 s：往后倒退、左右打晃、Hit / Pushed 交替；这段里挨上任何一刀都是补刀（致死），松开 F 再按一次就自动转身、抢上一步补一刀（拔刀时一直按着的那下不算）。一刀砍死的照样劈穿；卡着刀时挨打会松手；刺刀不卡。
- **拖拽挥砍（control `drag`）**：用户第二轮否了「甩一下选方向再点」那套（太不好操控），要「鼠标左键点住然后滑移，可以快速砍下去」。按住左键进拖刀架势（`aim`）：刀举在蓄力顶点，整副手臂连刀跟着鼠标偏出去（最多 14 cm）；**视角也跟着转，但只跟一部分**（用户第三轮：刀走一整步、视角走大约一半）—— 比例 `viewFollow` 默认 0.5，面板「玩法」组有滑条 0–100% 自己调（网址 `?meleeViewFollow=0.5` 也行），实验场插件按它缩放按住左键这几帧的转视角。鼠标一甩（最近 0.1 s 走过 ≥ 60 px、最快那一帧 ≥ 1200 px/s）刀就顺着这一甩的方向砍下去，起手只剩 0.1 s（甩本身就是起手），甩得越快越重（伤害 ×0.85 → ×1.3）。往下甩是竖劈（更重、收招长），左右甩是横扫，斜着甩是斜劈 / 上撩，共八个来向，由一条实拍刀轨组合：倒放（上撩）、左右镜像整副手臂（从左边来的几刀）、绕视线滚转 ±45°。屏幕上不画方向轮盘（第三轮撤了）。砍完左键还按着就回到拖刀架势接着甩，松开回警戒；右键随时拨挡。**点一下也出刀**（第四轮，用户：连点左键好几刀出不来）：按下到松开不到 `tapS` 0.22 s、没甩出刀的，刀架偏出去了就顺着偏的方向、否则右上斜劈，力道最轻一档；出刀中再点排进缓冲，这一刀收完马上接下一刀。
- **吃肉顿刀 · 拖刃拉豁（impact `cleave`）**：解决大刀砍中人体像切空气、对手只原地播特效的问题。大刀命中活体瞬间进入 `cleave`（0.36 s）：第一人称刀身按 `MELEE_CLEAVE.crawlN` 极慢阻尼嵌入躯干锚点并震颤，相机给 FOV 压近与顺刃侧倾冲击，对手同步进入 `cleaved` 双向咬合僵直；屏幕中央亮出绯红提示环「拉豁」，窗口内**顺势甩动鼠标（≥42 px）或再点一次左键**即触发 `rip`（拖刃拉豁）：刀身加速撕出伤口，追加重创与失衡，爆出顺着刀刃出口切向的动脉血雾、骨裂与撕布声，并把对手身体沿刀刃切向横扯出去。若不补输入则咬合结束后自然滑出收刀，不断连招。
- **磕枪顺刃 · 压杆劈杀（impact `slide`）**：把二十九军破锋大刀破三八式长刺刀做成三维武器咬合交互。右键迎击对方出刺／挺枪（或挥刀撞上对方突刺窗口）时，刀口不简单弹开，而是直接架锁在日军三八式枪管上进入 `sliding`（1.45 s），枪管交点爆出钢火与金铁声，第一人称大刀实时钉在枪管世界锚点上。此时**按住 W（或前推鼠标）**即可压着刀口沿三八式枪管向护手与咽喉推进，玩家同步欺身踏进刺刀死角、连续擦出钢火与刮铁声；推进过 `strikeMinProgress`（42%）后中央环变为绯红「左键」，**点击左键（或一路推到底）**即顺杆削劈咽喉／锁骨（`slideSlash`）一击必杀；超时不推则双方挣脱弹开。
- **横枪硬接 · 震断破防（impact `crush`）**：正面 ±35° 戒备的日军不再站桩吃刀播血花，而是横起三八式硬接大刀（`guardBlock`）：交点迸出钢火与护木碎屑、响起磕枪裂木声，对手被大刀震退、上身与双臂受骨骼弹簧冲击后仰，护枪架势（`guardPoise`）按轻重劈削减；玩家刀身短促弹震（`guardBounce`，期间可立即缓冲衔接下一刀连砸）。**侧移绕到日军侧翼出刀可直接绕过护枪砍进血肉**；正面重劈或连砍把护枪架势清零即震断破防（`guardCrush` → `crushed` 1.95 s），中央亮出绯红「F」处决环，按 F（或补任意一刀）自动抢步转身劈杀（`crushFinish`）。
- **破锋全开 · 三合一（impact `pofeng`）**：在同一场对决中同时开启「横枪硬接破防 ＋ 磕枪顺刃压杆 ＋ 吃肉顿刀拉豁」三套特色白刃交互及挥刀重量／磕墙火星反馈。所有新增变体仅在 `?melee=1` 实验场内启用，正片白刃层保持 `classic` 不变。
- 取证口 `Debug.MeleeCombat` 的 `SetVariant({control, impact})` 支持 `impact: "classic" | "lodge" | "cleave" | "slide" | "crush" | "pofeng"`；`State()` 新增 `cleave`、`slide`、`enemyGuard`，`stats` 新增 `cleaves / rips / slides / slideSlashes / guardBlocks / guardCrushes / crushFinishes`。验收：`Script_MeleeCombatTest`（68 项纯 Node 规则）与 `Script_MeleeLabVariantsBrowserTest`（含全部变体及 `pofeng + drag` 组合实机操作，`--shots` 出图到 `tmp/DadaoLab/shots`）。
