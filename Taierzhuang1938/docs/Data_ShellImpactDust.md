# 落地扬尘：贴着地形的尘（2026-10-20 起）

用户要求（2026-10-20）：炮弹、炸弹、手榴弹落地扬起的尘土，**起始形态要和壕沟形状一致**（沟里炸，尘顺着沟走、从沟里冒出来），
之后升起、随风飘散；形态不对等于白做。参考是一部纪录片里炮击阵地的镜头（炸点中间一团压低铺开的黑褐尘，
把后面的碉堡整个挡住，旧的尘还没散新的又来）。测试场景见 [炮击扬尘测试场](Data_ShellImpactRange.md)。

2026-10-21 用户补充（附图：炸点外一个黄圈 + 沟沿、土垄上的红点）：**除了炮弹本身的烟尘，炸点半径以内的地面会被震起一层
很细的浮土**，开始时形状和地面一致（沟沿、土垄这些边上起得多），之后慢慢散开 —— 不是炮弹炸出来的土，是震动掀起来的细尘。
于是一团落地扬尘由三份组成：

| 部分 | 是什么 | 长什么样 |
| --- | --- | --- |
| 土柱 + 弹道土 | 炮弹炸出来的黑褐土 | 竖直冲起、矮胖的一团，几条弹道土柱往外甩，部分塌下来 |
| 贴地尘浪 | 炸出来的土尘贴地往外滚 | 沟里炸顺着沟走、拐过折角；平地上一圈往外滚 |
| 震起的细尘 | 冲击波扫过时地面浮土被震起来 | 炸点半径内一层很薄、透明、颗粒细的土黄色薄纱，底面贴着地形，沟沿 / 土垄顶 / 沟壁起得多，慢慢变厚、离地、晕开、随风飘、变淡 |

## 为什么不用原来的土尘体积

原来炮弹落地播一份预烘的流体序列（`DustImpact`，JangaFX CC0）。它是死的：炸在沟里、沟沿、空地上长得一模一样，
4.7 秒就散（测试场的「新 / 旧扬尘」A/B 开关能直接对比：旧路径在同一机位只有一小团）。新做法让尘「知道」脚下的地形：
每次落点在炸点周围铺一张局部网格（格距约 0.42 m，N 48–96），跑一个很便宜的模型，再沿视线积分画出来。

## 模型（`Script_DustFlow.mjs`，纯 JS，零 three）

| 层 | 网格 | 状态 | 做什么 |
| --- | --- | --- | --- |
| 贴地尘浪 | 跟地面固定 | 厚度 H、光学深度 Sg、新鲜度、交错网格面速度 | 爆风推、按尘面高低往低处流、被墙挡、卷吸变厚、被卷起、落回地面 |
| 悬浮尘云 | 跟着风平移，2.5 s 后整体缓慢胀大 | 每格一段竖直的尘：光学量 M、底 Zb、顶 Zt、上升速度 R、新鲜度 | 土柱冲高、上下扩、水平扩散、随风飘、落掉、褪色 |
| 震起的细尘 | 跟着风平移（0.8 s 起） | 每格一份竖直光学深度 K；厚度 / 离地高度全场一个数 | 冲击波扫到才出现，变淡、晕开、随风飘 |

**贴地尘浪的爆风按「沿沟路程」走**：从炸点出发，只走爆风平着能过去的低处（沟底与坡脚，比炸点地面高不过 0.35 m + 0.5·弹坑半径），
Dijkstra 算每格的路程 D。爆风方向 = D 增加的方向，大小按路程衰减；比直线多绕出来的路按 0.8 倍记入衰减。
平地上 D 就是直线距离（一圈往外）；沟里炸，爆风顺着沟走、拐过折角（护墙挡掉大半，余下的拐过去），
不会把尘一路推上沟壁 —— 漫出沟沿的那部分来自土柱回落与卷起，而不是爆风。
被夹住时：按 48 个方向从炸点平着量通畅长度，得出「被夹住的比例」；爆风变强（`boost` 上限 2.6）、衰减变慢、持续更久，
土柱更高更窄，源头的堆尘上限压低（让尘先顺沟走）。

其余规则：
- **墙的规则只有一条**：尘面没有高过邻格地面，就过不去。尘灌进沟、顺沟淌，被抛土垄挡住，坡上往下流。
- 爆风只推不刹、但**推不上坡**：下游尘面比上游高出半米、或下游已堆到七成封顶厚度，就不再往里推；贴地层厚度封顶
  （挤成一堆的尘变浓、不变高）。不加这几条，路程场的死角会把尘一格格挤成三十多米高的一根细柱（画面上是一根黑丝）。
- **土柱回落**：0.32–1.5 s 里土柱 42% 的光学量落回炸点附近变成尘浪；沟里炸多半落回沟里。
- **斜着砸进去的弹**（Combat 把弹的速度传进来；测试场的手榴弹 / 航弹也传了命中速度）：爆风、源头注入、弹道土柱都往下游偏。
- **新鲜度**只管颜色：刚掀起的湿黄土 + 炸药烟是黑褐（参考图最黑的核心），5.5 s 时间常数褪成灰褐。震起的细尘是地表浮土，不算新鲜。
- **震起的细尘**：半径 15·∛W（75 mm 约 14 m），外沿按方向起伏（花瓣形）；中间多、边上少；坡陡处 ×(1 + 1.1·坡度)、
  凸起处（沟沿、土垄顶、坑沿）×(1 + 2.4·凸度) —— 一开始这层尘把地形轮廓描出来。冲击波 160 m/s 从炸点扫出去，扫到才出现。
  厚度 0.3 m 起、头一秒涨 0.9 m、之后每秒 0.12 m；0.6 s 起每秒离地 0.14 m；变淡时间常数 10 s。
- 网格在建立后的第一次推进才采地面：那时弹坑已经挖好（`Combat.Blast` 先画特效再挖坑）。
- 尺度全按装药立方根（Hopkinson–Cranz，与 `Data_AerialBombs` 同律）；装药取 `Data_Explosives.fillingKg`
  （本轮新加 105 / 150 mm 榴弹与 50 / 250 kg 航弹四条，前两条按 75 mm 的装填比估算，已在表里注明是估值）。
- 模拟开销（node、本机负载高时的中位数）：每团每帧 0.2–0.8 ms，250 kg 航弹后期约 1.6 ms。

数值全在 `Data_Tuning_GroundImpact.mjs`（`GROUND_IMPACT_DUST`、`GROUND_IMPACT_SURFACES`、`GROUND_IMPACT_RENDER`）。

## 画面（`Script_DustFieldRenderer.mjs`）

每团尘一个世界坐标包围盒（画背面、不做深度测试，相机进到尘里照样画），片元里从相机打射线进盒子，按预通道深度截断，逐步累加。

- **炮弹本身的尘**（贴地尘浪 + 悬浮尘云）：消光 σ = 光学深度 / 厚度 × 竖直剖面。网格按光学量预乘上传，线性过滤时底 / 顶 / 新鲜度
  按尘量加权；密度采样前格内坐标过 smoothstep（地面高用普通双线性 —— smoothstep 在坡上会变成台阶）。
  采样坐标先做三维扭曲，再按「水平集」定团块：覆盖度 c = 1 − exp(−6σ) 加卷团 / 细节噪声后过 0.5 的阈值，阈值以内按
  σ + 0.8·c 算 —— 边界清楚、里面实心的一坨一坨；团块以外再留 0.45 倍的柔和残尘（散开后慢慢变成一层灰蒙蒙）。
- **震起的细尘**：不扭曲、不过团块阈值，底面贴着这一处的地面（+ 离地高度），顶面跟着大缕起伏；斑驳用固定米制尺度
  （三层噪声，约 1.5 m / 0.4 m / 0.15 m，随时间往上飘），叠一层沿半径拉长的放射条纹；颜色是浅一点的土色，前向散射弱（0.12），
  光学深度比炮弹本身的尘小一个量级 —— 薄、透、颗粒细，透过它看得见地面。
- 步长按射线在盒子里的长度定（高画质 0.42 m×√∛W，上限 120 步），空处两步并一步；在细尘层和贴地尘浪那一层附近自动加密。
- 尘层下沿伸到网格地面以下，真正的接地线由预通道深度（真实地形）切，贴地处按 0.45 m 软过渡。
- 受光照抄体积粒子：朝太阳几步遮光、HG 前向散射、二阶散射近似、天光 + 暖色地面反光（背光面是暖灰，不是蓝灰剪影）。
- 输出预乘颜色 + 透过率，保留目标 alpha；不进预通道；同屏最多 10 团，超出的最老一团提前淡出。
- GPU：测试场 75 mm 1.5 s、34 m 机位同页交替开关 6 轮，开 8.69 / 关 9.28 ms（各 54 帧中位数）—— 本机被别的会话占着，
  ±2 ms 内量不出差别，不能据此说「免费」；近景铺满屏幕时更贵，需在空闲机器上补测。

## 接口

```js
vfx.SetGroundSampler((x, z) => battlefield.GroundHeight(x, z)); // 含弹坑形变
vfx.SetGroundImpactDust(true);   // 打开的那一刻生成噪声；关卡用 phase.groundImpactDust 驱动
vfx.GroundImpact(position, { chargeKg: 0.81, incoming: shellVelocity, groundY, surface: "loess", massScale: 1 });
vfx.ClearGroundImpacts();
vfx.dustFields.Inspect();        // 每团的网格、夹住比例、土柱高、三份光学量、细尘半径
```

开着时 `Vfx.Explosion` 对落在地上的爆炸（离地不超过该弹 `groundReachM`）自动走 `GroundImpact`，不再播 `DustImpact` 体积与贴地尘环；
闪光、点光、火星照旧，碎块换成按装药缩放的土块，弹道土柱用炮弹的外观（比航弹那套矮、团大、土色）。
`BombBlast`（第一关空袭）开着时整颗交给 `Explosion`。`Combat.Blast` 把 `explosiveId` 与 `options.incoming` 交给 `Explosion`。
没开的关卡逐位不变（目前只有测试场开）。

## 验收

- `node Taierzhuang1938/Script_DustFlowTest.mjs`（TestRunner tier0 / explosives 域）：合成锯齿壕沟上，沟里炸被夹住、0.4 s 时看得见的尘浪
  覆盖区顺沟 / 横向展开比 > 1.6、1 s 时 > 1.5，顺沟的尘远多于沟外；平地覆盖区是圆的、四向对称；斜砸下游多；
  不凭空造尘、逐位可复现、悬浮尘随风漂、会自己收工；250 kg 航弹网格不超预算。
- 画面：测试场里按时刻截图（本地取证脚本，截图留在已忽略的 `tmp/`），75 mm 打沟内直段三机位 × 0.1–12 s、
  各弹种 0.3 / 1.5 / 5 / 12 s。

## 还没做

- 尘不认碉堡、房子这类非地形障碍（只认高度场）；画面上由深度截断，模拟里会穿过去。
- 只有干黄土一种表面；湿泥 / 雪 / 砖石按 `GROUND_IMPACT_SURFACES` 同格式加。
- 每团一张局部网格；连续炮击时还没有把旧尘并成一张区域网格（「落区越打越朦」），也没接体积雾的局部雾体。
- 没有挡 AI 视线；正片（第一关）默认没开，开之前要过性能与「看得见敌人」两本账。
- 真实参考（高速摄影 / 纪录片）另一个会话在找，按参考再调形态与时间尺度。
