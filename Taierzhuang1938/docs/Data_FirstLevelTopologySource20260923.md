## 四个空间区（节选 A）

**A 前沿与后交通壕（01—06）**：掩蔽部遭炮击、后侧救援、沿仍由我方掌握的交通壕接应守军；03—05围绕同一个撤退缺口连续展开：03随班长推进夺取右侧阵位并接回第一批守军，04战车沿既知道路压进并重新封口，05从阵位后侧取弹、解除封锁、接回余队。02去03时先经过伤员集结处，05结束后再回06接后送命令。

## 敌军持续关系（与 01–05 相关）

- **炮兵：**场外持续存在。01造成掩蔽部坍塌，后续继续轰击其他阵地与村落；不会每阶段精准落在玩家脚边。
- **前沿步兵：**03—05沿北侧既有弹坑、土埂与破墙逐段接近，区分后方射击人员、前出进攻组和绕向土坎侧端的人员。03被老周与夺点后的玩家暂时压退；04在战车支援下继续接近；05仍受何有田及接防人员阻挡，不因玩家去取弹就停止行动，也不凭空出现在后沟。
- **右侧阵位守卫／伴随步兵：**03守卫破墙阵位及连接口；04伴随步兵从东北道路跟随战车进入；05其中少量人员从已知道路连接口切入支沟。去程被击倒的敌人不在返程原位复活。
- **战车：**03尾声在东北道路远段先有声音和车影，04驶出路弯，先压制右侧阵位正面射位、再前移封锁撤退缺口；05沿同一道路前移或停留射击。战车不瞬移、不跨阶段倒退、不全程精准追踪玩家。阵位可以局部受损，但后墙、土坡和下沉支沟保留实遮挡。

## 01—03局部空间与推进

01—02发生在同一段前沿交通壕与侧壁防炮洞，03从后交通壕折角转入前沿支沟，不换地图、不瞬移。

### 01｜防炮洞受困、先头兵突入

**防炮洞：**位于前沿交通壕侧壁，不是独立房屋。洞口直接连交通壕；顺子、幺娃等从这里准备向后交通壕撤离。
**炮击与塌方：**近失弹落在洞口外侧附近，造成洞口局部塌落和断木阻塞。顺子被震晕后留在洞内，汉阳造掉在洞口附近、处于可见但暂时够不到的位置。塌方只限制顺子，不把整条交通壕炸断。
**敌军来向：**日军先头兵沿前沟方向连续进入，前出人员继续向纵深推进，部分人员在洞口、岔口短暂停留。被炸晕的川军在洞口附近被日军拖起、审问并杀害。日军不能为了演出全部停在洞口，背景必须始终保留向前推进和交火。
**顺子位置：**玩家被断木和背包带卡在洞内低处，只能小幅观察；被发现后由日兵从洞口拖入交通壕边，直接进入02，不切换场景。

图 01 要点（比例尺 0–30 m）：防炮洞约 10×8 m 的土木洞室开在一条东西向交通壕的北侧壁；洞口朝东南，炮弹落点在洞口外侧；伤员（川军）倒在洞口外；汉阳造落在洞口内侧；传令兵自东沿前沟跑来；前沟（东侧）是日军突入方向，日军沿沟向西、再折向南进入内部壕沟纵深；后交通壕在洞室西南，计划撤退路线从洞口向西南。

### 02｜近身反扑、拾枪、撤入后交通壕

**审问位置：**就在01洞口外的交通壕边。顺子仍受爆炸和枪托影响，保持耳鸣、重影和失衡。前沟仍有日军推进，后交通壕方向仍由我方控制。
**救援来向：**罗班长、何有田从后交通壕折角沿沟贴近，不从敌军后方凭空出现。近处敌我人员混杂时使用四川大刀近身解决贴身日兵；刘文财等人在射线空开后才用步枪处理较远敌人，避免朝己方近战区域射击。
**还权位置：**罗班长将顺子拖入洞口塌土形成的短遮挡后，确认"还能打不？"后把顺子的汉阳造踢到手边。玩家在这里恢复移动、视角和武器操作。还权时前方敌人仍然存在，不以NPC先清空四名日兵为前提。
**撤离路线：**洞口塌方后 → 沟壁塌低段 → 完整土壁遮挡 → 后交通壕折角。玩家利用射击和同伴掩护通过短暴露段；日军沿原进攻方向追入，不从玩家退路刷出。越过折角后，地形切断近处直射，但另一侧仍能听见追兵和交火。

图 02 要点（比例尺 0–25 m）：塌陷地堡在东、审问位置在其南侧壕沟边、川军遗体旁；近处近战区在审问点西侧；还权（踢枪处）在近战区南侧；撤退路线自东向西约 45 m，途经「沟壁塌低段（短暂暴露）」与「完整土壁遮挡」，终点「后交通壕折角」在西端，折角再向南接后交通壕（我方控制）；罗班长/何有田自西南后交通壕沿折角向东接近；日军前沿部队自北侧前方战壕向南推进；刘文财等远射位在东南（待机射击）。

### 03｜从后交通壕回头接应前沿守军

**起点：**02结束于后交通壕折角及支沟交汇处。这里能看到伤员、担架和撤回人员，随后守军报告"东头丢了、西边机枪还在顶、前头的人下不来"。
**玩家转向：**罗班长带顺子从后交通壕转入通往前沿的支沟，目标不是重新冲回01洞口，而是前往被机枪火力封锁的前沿守军区域。
**固定关系：**后交通壕位于安全侧；支沟负责把玩家带向前沿；待撤守军位于前沿土坎南侧背坡；撤退缺口连接背坡与后交通壕；右侧敌军阵位控制缺口。玩家与班长沿右侧低沟、土坡和残墙接近阵位，避免直接走正面空地。
**03核心路线：**后交通壕交汇处 → 支沟 → 右侧低沟/连续遮挡 → 右侧机枪阵位 → 取得对撤退缺口和指定进攻组的射界。夺取阵位后再掩护第一批守军穿过缺口，实际进入后交通壕折角后的安全区。
**连续性：**01的日军推进、02的追兵与03前沿正面压力属于同一轮进攻，不应表现为三个互不相关的刷怪场景。01—02建立"敌军已经突入"，03把玩家从被动逃生转为主动回头接人。

图 03 要点（比例尺 0–100 m）：后交通壕在西侧南北走向，安全区在其北段折角后（伤员、担架）；后交通壕交汇处为 03 起点；支沟自交汇处向东约 90 m 呈锯齿（折角）走向，再转为右侧低沟向东北；右侧敌军阵位在支沟东端北侧、撤退缺口正南；撤退缺口向北连接前沿土坎南侧背坡（守军隐蔽位置），守军位置在东北、被弹坑与铁丝网包围。

## 03—05局部空间与推进

三阶段不换地图，玩家位置、阵位状态和敌军来路连续继承。

### 固定空间关系

统一以上北下南为文字方位：敌军从北面前沿与东北道路接近，我方后交通壕在南面，右侧阵位与取弹支沟在东侧。友军被困位置在前沿土坎的南侧背坡，不把友军摆到土坎敌侧后再要求其翻越迎敌。

| 位置 | 固定关系与用途 |
| --- | --- |
| 前沿土坎与背坡 | 正面敌军位于北侧；第一批和后续守军均已在这一片前沿，缩入南侧背坡后可避开正面直接射线。守军靠近撤口的先撤，远端守军随后收拢，不到04才生成第二批人。 |
| 撤退缺口 | 位于背坡至后交通壕的路线上，是塌浅沟段形成的一小段暴露通路。03由右侧机枪封锁，04被战车重新封锁；05打开的仍是这一个缺口。缺口前有供余队停留的最后遮挡。 |
| 后交通壕与安全区 | 在南面。安全区设在壕内折角后，须能挡住当前敌军直射，并继续连接06背坡集结处。刚跑到沟口不算接回。 |
| 左前侧机枪位 | 在己方后交通壕左前侧，可沿己方沟道进出。通过侧向位置或地势取得对正面接近路线的射界，不能画成隔着完整土坎穿墙射击。03由老周操作，03尾声至04由何有田接替。 |
| 右侧机枪阵位 | 在撤口右侧、道路西侧。03先由敌军占领，玩家与班长沿右侧低沟接近并夺取。夺点后应能观察撤口、正面指定进攻组与道路来敌；机枪须有可用转向或另设射位，不能夺下后仍只能对着友军。 |
| 阵位后墙与支沟岔口 | 紧贴右侧阵位南侧，是04短撤的终点、05取弹的起点。后墙、土坡和下沉沟道提供实遮挡；战车并未把整个阵位夷为平地。 |
| 旧弹药屋 | 在右侧阵位东南后侧的旧院内，仍位于道路西侧，由院墙与土坡隔开。经后侧支沟从屋后进入，不要求横穿敌军道路，不再另设一个北侧弹药屋。 |
| 道路旁攻击位置 | 位于右侧阵位邻近、道路西侧的低沟或残墙后，由已知岔口转入。与旧弹药屋不是同一点，也不是原机枪射口。去程已能辨认入口，取弹后返回岔口再进入，不临时生成新通道。 |
| 战车道路 | 从东北远段经右前方路弯进入。战车沿道路绕至前沿土坎的右侧端，才逐步取得对阵位及缺口的射界；白盒须实际验证遮挡，不能靠一个覆盖整片地图的火力扇形替代。 |

**三条路线不混用：**守军走"前沿背坡→撤退缺口→后交通壕安全区"；战车走"东北道路远段→路弯→压口位置"；玩家与班长走"后交通壕→右侧低沟→右侧阵位→阵位后侧支沟→旧弹药屋→返回岔口→道路旁攻击位置→沿支沟撤回后交通壕"。取弹支沟不直接连通被困守军所在背坡，不能变成绕开撤口的免费撤退捷径。

### 03｜推进夺点，打开第一次撤离窗口

**玩家与班长：**从后交通壕沿右侧低沟、土坡和残墙推进，清除阵位守卫，实际占据右侧阵位。随后选择使用夺下的机枪或自己的步枪，协助老周打退正面指定进攻组。
**正面敌军：**从北侧遮挡逐段接近，进攻组试图逼近土坎侧端及撤口；受到左右火力后，剩余人员退入遮挡或暂缓前进。不要求杀光全场，不把正面演成一排永远站着的靶子。
**守军与留守人员：**第一批先在背坡等待，封锁解除后穿过同一缺口，进入后交通壕折角后。后续守军仍在原有前沿位置，不凭空新增。老周的腿伤在03开始已可见；第一批撤回后，何有田沿己方沟道接枪，幺娃与搬运人员扶老周撤往06，玩家不回左侧重复接枪。
**进入04：**玩家和班长留在右侧阵位；战车的声音与车影已在东北道路远段出现，但尚未封住缺口。老周撤下与战车逼近是连续进展，不是04突然同时触发的两段新演出。

图 03 阶段鸟瞰要点：前沿土坎（沙袋）东西横贯画面中上部，背坡南侧是第一批守军；正面敌军从北侧大片弹坑、铁丝网、残墙逐段推进（多路箭头）；撤退缺口在土坎中段偏东，守军撤退路线由此向南蜿蜒到我方后交通壕；老周机枪位在西南，扇面朝东北压制正面；右侧机枪阵地在东侧残墙院落（道路西侧），扇面朝西压缺口；班长+玩家推进路线自后交通壕东端向北沿残墙到阵地；道路在最东侧南北走向。

### 04｜战车压制射位，重新封住撤口

**战车与敌军：**战车由已露面的道路远段驶出路弯，伴随步兵沿道路边缘跟进；先攻击开火中的右侧阵位，随后向前挪动，取得对缺口的射界。正面敌军借支援继续接近，但仍受何有田及留守人员阻挡；不要把进攻箭头等同于已经突破整个前沿。
**玩家与班长：**先在03夺下的阵位继续对抗步兵，再被战车火力逼离正面射口。班长带玩家短撤至本阵位后墙，不重置回03的起点，不穿越正面空地。正面射位暂时难用，后墙和支沟仍可通行。
**守军与留守人员：**后续守军从原位置收拢至缺口前最后遮挡，因封锁停下。何有田保持左侧火力，文财看住后交通壕入口，幺娃照看已撤下的老周。何有田负责阻止步兵逼近，不是让战车无限转头的诱饵。
**进入05：**班长从后侧遮挡确认旧弹药屋方向与可通的支沟，安排留守分工，带玩家出发；取弹行动来自"刚夺下的阵位已不能保障撤退"，不是凭空插入跑腿任务。

图 04 阶段鸟瞰要点：战车沿东侧道路自北南下，停在右侧阵位东北、道路上，火力封锁区扇面向西覆盖撤退缺口；敌军步兵沿道路两侧伴随推进；后续守军停在土坎背坡；右侧阵位（已夺下但正面射位被压制），玩家+班长从阵位向南后撤到阵位后侧，再沿「通往弹药屋的支沟」向东南；老周从西南机枪位撤下进入后交通壕。

### 05｜沿支沟取弹，解除封锁后接回余队

**去程：**从04结束的阵位后墙出发，沿既有支沟绕到旧弹药屋后侧。受损沟段要求降低姿态，是因为上方存在直射威胁；不是无意义的强制匍匐。道路观察口让玩家看见同一辆战车的位置变化。
**敌军动向：**正面进攻继续由何有田和留守人员应对；道路伴随步兵中的少量人员从可辨认的连接口切入支沟，成为玩家近处的交战对象。敌人必须有来路；不在脸前生成，不在返程复活去程敌人。
**取弹与返程：**玩家取得集束弹后，沿原支沟返回已知岔口，再跟班长转入道路旁的遮蔽攻击位置。此时战车仍在同一道路前移或停留射击，不能从04的近处位置突然退回远端。
**攻击与撤离：**班长带路并照应近处敌兵，玩家完成游戏内攻击并退回遮挡。战车不能继续推进且缺口有效火力中断后，再处理仍直接封路的步兵，放行余队。正面敌军不会全体消失；留下的友军继续阻止其突破，为撤退争取时间。
**收束：**剩余存活守军实际进入同一安全区。玩家与班长从攻击位置沿短支沟退至阵位后侧，接回后交通壕；接防人员从己方后方沿沟到位，接替留守人员，小队回到06集结处。不沿敌军道路撤退，不横穿正面空地。

图 05 阶段鸟瞰要点：弹药屋在东南角院落内；取弹路线自右侧阵位后侧向南沿支沟（后侧通道）到弹药屋，返程回到阵位后侧，再向东北「转入道路侧攻击位置」；战车停在阵位东北的道路上被集束手榴弹炸停；剩余守军沿缺口撤回；何有田在西南机枪位掩护步兵。

### 触发与完成判定

**夺点不等于接回。** 03先确认阵位直接威胁解除且我方实际占据，再转入掩护。第一版白盒采用"指定进攻组击杀阈值达到＋撤路直接火力已解除＋路径可通行"启动第一批撤退；玩家和NPC击杀均计入，具体阈值待白盒测试确定，不凭图上的人数定数值。
**开始跑不等于阶段完成。** 每一批均以所有仍存活人员实际进入后交通壕折角后的安全区为接回结果，且至少一人活着接回；整批阵亡不能以"没有剩余人员"误判完成。途中重新出现封锁时，未出发者留在遮挡内，已出发者转入最近遮挡，不在空地停住等计时器。
**停驶不等于解围。** 05须同时检查战车无法继续推进、撤口有效封锁已经解除；武器仍能扫射撤路，或步兵仍直接控制缺口时，不放行。解除的是这条撤路的直接威胁，不是要求整个正面清场。
**空间与玩法待白盒验收。** 接近路线须有连续可用遮挡，必要交战目标须在玩家可识别和有效射击的距离内，攻击位置须符合游戏内投掷与退避空间；上述条件尚未由实际游戏坐标验证。敌军推进趋势、实际位置与射界分别检查，不能用箭头代替碰撞、地形和视线测试。
