# 操作交互测试场（现状）

入口：主菜单 → 选择章节 → 测试场景 → 操作交互测试场，或 `?movement=1`。
这是永久的玩法测试场景，复用正式 PlayerController、输入、动画和 Rapier 碰撞。场景没有敌军、不自动换关，也不覆盖正式存档进度。

## 五区与标尺

- 跳跃高度：原地起跳区、按米标注的低障碍、每 0.1 m 的竖尺。原地与满助跑的抛物线参考由 `PlayerMovementReference()` 读取当前跳跃常量；红线读 `TRAVERSAL.jumpRiseMax`。参考值不等同于离散物理步进的实测峰值。
- 助跑跳远：14 m 助跑段、8 m 测距段，0.25 m 小刻度与 0.5 m 数字标尺。0 m 是可见起跳参考线；成绩从实际起跳点量到实际落点。会话最佳黄线从 0 m 投影该距离，不要求玩家恰在 0 m 起跳。
- 翻越／攀爬：包含 `vaultMin`、`vaultMax`、`mantleMax` 及超限对照，牌上写实体净高。橙色为翻越、紫色为攀爬、红色为超限。翻越／攀爬水平位移也读取通行表。
- 蹲起移动：不同净空的长通道，测进入、退出、前后左右移动和低顶下起身。
- 匍匐移动：更低的净空通道，测正常／快速匍匐和姿态转换。净空标的是可见顶板底面，不把眼高当碰撞体高度；窄档用于发现当前胶囊尺寸的边界。

`Space` 沿用正式分流：低姿态先站起；站姿先尝试翻越／攀爬，再跳跃。提前起跳才能测纯跳障碍。低台阶可能被自动跨过，不能把它当跳跃成绩。

## 记录与复位

面板显示姿态、实际移速、体力、眼高、脚底高度，以及最近一次动作的脚底净抬高和水平起落点直线距离。原地／慢步跳、助跑跳、翻越、攀爬分别统计。纯跳完成并越过障碍前后表面，才记“跳过障碍”；攀爬的障碍净高与曲线峰值分开显示。

跑跳最远成绩只接受位于平地跑道、起落高度相同的标准移动样本，避免从高台往下跳、调试穿墙或加速污染成绩。正常体力消耗照常发生；成绩是当前会话测得的最佳值，不宣称穷尽所有按键时机后的数学极限。刷新页面后清空。

- `Home`：本区复位，使用正式 Spawn 恢复生命、体力并中止未完成测量。
- `PageUp / PageDown`：上／下一区。
- 面板提供工位按钮、复位与清空成绩；按住 Alt 可点击，指针锁定时可用快捷键。
- `Esc`：暂停菜单，选择“退出操作测试场”返回正式菜单。

`Debug.MovementRange` 提供 `State / Fixtures / Stations / GoTo / Reset / Clear`。`GoTo` 支持工位或障碍 id，便于后续定向自动化；它只摆测试起点，不替代正式动作判定。

## 维护与验收

布局与实体尺寸在 `Data_MovementRange.mjs`；合批几何、碰撞与标尺在 `Script_MovementRangeField.mjs`；测量和局部 HUD 在 `Script_MovementRange.mjs`。新增操作迭代在同一场复测，标尺从正式参数取值。实际测试场随游戏交付，验收截图与记录仅存本地 `_shots/MovementRange/`。

`node Taierzhuang1938/Script_TestRunner.mjs --only=MovementRangeTest` 验证实际按键、场景隔离、标尺对应的碰撞尺寸、跳跃／跑跳区别、翻越与攀爬上限、超限墙、蹲行／匍匐通道、站起不跳、复位及士兵不会自动补入。既有 JumpTest、StanceTest、PhysicsTest 继续守正式控制器。
