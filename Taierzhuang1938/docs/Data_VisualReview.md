# 视觉审查评分表（对标 Easy Red 2 / 3A FPS）

审查 agent 的唯一输入是 `Taierzhuang1938/_shots/` 里的 PNG（1600×900，固定机位、固定帧数，
由 `node Taierzhuang1938/Script_ShotTest.mjs` 生成）。**只看截图打分，不看代码找借口。**

评分：每项 0—5。
- 0 = 完全没做
- 1 = 做了但错了（比 不做 还糟）
- 2 = 勉强能看出意图
- 3 = 合格，网页 demo 的水准
- 4 = 接近 Easy Red 2
- 5 = 达到或超过 Easy Red 2

**目标线：全部项 ≥ 4，且加权总分 ≥ 85%。** 没到就继续迭代。

## A 组 · 光照与大气（权重 ×2）

| # | 项 | 怎么在截图上验 |
|---|---|---|
| A1 | 接触阴影贴根 | 沙包/墙角/人腿与地面的交线处应有 3—10 px 由深到浅的暗带，随几何弯折。整墙均匀发灰 = 半径太大；完全没有 = AO 没注入或注到了直接光 |
| A2 | 背光面不死黑 | 完全背光的墙面/人物背部仍应能分辨砖缝、布料褶皱与偏冷的天光色，而不是一整块 RGB(8,8,8) |
| A3 | IBL 反弹光有颜色 | 阴影中朝上的面应更亮更偏冷（天空色）；屋檐下方、人物下巴应偏暖（地面反弹）。全场阴影同色 = 没挂 scene.environment |
| A4 | 三层大气纵深 | 沿视线取 <10 m / 30 m / 80 m+ 三组同材质：明度对比与饱和度应逐级下降，最远那组明显偏向天空色，明度差 ≥15% |
| A5 | 体积光柱被几何切断 | 门洞/断墙/屋顶缺口处应有锥形光束，且在被墙挡住的位置**干净地断掉**，断口与墙的轮廓一致。糊成一团 = 只是径向模糊 |
| A6 | 阴影软硬对 | 近景（<8 m）阴影过渡带 1—3 px，远景更宽。单像素锯齿或点阵 = 落到 SHADOWMAP_TYPE_BASIC 了 |
| A7 | 阴影无痤疮无彼得潘 | 斜面阳光区不应有条纹摩尔纹；柱子/人腿与地面接触处阴影不应脱开 |
| A8 | 天空有结构 | 天不许是一块纯色或纯白。应有云/烟的层次、太阳位置可读、地平线与天顶有可分辨的色相差。**一整片死白 = 不合格** |

## B 组 · 材质与表面（权重 ×1.5）

| # | 项 | 怎么在截图上验 |
|---|---|---|
| B1 | 凹凸来自高度场 | 侧向受光的砖墙/夯土墙，砖缝应有明确的受光侧亮/背光侧暗，方向与主光一致。只有颜色深浅 = 没有法线 |
| B2 | 没有纯色平面 | 转灰度后每个可见表面仍应有可读纹理，不是一片均匀灰 |
| B3 | 无肉眼可见的等距重复 | 沿长墙看：砖缝层厚与砖长应有抖动，不许精确等分；同一面墙找不到两块一样的破损 |
| B4 | 金属有方向性高光 | 刺刀刃/枪管/铁件的高光应沿长轴拉成带状，不是各向同性圆斑 |
| B5 | 地面远景不糊 | 沿地面向远处看，纹理应保持到中远景才消失，不该在中景就糊成均匀色（anisotropy） |
| B6 | 材质分得开 | 砖 / 夯土 / 瓦 / 木 / 布 / 钢 六种在同一张图里应能凭质感（不是凭颜色）分辨 |

## G 组 · 枪械近观（权重 ×1.5）

**这一组不看 `Script_ShotTest.mjs` 的正片截图，看 `node Taierzhuang1938/Script_WeaponShot.mjs`
出的枪械四宫格**（台架：正侧 / 俯视 / 四分之三 / 机匣特写；加 `--fp` 出第一人称那一份）。

为什么单开一组：正片截图里枪只占几十个像素，A—F 六组全给满分也验不到枪。
第 2 轮实机审查（用户直接截图反馈"很多面穿透，还不如纯色不给贴图"）里暴露出来的

拉机柄球头飞在机匣外、木纹拉成黑橙虎斑、编辑器第一人称那一栏只剩地面 ——

| # | 项 | 怎么在截图上验 |
|---|---|---|
| G1 | 零件之间没有缝 | 机匣特写里逐个接缝看：托与机匣、握把与机匣、弹匣与机匣、刀身与护手。看得见地面 = 飘着；一闪一闪 = 共面。构建期 `TzmCore.AuditSolid` 已经卡住大部分，但斜着插的细杆它抓不到 |

### 已知未修（看到别重复报）

- **细杆在亮天空前被辉光吃掉**：大刀刀身（厚 5 mm）、枪管、两脚架腿在天空背景前会
  整段泛白，地平线以下又变回黑，接缝正好落在背景的地平线上。已验明是 bloom：
  把 `Script_Post` 的 `bloom` 强度临时改成 0，同一帧刀身就是均匀的暗色。
  根因是**天空本身整体高于 bloom 阈值**（`bloomThreshold` 默认 1.18），
  于是整片天在发光，任何比光晕半径细的深色物体都会被糊掉。
  改的是 `Script_Main` 传给 `post.Render` 的 `bloomThreshold`（往上抬到天空亮度之上，
  只让太阳盘/枪焰/火发光），**这会动全场观感**，属于 C 组的事，不要在 G 组里顺手改。

## 输出格式（审查 agent 必须照此返回）

对每一张截图分别打分，然后给一份总表。**最后必须给出「本轮最该改的五件事」**，
每件写清楚：改哪个文件的哪个参数/加什么、期望画面上出现什么变化、为什么这一条比别的更值。

不要写"可以适当增强"这种话。要写"`SKY_PRESETS.burningStreet.horizon` 从 `[2.70,1.62,0.86]`
降到 `[1.35,0.95,0.62]`，天空就不会糊成一片白，屋脊的轮廓线才能读出来"。

**不许给分数注水。** 这份表存在的意义是找出差距，不是让人高兴。
如果某一项在所有截图里都是 2 分，就写 2 分。
