## 3. 离 3A 配乐沉浸感还差什么

按影响从大到小：

1. **不是可交互的分层配乐。** COD / 战地的战斗曲是分轨（鼓 / 低音 / 弦 / 铜管）或分段，按战况加减层、按小节切段。我们是整首 90–120 s 立体声文件循环，战况只能改总音量（03–05 按战斗强度压到 0.45 倍）。补法：用分轨分离（Demucs 一类）把战斗曲拆成鼓 / 低音 / 其他三轨，强度驱动层，不必重新生成。
2. **切换不对拍、没有尾音。** 换曲是 1.6 s 交叉淡，不管拍子；3A 在小节线上切，并在停乐时放一个尾音（tail）或标点（stinger）。补法：每首记 BPM 与小节起点，切换排到下一个小节；每首配 1–2 条 3–6 s 的收尾。
3. **剧情曲循环会掉坑**（§1 首尾差 +18 … +35 dB）。新方案十首已经按「首尾同一能量」生成；若保留现行曲，至少要切出可循环的中段。
4. **同一首用太多次。** 「交火前沿」6 步、「钢铁围攻」5 步；一关真人 45–55 min，90 s 的循环会被听二三十遍。新方案每首最多 5 处，且多数是床。
5. **没有贯穿的主题。** 九首各自生成，调性（D 小 / E 小 / F 大）、配器、混响都不统一；「D—A—F—E」写在提示词里，模型未必照做。3A 有一条从开场到结尾反复变形的主题（战地的四音、COD4 的 Main Theme）。新方案用统一的声音签名 + 动机残片→完整陈述的安排，但 AI 生成仍不保证动机一致——要么人工挑 take，要么请作曲做主题、AI 只做铺底。
6. **没有音乐标点。** 关卡开场、目标完成、玩家倒下 / 重来、关卡结束都没有 stinger（Complete 直接停）。03–05 的两个「标点」只是把电平抬到 1.15 倍，不是音乐事件。
7. **缺地域与年代识别度。** 现行提示词都写「汉斯·季默风格」，出来是通用预告片管弦。COD5 太平洋战役用太鼓 / 尺八，战地 1 用失真弦乐，一听就知道是哪部戏。新方案定了「大堂鼓 + 低音埙 + 失真低弦」，但 SeedAudio 对民族乐器不稳（Data_MusicSources：二胡两次都出成弹拨），要试听确认。
8. **战场里的「乐器」没用上。** 日军冲锋号、国军军号、远处的锣——这些是场景里的声音，但在 COD5 / 战地 1 里是沉浸感的主力之一。
9. **混音口径粗。** 只统一了 RMS，不是 LUFS；112 kbps MP3；对白让位是整条音乐压音量（配乐组 −7.5 dB + 对白侧链 −6 dB），不按频段让——3A 常只挖掉人声所在的 1–4 kHz，配乐的低频与氛围不受影响。2026-09-27 实测配乐 p90 仍比远处的仗高几 dB。
10. **AI 生成本身的质感**：高频发糊、瞬态偏软、偶有不该有的结构（突然停拍、渐强渐弱）。这一条只能靠多掷挑选或换真人作曲 / 采样库编曲解决。

## 5. 拍板后怎么接进游戏

1. 不满意的曲子改提示词（`Data_FirstLevelScoreRedesign.SCORE_REDESIGN_CUES`）后 `--only=<Id> --force` 重掷；`Script_FirstLevelScoreRedesignTest` 会拦住「提示词改了但文件没重掷」。
2. 定稿后把选中的曲子并进 `Data_FirstLevelMissionMusic`（`FIRST_LEVEL_MUSIC_CUES` + `FIRST_LEVEL_STAGE_MUSIC`，步骤级；关键帧级的差别——如 05-4 静、06-1 静、10-2 静——要落到对应的事实门上，不是阶段表能表达的），更新 `Script_FirstLevelMissionMusicTest` 的曲目数与清单校验、`docs/Data_FirstLevelMusic.md`，再跑 `FirstLevelMissionMusicBrowserTest`。
3. §3 的 1、2、6 是引擎侧工作（分层、对拍切换、标点），与换曲独立，建议单独立项。
