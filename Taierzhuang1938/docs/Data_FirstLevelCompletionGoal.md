# 第一关完整白盒 Goal

按[当前第一关设计](https://app.notion.com/p/3d360335331c81ea86f6f637ab92327c)实施。正式入口为 `?whitebox=p012`。按用户补充，Notion 仅作需求来源，不继续写入。

## 达成条件

- 从军列开场到城边撤出完整通过 25 个运行阶段；使用移动、射击、投掷、白刃、搬运和交互，通关过程中不改写敌军生命、任务事实或玩家位置。
- 敌军实际推进、开火、受压退缩和侧翼运动；原车厢援兵沿联络壕进入阵地，原前沿守军实际撤回。
- 战车推进并停驶射击，集束爆炸实际炸停履带；两次投掷失误后可以原地补给重试。
- 保留 20 副担架、36 名轻伤员、14 名医护、8 名平民；排队、医护检查、抬上车辆、驶离和下一车入位均使用连续位置。
- 空袭破坏已运行的运输；担架员伤亡后由实际医护/平民走到把手接替。伤亡人数变化不能留下等待不存在乘员的条件；接收院与最终撤出同样处理接替。
- 军列下车、机枪掩护、炸车、村战、院门、转运、两次搬运、三段断后和最后撤出均有实体路线及操作反馈。路口、掩体、装载点和地表分区能从人物视角辨认。
- 南行 1–2 分钟、村后过渡 30–60 秒、转运防御 2–4 分钟、扑沟限控 2 秒、死亡限控 8–12 秒按事件时间验证。30–40 分钟为普通玩家体验目标；脚本的理想路径时长单独记录，不用空等补时。
- 相关快测、整关浏览器回归、关键段常速观察、画面和渲染预算检查通过；发布前修复所有本轮已复现阻断。
- 更新模块缓存戳，合入 master，并核对 Pages 对应部署与线上版本。

## 迭代规则

1. 保留失败现场，先定位事实门、人物/车辆位置、生命和交互状态。
2. 修复真实行为与碰撞；不以删除事实条件、复活普通伤亡者或自动完成任务解决卡关。
3. 复测原失败路径，并补正常玩家可能遇到的恢复路径；有可见改动必须审看实际画面。
4. 区分纯规则测试、脚本步进通关和常速运行；不把这些结果互相替代。
5. 源码和验收脚本提交；截图、日志及预览只保存在本地忽略目录。
