# 测试场景角色光照基准

枪械射击白盒、玩法靶场、爆炸场、白刃战实验场和 P0/P1/P2 白盒统一使用 `Script_Sky.mjs` 的 `TEST_SCENE_DAY`，入口名为 `testSceneDay`。旧的 `weaponRangeDay` / `p012WhiteboxDay` 调试名称指向同一对象，不再维护独立参数。正片和过场仍使用各自时段预设。

该基准采用固定世界方向的日光主光、中性环境底光和 Global SH 天光。太阳从射击线一侧照向靶子；背光面仍能辨认脸、军服和装备。曝光、对比度、饱和度、雾和泛光一起收在共享预设中，避免只改太阳强度后仍被另一场的曝光或雾盖掉。`LightRig.ApplyPreset` 同时设置环境光颜色，切回正片时恢复原有冷色底光。

参数是项目线性 HDR 渲染单位，不声称为经过物理标定的 lux。比较角色时使用相同画质、GI 开关、朝向、姿态和无建筑遮挡的室外位置，排除临时火光、受伤及压制滤镜。共同标准是相同的入射光与曝光；军服、肤色和装备保留原始反照率，不强制所有材质变成相同像素亮度。室内遮挡和主动开启的 GI 仍正常影响光照。

## 验收

```powershell
node Taierzhuang1938/Script_TestSceneLightingTest.mjs --scenes --shot
node Taierzhuang1938/Script_WeaponRangeTest.mjs --smoke --shot
```

前者检查五个场景的数据绑定、实际运行时光照与曝光、四个方位的 18% 灰卡暗部可见性、正片与测试预设往返，并在同一户外位置展示十套国军/日军士兵与军官，以及四类百姓。后者保留实际射击线的整帧亮度与玩法回归。截图与数据均保存在 `_shots/`，只留本地，人工查看角色和环境后再交付。
