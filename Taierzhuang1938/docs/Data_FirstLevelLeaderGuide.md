# 第一关：罗班长带路、等待与任务提示

2026-09-14 用户授权：班长作为第一关任务引导，一路在位置上等待玩家；提示方式与 HUD 参照 COD WWII / World at War，并生成配套语音。此要求更新此前第一关“只在暂停页看目标、不画跟随标记”的决定。

## 行为与信息层级

- 赶路时仅标记真实罗班长：跟随 / 集合、名字、距离。任务操作时切换到真实目标，不把正在操机枪、投弹或抬担架的玩家叫离岗位。
- 班长沿现有物理路线行进，在通过导航、地形高度、碰撞和通视检查的路侧点等候；玩家接近且可见，或已经沿折线路线超过该点时继续。已经释放的停点不再拉玩家回头。
- 原有战壕交替掩护的实体掩体与释放门保持不变；整段交替掩护路线不添加普通等候点，避免班长等玩家、后组又等班长的循环。普通队员保留错峰喘息；班长不参加随机喘息。
- 等人时回望、短促招手。仅叠加空闲左臂，右手与枪保持原持枪姿势；开火、移动、威胁、救援与搬运立即交回原动作。既有避弹与战斗响应优先。
- 一个世界空间标记，无常驻任务面板、路径线或叠加多个路标。屏外用边缘方向指示；近距离收起名字与距离。左上目标变更两行短暂出现再淡出；情境按键提示保留已定 COD WWII 样式。
- 战车阶段取得集束弹后转为投弹位置；院门阶段随机枪沉默 / 门开启转换；转运区随真实敌波改变方向；担架标记在接手点和交付点之间切换。
- 合入 2026-09-15 前沿修订：04 的主要指令是击退敌军，机枪可选；05 的路标逐个指向北侧侧沟的真实折点，拿弹后沿原沟返程，低顶通道沿用既有匍匐领路，不插额外路侧停点；07 黑屏转场隐藏引导。`GuideSouth` 保留为未启用的备用录音，不再在已取消的长距离南行段播放。
- 机枪最后一个弹匣仍有子弹时保持掩护指令；弹匣与备弹都打空才指向实际前沿弹药箱。下枪不丢失补给目标，补充后再指回机枪。
- 最后断后标记位于后门外的实际出口，不停在院内防守位；玩家必须穿过后门才能处理绕到西侧墙外的追兵。
- 开场受控演出、濒死剧情、完成与失败清掉标记；新任务 / 重试重建引导状态。暂停冻结游戏时钟与配音。
- 这里复用 COD 的单人战役信息层级与交互约定，不声称有原版 HUD 像素逐项测量或一比一素材复刻。仍不新增罗盘。

## 配音与人设

新增 27 条独立短命令，全部由 Volcengine `seed-audio-1.0` 生成，一条完整录音对应一个 cue。原有剧情对白仍保留完整录音，不剪成催促句。每条语音的源文、提示词哈希、文件哈希与时长由清单记录；新短句使用整段源音频区间作为单行字幕范围，非伪造逐词对齐。

罗班长：三十二岁四川老兵，低沉粗粝、短促直接；骂人带急火，但指令必须先让玩家明白“去哪、干什么、何时撤”。护着伤员时放低放缓，不每句话堆脏话。旁白和 UI 不写四川话，口语由班长承担。

剧情对白优先。新命令只在语音空闲且过冷却时播放，故事触发会取消可选提醒；等人催促可重复，但不会重复提交任务事实。实际声源跟随班长，远离班长不刷催促；关闭语音时仍保留可读提示。
