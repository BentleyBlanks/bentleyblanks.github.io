# 关卡结构：线性剧情关，不是抢点

> 2026-08-19 用户定的方向，**优先级高于之前的 Easy Red 2 占点结构**。
> 这份文件是关卡层的宪法，跟它冲突的一律以它为准。

## 一、一句话

**这是一部线性的、有故事走向的战役，不是一张开放战场。**
Easy Red 2 对标的是**手感与操作**，不是它的任务结构。

| 对标 ER2 的（保留） | 不对标 ER2 的（改掉） |
|---|---|
| 压制、伤势与流血、包扎 | ~~占领点进度条~~ |
| **死亡换人**（样式也要照它） | ~~攻守双方票池对耗~~ |
| 无准星、铁瞄偏心、视差、后坐、弹道 | ~~Push the Frontline 双向推拉~~ |
| 不显示步兵弹药数 | ~~开放地图任选路线~~ |
| 班组命令、指挥权顺位 | ~~阶段按时间自动推进~~ |
| 姿态、翻越、通用交互 F、径向轮盘 | ~~胜负 = 耗光对方票~~ |
| AI 行为层次、分帧决策、守点纪律 | |

## 二、关卡怎么推进

**目标链，不是占领条。** 每一关是一串有先后的目标，一个做完才出下一个：

```
到达某处  →  守住某处 N 分钟  →  掩护某人撤下去  →  摸掉哨位  →  推进到某处
```

推进条件写死在剧本里，由叙事层派发；**不许再出现"站在圈里等进度条涨"**。
`Data_Battle.OBJECTIVES` 那八个占领点降级成**地标**（用于寻路、生成、旁白锚点），
不再有 owner / progress / 反夺。

## 三、实机演出（这是本次新增的核心要求）

**数量要少，主要交代目标与去向。** 不做过场动画、不切镜头 ——
玩家始终是第一人称，人物真的在场、真的在动、真的在说话。

一场演出的构成：
- 说话的人**站在你面前**（Actor 真实存在于场景里，有口型幅度的头部微动与手势）
- 他**指向**要去的方向（手臂指向 + HUD 上一个很淡的方向标）
- 说完他**自己往那边走**（玩家跟着走就对了 —— 这是最不打断沉浸的引路方式）
- 期间玩家**不被夺走控制权**，可以走开（走开则台词继续播完，不强制）

一关最多两到三场，每场不超过四句。**目标与去向靠人说，不靠 HUD 打字。**

## 四、故事走向（史实骨架）

底本是 `Data_HistoryTimeline.md` 的逐日过程，参考影片《血战台儿庄》（1986，
广西电影制片厂，杨光远/翟俊杰导演）的场次选择 —— 但**影片的戏剧化处不许照抄**，
凡与 `Data_HistoryQuotes.md` 的 cautions 冲突的以考据为准。

| 关 | 时间 | 玩家要做的 | 史实锚点 |
|---|---|---|---|
| 序 · 上墙 | 3.24 午后 | 跟班长上北寨墙，打退第一次步兵冲击 | 日军以飞机重炮战车猛攻寨墙 |
| 一 · 破口 | 3.27 晨 5:30 | 堵缺口失败，退进街巷，学凿墙 | 日军突入城内，转入"室战墙战" |
| 二 · 室战墙战 | 3 月下旬 | 沿墙洞推进到清真寺，集束手榴弹打战车 | 清真寺是 186 团指挥所，拉锯七天七夜 |
| 三 · 白毛巾 | 3 月底夜 | 敢死队夜袭，摸哨、大刀、夺回西北角 | 王范堂 57 人，生还 13 |
| 四 · 最后五分钟 | 4.6 夜 | 守住阵地等反攻信号 | 孙连仲「整个集团军打完为止」 |
| 尾 · 清晨 | 4.7 清晨 | 走出去，遇记者陆诒 | 陆诒、范长江 4.7 清晨进城 |

这六关就是 `Data_Script.mjs` 里早就写好的 L0—L5，**它本来就是照线性关卡写的** ——
之前为了塞进开放战场做的那层触发式翻译（`Script_Story.mjs` 的 TranslateAt）
可以大幅简化：回到原生的 `zone: / event: / waveClear:` 语义。

## 五、死亡换人的样式（对标 ER2）

ER2 的做法：阵亡后全屏显示**刚才那名士兵的姓名与生卒年月**，然后接管另一名士兵。
我们已有卡片，要对齐的是**呈现**：
- 黑底、居中、无装饰
- 姓名（大）→ 籍贯 · 生—卒（小）→ 部队番号（更小、更暗）
- 停留约 2.5 s，淡入淡出，**期间没有任何 HUD**
- 之后镜头**平滑飞到**接替者身上，而不是硬切
- 线性关卡下，接替者是**同一场战斗里的另一个人**，兵员池仍然有限；
  池子空了这一关就是失败，回到上一个检查点

## 六、失败与检查点

线性关卡必须有检查点（开放战场那套"换个人接着打"在这里不够）：
每完成一个目标存一次；兵员池耗尽或关键 NPC 阵亡则回到最近的检查点。

# 【2026-08-19 追加·优先级最高】战场改为滕县保卫战，场景完全照史实重建

用户原话：「整个剧情改掉，我要做滕县保卫战。请你完全遵照历史的剧情发展。
在关键节点（例如王铭章牺牲时刻、李宗仁电联汤恩伯等）要做简单的过场动画；
整体场景要还原历史尊重历史（可以从文字描述中还原，应该有各种历史记录和照片）。」
以及：「**场景就遵照历史，历史上是什么样就是什么样，不要管之前场景设计成什么样。**」

## 这一条怎么执行

**滕县城是照史料重建，不是把台儿庄改个名字。** 两者根本不是一个东西：

| | 台儿庄（作废） | 滕县（现行） |
|---|---|---|
| 性质 | 运河北岸的**商镇**，「庄」 | 真正的**县城** |
| 城墙 | 砖包土坯**寨墙，高约 4 m**、顶宽近 3 m | 明清县城城墙，尺度另查（砖包夯土，远高于 4 m） |
| 门 | 六座，两层门楼约 7 m | 另查（县城规制，可能有瓮城） |
| 城外 | 护城河宽 10 m、深 2 m | 另查；**东关是城外附郭街区，是主战场之一** |
| 内部 | 八条街、437 个巷口、码头商埠 | 十字街、县衙、文庙、钟鼓楼、龙泉塔、津浦铁路滕县站 |
| 结局 | 守住了 | **必然陷落** |

所以 `Script_World.mjs` 里那套**建筑构件**（鲁南民居的硬山顶、四合院、青砖灰瓦、
对外不开窗、过墙石）可以留 —— 那是同一片地域的同一种民居形制。
但**城的骨架**（`Data_Battle.TOWN` 的寨墙、六门、护城河、运河、浮桥）**整个作废**，
按滕县的实测/记载重建，新建 `Script_TengxianCity.mjs`。

## 硬规矩

1. **凡是史料里有的，照史料。** 城墙周长高厚、城门数量与名称、东关的位置与形态、
   十字街的走向、龙泉塔在城内还是城外、火车站与城墙的相对位置 ——
   有记载就用记载的数字，不许为了「关卡好玩」改。
2. **凡是史料里没有的，标注为推定**，并在 `docs/` 里写清楚是推定。
   不许把推定值写得像史实。
3. **优先找影像**：1938 年的日方画刊、战后照片、现存城墙遗迹、
   王铭章殉难处的实景。照片能读出来的细节（砖的砌法、门楼的层数、街面的宽度）
   优先于任何文字描述。
4. **玩法迁就场景，不是场景迁就玩法。** 如果史实的城墙位置让某个关卡不好打，
   改关卡，不改城墙。

## 结局是必败，设计必须建立在这个前提上

玩家是 122 师的一名基层士兵。他在场，但改变不了结局。
每一次成功都只是「多守了一小时」—— 而多守的时间正是这场仗的全部意义：
它为台儿庄争到了三天。李宗仁：「若无滕县之苦守，焉有台儿庄之战果。」（待考出处）

这跟台儿庄那个「守住了」的结构完全相反。**不许给玩家一个能翻盘的分支。**
