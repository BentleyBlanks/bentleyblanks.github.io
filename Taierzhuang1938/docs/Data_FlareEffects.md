# 信号弹与白光伞降照明

2026-10-25。游戏、特效编辑器和白盒预演共用 `Script_Flare` 的时间线与 `Script_FlareVisual` 的画面，不再用爆炸火球冒充信号弹。

## 依据与边界

已打开核对美国陆军部《日军手册》TM-E 30-480（1944），[第十章·信号装备 §17](https://www.lonesentry.com/manuals/handbook-japanese-military/signal-equipment.html)。其列出红、绿、白星体、带伞型、十年式及八九式掷弹筒发射信号，并报告35毫米信号手枪的星体燃烧4–15秒。它是战时汇编，不是1938年滕县某次发射的记录。

当前选择**无伞短燃烧红星**与**白光伞降型**作为视觉复原；没有混用现代海上救生火箭标准，也不标成已确认的某一弹型。具体发射位置、红色含义、顶空高度、发光强度、伞形尺寸、风与摆幅属于游戏复原参数，唯一入口 `Data_Tuning_FlareEffects`。东关夜战里那场突然暴露的交火仍列「创作」。Notion 对照表及资料馆同步说明了装备类型与具体事件的区别。

## 行为

- 升空为连续抛物线；高度以发射地面为基准，不跟着下面的坡地起伏。信号星顶空点燃后自由落体，照明体展开伞衣后向终端下降速度平滑过渡。
- 燃烧体、少量下落火星、世界空间烟迹共用同一时间。烟在风中升起、扩散和消退，不随弹体整串平移；顶空没有手榴弹式爆炸。
- 照明体有实体分瓣伞面、悬索、微摆和暖白燃烧点。灯走既有 LightRig 池；新预设用固定烛光强度，下降时地面照度按距离自然增加，不逐帧强行保持地面照度。信号弹不扩大 AI 发现距离。
- 熄灭后灯关闭，余烟继续消散；完成、停止、换关都收回自有资源。主光仍沿用现有无阴影点光预算，不声称完成独立的伞灯投影或织物物理模拟；伞形与摆动是程序复原。

## 接入

- `Debug.Flare.Launch({preset:"SignalRed"|"Illumination",from:{x,z},at:{x,z}})`：真实游戏入口。旧 `crossLane` / `narrowLane` 保留既有节奏、视距与测试。
- 第一关 `AirFirst` 发射红色信号星；位置在 `MID_TUNING.signalFlare`，重建/退出会收回。没有在夜行军里新增随机发射或恢复已下线章节。
- 白盒 `FirstLevel1218` 的 `13-2` 使用 `flare` 事件，移除白烟、空中爆炸与缺特效说明字。`Script_FlareTrack` 按绝对时间驱动正式效果，Seek 前后与暂停可复现；默认白盒画质下仍显示同一渲染器。
- 特效编辑器效果库新增「红色信号弹」「白光伞降照明弹」，提供完整弹道、燃烧体近景、地面照明镜头和夜间对照。烟迹/伞形为弹药组件，不能冒充可独立编辑的通用粒子层；原有自建粒子层仍可叠加。弹药保持米制，不受整体缩放滑条影响；风与种子可控。30秒时间轴覆盖全生命周期。

## 验收

`Script_FlareTest` 检查原有契约及新弹道、地形独立、固定光强、信号视距与资源所有权；`Script_FlareEffectsBrowserTest` 使用真实浏览器检查两种画面、往返 Seek、暂停、真实地面照明像素、结束/停止/退出还原及 13-2 预演。截图与报告在忽略目录 `_shots/FlareEffects`，不提交。

同时运行粒子编辑器既有控制/白盒回归、模块图、字体、史料账目及受影响任务检查。不能以脚本数值通过代替查看实际截图。
