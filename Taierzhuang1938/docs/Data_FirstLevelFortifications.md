# 第一关地面工事布设

正式入口：《往南的路》`?whitebox=p012`。本次复用已入库的战场包沙袋、木梁障碍、三道桩铁丝网和军需箱，接入第一关专用布设。旧归档白盒不加载这套工事。

## 历史依据与推定边界

2026-09-10 在线读取以下资料正文：

- [《滕县保卫战》](https://zh.wikipedia.org/wiki/滕縣保衛戰)：部署、外围战两节记述津浦铁路东西两侧外围阵地，界河、香城、普阳山等防御位置，以及北沙河第二线阵地和池头集纵深防守。用来确定“铁路外围前沿—交通联系—后方第二线”的空间关系。这是二手汇编，并非可测量的原始工事图。
- [Trench warfare：Construction / Trench systems / Wire](https://en.wikipedia.org/wiki/Trench_warfare)：正文与图例介绍射击段、横向遮障、折线交通壕，沙袋和木框护壁，以及阵前桩网与机枪火力的配合。仅作为当时已存在的野战工事形制参考，不把第一次世界大战西线的规模或尺寸套称为滕县实测。

现有第一关是压缩、重组后的叙事关卡；未找到能把这些工事一一定位到其游戏坐标的原始部署图。以下坐标、数量与间距都是关卡推定。资料能支持外围阵地、交通壕及纵深防守关系，不能证明“1938年这个坐标有这一件模型”。

没有为填满资产库而摆混凝土碉堡或钢制反坦克拒马：此次读到的资料不足以确认其在该段临时阵地上的存在。也不把整件“战壕地形”模型盖到共享高度场上，以免把真实开挖的壕沟填平。

## 布设与通行

| 区域 | 工事与位置关系 |
| --- | --- |
| 前沿横壕及警戒哨 | 原胸墙、短翼、机枪支撑与撤回掩体改为三种现有沙袋模型交错堆叠；射手正面朝北，短翼后方敞开 |
| 前沿两翼 | 三道桩网分段放在西翼与东翼接近地；木梁障碍位于侧面，中央坦克道路和警戒哨撤回路线保持贯通 |
| 交通壕 | 弯折与连接段外侧增设低沙袋掩体；沿用现有土壤开挖、木护壁和交通壕底 |
| 车站 | 卸载区北侧临时沙袋与侧后方军需箱，离开列车下车口、集合点和支援行军线 |
| 村口、转运区及后卫 | 村口路障、转运区边缘、后方撤离掩体使用实际沙袋；转运区东缘另设分段桩网，装车通道保持开放 |

`Data_FirstLevelMissionFortifications` 是本次布设数据源。原掩体体积按横向分段、纵向分层填充沙袋，并继续使用同一个实体碰撞盒及 AI 掩体点；模型不会把门口或射击位包成实心大盒。木障碍和箱体按实测网格包围盒登记旋转碰撞；桩网按源工程的三根桩、三道网线分别登记碰撞，保留射击孔隙，不能用整片包围盒挡子弹。底面从共享高度采样器读取。

静态工事经 `BuildSink` 按 32 米分区、材质合批；换关释放本场几何，保留共享模型与材质。加载失败会明确报缺失资产，不把“成功进入白盒”当成工事已显示。

## 壕沟支路与回路

在原有四条开挖线以外，增加七条相连的沟段：西侧并行交通壕、二线联络横壕、西翼观察支沟、预备队掩蔽支沟、中段并行交通壕、车站北侧局部回路和西侧后撤回路。全部由共享高度场实际开挖，木护壁随地形生成；交叉口与增援行军线上的护壁让出开口。

前沿至中段有原交通壕和西侧交通壕两条主要线路，中段至车站侧有至多三条局部选择，后撤段有原线和绕行线。横向联络与尽端掩蔽支沟服务当前区域，不直接接到后续任务目标；既有任务事实门禁仍然决定阶段推进。沟网折线、支沟和纵深联系参考上述历史形制，具体走向仍为关卡推定。

专项测试双向走完每条新增沟段，另查原主线、友军增援、警戒哨撤离与敌军行军净空。局部胶囊验证与完整战役真实输入验收分别记录。
