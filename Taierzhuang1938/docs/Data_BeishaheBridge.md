## 产物契约

- `Model/Model_BeishaheBridge.glb`：一座完好桥，标准glTF Y-up，X为桥梁局部横轴、Z沿桥轴由北端指向南端，单位米；原点在桥中心枕木顶。X/Z本身不是地理正东／正南，地图放置须使用上面的现代示意变换。支承轴总长280米，含翼墙外包长度约287.7米。
- `Model/Data_BeishaheBridge.json`：实际GLB哈希／字节数、包围盒、实例三角数、每跨4个支座坐标、来源和创作边界。`_blender/Data_BeishaheBridgeSpec.json` 为设计尺寸输入。
- 14个跨组共享主钢结构；桥面有七组由同一构造脚本和同一材质生成的确定性木板变化，沿桥循环使用；木枕与13座中间石墩各有三组确定性UV及砌块差异，两端桥台独立。低矮半穿钢桁的轨道上方敞开，无高门架／顶横联、道路铺装或另加人行栏杆。
- 两轨头内缘净距1.435米。节点 `Intact_Span01…14` 含 `Trusses / Rivets / Sleepers / SleeperEnds / DeckPlanks / DeckBearers / GuardTimbers / GuardFasteners / RailWest / RailEast / RailWear / RailMidSplice / RailMidFasteners / Bearings`；`Shared_Pier / PierDamp / Cap / Abutment` 独立。连续横铺木板架在纵向托梁上，名义板宽约0.34米并有逐板变化、板缝约6毫米；板宽依据生成式构造图作设计推定。轨脚和扣件周围留出局部窄槽，轨头高出板面约65毫米。扣件参照早期德国铁路资料推定为每轨座外侧两颗、内侧一颗的方头螺纹道钉及外侧钩板，杆体伸入木枕120毫米；螺纹与钻孔未建模，实体杆与未钻孔的木枕、垫板有意交叠。钉型、数量及尺寸不能认定为北沙河原桥实测。两轨外侧的低矮纵木、分段与固定方式参照地点未知的1941年同线照片推定，其跨墩短木、侧板和穿栓用于连接相邻跨。13处跨墩木面设独立实体接段、托片及螺栓，接段两端各留2毫米缝，钢桁自身保持120毫米结构缝。
- 钢轨按1937年线路资料取名义10米轨节，跨中及墩轴处设6毫米缝、双侧夹板及四组螺栓；接头落点、缝宽、夹板及轨道截面均为设计推定。模型的螺杆与未钻孔的实体轨腹和夹板交叠，未模拟钻孔。两片桁架内外均有双排铆钉，节点板为实体；桥墩和桥台有内缩实心核心。墩帽采用四块实体帽石和下方承托核，块缝避开支座足面，形制参考生成辅助图而非原桥实测。桥板铺法、护木、铆钉间距、连接、配色、块色及墩底污迹均非原桥实测，不代表1938年实测水位。
- `BeishaheSteel`、`BeishaheSleeper`、`BeishaheSleeperEnd`、`BeishaheDeckPlank`、`BeishahePierStone`、`BeishahePierDamp` 六套PBR共18张图嵌入GLB；轨身另用较暗的钢材，轨顶采用磨亮窄条金属材质。木纹顺各构件长轴，端纹两轴物理比例一致；桥面纹理色调及逐板色差依据生成图作创作推定，同一板的三段共用色调。干湿石面共用粗凿源图，块间纹理方向变化，灰缝由实体构件表达。ORM遮蔽与法线使用真实贴图；不增加boot或关卡贴图请求。
- 版本 `2026102902` 的桥梁候选为1,267,328实例三角、354个网格对象和20,562,384字节；七组木板变化比上一版增加约4.35 MB，尚无LOD或游戏装配，整桥进入正式关卡前须评估可见范围、合批与性能。此前版本另留OneDrive `Archive/`。

## 重建与源工程

源文件与备份：`C:/Users/Bentl/OneDrive/AI/Models/Blender/Taierzhuang1938/BeishaheBridge/Scene_BeishaheBridge.blend`。原图、生成输入和参考在同目录 `References/`；其中 `Reference_BeishaheDeckStudy.png` 为桥面构造推演，`Source_BeishaheDeckPlankV4.png` 为采用的生成木纹源图，均非历史照片。钢材源图由 `Source_BeishaheSteelV2.png` 与 `Source_BeishaheSteelV3.png` 混合而成。生成提示词包括 `_blender/Prompts/Reference_BeishaheConstruction.txt`、`_blender/Prompts/Reference_BeishaheDeckStudy.txt` 及 `_import/Prompts/Texture_Beishahe*.txt`，均走内置imagegen。

```powershell
node scripts/Script_BlenderMcp.mjs start --task BeishaheBridge
node scripts/Script_BlenderMcp.mjs exec --code "import runpy; runpy.run_path(r'<worktree>/Taierzhuang1938/_blender/Script_BuildBeishaheBridge.py', run_name='__main__')"
node scripts/Script_BlenderMcp.mjs stop --save
node scripts/Script_BlenderMcp.mjs status --scan
```

在任务独占worktree运行。脚本拒绝覆盖源目录以外的已打开工程，重新生成GLB及sidecar；使用中的文件贴图即使尚未解码也会打包进 `.blend`。最终工程实际重开后核对18张贴图均已内嵌，14跨桥面均在；重烘GLB与已验收版本哈希一致。钢面混合源可用 `_import/Script_PrepareBeishaheSteelSource.py --input-dir <References> --output <References>/Source_BeishaheSteelV2V3Blend40.png` 重建；石面混合源对应 `_import/Script_PrepareBeishahePierStoneSource.py --input-dir <References> --output <References>/Source_BeishahePierStoneBlend40.png`。PBR重烘记录位于 `_import/TextureBakes/`；换电脑重新烘焙贴图时先映射到保留的源图路径。

## 验收

`node Taierzhuang1938/Script_BeishaheBridgeTest.mjs` 检查真GLB米制尺寸、分孔、桥面覆盖与托梁接触、护木支承、跨中及13处墩轴轨缝、夹板、轨座、扣件入枕与工具空间、轨距、双排铆钉、墩台实心及帽石支承、背面剔除、木纹方向与端纹比例、逐石颜色、贴图解码像素与哈希；`Script_TextureStandardsTest`检查纹理和预算。机车和敞车各401个离散姿态在两个代表接头的附属构件处通过净空检查，不等于所有车辆的通用限界或连续运动验证。数值测试不能替代视觉对照。

本地页 `tmp/BeishaheBridge/QualityReview/index.html` 支持旧版／新版切换、整桥侧视、节点、枕木、端纹、桥墩与桥底机位、原照片及局部推演图对照。仓库LocalPreview静默预览；`Script_QualityReview.mjs` 复用静音浏览器，保持1440×960实际视口，观察图长边640，检查JSON与截图只留本地。Blender渲染留源目录 `Review/`。

可验的对标范围是低桁轮廓、直上弦、斜端柱、多短跨与石墩关系，以及依用户要求补做的实体木桥面与生成式构造图对照。原图不能辨认的桥面、截面、铆钉、支座和材质按创作补足，不升级为“1938年原桥已精确复原”。
