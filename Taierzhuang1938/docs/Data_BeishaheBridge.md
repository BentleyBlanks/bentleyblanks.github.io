## 产物契约

- `Model/Model_BeishaheBridge.glb`：一座完好桥，标准glTF Y-up，X为桥梁局部横轴、Z沿桥轴由北端指向南端，单位米；原点在桥中心枕木顶。X/Z本身不是地理正东／正南，地图放置须使用上面的现代示意变换。支承轴总长280米，含翼墙外包长度约287.7米。
- `Model/Data_BeishaheBridge.json`：实际GLB哈希／字节数、包围盒、实例三角数、每跨4个支座坐标、来源和创作边界。`_blender/Data_BeishaheBridgeSpec.json` 为设计尺寸输入。
- 14个跨组共享主钢结构；每跨按咸宁现代照片的视觉类比做成9格、跨中3格带交叉杆，两端斜杆向跨中汇聚。该排布、断面、节点以及杆件位于桁架内外哪一面均为设计推定，不能据异地照片认定北沙河原桥桁式。交叉杆端部与节点板接触，杆件穿过视觉交叉处时位于不同的横向平面；连接铆钉为实体。桥面有七组由同一构造脚本和同一材质生成的确定性木板变化，沿桥循环使用；木枕与13座中间石墩各有三组确定性UV及砌块差异，两端桥台独立。低矮半穿钢桁的轨道上方敞开，无高门架／顶横联、道路铺装或另加人行栏杆。
- 两轨头内缘净距1.435米。节点 `Intact_Span01…14` 含 `Trusses / Rivets / Sleepers / SleeperEnds / DeckPlanks / DeckBearers / DeckFasteners / GuardTimbers / GuardFasteners / RailWest / RailEast / RailWear / RailMidSplice / RailMidFasteners / Bearings`；`Shared_Pier / PierDamp / Cap / Abutment` 独立。连续横铺木板架在纵向托梁上，名义板宽约0.34米并有逐板变化、板缝约6毫米；板宽依据生成式构造图作设计推定。每块板在两条内侧托梁上各设一对简化实体固定件，跨墩短板也有对应固定件；模型取直径12毫米、长度71毫米，进入托梁25毫米，圆柱体与未钻孔木材有意交叠，无独立钉头或螺纹，不能当作原桥钉型或施工承载设计。轨脚和扣件周围留出局部窄槽，轨头高出板面约65毫米。扣件参照早期德国铁路资料推定为每轨座外侧两颗、内侧一颗的方头螺纹道钉及外侧钩板，杆体伸入木枕120毫米；螺纹与钻孔未建模，实体杆与未钻孔的木枕、垫板有意交叠。钉型、数量及尺寸不能认定为北沙河原桥实测。两轨外侧的低矮纵木、分段与固定方式参照地点未知的1941年同线照片推定，其跨墩短木、侧板和穿栓用于连接相邻跨。13处跨墩木面设独立实体接段、托片及螺栓，接段两端各留2毫米缝，钢桁自身保持120毫米结构缝。
