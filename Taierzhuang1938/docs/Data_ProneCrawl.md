```powershell
node scripts/Script_BlenderMcp.mjs start --task ProneGroundMotion
```

## 同日 V2：脚踝、弯曲连续性与中段携枪

上轮接地、骨长通过仍遗漏了脚踝方向、关节逐帧转角和手指包握，用户在实时起伏预览中
指出这三处缺陷。本轮把它们加入验收，不以上轮的通过记录代替。

- Blender 去掉脚部 180° 翻转，脚尖向后下方，鞋的朝向跟随小腿；腿的后伸保留弯曲余量。
  收腿段采用与支撑段速度相接的五次曲线，循环和离地时不突然改向。
- 作者化及运行时都使用连续的弯曲平面。去掉按肘膝高度选圆周两个解的逻辑，避免手腕
  接近肩膀正下方时跨分支翻转；蒙皮支撑面的最近邻切换改为连续加权。
- 右掌朝下横握护木中段，四指弯曲、拇指对握；携枪挂点使用实际武器的前握点纵向位置，
  补偿握持面的高度和掌心厚度。枪身中心跟随右手，左手独立支撑；停止后回原卧射挂接。
  携枪手在右肩外侧、肘部朝下，前臂滚转匹配掌面，避免右肘上折和手腕蒙皮拧成细条。
  按各指长度分别弯曲，短指贴护木侧面，不能统一卷成穿过木头的拳头。原地卧射的瞄准层最后执行，
  下一帧按相反顺序恢复，贴地层不覆盖枪口的目标方向。
- 验收覆盖六套外观 × 五种地形（新增实时预览的正弦局部起伏），30 FPS / 0.3 m/s 下
  检查八个肘膝相关骨骼相邻帧转角小于 15°、脚尖低于踝骨且朝向跟随小腿、右掌与护木
  中段纵向误差小于 5 mm；原骨长、皮肤穿地与滑动断言保持。另输出握枪和脚踝近景。
- 用户第二次指出“枪从手指中穿出来”后，握点/骨骼包围检查被证实不足。新增真实手部
  蒙皮顶点和三角形中心对武器截面的穿插检查（深度 < 3 mm），并检查拇指、四指两侧
  与枪托的实际表面距离（均 < 8 mm）。两者同时通过，不能靠把枪移远来避开穿插。
  握点在护木下方、指根在枪管上方，两点的三维距离不等于接触距离；保留纵向位置门禁，
  原三维握点距离由更严格的实际蒙皮穿插/接触门禁取代。

## V3：修正持枪腕的非自然折角

用户在 V2 的实际近景中指出手腕仍明显扭折。V2 的 70° 方向门禁过宽，且未检测沿前臂
轴的扭转；上文 V2 的通过记录不能作为手腕自然的验收结论。

持枪臂不负责承重。Blender 在已校准的持枪高度同时求肘、腕：肘部向前并抬到手腕高度，
保留上臂/前臂长度，让前臂横向接入掌心；前后携枪摆动只加入小幅偏角。左手和腿继续
承担地面支撑，枪的握持位置与逐指包握保持。检查同时限制前臂—掌心夹角，以及相对
绑定姿势的完整腕关节旋转，两者均 < 30°，在六套外观、五种地形的每个采样帧执行。

V3 在已集成的新步幅运行时上通过 30 组专项检查：平地最大腕部折角 17.35°，实时预览的
局部起伏为 16.87°，最陡复合坡面为 27.81°；包含轴向扭转的完整腕部旋转最大 27.65°。
最低皮肤距地 4.42 mm，肘膝相邻帧转角最大 10.97°，手部最短穿插深度仍低于 3 mm，
握持接触、支撑滑动、骨长与循环接缝均保留原检查。内置预览新增“肩肘腕连线”机位，
并检查了国军、日军的手臂整体及两侧近景；截图、报告仍仅保存在本地。
