# 第一关六种动态硝烟（2026-09-27）

上一版四类烟的运动相近，浅色烟透明度低，实际场景主要读到黑烟。本轮把颜色与运动参数移入 `Data_Tuning_BattleSmoke`，继续使用真实第一关的同一体积烟渲染器，增加贴地白烟幕与间歇扬尘。

| 类型 | 场景数量 | 形态与运动 |
| --- | ---: | --- |
| 浓黑烟柱 | 15 | 窄根部，缓慢上卷并顺风扩散 |
| 灰白翻滚烟 | 15 | 更亮、更宽，逆向翻滚、上升、解体 |
| 黄褐地面尘烟 | 14 | 低矮土色尘层，快速侵蚀与横向摆动 |
| 风吹散烟带 | 11 | 扁长冷灰烟，持续横向舒展 |
| 贴地白烟幕 | 4 | 低空翻卷、补充与散开 |
| 间歇扬尘 | 5 | 同源烟团快速膨胀后消退，各点错峰，留有安静间隔 |

颜色以线性工作空间存储；密度噪声随时间平移并分层旋转，烟团同时上升、增大、横摆、淡出。尘烟按固定种子错开喷发相位。属于实时体积近似，并非流体模拟。

固定种子仍为 `19380406`，总计64处：32远景、23近景、9中景。道路采样轮换六种配方；另设成功通过净空筛选的前沿灰白烟、两处前沿扬尘、村边白烟幕、桥边扬尘及后方灰白烟点。扩大各烟源间距与路侧偏移，保留逐龄烟冠、风偏、最大横摆扫掠的路线净空检查。地形高度、建筑与河流拒绝规则沿用共享场景数据。

全部类型合用一个实例批次，仍为低/中/高/极高512/704/896/1024个实例，无新增图片下载或战斗粒子占用。保留深度软交界、透明预通道排除、检查点恢复、清理与资源释放。

## 验证

- 布设测试覆盖六类各至少3个道路近中景点、每种至少一条真实任务道路的无遮挡视线、固定随机种子、实际地形、烟龄及最大横摆的路线净空、K6/K7/K9/K11视线、实例预算及生命周期。
- 真GPU逐类检验：每种烟独立可见，推进1秒均产生明显像素变化；扬尘安静阶段为0可见像素。前景遮挡与清理残留均为0，WebGL错误0。
- prepush通过43项后在已有 `OpeningSetTest` 的 `spoilEarthSkin x rescue.interpreterReturn at (0.43,-123.54)` 断言失败；与前两轮基线同一问题，未改动对应布景。不是全量回归全绿。
- 单独通过运动向量契约47个GPU场景和第一关任务测试。
- 正式浏览器包高画质实景检查前沿、取弹路、南行路、村路及近烟；前沿和白烟幕分别连续推进8秒，南路扬尘推进12秒。保留逐帧截图与动态预览，WebGL错误0；调试定位录像不作为整关连续通关证据。
