# 〇、一句话定位与三条红线

**一个第 31 师 186 团的一等兵，在台儿庄城里活过的十四天。**

玩家叫李长根，河北雄县人，十九岁，虚构。他的直接长官是 186 团团长王冠五（真人），师长池峰城在运河南岸，够不着。他从头到尾没有一次是"关键先生"：北墙的破口是集体堵上的，西北角是王范堂的连队带队夺回的，最后的胜负是外线汤恩伯部压下来的。他做的事只有一件——**填进去，然后活着，然后接替倒下的人的位置**。

三条不可越的红线：

1. **不做"一个人扭转战局"**。任何一个"若玩家失手则台儿庄失守"的设计都是错的。玩家失手 = 玩家死 = 换一个人上来。这就是"填进去"的机制化。
2. **牺牲的重量不靠台词，靠机制**。玩家身边每一个 NPC 战友倒下，都会有一个新的从后方跑上来接他的位置。这条贯穿全 demo，是本作唯一的"计数"，而且它不是分数，是账单。
3. **结局必须落在真实的胜利上**。4 月 7 日凌晨一时，日军残部向峄县、枣庄退却。不是全歼，不是围歼——日方 4 月 5 日已接到转进命令，中方总攻与日方撤退命令在时间上重叠。这条史实分歧不回避，做进尾声的"史料卡"里并列呈现。

主题的三个面，各由一关承担：
- **血肉筑长城** → L1 破口：墙塌了，人堵上去。
- **以劣势装备死守** → L2 室战墙战：手榴弹、大刀、打洞对射，对面是战车与掷弹筒。
- **明知代价仍然填上去** → L3 白毛巾 + L4 最后五分钟：出去五十七个，回来十三个；然后还得再出去一次。

# 一、核心玩法循环

## 1.1 五秒循环（微观）

```
听 → 定位 → 探头 → 一枪 → 缩回拉栓 → 移动换位
```

栓动步枪把射击变成一个**有明确代价的决策**：开一枪就要付出 1.05 秒的拉栓，这段时间里视线被抬起、不能瞄准。所以玩家的默认状态不是"举枪扫射"，而是"贴着墙听"。台儿庄的交战距离是 10—30 米，这个尺度让"听"真正有用：脚步、三八式的脆响、九二式重机枪的"啄木鸟"节奏，都能在两三米厚的墙那边被听见。

## 1.2 三十秒循环（中观）

```
推进到下一个掩体 → 被压制 → 用手榴弹解压制 → 拿下一个房间/院子
```

压制是本作的核心张力源。日军机枪组一架好，玩家在压制锥里暴露 1.2 秒以上就进入压制态：画面边缘向内收缩、准星发散翻倍、sway ×2.5、无法 ADS。**解压制只有三条路**：绕（走次巷，机枪不追）、炸（手榴弹，但你只有八枚）、等（十一年式打满 200 发过热 8 秒——这 8 秒是设计送给玩家的窗口，音效上有明确的"哑火 + 换弹斗"提示）。

## 1.3 一关循环（宏观）

```
守 → 顶不住 → 后退一条街 → 夜里打回去
```

这是台儿庄的真实节奏，也是关卡节奏："白天丢阵地，晚上夺回来"。全 demo 的战线曲线是：北墙 → 城北街巷 → 清真寺 → 西北角 → 西南一隅 → 总攻推回去。**玩家的地图坐标一路往南退，只有最后一关往北打。**

# 二、FPS 手感参数

## 2.1 移动

| 项 | 值 | 说明 |
|---|---|---|
| 眼高（站/蹲/卧） | 1.62 / 1.05 / 0.42 m | 蹲下能藏在 2.0—2.5 m 院墙后，卧倒能进"半人高立射壕" |
| 行走 | 3.1 m/s | |
| 冲刺 | 5.0 m/s，限 3.5 s，冷却 6 s | 冲刺后 2 秒内 sway ×2.2、拉栓时间 +15%（疲劳） |
| 蹲行 / 匍匐 | 1.5 / 0.8 m/s | |
| 地面加速 / 刹车 | 28 / 34 m/s² | 有一点惯性，不做"贴地滑块"手感 |
| 空中控制 | 0.12 | 几乎没有 |
| **跳跃** | **不做** | 见 §2.6 |
| 鼠标灵敏度 | 默认 0.0022 rad/px，可调 | 指针锁定，无鼠标平滑，无加速度 |
| FOV | 75°（可调 65—90），ADS 按武器 `adsFovScale` | |

## 2.2 栓动步枪节奏（最重要的手感）

以中正式为基准（数据已在 `Data_Weapons.mjs`）：

- `boltTimeS = 1.05`，`fireIntervalS = 1.25`。开火 → 自动进入拉栓 → 拉栓中枪机上抬，准心离开目标 → 复位。
- **预拉栓**：不开火时按 R 主动拉栓抛壳，之后下一发即时击发，省 0.35 s。这是给老手的节奏奖励，教学在 L0 由班长刘振海一句话给出："打完就拉，别等要打了才拉。"
- **桥夹装填**：五发桥夹压入固定弹仓，**必须空仓才能压桥夹**（史实：固定弹仓）。半空弹仓只能一发一发塞，0.9 s/发。这条制造了"打了三发要不要现在换"的持续微决策。
- **拉栓可打断**：拉栓中途松开或切武器会中断，回来要从头拉。慌乱时会付代价。
- 汉阳造 `boltTimeS = 1.18`、`swayScale = 1.12`、精度更差——玩家在 L1 会被迫捡起一支汉阳造，**手感的降级本身就是叙事**："中正式没了，拿这个。"

## 2.3 后坐力

- 中正式：pitch 2.9°、yaw ±0.55°、kick 0.055 m（枪身后座）、`recoverS = 0.42`。
- **恢复只回 72%**，剩下 28% 永久留在视角上，需要玩家自己压回来。这样每一枪之后都要重新找目标，符合旧栓动步枪的手感，也自然抑制了"连点"。
- **依托机制**（本作的掩体核心）：贴住垛口、窗台、墙沿、沙包时（自动检测，屏幕左下角出现一个极小的"倚"字形符号），`spread × 0.35`、`sway × 0.30`、后坐恢复 ×1.4。**这是掩体唯一的奖励**——不做"掩体系统"的按键贴墙，不做第三人称探头。

## 2.4 手榴弹（真正的主战兵器）

第 31 师一役用掉三十万余枚手榴弹，战后满地木柄——这条史料决定了手榴弹在本作是**主武器地位**，不是消耗品。

- 携行 8 枚（背后 4 + 胸前 4，仵德厚敢死队装备清单）。
- 两段式投掷：按住蓄力 0.35 s → 1.0 s，映射投速 14 → 26 m/s。松手投出。
- **可 cook**：按住 G 即拔弦、引信开始烧（4.2 s）。**UI 不给计时条**，只有"嗤"的一声引信音 + 手部逐渐加剧的抖动。老兵行为不给拐杖。cook 过头会在手里炸（这是真实的，且必须保留）。
- **不画抛物线预测线**（默认关，可在辅助设置里开）。窄巷里靠听落点回声判断。
- **集束手榴弹** 2 枚：五至七枚去柄捆在一枚带柄弹上，投速只有 8—13 m/s，扔不远。只对战车顶部/后部有效，正面砸中会有明确的"叮"一声弹开 + 火花——这是对玩家第一次误用的教学否定。

## 2.5 大刀

- 一击 260 伤害（人形即死），swing 0.62 s，reach 2.05 m，挥空硬直 0.85 s。
- **只在两种场合成立**：夜袭（`silent: true`，不触发日军警戒扩散）、弹尽（携弹为 0 时屏幕左下弹带全瘪，班长喊"刀！"）。
- **拼刺你赢不了**：三八式上刺刀 1.663 m，比中正式上刺刀 1.505 m 长。日军刺突先手，正面对刺玩家必输。解法是侧身贴进去用大刀，或者后退两步开枪。这条不做成"技巧挑战"，做成"你打不过就别打"的现实。
- 背法：斜挎，刀柄露在左肩上方，右手过左肩抽出。**不做武侠式竖背反手拔刀**。

## 2.6 弹药稀缺与不做跳跃

**弹药**：起始携行 = 弹仓 5 + 三个桥夹 15 = 20 发（杂牌部队"最多二三十发"）。

- 补给只来自**自己人的遗体**：靠近按 E，随机 0—5 发。没有弹药箱，没有补给点。
- 日军遗体上是 6.5 mm 有坂弹，**和 7.92 不通用**。玩家可以捡起三八式改用日械（史实上守军确实"打光子弹推倒墙抢日军枪支"），但换了之后自己剩下的 7.92 就成了死重。这个抉择每关出现一次，L2 是第一次。
- 弹带 HUD：屏幕左下一条布弹带剪影，六格，鼓起 = 有，瘪 = 空。**没有数字**。数字只在按 T 低头检视武器时短暂显示。

**不做跳跃**：这是一条刻意的设计选择。取而代之的是上下文动作（按空格）：翻越 0.9—1.3 m 矮墙、踩石磨/条凳上 2.0—2.5 m 院墙、爬梯上寨墙、从二楼窗口跳下（有落地硬直 0.6 s）。**4 m 的寨墙必须走坡道或梯子**——这不只是拟真，它把"上墙/下墙"变成关卡节点，而不是随便一跳。

## 2.7 掩体与破坏

三种墙体材质，玩法完全不同：

| 材质 | 表现 | 玩法 |
|---|---|---|
| 夯土 / 土坯 | `#A8926E`，粗糙带草筋 | **步枪可穿**，2—3 发穿透。躲在它后面会死 |
| 青砖 | `#7E8388`，卧砖/甃砖条带立面 | 步枪不穿。手榴弹 ×2 或掷弹筒 ×1 破洞 |
| 过墙石 / 条石 | `#B3B0A6` 灰白条带 | 不可破。这是关卡的硬边界 |

**打洞机制**（史实：守军"在墙壁上开凿射孔，或沿墙基挖成半人高的立射壕"）：

- 在标记墙面按住 F，3.2 s 开出射孔 0.15 × 0.20 m（可射击不可通过）；再按住 4.0 s 扩成人洞 0.60 × 0.90 m（可通过）。
- **开洞期间不能开枪、不能移动**。这是关卡节奏的沙漏——你在墙这边挖，敌人在墙那边推进，班长在你背后打掩护，你听得见每一声。
- 实现上**不做实时体素破碎**。每面可破墙预生成四个几何状态（完整 / 射孔 / 人洞 / 塌），切换即可，配 InstancedMesh 碎砖 + 尘土粒子。破坏是**预授权的关卡语言**，不是物理沙盒。

# 三、关卡

总时长基线 18 分钟，熟练玩家 13—14 分钟，含死亡重来落在 12—20 分钟区间。

## L0 序 · 上墙（2.5 min，1938-03-24 午后，`smokyDay`）

**目标**：跟着班长上寨墙，打退第一波。

**节拍**：
1. 起手不在战场。你在寨墙内侧的坡道下，班长刘振海拽你一把："长根，跟紧了。上墙。"——**没有过场动画，第一帧就是可操作的**。
2. 上坡道时能看见整座庄：4 米的砖包土坯寨墙、7 米的中正门门楼、城南运河与浮桥、远处返青的麦田。**这是全 demo 唯一一次给你看全景。**
3. 上墙 → 教学"依托垛口"（右键）。班长："这墙才四米，垛口不厚。别把脑袋支在一个地方超过两下。"
4. 连长孟怀山："弟兄们，把子弹省着点。打得着再打。"——弹带教学：一条弹带里够数的没几格。
5. 第一发日军炮弹（`event:FirstShell`）。趴下。屏幕震动 + 耳鸣（音频低通 1.8 s）。
6. 波次 1：日军步兵试探，30—60 m，标准跃进推进。教栓动节奏。
7. 波次 2：掷弹筒登场。**这是全 demo 最重要的一课**：曲射能越过垛口落进来，原地不动就是靶子。
8. 打退后的静场。班长："咱们打退三回了，他们的人一回比一回多。"连长讲滕县：川军替我们多守了三天，王铭章三月十七殉国，电报只有一句"决心死拼，以报国家"。班长收尾："咱们这几天，是从人家血里借的。"
9. 关尾旁白（黑底一行）："这一夜日军的炮没停。三天之后，寨墙塌了一个口子。"

**新机制**：移动 / 依托 / 栓动 / 弹带 / 掷弹筒规避。
**视觉爆点**：**体积光**。硝烟遮日，太阳在寨墙北侧的烟柱后面。从门楼门洞往外望，是一柱一柱的丁达尔光穿过硝烟落在护城河上。`godStrength = 0.55`、`smoke = 0.72`。同屏 InstancedMesh 铺满砖垛、垛口、麦田。
**史实锚点**：3 月 24 日日军以飞机、火炮、战车支援猛攻中正门方向，186 团重大伤亡多次击退；滕县 3 月 17 日王铭章殉国。

## L1 破口（3.0 min，1938-03-27 晨五时三十分，`dawn`）

**目标**：堵住缺口，退进街巷。

**节拍**：
1. 黑底标题卡 2.5 s，然后你已经在跑。孟怀山："北墙破了！三班跟我上——"
2. 破口是一段 12 米宽的塌墙，砖屑坡度约 30°，日军从坡上逆光涌下来——**全是黑影**。
3. 波次 1：正面顶。这一波故意让玩家顶不住：日军人数明显多于你这边，机枪组在破口外侧架起来。
4. `event:MengDown`：连长孟怀山中弹。班长刘振海："他倒了我上，我倒了你上。这话不是我说的，是上头传下来的。一层一层传到咱们这儿，就这么一句。"**"填进去"这句话第一次以士兵能听懂的形态出现。**
5. 目标变更："退进街巷，堵住巷口。"——**第一次主动放弃阵地**。
6. 波次 2—3：巷口防御。窄巷 2—3 m，日军战车堵在主街进不来，只能用机枪从街口打。玩家第一次体会"揪住裤腰带打"的原理：贴得越近，敌人炮火越不敢用。
7. 中途玩家的中正式打空、缴不到 7.92，班长扔过来一支汉阳造。手感降一档。
8. 关尾：巷口用门板、水缸、粮包垒起街垒。旁白。

**新机制**：破坏（墙塌）/ 街垒构筑（按 F 推倒门板、拖粮包）/ 武器降级 / 主动放弃阵地。
**视觉爆点**：**逆光剪影 + 尘埃**。太阳高度角 4°，`godStrength = 1.35` 全 demo 峰值。破口处升腾的砖粉黄土（`#C4B49A`）被晨光穿透，日军全部是剪影，你看不清脸——**这是刻意的：本作从不给日军特写脸**。
**史实锚点**：3 月 27 日晨五时三十分日军突入城内，此后转为"室战墙战"。同日炮兵第 52 团 8 连以 4 门 PAK36 对阵 11 辆日军坦克。

## L2 室战墙战（4.0 min，1938 年 3 月下旬，`burningStreet`）

**目标**：沿墙洞推进到清真寺（186 团指挥所）。

**节拍**：
1. 起手：一面青砖墙，墙那边有日语说话声。班长把工兵镐塞给你。**打洞教学**。
2. 射孔 → 从射孔开一枪 → 对面立刻还击并把射孔打大 → 你被迫扩成人洞钻过去。
3. 逐屋推进：三个院落，每个院落是一个小谜题。鲁南民居对外不开窗，所有窗朝院内——**所以街上是瞎的，进了院子才有射界**。这条建筑规则就是关卡设计的底层语法。
4. 中段：日军投催泪筒。**白—灰白色浓烟贴地翻滚**（不是绿色毒雾）。守军没有防毒面具，玩家画面模糊 + 咳嗽 + 强制退出房屋。绕路。
5. `event:TankStreet`：一辆八九式中战车压上主街。正面无解。玩家必须爬上二楼/院墙，从上方用集束手榴弹砸下去。第一次正面丢会被"叮"一声弹开否定。
6. 波次推进到清真寺院外。这里的墙是"弹孔墙"——按史实做到每平方米上百个弹孔密度，砖已深凹墙内。**不是贴图，是 InstancedMesh 的凹坑几何 + 法线**。
7. 关尾：进入清真寺，186 团指挥所。团长王冠五第一次出场。他不喊口号，他在打电话，你从旁边走过。

**新机制**：打洞 / 逐屋清理 / 反战车（集束手榴弹从上方）/ 催泪筒规避 / 缴获日械抉择。
**视觉爆点**：**火与烟**。燃烧的商号，动态点光随火焰噪声抖动（同屏 6 盏火光点光，只有最近 3 盏投影），`bloom = 0.66`，HDR 域泛光在烧穿的屋顶处炸开。黑烟柱（billboard + noise）从三个方向升起。合成阶段加一个廉价的热扭曲（屏幕 UV 扰动，只在火焰上方的窄带里）。
**史实锚点**：清真寺是第 31 师 186 团指挥所，中日双方在此拉锯七天七夜；西小讲堂南外墙每平方米弹孔上百个（1988 年一处墙面被中国革命博物馆收藏，定为国家一级文物）。**注意：28 米高的四层望月楼是 1942 年才增建的，1938 年战场上没有它。**

## L3 白毛巾（3.5 min，1938 年 3 月底 · 夜，`night`）

**目标**：跟着敢死队摸上去，夺回西北角。

**节拍**：
1. 出发前的院子。第 27 师 158 团 3 营 7 连的王范堂（真人）带队，玩家是被抽调进去的 186 团的兵。秦四喜是 27 师那批翻墙进城增援的陕西兵。
2. 装具：每人一支长枪、一支短枪（驳壳枪）、肩背大刀、腰间挂满手榴弹、**臂缠白毛巾**（夜间敌我识别的实用做法）。**换装动作是原位的**：你低头看自己的手臂，别人给你缠上。
3. 有人低声哼《大刀进行曲》（单一正弦 + 微颤，不做和声，不做交响）。这是全 demo 唯二的"音乐"之一。
4. 黄樵松的《榴花》以旁白出现（据载为敢死队出发前诵读的诀别诗）："昨夜梦中炮声隆，朝来榴花遍地红。英雄效命咫尺外，榴花原是血染成。"
5. **潜行段（限时 90 秒，只此一次）**：借夜色和废墟接近西北角。大刀是无声的。**这一段不做完整潜行系统**——没有敌人视锥 UI、没有"警戒条"、没有蹲下暗杀提示。你只有黑暗、脚步声和别人的白毛巾。
6. `event:Flare`：日军放照明弹。全场瞬间被一盏带阴影的移动点光照亮，拖着烟迹缓缓下落。**所有人趴下。**照明弹落地熄灭前的 11 秒是最紧张的 11 秒。
7. 强攻段：手榴弹 + 大刀，近距离肉搏。
8. `event:LiuDown`：班长刘振海倒下，把刀交给你："我这把是喜峰口那年发的。使了五年了。……班长这个位置，你顶上。"
9. `waveClear`：王范堂："西北角拿回来了。"旁白："这一夜出去五十七个人。回来十三个。"
10. 关尾旁白："这样的队伍，那半个月里出去了两百多支。"——**这一句是本关的全部意义**：不要把它写成唯一的一次悲壮孤例。

**新机制**：夜视适应（曝光自动调节）/ 无声近战 / 照明弹规避 / 接替阵亡者的位置（你成为班长）。
**视觉爆点**：**夜战**。`exposure = 3.6`，几乎无方向光，光源只有三种：余火、照明弹、枪口闪光（每次射击是一盏 0.05 s 的点光，能照亮半条巷子）。SSAO 在夜里贡献最大——所有形体靠环境遮蔽的层次撑起来。运动模糊 + 颗粒 + 色差全开，`saturation = 0.72`。
**史实锚点**：敢死队是制度化、多批次的（仵德厚 40 人生还 3、王范堂 57 人生还 13、孙遇贤 250 人与 200 人、王冠五特务连 72 人）。**不打日期字幕**——史料在 3 月 30 日 / 31 日 / 4 月 1 日 / 4 月 3 日之间摇摆。生还数"11 人"与"13 人"两说并存，史料卡里并列。

## L4 最后五分钟（3.5 min + 尾声 1.5 min，1938-04-06 夜 → 04-07 清晨，`night → dawn`）

**目标**：撑到反攻信号，然后往北打。

**节拍**：
1. 团部。王冠五在接电话，玩家只能听见半边（漏音）："……是。是。第二集团军还剩多少，总司令那边清楚。……知道了。绝对服从命令。"
2. 传下来的话："总司令跟长官部回的话——我绝对服从命令，整个集团军打完为止。""长官部还有一句：胜负决定于最后五分钟。"秦四喜："……还剩几分钟啊。"王冠五："不知道。撑住就是了。"
   **注意呈现层级**：这两句都是**回忆录记载**，不打"据战报"角标；且都是总司令对师长、长官对总司令的话，玩家只是路过着听见。孙连仲绝不站在街垒上喊。
3. 波次 1—3：守最后一块阵地，背后就是运河。战线被压到西南一隅。
4. 波次 4：担架兵、炊事兵、伙夫拿着枪上来了。王冠五："团部现在没有后方了。这儿就是后方。"——李宗仁 4 月 4 日"把担架兵炊事兵一齐编起来"的命令，落到基层就是这个画面。
5. `event:QinDown`：秦四喜倒下，报家门："陕西泾阳，仵家庄东头第三家。你要是能出去……"没说完。
6. `event:Signal`：红色信号弹升空。王冠五："——信号！全线反攻！"旁白："四月七日凌晨一时。"
7. **反攻段**：目标第一次变成"往北打"。这一段刻意做得**顺**——不是因为你变强了，是因为外线的压力下来了。远处地平线上有炮火闪光（那是汤恩伯部）。这是本作对"胜利机制是外线合围"的机制化表达。
8. 旁白："日军残部向峄县、枣庄退却。"**没有歼敌数。**
9. **尾声 · 清晨（可走不可战）**：天已经亮了。战地记者陆诒（真人，4 月 7 日清晨确实进入台儿庄）跟着你走："老总，能问一句吗？我是《新华日报》的，姓陆。……你们守了半个月？报社要我写一篇。你想让外头知道点什么？"旁白："（李长根没有回答。他在数街两边的门牌。）"
10. 卖香油的万有福老人从废墟里出来："老总……我这半缸水，你们还没舀呢。"——**平民只出现在这里，只作为代价，不给任何奖励**。
11. 走到城南运河边，浮桥断了。终局字幕：只有日期、地名、以及各方伤亡说法的并列表。

**新机制**：昼夜插值（战斗中天亮）/ 阵地推进反转 / 可走不可战的尾声。
**视觉爆点**：**时段插值**。`night` 预设在 90 秒内插值到 `dawn`——SkyDome、LightRig、PostPipeline 三者联动，天空、方向光、曝光、God rays 同步变化。玩家是在打的过程中发现天亮了的。尾声段 `godStrength = 1.35` 拉满，晨光从东边斜穿过所有昨夜打过的巷口，SSAO 与材质脏化在静态下第一次被看清楚——这是技术展柜关。
**史实锚点**：4 月 4 日深夜孙连仲电请撤过运河、李宗仁严令死守（《李宗仁回忆录》）；4 月 6 日李宗仁下达全线总攻、当晚发起；4 月 7 日凌晨一时全线反攻；陆诒、范长江 4 月 7 日清晨进入台儿庄。**同时必须并列**：日方记载 4 月 5 日坂本支队已接到向沂州转进的命令，4 月 6 日日没后两支队开始转进，濑谷支队长系"独断离脱"。

# 四、敌人 AI 与波次编排

## 4.1 四类敌人

**① 日军步兵（分队 8—13 人，昭五式立领、九〇式钢盔或战斗帽、无垂布）**

状态机：`Idle → Advance → Suppress → Flank → Assault → Bayonet`

- 三八式 `aiAccuracy = 0.62`，**射击前有 0.85 s 举枪停顿**——这是留给玩家的反应窗口，也是本作"公平"的来源。
- 永远以 3—4 人小组交替跃进：一组动，另一组打。**单个日军兵不会孤身冲锋。**
- 6 m 内 30% 概率切刺刀突击。上刺刀后移动速度 +15%，射击停止。
- 受压制会趴下、寻找掩体、呼叫掷弹筒——**不会站在原地被打**。
- 日语音效只用最基本的口令与呼喊，**不做"八格牙路"口头禅**。文书口语称中国军队为"支那兵"。

**② 机枪组（十一年式 2 人 / 九二式 3—4 人）**

- 架设 2.5 s（有明确的架枪音效与姿态），架好后建立**压制锥**（水平 ±22°，射程 60 m）。
- 十一年式：连续 200 发过热，冷却 8 s。**这 8 s 是设计给玩家的突进窗口**，音效上有明确提示（哑火 + 打开弹斗 + 桥夹叮当）。
- 九二式：200 rpm 的"啄木鸟"节奏，不过热，但换保弹板（30 发）要 4.4 s——窗口更短更频繁。
- 机枪组**不追击**，只随步兵推进重新架设。它是空间否决器，不是追猎者。

**③ 掷弹筒组（1—2 人，藏在街角/院墙后）**

- 射程 40—700 m，**它是全 demo 的节奏心跳**：玩家在同一位置停留超过 4.5 s 就会呼叫一发。
- 落点前 1.5 s 有下行啸声 + 地面暗环标记。**这是唯一一个给玩家明确预警的敌人**，因为它的功能是驱赶而不是击杀。
- 它让"蹲坑"变得不可能，逼玩家保持移动 —— 这正是史实里日军曲射武器在巷战中的作用。

**④ 装甲（八九式中战车 / 九四式轻装甲车）**

- **路径规则：净宽 < 2.5 m 的路不可通行**。战车只走主街（4—6 m）。次巷（2—3 m）、夹道（1.2—1.8 m）是玩家的安全区。这条规则直接来自建模参数，也是"集束手榴弹从墙头砸下"成立的物理前提。
- 八九式：炮塔转速 22°/s，57 mm 短管炮 4.5 s 一发，同轴机枪持续压制。装甲 6—17 mm。
- 弱点：车顶格栅、履带、后部散热。集束手榴弹从上方一击。正面砸弹开。
- 九四式豆战车：只有一挺 6.5 mm 机枪，装甲 12 mm，**手榴弹一枚就能瘫履带**。它的作用是"看起来像坦克但其实很脆"，教玩家不要怕。
- **不做多辆坦克并排推进的画面**。濑谷支队方向的装甲总量级是战车 7 + 豆战车 39，全 demo 出场装甲车辆总数不超过 5 辆。

## 4.2 波次编排规则

- 每关 3—5 波，每波 60—110 秒。
- **波次的结束条件是"目标完成"，不是"敌人清零"**。绝不让玩家满地图找最后一个兵。
- 压力曲线：每一波内部是"接触 → 压制 → 高压峰值 → 解压制 → 短暂静场"。静场 8—12 秒，用于台词与呼吸。
- **同屏活跃 AI ≤ 14**，其余在"休眠位"（不做 AI 计算，只做低频姿态）。
- **"填人"机制**：玩家所在阵地每损失一名 NPC 战友，8—15 秒后有一名新的从后方跑上来接位。屏幕下方短暂出现一行小字：番号 + 名字（无名者显示"—"）。**这行字不累加、不计分、不给任何奖励，只是出现一下就没了。**这是本作牺牲重量的主要载体。

# 五、HUD 与叙事呈现

## 5.1 常驻 HUD（只有三样）

1. **弹带**（左下）：布带剪影 6 格，鼓 / 瘪。无数字。
2. **手榴弹**（右下）：小图标 + 数字。**这是唯一允许出现数字的 HUD**——因为投掷决策依赖精确数量。
3. **准星**：默认无。ADS 时用武器模型自带的照门/准星（真实瞄具）。腰射时是一个 2 px 暗点，随 spread 缩放，**不是十字**。

## 5.2 不做的 HUD

无血条、无小地图、无指南针、无常驻任务箭头、无击杀提示、无连杀播报、无经验值、无武器轮盘。

**受伤表现**：屏幕边缘沾血渍（CanvasTexture 生成 4 张贴片逐级叠加）+ 低频心跳 + 去饱和 + 呼吸声加重。三级伤：轻（边缘微暗）→ 中（明显血渍 + 移速 -12%）→ 重（画面明显去饱和 + 呼吸急促 + sway ×1.8）。脱离交火 6 s 后 12 s 内回到"轻伤"，**重伤不自动回满**，必须走到关卡节点由卫生兵包扎（一个原位动作，8 s，期间你听得见旁边的人在打）。

**方向引导**：靠 NPC 战友的 3D 音源呼喊、火光、目标物的高对比剪影。只有玩家迷路超过 20 秒，屏幕边缘才出现一个极淡的方向楔形，找到路后立刻消失。

**目标提示**：一行灰白宋体，出现 4 s 后淡出，不常驻。

## 5.3 叙事呈现：原位叙事，零过场动画

**核心原则：玩家永远不失去控制权。**

- **零全屏 CG**。唯一的电影化元素是每关开头的黑底标题卡（地名 + 日期，2.5 s）与关尾一行旁白。
- 所有台词从 3D 音源发出，说话的人就在你旁边跑动、装弹、倒下。字幕两行居下。
- **指挥层级的呈现规则**：最高层的命令，玩家永远只能"路过着听见"。孙连仲—李宗仁那通电话，玩家听到的是团部屋里一台野战电话的漏音，可以走近听，也可以不听（不强制、不锁门）。这条规则同时解决了两件事：史实上的指挥链正确（玩家的直接长官是王冠五），以及戏剧上的"你只是个兵"。
- **史料卡（note）**：按 Tab 打开，不打断主线。触发式收集（滕县、王铭章、敢死队、伤亡数字、记者、浮桥）。**每一张涉及争议的卡必须并列各方说法**，而不是给一个权威数字。伤亡那张卡长这样：

  > 日军损失，各家说法：
  > 中方战报：毙伤 11984、俘 719
  > 日本华北方面军参谋部（1938.6）：第 5、第 10 师团合计 11984 ——但时间跨度 2/20—5/10，范围远超台儿庄
  > 步兵第 63 联队战斗详报：参战 8464，阵亡 346、负伤 1154
  > 姜克實（岡山大学）：台儿庄本体战死约 636
  > 西方研究：战死 8000—20000 不等
  > 中国方面：第 2 集团军伤亡逾十分之七；第 31 师战前八九千人，战后能点名者约 2000

  这张卡本身就是本作对"历史"的态度声明。

## 5.4 语言与台词红线

- 官对兵：**"弟兄们"**；兵对官按职务："连长""营长""团长"；正式场合"长官"。
- **禁用**："同志们""国军弟兄们""军座/师座/团座""为了新中国""日本帝国主义""八年抗战""二战""三八大盖"（用"三八式"）。
- 士兵自称番号："我们三十一师""九连的"。
- 骂敌："鬼子""日本鬼子""东洋鬼子"（1938 年北方已完全通行）。
- 口音混杂：河北（孙连仲、池峰城、玩家）、河南（黄樵松、孟怀山）、陕西（王范堂、秦四喜、仵德厚）、鲁南（当地百姓）、桂林官话（李宗仁，只在电话漏音里）。**不做全员标准普通话，也不做全员山东话。**

- draw call ≤ 260；三角形 ≤ 900k
- 同屏活跃 AI ≤ 14；动态阴影 CSM 2 级（近 18 m / 中 65 m）
- 点光源同屏 ≤ 6，投影点光 ≤ 1（只有夜战照明弹）
- 材质种类 ≤ 12（走 `MaterialLibrary`）；CanvasTexture 全部 512×512，共 ≤ 18 张，启动时一次性烘焙，首屏 ≤ 3.5 s
- 粒子全部 InstancedMesh billboard，同屏 ≤ 1200
- 后处理默认 `quality = "medium"`（无 MSAA，走 FXAA），设置里可升 `high`
- WebAudio 同时发声节点 ≤ 48

**音效（全部 WebAudio 现场合成）**：

- 步枪：短噪声爆 + 带通扫频 + **程序生成的街巷卷积尾**。交战距离 10—30 m，回声是本作音效的灵魂。
- 九二式重机枪：200 rpm 的"啄木鸟"节奏，每发间隔 0.3 s，音色比中方马克沁低沉且慢——史料里最有辨识度的一条，必须做对。
- 掷弹筒：出膛"咚"（低频正弦冲击）→ 3.2 s 静默飞行 → 落地前 1.5 s 下行扫频啸声 → 爆炸。
- 拉栓：三段金属瞬态（抬-拉-推），每段短噪声 + 高 Q 带通。
- 大刀：出鞘是金属摩擦扫带通；命中是**闷响不是"锵"**。
- **不做旋律配乐**。唯二例外：L3 出发前有人低声哼《大刀进行曲》（单一正弦 + 微颤，无和声），尾声一段极简单音持续。**绝不做交响乐。**

# 七、失败与重来

**死亡不是惩罚，死亡是主题。**

- **自动检查点**，密度高：每关 3—5 个，每个波次开始前一个，每个关键节拍前一个。无手动存档、无存档菜单。
- **死亡表现**：不是"YOU DIED"。画面缓慢倒向一侧、失焦、声音变闷（低通 400 Hz）、心跳减慢至停。黑屏，出一行小字：

  > 你会有第二次。他们没有。

  然后 2.5 s 从检查点复活。**这句话每次死亡都出现，是本 demo 唯一允许的说教。**
- **无重来次数上限、无难度惩罚、无扣分、无"死亡次数"评级**。
- 复活时弹药回到该检查点的存量（不补满）。你死一次，弹药并不会变多。
- **代价账本**（终局唯一的"统计"，且它不是分数）：
  - 有名有姓倒在你身边的：孟怀山（连长）、刘振海（班长）、秦四喜……
  - 无名者接替位置的次数：N
  - 你死过：M 次
  - 万有福的香油铺、他孙女的鞋——**只列，不计数，不加分，不解锁**
  - **不出现歼敌数。**结尾只有一句事实性表述："日军残部向峄县、枣庄退却。"
- **平民苦难只进代价账本**。万有福的对话与他半缸水的静物，玩家可以完全错过，错过没有任何损失。**绝不做"救 N 个平民得 X"。**

# 八、明确不做什么

1. **不做"一个人扭转战局"。**玩家没有一次是关键先生。
2. 不做击杀数、连杀播报、"+1" 飘字、爆头特写、慢镜头、断肢、血浆喷溅。战损靠**弹孔密度**与**尘土**表现。
3. 不做技能树、装备升级、经验值、货币、成就、排行榜。
4. 不做载具驾驶。玩家不开坦克、不开飞机。
5. 不做全屏 CG 过场、不做黑屏读条剧情、不做夺走控制权的镜头动画。
6. 不做多结局。结局只有一个：4 月 7 日清晨，日军残部退却。
7. **不做精确歼敌数结算。**所有伤亡数字只以"各方说法并列"形式出现在史料卡里。
8. 不做"敢死队换日军军服"的潜行玩法作为主玩法。史料里那只是少数几次夜袭，L3 里只有一段 90 秒的接近段。
9. 不做完整潜行系统：无视锥 UI、无警戒条、无暗杀提示。
10. 不做自由跳跃、翻滚、滑铲、攀爬自由化。上下文动作代替。
11. 不做实时体素破坏。破坏是预授权的关卡语言（四状态切换）。
12. 不做武器改装、配件、瞄具切换、武器轮盘。
13. 不做治疗包拾取。重伤只能靠关卡节点包扎。
14. 不做常驻小地图、指南针、任务箭头。
15. 不做多人、联网、无尽模式、第二周目。
16. 不做外部图片/音频资源，不用 `examples/jsm`，不用任何第三方后处理库。全部程序化生成 + 手搭管线。
17. **不做恐怖化/猎奇化日军**：不演人体实验、不演屠杀场面。毒气只做催泪筒（白灰烟、被迫弃屋），不演糜烂性毒剂。
18. 不给日军特写脸。日军在本作里始终是剪影、背影、烟里的形状——**这不是回避，是视角的诚实**：一个一等兵在 10—30 米的巷战里，本来就看不清对面是谁。
19. 不做"大刀砍机枪"的影视化画面。装备比例照仵德厚敢死队：8 枚手榴弹 + 上刺刀步枪 + 背一把大刀 + 一支驳壳枪。
20. 不做德式 M35 钢盔。第 2 集团军是杂牌：灰布军服、布军帽、草帽、草鞋、空瘪的弹袋。**"杂牌"要靠这几样读出来，不是靠德盔。**
21. 不做日军"屁帘"（垂布 1938 年 6 月 1 日才配发），不做九八式折领军服（1938 年才定型）。台儿庄的日军是**昭五式立领 + 步兵红平行四边形领章 + 九〇式钢盔**。
22. 不做十几米高的府城城墙、瓮城、马面、角楼。**4 米寨墙 + 7 米门楼**，翻得上去、炸得开。
23. 不做清真寺的 28 米望月楼（1942 年才有）。
24. 不做积雪、盛夏浓绿、通透蓝天。鲁南 3—4 月：春旱、多西南风、麦苗返青 15—30 cm、杨柳刚发芽枝条透光、地表大量裸土与浮尘、天空常带尘霾。
25. 不引"毛泽东说每个月打一个台儿庄"。《论持久战》原文恰恰是警告。
26. 不用"东方凡尔登""《生活》杂志并列滑铁卢"——找不到可核验原刊出处。
27. 不给敢死队夜袭和断浮桥打日期字幕。史料在多个日期之间摇摆。
28. 不把王铭章、张自忠塞进台儿庄城墙上。三条战线不串味。
29. 不演王铭章举枪自尽。其后人公开否认自杀说。
30. 不把池峰城写成"违抗上级、擅自炸桥的孤胆师长"。所有版本里炸桥都发生在"敢退过运河者杀无赦"的死命令之下，是执行不是抗命。
31. 不让孙连仲站在街垒上对士兵喊话。那是总司令对师长的电话命令。
32. 不写"矶谷师团全歼"。日方是奉命转进、成功脱离，濑谷支队长甚至系独断离脱——这条分歧写进史料卡，不回避。

# 九、施工顺序建议

1. **第一周**：玩法内核（移动 + 栓动 + 依托 + 手榴弹 + 伤害）在一个白盒巷道里跑通，帧率先钉死在 55 fps 以上。手感不对，后面全白搭。
2. **第二周**：L2 室战墙战整关做完（它是最复杂的一关：打洞、火、战车、催泪筒）。**L2 通过 = 全 demo 的技术风险清零。**
3. **第三周**：L0 / L1 / L3 / L4 依次填，复用 L2 的资产与系统。
4. **第四周**：尾声、史料卡、音效、代价账本、性能收尾。

**验收闸门**（每关必过）：
- 1600×900 Chromium 实测 ≥ 55 fps（`quality = "medium"`）
- 首屏加载 ≤ 3.5 s
- 全关无一处出现 §八 清单里的任何一项
- 台词逐条对照 `docs/Data_HistoryQuotes.md` 的分级：第三档只能以"据载"旁白出现
- 用一个没玩过 FPS 的人跑一遍，看他会不会在 L2 的窄巷里迷路
