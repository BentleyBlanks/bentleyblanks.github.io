# 第一关道路沿线与体积硝烟（2026-09-26，第三轮）

本轮回应“形态太丑、地图远近处和道路可见处继续布设”的反馈。采用本文件，前两版说明保留为历史。

## 形态

`Script_BattleSmoke` 停用上一版二维烟雾图集叠片，改用三维噪声密度的烟团积分。复用引擎 `MakeVolumetricNoiseTexture` 的 32³ RGBA 数据纹理，随烟龄上升、横向漂移、膨胀并消散；粗细两档噪声打散轮廓，沿太阳方向采样密度差形成明暗。近景能看到烟内透光和卷动，远景保留相互搭接的大烟柱。它是游戏实时烟雾近似，并非流体模拟。

四种配方为浓黑烟、灰白烟、低矮土尘、风吹散烟。收窄底部、分开顶部膨胀和透明度衰减，避免旧版粗糙横纹和规则球串。旧 `Texture_BattleSmokeAtlas.png` 仅留作第二轮历史资产，当前游戏不请求该图片；本轮未重新调用生图服务。

## 布设

固定种子 `19380406` 共生成64处：32处参考远景、25处近景、7处中景。新增32处沿战车道路、支援沟、取弹沟、攻击支路、南行道路、村落绕行线、主街、接运车道、撤离线和铁路桥接近路随机布设。随机参数包括路肩侧别、间距、侧向偏移、尺度、烟龄与风偏；检查点重建和重返同一段路保持位置一致。

`Data_FirstLevelDistantSmoke` 使用真实路线作采样基准，并拒绝落在水面、建筑实体和通行走廊内的候选点。掩蔽部和伤员集结处留出近距离人物演出空间。所有烟源接共享地面采样器。烟团逐龄扫过的低空范围在回归中检查：近中景至少保留2.5米通行净空，远景沿用10米缓冲；高空烟冠允许跨过道路。烟不参与碰撞或AI视线判定。

新增近烟约3–12米高，中景约17–25米高；远处保留高烟柱和横向烟带。近烟在2.4米内渐隐，修掉上一版20–45米近距离完全看不见的问题。

## 渲染与预算

全部烟保持一个实例绘制批次，不占枪口、战车、爆炸的粒子槽。低/中/高/极高画质每源8/11/14/16团，当前总数512/704/896/1024；每像素射线分别8/8/10/12步，每步两次密度采样。3D噪声一次生成上传，约128KiB，无新增网络图片请求。

保留透明深度测试、关闭深度写入、法线/运动预通道排除、场景深度软交界、与VFX共用的雾色及全局淡出。清理立即隐藏，检查点时钟重置后恢复稳定烟龄，移除烟源重建实例，Dispose释放纹理、几何和材质。
