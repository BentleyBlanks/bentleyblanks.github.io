# 第一人称枪械动作与视觉真实度

本轮在 `07248b0a` 的连贯性修订上，补齐机械拆件、漏夹流程和连续动作。
原有接触测试和四帧截图只证明有限的接触与静态姿势；验收同时覆盖实际渲染、完整时序与机械事件，
不将通过次数作为真实或 3A 观感的证明。

## 要达到的结果

- 工作手先接触再驱动机柄，跟随机柄抬、拉、推、压转腕；支撑手承重，前臂和袖子让开观察区。
- 汉阳造使用整包进入弹仓的曼利夏漏夹；中正式、三八式使用压弹后取走的桥夹。
  空仓和有余弹时的机械流程分别正确，所有弹药道具完整进入进弹口后才被遮挡。
- 捷克式上插弹匣、十一年式漏斗及九二式横向保弹板各自遵循实物结构。
  九二式动作与主机弹药/声音接线由并行枪感会话负责，不重复修改。
- 弹壳、空夹与弹匣具有可辨识的几何；捷克式向下出壳；释放后沿世界轨迹运动，不被视角拖走。
- 步枪、轻机枪、重机枪具有各自的短枪焰、快烟与余烟节奏；连射不持续挡住目标。
- 中性光下供弹机构及运动件的暗部可读；继续使用已选模型和已验证的握持、骨长与瞄准关系。
- 检查正常与慢速连续播放、空仓/部分装填、ADS 起手、换弹打断及实际射击循环。
  关节/接触/机械事件的量测与画面需同时成立，不能用隐藏部件或放宽阈值替代。

## 与主机的视觉接口

`Viewmodel.TriggerReload({ remainingRounds })` 的参数是按 R 前的剩余发数。
不传时使用最近的 `Update` 弹量；编辑器显式传零作为空仓预览。
主机应在记账前取快照并传入。此方法不修改库存。
`Viewmodel.Update(dt, { ammo })` 接收当前实际剩余发数；有该输入时，枪机留后按 `ammo === 0` 判断，
不把 HUD 的“仅剩一发”提示直接当空仓。漏夹排出时机也使用此数值。

动作对象保留 `startedOpen`、`roundsRemaining`，并提供 `packetRounds` 区分需取出旧漏夹的情况。
中正式、三八式的 `loadRounds` 按开栓退膛后的弹仓余量计算；桥夹只带实际缺少的弹，
从夹底对齐，以较短行程补入剩余空位。有三发余弹且退掉一发膛内实弹时，新夹提供三发。
`spentCasePending` 仅跟踪第一人称枪膛表现，不改变伤害、射速、库存、存档或取消换弹退款规则。

当前节点如下，时间均为当前枪械换弹总时长的比例。
声音表的推栓与最终闭锁应分别对应 `.825` 与 `.905–.935`，不能把整段闭栓声拖到动作结束才播放。

不能在每次装填后从上方抽走。余弹旧夹移除与新夹入账须保持同一动作快照。

### 汉阳造完整抬柄与普通拉栓承重

Smith 的开栓剖视说明明确记载 Gewehr 88 需抬柄 90° 后再后拉。
汉阳造的运行时抬柄由原先统一的 1.35 rad（约 77.35°）改为 π/2，普通拉栓、
换弹和空仓留栓共用同一角度；已校准的手掌接触参考仍为 1.35 rad，不能随之改动，
否则会把手掌偏离真实机柄。其它枪保留各自当前角度，待单独复核。

普通拉栓给抬柄、压柄分别留出约 152 / 147 ms，前后直线行程同步重排，
总循环和射速保持。操作期间以两端速度为零的曲线向身体收枪最多 20 mm，
让右臂在完整抬柄时保持弯曲；枪与实际握点一起移动，不拉伸手臂或放宽人体阈值。
`FpsReloadMechanicsTest` 量测真实机柄半径的转角，并检查空仓留栓接入换弹时没有位置或角度跳变。
原持枪呼吸片段带有闭锁枪的机件通道，曾在拉栓结束的同一帧把留后枪栓复位。
运行时呼吸仅写身体和姿势通道，保留枪械机件状态；编辑器显式预览仍播放完整片段。
`FpsAnimationTest` 用实际发布的呼吸片段验证骨骼继续运动、枪栓保持留后与显式预览可回放；
`FpsHandContactTest` 另测从真实留栓状态起手的完整换弹。

该次定稿证据在 `_shots/BoltLift/`：接触门禁覆盖 618 帧（空仓、余弹、留栓起手和普通拉栓），
双手无不可达帧、握点残差为零；普通拉栓的单帧最大转角约 18.51°。
双臂 90 项、机械六个步枪循环、瞄准视野、49 个运动矢量场景和实际动画时间轴回归通过。
`FinalGame/` 保留高画质普通拉栓、空仓留栓、空仓/余弹换弹的全部连续帧与逐帧腕角、接触记录；
正常与半速视频仅留本地。以上为本次修订的验证，不代表其它枪械及整个真实度目标已完成。

## 连续动作与机枪

工作手在接触段严格跟随机件，在脱手段经弧线与连续转腕回收；松手使用微屈手型，
避免完全张手的僵硬轮廓。肩位和肘引导仅在换弹时做小幅承重调整，骨段长度保持固定。
普通拉栓的等待 / 动作时间分别为汉阳造 `.07 / .95 s`、中正式 `.07 / 1.18 s`、
三八式 `.07 / 1.28 s`；总循环仍为 `1.02 / 1.25 / 1.35 s`，保留既有射速。

捷克式先握住旧弹匣再拔出，新弹匣从补给位置抬至插口上方、对齐后压入；
完整弹匣几何与拉机柄读取新版源模型。正常换匣保持待发，直接回握；
余弹旧匣收回补给位置，空匣才抛弃。初次装填所需的手动拉机柄仍有独立 `TriggerCharge` 动作。
十一年式先抬压弹板，六个桥夹的五发弹始终留在夹内，
在同一 X/Z 位置沿 Y 叠放；有余弹时先取走旧叠夹，再装满。每五发供完后从底部落下一只空夹。
左手抓住压弹板外缘并随它抬起、保持和放下，前臂留在机匣下方；枪托向身体收拢。
最后一夹放入后，右手先沿弧线回握，左手继续控制压弹板并完成对应的待发准备；不让弹簧压弹板悬空停住。
空仓流程现于右手回握后，先放下压弹板，再由左手抓住操作柄后拉并推回前方卡笋，最后回到前托；
余弹流程不重复拉柄。两种流程均保持 4.65 s、原 `.78` 入弹事件和取消时的弹药记账规则。
扶板手型独立保存在 `FPS_HAND_SHAPES.hopperFollower`，基于实际蒙皮指腹与原板面校准，
同时约束关闭、抬起、打开和放下阶段的腕角；拇指与食指、中指相对扣住板沿，其余两指保持放松。
靠近与回收时掌位、朝向同步插值，余弹流程也先抓稳再抬板。静态托枪与所有手指骨段长度保持。

十一年式随后接入既有 Artec 扫描手／腕／前臂资产，采用固定骨段，不再使用旧桥接器的放大骨段。
原桥接器隐式肩位改为该枪的显式肩位，枪体、掌位和瞄具保持。Blender 按完整蒙皮逐指拟合握持，
扳机指到实际扳机约 0.995 mm，支撑五指最大取样间隙约 2.20 mm；握持手指的最大表面穿入约 1.74 mm。
右食指保留独立扳机屈曲。靠近时掌位先到板沿附近再转腕，回手按相反顺序展开前臂。
源工程在 `OneDrive/AI/Models/Blender/Taierzhuang1938/Type11ScannedHands_20261015/Model_Type11ScannedHands.blend`；
同目录保存输入、拟合报告、许可证及脚本；重建入口 `_blender/Script_Type11HandFit.py`，
设置 `FPS_PROJECT_ROOT`，并可将 `FPS_TYPE11_INPUT` 指向源目录重用 `Data_Type11HandInput.json`。
该工程只输出握持旋转，游戏继续复用已登记的扫描手 GLB；来源与许可见[扫描手说明](Data_FpsWeaponGripRepair20261015.md#扫描手形连续腕部与力量握持2026-10-15)。
九二式继续使用独立横向保弹板及主机事件接口。

### 十一年式独立操作柄与抓握

[《Japanese Infantry Weapons》](https://www.forgottenweapons.com/wp-content/uploads/2012/02/Japanese%20Infantry%20Weapons%20report%20%28English%29.pdf#page=107)

110 mm 行程按现有机匣空间拟合，操作柄只平移，手掌始终跟随真实接触挂点。

空仓装填末段适量抬枪、向前送枪，由右手承重，左肩肘配合左手下移抓柄；
工作手提前准备勾握手型，松柄后先转腕再回到前托，避免快速张手、握拳造成的僵硬轮廓。

两段拉柄声仅在空仓流程触发，分别跟随后拉和送回。

重建入口 `_blender/Script_Type11MechanismBake.py` 的 `Bake(projectRoot)`，
源工程保存在 `OneDrive/AI/Models/Blender/Taierzhuang1938/Type11Mechanism_20261015/Model_Type11Mechanism.blend`；
该场景使用与第一人称一致的归一化位置，保留源 UV、法线和四张打包底图。
`Model/Data_Type11Mechanism.json` 记录原始／保留／新增面数、挂点与行程。
`FpsHandContactTest` 同时检查指腹与完整手指表面的穿入；`FpsReloadMechanicsTest`

原贴图、世界模型和场景照明保持。

## 用户反馈后的节奏修订

针对“速度慢、动作仍僵硬”的反馈，缩短装填时长，并重新分配手部转移与闭锁时间。
汉阳造空仓/余弹仍使用同一总时长；所有枪的声音、入账与结束事件跟随新的实际时钟。
正常射击间隔与普通拉栓循环保持。

| 枪械 | 上一版 | 当前 |
|---|---:|---:|
| 汉阳造 | 3.80 s | 3.10 s |
| 中正式 | 3.40 s | 2.85 s |
| 三八式 | 3.50 s | 2.95 s |
| 捷克式 | 3.00 s | 2.35 s |
| 十一年式 | 5.20 s | 4.65 s |
| 九二式 | 4.40 s | 4.00 s |

步枪的脱手转移使用连续加减速，取夹后手腕提前转向下一接触点；回握时掌位与朝向同步回收。
中正式/三八式抽夹后增加经过点，汉阳造旧漏夹收回取消双重缓动。
右肘在取夹、压弹与回手阶段有小幅引导，左臂按实际受力拍变化；手掌接触与骨段长度继续保持。
回收手型增加自然屈指，减少张平手掌的轮廓。推栓在 `.890` 完成，再用较完整的时间压柄闭锁，
避免全程加速后最后一次转腕过急。
