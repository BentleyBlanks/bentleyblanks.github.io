## 原稿尺度冲突

P2 给定的 Z09、Z02、Z04 坐标意味着回撤中心线的几何下界已经超过所写的“约 95 米”。本版本优先保留区域方位、节点坐标与真实西侧回环；实际长度由布局路线导出，回撤节奏按 P1 的行动与事件校准，不用传送缩短。

### 当前工作批：开场因果、铁路兵站与真实台阶（2026-09-04，验收中）

用户最新反馈优先于 P1 原稿中的机械任务名：村口不再重复领弹；四向看路进度改为向罗班长借望远镜、主动举镜观察实际北行士兵与南行伤员、交还。望远镜期间武器封火且隐藏无效武器提示；黑色镜片外的目标不计识别。借镜不能吞掉已开始的近战／投掷蓄力；暂停或失焦取消未完成的按住交互。

北上段不再预告炮击。真实位置触发交谈，随后附近炮弹真实落地，才显示卧倒／进沟目标并让罗班长停下卧倒。新增闲聊与接话暂为纯字幕，不请求配音；实际弹着会打断旧纯字幕，旧辨向与闲聊不在炮后补播。没有夺取玩家镜头或强制等待对白的过场。`OpeningDialogueImpact` 的开场输入与因果负例通过，根代理看图确认炮前闲聊、弹着后的卧倒字幕；班长与玩家距离仍可能过近，不能把截图成功当视角表现最终合格。

开场交通池采用现有程序化平民，北行士兵实际沿村路转去前线，不再释放后回原兵站目标。`OpeningCausalityVerified` 实际同时在场上限为十名武装友军、十五名无枪群众／伤员；根代理检查近处群众画面，不把总计数当所有百姓始终可见。班长按主角正常移动速度跟进，玩家离队太远时等待或追上，不能用慢班长凑章节时间。

第一人称白盒不应靠说明牌才看懂用途。新 `Data_FirstLevelP012Station` 组织车厢、机车、车轮、连续双轨、枕木、站房门廊、卸货棚、货物和后送棚。车内地板与每级台阶通过同一布局顶面进入 `GroundHeight`，屋顶不加入地表；旧白盒不提供该配置时仍为平地。新 `Data_FirstLevelP012Horizon` 替换贴近开场的四面高墙为远处可见土缘、离散土岗与村落，外场为 780×780 米，出生点到实体土缘超过 200 米。外场扩展不是任务路线加长，也不是 P0 时长达标。原先横穿兵站且与新车头重叠的 122 米悬空铁路桥已移除，只在远侧回撤沟道保留 23 米短公路桥；西侧真实双轨与南端短装卸线不再互相断开。

已保留的失败：`OpeningCausalityCampaign` 在 B23 停止。两副担架已到站，玩家却仍被要求回旧掩护点并同时贴近担架，条件互斥。已加真实队伍停靠／低姿接应与到站旧状态兜底；兜底单独记录原因，不补历史掩护事实。`RailStationCampaign` 完整输入到 B25，三处掩护 `[2,4,6]` 均由真实低姿接应完成，没有使用到站兜底。两副担架到站、同一副担架重新抬入掩蔽部、终局冻结、批准后启程、窗外担架与飞机转向同屏断言通过。普通死亡 0 次，故意扑救回退 1 次；末尾生命 22.34。整关测试先保存这些功能证据再检查严格 P0 首枪时间门，没有降低要求：本轮第一枪 124.783 秒，因此命令仍以失败退出；总时长 897.983 秒（14.97 分钟），不是 23–26 分钟合格记录。B23 实际 153.367 秒，也高于 P1 的 105 秒目标。

最终站场 `StationFinalSurface` 实际从车厢地板 1.25 米依次踩过 1、0.75、0.5、0.25、0 米，无位置跳变，继续完成领弹、枪械检查、望远镜与炮击因果至 B06；十名武装友军／十五名无枪群众伤员上限通过，浏览器零错误。根代理检查了回看车厢、机车、站房分区和主动低头看台阶的第一人称图；站台与路线色带共面闪烁已修复。取景仅测试输入主动转头，不是生产强制镜头。站场早期漏拍两个回看视角的 `StationDescentVerified` 失败记录保留。

本批 quick 38 项通过，旧白盒浏览器回归通过；VoiceTest、AudioTest 与 GunFeelTest 通过。完整 prepush 已执行，但本次发布时仍有长程正式关卡探针在运行，不表述为整套全绿。PhysicsTest 的正式下载布景缺少碰撞体断言，在未修改的主检出 `66ab22a5` 上只读复跑也失败（相同构件、零控制台报错），确认不是本批新增。部分浏览器探针的玩法断言通过但发生 `ERR_NETWORK_ACCESS_DENIED`；同源码 RangeTest 经批准在无此网络限制的环境复跑，18 项全部通过。MenuTest 初次因 `_shots` 写权限失败；批准后重跑完成了白盒完成菜单／选章等断言，随后截图等待远程字体超时，仍记失败。字幕检查点回退另验证清除旧时间的频道占用，并保护恢复中的批准字幕不被新闲聊打断。

### 空间重排：战场纵深、交错人流与实体回环（2026-09-04）

本批在独立 `P012BattlefieldDepth` worktree 中实现；用户截图确实来自本 P012 白盒，不归咎于打开旧入口。P0/P1/P2 重新读取并按 Notion spec-to-implementation 工作流转成以下本地验收项，未改写 Notion 原文。

- `Data_FirstLevelP012Space` 将北侧战术区向北刚性平移、东南战术区向东刚性平移；原稿坐标与编译后的世界坐标分开，跨区道路单独重排。人物、掩体、碰撞宽度、玩家速度没有同比放大或调慢。
- 当前外框实测 295×375 米；北上 208.119 米、后送 334.129 米、回撤 244.961 米。`DepthScale` 实际正常输入贯穿西侧 355 米走廊用时 83.267 秒；10 秒仍走 49.556 米。快速调试模式另测 26.467 秒／10 秒走 149.116 米。后者只是对照，未读取用户当前开关状态。
- B08 机枪终点距东侧枪眼约 70 米，补充有限机枪阵位与遮蔽出生路径；机枪保留正式生命、弹道与伤害，不靠增加血量延长战斗。
- 北侧连接增加折角、东南道路横向绕过院落，西侧回程真实穿过抬高的铁路支线并重访原枢纽。回撤门按新路线横断面与两岸相接，原 `SouthCut` 同步改变可见实体与碰撞；闭门不封后送道路。低沟岸仍可翻越，不能把沟内封闭说成整张地图绝对不可绕。
- 开局有限人流由三名北上士兵、五名南下平民、两名步行伤员组成，五名平民更早在前左方接近。慢玩家的村路对向组合保留。六名非交通友军在开场组装时各自安置于安全站位，随后错列跟进，B03 恢复原有行为；不在运行途中循环传送或补人。
- 根代理检查实际画面，确认原六人贴脸重叠问题已拆开。旧前奏夹具无视公开 3 米到达半径，始终追到班长 1.2 米背后；现开局按公开半径跟随，后期担架／护送夹具不变。玩家仍可自由接近角色，不强行推镜头。

本批保留的失败过程：第一版扩大南北纵深使回撤超出 P2 时长，已改为主要向东展开；早期 B08 远距夹具总选低躯干导致连续打在墙后，精确夹具现在长距先尝试通视头部，生产命中规则未动。`DepthCrowdTen` 的 B13 假卡住来自测试未计入队列路点进展，已补只读进度；`DepthBalanced` 在 B20 的卡住是真实 AI 长距离导航量化把目标吸入隔墙内，已把这批手工接近路分段，追兵也改为绕沟口进入而不横切新沟岸。旧失败证据不覆盖、不记作通过。

最终源码为 Main150 / Data16 / Layout14 / Space1 / Flow18 / Runtime21 / Setpieces22。`DepthFinalObserver` 从开场真实输入完成 B25，1063.133 秒（17.72 分钟），第一枪 301.433 秒；零普通死亡、一次故意扑救回退，最终生命 90.24。实际批准后启程、窗外担架、转弯同屏、空地火力重叠、两副担架、原担架重抬及终局冻结全部通过，浏览器零错误。敌人有限，不因追兵死亡而复活补齐；本轮 B21 是步枪清场，不声称投掷成功。
