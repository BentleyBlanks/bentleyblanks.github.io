# 布料双面吸血

入口仍为 `?cloth=1` 布料测试场。效果是共用 `ClothBlood` 组件；本次只在测试场装配，没有改 07、14 剧情或原单被资产、原布料求解器与参数。

## 模型与边界

`Script_ClothBloodModel` 为纯 JavaScript 双层有限体积薄片模型，每层包含可移动血色、已吸附血色和湿润量；两层共用静止平面坐标。注入按接触足迹分配，邻格交换守恒、边界不外流，多血源直接累加。可移动血色缓慢转为吸附血色，停供后仍会扩散，最终留下不再移动的色迹。湿润量独立指数衰减，所以干涸不会删除血迹；干燥时间旋钮是湿润量的 e-fold 时间，默认数分钟，不是倒计时到零。

薄布、毛巾、厚棉被的容量、扩散系数、穿透时间和吸附时间分别在 `Data_Tuning_ClothBlood`。厚织物容量较大、背面出现更慢；同样血量在厚织物上的浅色边缘更紧。参数单位是作者调参单位，**未用实测血液或特定织物标定**。没有求解自由液面、滴落、重力汇流、折叠面间的接触转印、纤维三维孔隙、凝血或湿布重量对力学的反馈；它是可控的视觉近似，不是完整流体或毛细管求解。布料原有无自碰撞和无棉胎体积压缩限制继续适用。

双面格场每 0.1 s 固定步长更新，物理仍是 1/60 s。异质导通率和经纬方向性固定在布面上；局部细纤维形状由同一静止坐标着色补足。血色总量没有固定源槽覆盖；事件最多 2048 条，保留最后一条给停止供血，满容量明确拒绝新编辑，清除后释放。回放上限一小时，编辑过去时截断未来；每 10 秒缓存完整状态，最多 24 份（标准单件约 6.4 MB），历史修改使对应未来缓存失效。时间条松手时才执行回放，避免每个鼠标移动事件从零重算；未缓存的长历史仍需同步重算。清除保留当前旋钮，移除血迹、供血与时间线。

## 材质与运动契约

`Script_ClothBlood` 在厚度修改和蒙皮之前复制 `clothBloodRest` 属性：X/Z 映射为布面的归一化坐标，Y 正负区分真实封闭壳两面。点击用已变形三角形的重心坐标还原到该属性，正反面不取相机朝向或世界贴花位置。包边在两面之间插值；不跨 UV 图集缝接。

材质经过 `CloneShadedMaterial`，保留所有原补丁后通过 `MaterialPatches` 注册血迹补丁。每件样品私有状态和一张 RGBA 双面图集，只增加一个 sampler，颜色数据为 `NoColorSpace`。基础法线、纹理和蒙皮不改；颜色、保留织纹的底色混合式及干湿粗糙度取自现有 `CharacterWounds` / `BLOOD_WOUND`。Fresh/Dry 色通过 `THREE.Color` 转入线性空间。浓处深暗红，薄边逐渐露出布纹；新血与旧色迹混合后会重新湿润、降低粗糙度。

没有透明覆盖片、额外渲染几何、自定义顶点形变或对象 draw 钩子。组件复制输入几何，避免两个共用源模型互相覆盖静止坐标。连续动作仍由现有骨骼历史写 MotionVector；切镜、恢复姿态和厚度改变继续通知 camera cut。清除与回放只改材质状态，不伪造运动历史。Dispose 恢复原材质/几何并释放私有图集与克隆材质、几何。

## 检查

`ClothBloodTest` 检查守恒、非负、干湿独立、双面先后、多源、容量、确定性回放、历史分支和隔离；`ClothBloodBrowserTest` 在正常 high 材质的真实布料场检查贴附、相机/动作、操作、正反面、干湿截图、材质隔离和 GPU sampler/蒙皮历史。既有 `ClothRangeTest`、`ClothRangeBrowserTest` 与 `MotionVectorContractTest` 保留。图片只留本地 `tmp/ClothBlood/`，模型观察使用 640 像素预览。
