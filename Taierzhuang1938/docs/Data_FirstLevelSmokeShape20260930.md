# 远景烟柱造型修整（2026-09-30）

用户反馈实拍里的烟「形态太奇怪」。用第 04 阶段站位（北屋脊、西北坡的远景柱）逐柱近看，原因有两条：

1. **洋葱圈**：每个烟团是一个球内的体积密度，但球面边上密度没收到 0，噪声在边缘仍为正，被四边形的圆边硬切成正圆弧；十几个同轴、半径远大于间距的球一层套一层，读作同心圈。
2. **飞碟摞**：所有烟团几乎在同一根轴上，上部又同时「横向拉宽 ×(1+spread)、纵向压扁 ×(1−0.2·spread)」，每团成了 2:1 的扁盘，整根柱子像一摞飞碟。

## 改动（`Script_BattleSmoke.mjs`）

- 片元：`Density` 乘 `rim = 1 − smoothstep(0.28, 1, |p|²)`，密度在球面上平滑到 0；场的下沿门限 `smoothstep(0, .56)` → `(-.06, .62)`，边缘更软。
- 片元：光照透射率与 1 按 0.16 混（粗略的多次散射），厚芯不至于成一团团黑斑；受光面的太阳色先压掉三成色度（黄昏太阳色把整根烟染成酱红）。
- 顶点：烟团按本团大小的比例散在柱轴四周（`0.13 → 0.30`，上部再 ×(1+0.7·spreadT)；路边烟只取 0.4），高度错开 ±0.11 个团宽。上部变宽主要靠这个散布；单团横向只再宽 0.45·spreadT、纵向只压 0.08·spreadT。
- 数量、位置、随机序列、`Data_FirstLevelDistantSmoke` 的配方数字都没动；每步两次纹理采样不变。

## 验证

- `Script_FirstLevelDistantSmokeTest`：路线净空断言按新顶点公式镜像（多算了散布量 `baseSize·scatter·√2`），仍全过。
- `Script_FirstLevelDistantSmokeBrowserTest`（真 GPU）：可见/动画/遮挡/清理/重置/近处/六类分层检查全过，WebGL 错误 0。
- 实拍：高画质、第 04 阶段，同机位改前改后各五个视角（北屋脊近/中、西北坡、风剪带、远景全貌）；同心圈与飞碟摞消失，柱子读成根部黑、上部翻滚变宽的烟。
