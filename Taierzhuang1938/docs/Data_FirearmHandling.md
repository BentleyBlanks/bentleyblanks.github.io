# 玩家枪械散布与近墙持枪

本次调校按 2026-09-13 用户要求：弹着中心更密；站稳、蹲下、开镜提高精度；移动和连射扩大散布，停火恢复；机枪有累积后坐；近墙向下收枪并限制开火。

## 运行时契约

- `Script_FirearmHandling` 的 `SampleShotDisk` 采样有边界的二维高斯分布。最大角度仍由 `Player.SpreadDeg` 与 HUD 共用；不是固定世界半径，不补偿远处的重力下坠。玩家手持与架设机枪共用分布函数。
- `FirearmHandling` 按武器 ID 保留连射状态，每帧衰减，换枪不会把扩散转给另一把枪，也不能用来清空原枪的扩散。当前一发使用扣扳机时的精度，出膛后再增加下一发的扩散。
- 原有姿态、受伤、压制、屏息、两脚架修正继续参与真实散布；开镜精度连续插值。移动停止后还有短暂回稳过程。栓动步枪的拉栓间隔足以清空单发扩散。
- 只对轻／重机枪增加连射后坐倍率和停火恢复延迟；蹲下、卧倒、两脚架降低手持机枪后坐。视角上跳与横摆有上限，回落只记入实际发生的视角位移。栓动步枪保留原来的单发反馈与全量回稳。
- 近墙用眼位与意图枪管方向的多条射线探测；长度按枪身长度缩放。不能用已经收下的枪口来判断是否该重新抬枪，否则会形成收放振荡。真实枪口遮挡检测仍保留为射击兜底。
- 近墙阻止射击时不扣弹、不触发枪声或枪焰；已收下的枪须抬回可射击位置才能开火。枪管围绕握枪手向下转动，手臂继续使用现有 IK。开镜与 FOV 随收枪退出；墙边自动探身仍响应右键意图，探出后恢复开镜。

## 参数与验收

新增参数唯一来源为 `Data_Tuning_FirearmHandling`；基础武器精度沿用 `Data_Weapons`，姿态与移动修正沿用 `Data_Tuning_Player`。

- `Script_FirearmHandlingTest.mjs`：分布密度、对称性、边界、分枪扩散与恢复、机枪支撑系数、枪身长度与遮挡。
- `Script_FirearmHandlingBrowserTest.mjs`：真实按键射击、姿态精度、三种机枪连射与停火恢复、长连射后坐上限、近墙枪口位置、停止开火与恢复、架设机枪。
- `Script_FixedCenterAimTest.mjs`：固定墙面实弹分布居中且中心更密，当前启用枪械的机械瞄具对齐。
- `Script_CoverLeanBrowserTest.mjs`：保留墙边探身、受遮挡禁止射击、手动侧身和 AI 视线契约。

截图与 JSON 报告放在忽略目录 `_shots/FirearmHandling`，不作为游戏资产提交。

## 枪口焰与瞬时照明（2026-09-14）

三八式、汉阳造及共用 Viewmodel 的火器复用已交付 Vefects 火焰遮罩，三片向前火舌与端面亮核合批。持续时间、颜色、强度和尺寸统一取 `Data_Tuning_FirearmHandling.MUZZLE_FLASH`；世界烟尘继续走 Vfx 枪种配方。没有新增生成位图。

玩家开火经 `VfxSystem.MuzzleFlash({player:true})` 获得灯槽短时优先权，NPC 不得在包络结束前把这盏灯移走。灯仍由 LightRig 驱动，low 走固定点光、其余档位走簇光，不增加灯数或开火时重编译。现有枪身 Standard/PBR 材质响应真实直接光，木托为漫反射、金属为粗糙镜面反射；没有用枪身自发光冒充照明。

`Script_MuzzleFlashTest.mjs` 验证两支枪的腰射和 ADS、high/low 两条光照路径、NPC 抢灯保护及熄灭。GPU 对照隐藏火光、世界和手臂，在同一真实枪身姿态只开关枪口灯，按枪身遮罩计量受光像素；正式后期截图另留 `_shots/MuzzleFlash` 本地复核。
