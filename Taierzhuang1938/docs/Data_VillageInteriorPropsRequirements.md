# 耿家庄室内小物件建模需求（第一关 06–10）

2026-10-29 写给执行方（Codex）。范围：**第一关第二段（06–10）耿家庄巷战**里玩家进得去、看得见的屋子，所需的生活用具、小物件、摆件的建模。墙、房子、地形不在本单内。做出来的东西要能在第二关东关、城内民房复用。

时间：1938 年 3 月中旬（春节 1 月 31 日刚过六周），鲁南平原村子，日军先头部队刚进庄。

---

## 0. 先读这几条

1. **滕县农家睡床，不是炕。** 新编《滕县志》·什物：民国时「多用雕花面子床、顶子床，铺草苫和苇席」。现在老耿家东间的白盒是炕（`Data_FirstLevelWhiteboxVillage.mjs` 的 `KitchenKang`）——**改不改等用户拍板**（见 §7），模型先按床做。
2. **主食是煎饼。** 《滕县志》·饮食：1949 年前富户吃麦子煎饼，穷户吃掺杂粮、糠的高粱煎饼；用石磨磨糊、鏊子烧柴摊烙。所以锅屋里一定有**鏊子、煎饼筐**，院里有**石磨**（街坊家那盘已经有）。
3. **厨房当地叫「锅屋」。** 仓库里叫「灶屋」，不用改名，但贴图上的文字、配音里如果出现，用「锅屋」。
4. **这是穷人家，在逃难。** 老耿家人正要走（两口锅已经装上驴车，灶上只剩空锅眼，见 `Data_FirstLevelWhiteboxVillage.mjs` 第 456 行注释），屋里是「收拾到一半」；街坊家是被日军堵在窖里，屋里是「被翻过」。**不要摆成博物馆样板间**，东西要旧、要乱、要少。
5. **没出处的东西标「推定」。** 下表每件都标了依据：「县志」= 新编《滕县志》原文有；「华北通例」= 华北农村普遍有、但滕县志没写；「推定」= 合理但没查到。按项目跨系统契约第 16 条，做完后把「推定」那几件同步进 Notion「史实与创作对照表」。

## 4. 制作要求

### 4.1 打包方式（照接收院 M15/M16 的先例）

- 用 Blender 生成脚本建：`_blender/Script_BuildVillageInteriorProps.py`。源工程放 OneDrive `C:\Users\Bentl\OneDrive\AI\Models\Blender\Taierzhuang1938\VillageInteriorProps\`，不进仓库。Blender 按根目录 CLAUDE.md 的 `Script_BlenderMcp.mjs start / exec / stop` 用完就关，报告附 `status --scan`。
- 按屋子分几个 GLB，不要一件一个文件：`Model/Model_VillageKitchenProps.glb`（锅屋）、`Model_VillageHallProps.glb`（堂屋）、`Model_VillageBedroomStoreProps.glb`（卧房 + 堆放）、`Model_VillageTempleShopProps.glb`（庙 + 铺子）。每件是**一个独立根节点**，能单独选。
- 每个 GLB 配一份 `Model/Data_<同名>.json`：每件的尺寸、三角数、字节、SHA256。
- 登记 `Data_ExternalAssets_VillageInterior.mjs` → `Script_ExternalProps`。

### 4.2 坐标与尺寸

- 原点在**底面中心**，米制，Y 向上，正面朝 −Z（与 WardProps 一致）。
- 按真实尺寸建，不靠摆放时缩放；`maxStretch` 只用来贴合旧占位盒。
- 「状态变体」（完好 / 翻倒 / 打碎 / 被翻开）做成**同一件的不同根节点**，命名 `<Name>_Intact`、`<Name>_Overturned`、`<Name>_Broken`、`<Name>_Opened`。

### 4.3 面数（游戏用）

| 档 | 例子 | 每件三角数 |
|---|---|---|
| 小件（< 0.3 m） | 碗、筷笼、灯盏、铜元、煎饼、弹壳罐 | 150–800 |
| 中件（0.3–1 m） | 罐、凳、风箱、鏊子、煎饼筐、纺车、衣箱 | 800–3,000 |
| 大件（> 1 m） | 灶台、条几、八仙桌、床、碗柜、大缸 | 2,000–8,000 |

- **P0 的贴脸件**（灶台、风箱、鏊子、煎饼筐、条几、八仙桌、座椅、弹壳罐）可以到档位上限，边缘倒角、木头开裂、缸口崩口要建出来，不靠法线贴图糊。
- 一间屋里所有摆件合计不超过 6 万三角；重复的小件（碗、罐）走合批，别每只一个绘制调用（`Script_LivedInProps.mjs` 文件头有写法）。

### 4.4 材质与贴图

- 先用项目已有的共用材质：木头 `VillageTimber`、陶 `HouseholdCeramic`、编织 `Wicker`、布 `HouseholdCloth`（经 `ResolveTengxianMaterial` 解析，同城调色一致）。
- 需要新贴图的（土布蓝白花纹、高粱煎饼、红纸门对、熏黑的灶面、柳条编织）按 `docs/Data_TextureAssetStandard.md` 四步走，登记 `Data_TextureManifest.mjs`。
- **旧化要做够**：锅屋整体烟熏（越靠上越黑）；手常摸的地方磨亮（风箱拉杆、门闩、椅背、条几边）；陶器露胎、崩口；布有补丁、洗褪色；纸发黄、卷边。
- 颜色口径：土布青、蓝、白为主（县志·服饰）；漆木家具是深褐/枣红但大面积磨掉；红纸门对已经褪成粉白。

### 4.5 碰撞和玩法

- 照 `Script_LivedInProps.mjs` 文件头的规则：**盒顶高出地面 0.56 m 以上**才挡路（导航和 AI 认它）；矮的只挡子弹、挡穿模。
- 灶台、大缸、条几、八仙桌、床、碗柜、粮囤：挡路 + 当掩体。
- 碗、罐、灯盏、茶壶：P2 做可打碎（中弹换成 `_Broken` 节点 + 碎片），没做之前就是纯视觉。
- 近战位置（09-7 灶台边）：灶台的碰撞盒要和翻倒动作对得上，改之前先跑 `Script_FirstLevelStreetFightTest` 和 0610 的 `SceneTest` / `KeyframesTest` 看有没有挡到人。

### 4.6 字

对联、中堂、年画、灶君神码、书页、账本上的字：

- **不用生图直接出的字**（生图里的汉字基本是错的、似是而非）。用字体在 Blender 或贴图脚本里排好真字，或者做成远看看不清的墨迹块。
- 内容只用老式通用吉祥话（如「天官赐福」类），不要编新句子，不要有任何人名、地名、年份、政治口号、商标。
- 写在模型说明里：每张带字贴图的原文是什么。
