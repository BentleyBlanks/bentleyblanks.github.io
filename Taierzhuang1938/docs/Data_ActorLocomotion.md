# NPC 位移与步态同步

`Script_ActorLocomotion` 是 `CharacterModel` 内的共享动画时钟与支撑脚校正层，适用于两军步兵、军官的原持枪跑，以及低姿前进、背枪跑。AI、任务路线和碰撞继续拥有角色根节点；动画层不移动胶囊，也不改变玩法速度。

## 距离时钟

- `moveSpeedMps` 为实际移动速度；`moveSpeed` 仅保留旧编辑器的归一化输入。原地编辑器预览只调播放速率，不把未移动的展示根误当成需要世界接触锁定的角色。
- AI 设置 `locomotionTracked`，用两次实际骨架更新间的水平位移与 `elapsed` 差值累计。LOD 跳帧、临时开火更新和变速不再以“本帧速度 × 固定降帧倍数”估算。
- 第一关任务适配器传入自己的实际地面速度；火车乘客使用相对车厢速度，车辆运输位移不能驱动脚步。
- 零 dt 挂点读取不消费位移；瞬移、长时间不可见后重新采样会清空接触历史。受阻时速度归零，低于移动阈值进入站姿，慢速移动不会过早被判成站定。
- 每段动作的参考速度乘真实模型世界缩放后才换算播放速率。播放速率没有人为的正下限；相邻步态保持相位，动作编辑器的强制播放保持原始时间。
- 远景 `ActorCrowd` 的姿势按原片 1 倍速从相位零等分烘焙；运行时 AI 即使不更新近景骨架，也累计真实位移并传入翻页相位和实速。远景减速、受阻时不会继续跟墙钟踏步，低速移动也不再停留在站姿桶。

## 速度分摊：播放速率 × 步幅（2026-09-28）

距离时钟保证了「走多远、放多少相位」，但只靠改播放速率时，一条 1.8 m/s 的跑步片要跑 3.4 m/s 就得 1.9 倍速，
日军蹲姿前进（0.22 m/s 的挪步片）被 AI 以 1.44 m/s 推着走时要 6.7 倍速（实机探针中位，P90 9.4 倍）——
脚没滑，但腿像抽筋，看上去和移动完全对不上。改用 UE5 Lyra 的做法，三件事一起：

1. **播放速率钳制 + 步幅缩放（Stride Warping）。** 速度比 `ratio = 实速 / (片速 × 世界缩放)` 拆成
   `播放速率 × 步幅`：速率留在 `playRateMin–playRateMax`（0.8–1.25），余下的由步幅承担（0.7–1.5）；
   步幅到限后再由速率接手，脚宁可快一点也不滑。步幅跟随平滑后的速度比（`strideSmoothS`），
   速率再按实际显示的步幅反解，所以任何一帧都满足 `速率 × 步幅 = ratio`，距离积分仍然精确。
2. **步幅缩放的做法。** 以骨盆在地面的投影为中心，把两只脚沿身体朝前方向（片子的步幅轴）的偏移乘步幅，
   横向位置、脚高和脚掌滚动保持原片；长步幅腿够不着时骨盆下沉（至多 `pelvisDropMaxM` 0.1 m），
   再用原长双骨 IK 解腿。之后才是支撑脚世界锁定，锁的是缩放后的落脚点。
   只对有测量支撑区间的循环步态启动；换到其他片时权重在 `strideBlendS` 内淡出，
   强制动作、腾空、白刃、死亡、布娃娃、抬担架与不在世界里移动的预览立即停用。
3. **按速度选步态。** 日军与国军同一套 TengxianHumanoidV1 骨架（53 根骨静息位置逐根相同），
   日军步枪兵蹲姿移动超过 0.45 m/s 改播 `AllyCrouchReady`（0.75 m/s 俯身据枪蹲走），
   低于 0.36 m/s 才回 `RifleCrouchAdvance`，中间留回差（`Data_Tuning_AllyGait.crouch*`）。
   两条片加上步幅缩放，0.12–1.9 m/s 的蹲姿移动都在 1.25 倍速以内。
   机枪手、手势中等不能用步枪动作库的人蹲着移动时，也播这条蹲走，不再用原地蹲姿在地上平移。

4. **分层步态（按骨骼分层混合）。** 抬担架与跛行是视频转骨骼的慢速原地挪步：前位担架的支撑脚只走 0.54 m/s，
   后位担架的片子是**倒着走**的（支撑脚 0.33 m/s 向前），跛行净位移接近 0；旧代码按 1.35–1.4 / 1.1 m/s 播放，
   06–07 护送段实测前位滑移 0.64、后位 1.12（脚比身体还快地往前倒滑），任何播放速率都救不回来。
   `Script_LayeredGait` 在移动时把骨盆和双腿换成共用骨架上标定过的 `AllyCarryWalk`（1.35 m/s，有支撑区间），
   骨盆以上保留原片，并把原片时间轴拉伸到走路周期上，颠簸节奏和步点对齐；停下时仍回原片。
   分层片（`<原片>Walk`）用走路片的标定，由距离时钟驱动；抬担架仍不做步幅缩放和支撑脚锁定
   （任务人物层自己把骨盆居中、把手钉到担架杆上），跛行两者都做。代价：跛行的腿不再拖步，只剩上身的伤姿。

数值在 `Data_Tuning_ActorLocomotion`。远景 `ActorCrowd` 不做步幅缩放，仍按原片步幅翻页。
本次没有做起步/急停的距离匹配（Distance Matching）和侧移的朝向扭转（Orientation Warping）：
现有素材没有起停与转身片，AI 走动时身体也朝着移动方向。

实机取证（第一关 01–07 真实流程，逐帧量「着地那只脚的世界位移 / 根节点位移」，0 为不滑、1 为脚跟着身体平移，
只计脚尖离根节点 7 cm 以内的帧；跑步有腾空相，P90 会混进腾空的脚，只看中位）：

| 人群 / 动作 | 改前速率中位 / P90 | 改后速率中位 / P90 | 改后步幅中位 | 滑移中位 改前 → 改后 |
| --- | --- | --- | --- | --- |
| 日军蹲姿移动 | 6.69 / 9.39（RifleCrouchAdvance） | 1.28 / 1.79（AllyCrouchReady） | 1.50 | 0 → 0（P90 1.36 → 0.02） |
| 日军跑步 RifleRun | 1.69 / 1.85 | 1.25 / 1.30 | 1.34 | 0 → 0 |
| 国军提枪蹲走 AllyCrouchCarry | 1.67 / 2.13 | 1.25 / 1.53 | 1.13 | 0 → 0 |
| 担架前位 / 后位（06–07 护送） | 0.94 / 0.99（原片） | 1.09 / 1.15（分层走路） | — | 0.64 / 1.12 → 0.012 / 0.012 |
| 日军机枪手蹲姿移动 | CrouchIdle 原地平移 | AllyCrouchReady 迈步 | — | 1.0 → 迈步 |

同样的变速在单人合成实验里（开/关步幅缩放 P90 均为 0）复现不出来，待查。

分层步态（侧视实测，支撑脚世界位移 / 身体位移）：前位担架 0.76 → 0.018、后位担架倒滑 → 0.018、跛行 → 0.007。

## 源片测量与支撑脚

`_import/Script_LocomotionProfileBake.mjs` 对正式 GLB 做 120 Hz FK 采样，测量低位、向后运动的脚尖支撑区间及后移速度，输出 `Data_ActorLocomotion.mjs` 并记录源文件 SHA-256。源持枪跑参考速度约为 NRA 1.914、IJA 1.879 米/秒；旧路径直接采用 3.6 米/秒导致明显欠步频。背枪跑实测约 2.600 米/秒。低姿前进沿用已独立验证的原动作位移标定。

支撑阶段把脚尖的水平接触点留在世界位置，用原长双骨 IK 调整腿部；保留原脚掌滚动和垂直曲线。落脚端渐变权重；不拉长骨骼，不把脚踝当鞋底压到地面。每帧 mixer 采样前还原上帧修正，防止累积。强制演示、腾空、白刃、死亡及协作搬运让给专用姿态。

**松锁（2026-09-28）**：一步支撑结束时，锁住那一刻累计的修正量（原片落脚点相对实际位移的漂移）不再在 `contactBlendS`（35 ms，约两帧）里一次还回去，而是带进摆腿阶段按 `contactReleaseS`（70 ms 时间常数，0.2 s 还掉 95%）衰减 —— 脚在空中，看不出来；下一步落地时从当前显示的位置接着锁。修正超过 `maximumCorrectionM`（转向、极慢速）时这一步当作提前抬脚，同样平滑还回，下一步重新锁，不再「断开再从脚尖重锁」。改之前开场探针量到：罗班长、何有田、刘文财、幺娃、传令兵出洞时每一步都有一帧小腿跳 25–45°、着地脚单帧挪 10–30 cm；关掉锁定这些跳变全部消失，确认是松锁那一下。

**跨接缝的一步（2026-09-29）**：一只脚的着地段跨过循环接缝时，contacts 里写成两段（`RelaxedWalk` 右脚 `[[0,0.1231],[0.5538,1]]`），其实是同一步。原来循环一绕回来就当成新的一步：锚点重设、锁定权重从 0 重爬，这一步攒下的修正一帧丢掉——开场日兵甲边走边骂转身时正好卡在接缝上，右大腿一帧 31°、脚挪 17 cm。现在从 0 开始、且最后一段收在 1 的那一段沿用最后一段的 key 和锚点，权重按最后一段的起点算（接着锁满），这一步照常在 0.1231 结束、按上面的松锁还回去。

本次保留现有动画素材。速度同步和接触校正不提供新的自然慢走、急停、侧移或原地转身动作，也没有实现全身 Motion Matching；已有素材仍决定这些姿态的表现上限。担架和跛行停下时保留其专用负重姿态与时间控制，移动时见上文「分层步态」。
