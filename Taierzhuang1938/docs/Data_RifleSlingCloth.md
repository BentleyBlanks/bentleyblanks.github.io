# 背枪枪带布料模拟

2026-11-04，用户：「国军日军身上背着的步枪有一根带子，我希望这个有一些布料模拟的效果，至少是看起来要符合物理的，现在他这个样子会很奇怪。」

模块 `Script_RifleSlingCloth.mjs`，数值表 `Data_Tuning_RifleSlingCloth.mjs`；门禁 `Script_RifleSlingClothTest`（纯 Node，真 GLB）、`Script_RifleSlingClothBrowserTest`（白盒实机与枪带 GPU 速度像素），TestRunner 域 `rifleSling`。模型、枪械和动作原件保留；只替换运行时带子的绘制与形变。

## 1. 原来为什么怪

背枪的带子是 `Animation/BackRifleRun/Animation_TengxianNraBackRifleRun.glb` 里的 `Model_BackRifleSling`：照原国军模型胸口捏死的一条扁带（72 个截面），挂在 `Socket_BackRifle` 下、整条跟着胸骨走。换了身材就不贴身——白盒的 X Bot 身上过右肩那段悬空翘成一个钩、斜挎过胸那段离开胸口；日兵甲、何有田肩上翘在外面；胖的人反过来切进身体。人跑、转身时一点不动。

## 2. 现在怎么做

- **一根绳**：32 个质点，两头钉在枪的上、下背带环上（资产带子的两个端点，跟着枪走），中间受重力、有惯性、碰身体。位置动力学（PBD），坐标系 = 枪的挂点（刚体、米制）。子步 1/90 s、每子步 10 轮：钉两头 → 段长（不许拉长、压短较软，正反交替扫）→ 抗弯 → 很弱地拉回资产形状（只管「从右肩过、从左肋下绕」这个走向）→ 碰身体（最后做）。贴身的点有摩擦。
- **惯性**：匀速走、跑时带子跟着躯干走；躯干变速（起跑、急停、每一步的上下颠、转身）时把变了的那一截按 `inertia` 传给带子（每点每帧最多 `inertiaMaxM`）。只传加速度、不传速度——传速度的话匀速跑带子会被一直往后吹（第一版就是这样，跑几秒带子拉长两倍、滑开 40 cm）。
- **身体 = 这个人此刻看得见的蒙皮网格本身**（白盒里是 X Bot / 日兵甲 / 何有田那层，原身体藏着；游戏里是国军 / 日军模型）：带子附近 16 cm 内的顶点按 3 cm 体素抽稀成表面采样点（带法线），每帧 CPU 蒙皮（四骨线性混合，与 GPU 同一公式）。每个质点取最近三个采样点按距离倒数插出切平面推出去。体素按真实尺寸划（日兵甲、何有田的 GLB 绑定空间是厘米）。
  - 不算的骨头 `skipBones`：前臂、手、手指、小腿、脚（甩起来从带子上掠过，不该推着带子走；试过前臂软推，甩手时带子跟着抖、采样点多三成）。
  - 上臂要算（肩头三角肌归上臂骨，不算的话过肩那段会陷进肩里）；大腿根要算（枪托那头的背带环在屁股高度，不碰大腿带子会从屁股里抄近路）。
  - 大腿根的粗采样保留软推 `softBones` / `softPush`；下摆到背带环的一段另收集实际索引三角面，每帧同公式蒙皮，用线段与三角面的相交修正补上点采样漏掉的衣角。
  - 采样切平面只在 `surfaceSupportM` 内有效。旧实现把裤腰、下摆朝上／朝下的面无限延伸到胯外空处，把相邻带子点分别向上、向下推，跑动单节会拉到约 1.67 倍。局部平面与真实三角面共同求解后，Node 四秒跑动实测最大约 1.17 倍，胯边线段与衣服三角面相交为零。
- **长度按身材定**：装上时先把带子收紧裹到身上（段长压到 0.75 倍推 40 轮，碰撞一律硬推——软推拦不住收紧的拉力），量出裹紧的长度，放松 2% 当绳长；垂 0.25 s 后若身体把它撑得更长就按撑开的算。所以每种身材都是「刚好挎紧、略有余量」。
  - 异步换可见身体时重新量长和挎带，不能只更换碰撞点而沿用原身材的绳长。
  - 胸前原始引导若已离身体超过接触余量，弱引导改用此人垂稳后的贴合解；过肩与绕胯仍保留拓扑引导。避免模拟已裹到新身体上、每帧又被旧固定带形拉回外面。
- **渲染**：一个质点一根骨头的 `SkinnedMesh`（截面 = 资产带宽 × 4.5 mm 的扁方条，每环 8 个点、环 i 全绑骨头 i）。GPU 蒙皮，运动矢量按骨骼历史自动对（[MotionVector 接入规范](Data_MotionVectorContract.md)：不许 CPU 改顶点）。骨头朝向：沿带子；贴身处带面贴着身体表面（宽度方向 = 切线 × 表面法线），悬空处与两头照资产带子的朝向；沿带子平滑两遍。材质拷原带子的一份（蒙皮 / 不蒙皮共用一个材质会每次重选着色器）。

## 3. 接线

- 原带子造出来的两处注册：`Script_RelaxedGait.UpdateRelaxedGaitWeapon`（白盒、开场导演）与 `Script_FirstLevelP012BackRifle.InstallP012BackRifle`（正片 P012），都是 `RegisterRifleSling(原带子, actor.root)`。
- 每帧：`Script_Main.RenderScene` 在整帧唯一一次 `scene.updateMatrixWorld()` 之后调 `StepRifleSlings(dt, camera)`（这时姿势、挂点是这一帧的终值；它直接写带子骨头的 matrixWorld，必须排在第一次 `renderer.render` 之前）。Profiler 桶 `slingCloth`。`dt` 是玩法时间：暂停时带子跟着挂点刚性走、不推模拟。
- **模拟出来的带子挂在场景根的 `RifleSlingCloth` 组下，不挂在人物底下**：白盒 X Bot 层会把人物底下所有蒙皮网格藏掉（`XBotSkin.hidden`），伤口 / 血迹也扫人物的蒙皮网格。
- **原带子留在原地当参照**：位置、显隐都照旧由原来的代码管（X Bot 的 `_KeepSling` 照常改它），只是 `layers` 全关、不画；模拟的带子每帧照它的显隐。没注册、没人调 `StepRifleSlings` 的页面原带子照旧画；资产带子认不出（不是「每截面两条边」的扁带）也照旧画。
  - 白盒的旧 `_KeepSling` 会反推整根刚性带子、按体型放大；这个矩阵只用作模拟的初始走向。两头由 `SetRifleSlingAnchors` 记录实际枪架及原始本地矩阵，避免枪已推到身后、端点却留在身前。端点朝向也跟实际枪架，按独立世界坐标量误差小于 1 mm。
  - 关闭或释放时恢复原有全部 layer 位；整个人物／挂点子树移出场景也会释放带子、几何与骨架，包括模拟关闭时。

## 4. 省钱

- 采样点每帧只蒙皮「某个质点的候选」那部分（候选 = 质点 10 cm 内的采样点，每 4 帧全算一遍重挑）。
- 原带子相对挂点没变就不重算资产形状。
- 身体与挂点矩阵未变时复用蒙皮结果；真实三角面先按线段附近选候选与所需顶点，再做包围盒排除，避免每轮全扫整个身体。
- 三角面只计算位置，不重复计算用不着的蒙皮法线；包围盒每次姿态更新后缓存。每段另缓存较窄的候选包络，投影超出包络时立刻补完整候选检查，不以丢掉碰撞换耗时；求解热循环不创建最近三点的临时数组。
- 12 m 外隔帧算（相位按注册顺序错开，两帧的时长合起来推）；30 m 外不模拟，刚性跟着挂点走。
- 从 30 m 外重新接近时按当前姿态重新贴合，避免远景冻结期间的人物重定向／姿态变化留下旧的包裹路径。
- 装上每帧最多 2 根（一根约 2 ms），没轮到的这一帧照旧画原带子——白盒一开场十来个人同时背枪不会卡一下。
- 性能以本次报告为准；旧版约 0.2 ms/根的浏览器结果不包含下摆真实三角面修复，不能充当新版性能证据。

## 5. 已知的

- **开口下摆的量法**：枪托背带环低于上衣下摆，最近三角面的法线符号不能判断开口衣服的内外。保留该距离作为诊断，但下摆不再豁免：Node 检查实际线段与衣服三角面零相交，且整条带子每节拉长均须小于 25%，不再允许胯边 2 倍。
- **背带环在身体外的人**：白盒里何有田的枪托伸到左胯外 5–10 cm（枪的摆放，不归带子管），带子要接到那里只能从左手外侧过去。
- 带子不推枪：枪还是刚性挂在胸骨上（`Socket_BackRifle`），只有带子动。
- 调试：`RifleSlingClothStats()`（`count / simulated / ms / cloths`）；`SetRifleSlingClothEnabled(false)` 全部退回原带子（A/B 对比）。

## 6. 验收口径

- Node 真 GLB：固定挂点、四秒跑动、真实衣服面、非刚性摆动、瞬移、暂停、显隐、异步换身体、原 layer 恢复、整个人物子树移除、关闭时释放与确定性。
- 白盒 02-7：国军和日军均接入当前可见身体。逐个人物将相机移入模拟范围、待重新贴合后，从实际蒙皮顶点独立量胸前十点，至少 70% 在表面外 25 mm 内、最深不超过 8 mm；不采用中断前改成的 50%。原 `rope.distance` 是局部平面的缓存诊断，冻结远景时会过期，不能代替真实表面；正面、斜面、侧面和背面近景为 1280×720。
- 03-1 连续预演：有模拟、有运动、固定点误差小于 1 mm，无 NaN，整条带子每节拉长小于 25%。浏览器每根中位数小于 0.8 ms：近景逐根计时，整组均值包括远处刚性更新在内；不能将整组成本只除以当帧处于模拟状态的根数。
- 真实 32 骨枪带几何写入生产 Prepass 的 RT1：首帧／停止为零，平移 2 cm 对应夹具相机的 6 px，弯曲和回摆方向正确。另跑通用 `MotionVectorContractTest` 与 `CarriagePropVelocityTest`。
- 回归保留 `BackRifleRunTest`、`FirstLevelP012AnimationTest`、`EditorBlockoutBrowserTest` 与 `BootTest`。背枪测试的原烘焙武器哈希作为来源保留，只额外接受已发布 `7b339eff3` 的精确枪机资产哈希；不重烘或替换动作。
