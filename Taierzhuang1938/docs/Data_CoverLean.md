# 靠墙自动探身（现状）

通用玩家机制，正式第一关与所有使用 PlayerController 的白盒共用。交互参考 COD14《使命召唤：二战》战役靠掩体瞄准时的自动探身；参数为本游戏米制场景调校，不声称复刻原作内部数值。

- 站立或蹲下，靠近墙角按住右键瞄准，向射界通畅的一侧探身；不自动扣扳机，开火仍用左键。
- 松右键、后退离开墙角、转离掩体、换弹、负重、架设武器、跳跃、翻越、卧倒会收回。拉栓期间保持依托，避免步枪每发都进出掩体。
- Q/E 保留手动左右探身，优先于自动选择。头部位移在当前物理场景上逐帧限幅，不能穿过侧墙；不开自动跳越低墙。
- 探测从未偏移的身体眼位出发，前方与内侧肩线识别近墙，外侧眼位和枪线检查开口。短进入延迟及当前侧优先避免抖动；移出范围时立即取消自动意图，镜头平滑收回。
- 眼位、相机与持枪模型一起偏移，腿部和移动胶囊保持原位。玩家头部、上身受击体积随偏移，AI 视线与射击瞄点识别探出的头部。没有额外命中率或减伤奖励。
- 出膛前校验眼位到枪口的墙体遮挡，枪管越过薄墙时弹着仍结算在墙上，不能从墙后生成子弹。

规则在 Script_CoverLean；参数在 Data_Tuning_Player.COVER_LEAN / CAMERA / MOVE；Player 负责碰撞、姿态和机位；Main 只接线武器占手状态与枪口遮挡结果。操作说明使用 Data_Text_Input。
