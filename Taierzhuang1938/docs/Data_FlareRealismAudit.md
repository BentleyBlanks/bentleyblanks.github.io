# 信号与照明效果：拟真总体验收账

目标保持为：游戏内及特效编辑器中的效果达到可验证的写实程度，符合时代/史料，或有足够证据与成熟 AAA 效果对照。前两轮为阶段记录，不能用接入成功或单张摄影棚截图代替完成判定；最终结果以文末交付验收为准。

测量对应 `_shots/FlareEffects/` 与忽略目录 `tmp/Flare/Revision*.txt`，原图及运行日志不提交。时间和强度是本游戏预设的数值，不是史料测量数据。

全套 `SamplerBudgetTest` 扩展矩阵遇到后续装载超时，**没有记作通过**。已返回的第一关 medium/GI 材质中有采样器达到16上限的变体；后续加入阴影不能未经预算处理直接增加一个采样器。新增特效的0/1采样器结论来自实际启动特效后的独立 GPU 检查，不来自这个未完成的全套矩阵。

## 第二轮尚未完成的检查（后续结果见交付验收）

1. 在实际夜间街巷、壕沟和建筑旁检查从发射到灭光的连续过程，覆盖中远景、遮挡和风向变化。
2. 检查光是否不合理穿过掩体/建筑、实体是否穿屋顶；评估现有英雄光/阴影路径，补足所需遮挡并量性能。不能把摄影棚“地面变亮”当成这条通过。
3. 与可观看的实拍或 AAA 参考做相同阶段的时间对照，核查光芯/烟迹比例、燃烧闪烁、伞摆与熄灭节奏。EA 的说明文章只确认照明用途，不证明视觉一致。
4. 在最终实现上重跑相关门禁、检查截图/连续运动和部署版本，再逐项做完成审计。上述缺项仍存在时不得把目标标为完成。

## 2026-10-26 第三轮过程记录

- 已核1945年原件封面与印刷页70–71：九五式70毫米照明弹约20秒、90,000烛光，原文明示未缴获实物。已将信号手枪与炮弹光学依据分开，Notion及游戏资料馆同步，未升级滕县使用认定。
- 实景屋面网格与当前破坏孔洞求交、发射受阻、地表变化：`FlareSurfaceTest` 2,189项通过，`FlareTest` 160项通过。实景屋顶落点与可见表面相差小于2cm；燃烧录音跟随位置、熄灭清声部。
- 新的簇光打包深度阴影不增加PBR sampler。固定夹具HDR屋下2.358→0.184，无遮挡点1.292不变；移开屋顶恢复2.358。双灯交替、相机移动、删除灯/重置与GL错误检查通过。约110m接收区域比完整视锥减少了这处实景的阴影绘制（约1,800→310），不将此视为全地图帧率承诺。
- 90,000强度暴露了未标定夜景只测光不调节的问题。新临时测光只允许压暗至多3EV，灭光后平滑恢复；`ExposureTest --probe-only`新增真实GPU回归通过，旧曝光/光晕/LUT检查也通过。已标定时段保留旧规则，编辑器保存恢复临时适应。
- 第一轮第三版门禁：Flare、Surface、Shadow、World、Effects、ClusteredLights、PostFrameGraph通过；这轮之后又加了曝光适应、实景HDR断言及载体斜面贴合，须在合入主分支后复核对应门禁。EditorTest遇到自动画质倍率干扰手动0.6分辨率断言，已明确关闭该独立倍率，保留原绝对像素断言，等待重跑。
- 有限边界：低档/白盒沿用既有降级；阴影为向下有限视锥，远处视锥外及体积雾未采此投影；伞衣为几何形变近似。此前全套SamplerBudget超时仍不算通过，最终需核最挤的第一关GI变体。
