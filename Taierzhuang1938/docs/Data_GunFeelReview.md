# 枪械手感评分表（对标战地系列）

> **常设审查项：每一轮迭代都要跑一次。**
> 对标基准是 **Battlefield 1 / Battlefield V** 的栓动步枪手感 —— 那是这件事的业界标杆，
> 而且它俩的年代（一战 / 二战）与我们的 1938 年最接近，参照系不用换算。
>
> 分工：**Easy Red 2 管系统与结构**（压制、伤势、班组、死亡换人、无准星）；
> **战地管开枪那一瞬间**（后坐、时序、声音、反馈、动作重量）。
> 两者冲突时的裁决写在文末。

评分：每项 0—5。
0 = 没做 ｜ 1 = 做了但错了 ｜ 2 = 能看出意图 ｜ 3 = 合格 ｜ 4 = 接近战地 ｜ 5 = 达到或超过

**目标线：全部项 ≥ 4。** 没到就继续迭代。

---

## A 组 · 后坐与镜头（权重 ×3，这是手感的骨架）

| # | 项 | 怎么验（必须是实测数字，不是"感觉") |
|---|---|---|
| A1 | **枪的后坐与镜头的后坐是两件事** | 战地的枪在视图模型里往后顶 + 上抬，同时相机另有一份更小、更快回落的 kick。两条曲线分开。我们若只有一条，画面会像"整个世界被推了一下" |
| A2 | 后坐**不是线性回落** | 顶上去要快（≤80 ms 到峰值），回落要慢且带阻尼。线性回落一眼假 |
| A3 | 后坐**完整回到零**，重量感在回落**曲线的形状**上 | ⚠️ 这一条 2026-08-19 改过，原文"战地留一截要玩家自己压"**是错的**（那是 CS/Valorant 的喷射弹道逻辑）。datamine 实测：BF1/BFV 栓动步枪残留为零，0.25—0.5 s 收干净，每发从同一瞄准点起。要验的是曲线：`Decrease ∝ TimeSinceLastShot^0.5`，t=0 时为 0 ⇒ 回落**从零速率起步再加速**（踢→悬→加速归位）。取证：给出回 25% / 50% / 95% 各自的毫秒数，前段应明显慢于后段，且**有限时间收敛到精确的零**（指数回落不满足） |
| A4 | 每发**有随机偏航**但有界 | 左右不能永远同一边，也不能真随机到不可学习 |
| A5 | 栓动的节奏是**三段**不是一下 | 开火 → 后坐峰值 → 拉栓（枪机后行/抛壳/推回）。三段的时长比要能读出来 |
| A6 | 开火那一帧有**画面顿挫** | 极短的 FOV 微缩或位移（≤2 帧），不是持续晃动 |

## B 组 · 开镜与时序（权重 ×2.5）

| # | 项 | 怎么验 |
|---|---|---|
| B1 | 开镜有**过冲**，不是线性 lerp | 枪抬到位会略微越过再回稳 |
| B2 | 开镜时间与武器重量挂钩 | 驳壳枪最快、捷克式最慢，差距要能感觉到 |
| B3 | **开镜动画播完前不给开枪** | 战地与 ER2 都有这条。抢开的一枪必须不准或不响 |
| B4 | 冲刺→开火有**延迟** | 枪从斜挎位摆回来要时间。没有这条，冲刺就是无代价的 |
| B5 | 屏息**收窄视野**而不只是稳住准星 | FOV 微缩 + 摇摆压到极小 + 听得见呼吸 |
| B6 | 落地/翻越有**短促下沉回弹** | 不是瞬间归位 |

## C 组 · 声音（权重 ×2.5，战地最强的一环）

| # | 项 | 怎么验 |
|---|---|---|
| C1 | 一声枪响是**分层**的 | 瞬态爆音 + 机械声 + 环境尾，三层能分辨。单层的"啪"是最廉价的破绽 |
| C2 | **近射与远射是两种声音** | 远处的低频被空气吃掉，只剩"啪—嗒"和长尾。不是同一个音量调小 |
| C3 | **室内/巷道有混响**，开阔地没有 | 台儿庄全是窄巷，这一条能直接把空间感做出来 |
| C4 | 拉栓、上膛、桥夹压弹**各有声音** | 而且要能盖过枪声尾巴，让玩家知道自己在装填 |
| C5 | 空仓那一下听得出来 | 我们不显示弹药数（对标 ER2），所以这一声是玩家唯一的弹药信息 |
| C6 | 爆炸后有**耳鸣/闷响**衰减 | 主总线临时低通 + 高频正弦衰减 |

## D 组 · 命中与反馈（权重 ×2）

| # | 项 | 怎么验 |
|---|---|---|
| D1 | 打在不同表面**反馈不同** | 砖=灰白粉尘+碎块弹跳、土=黄尘、木=木屑、金属=火星拖尾、沙包=沙流 |
| D2 | 弹孔贴花留在墙上 | 而且贴合法线不 z-fighting |
| D3 | 打中人有**明确但克制**的反馈 | 战地有击中提示音；我们对标 ER2 默认关准星与命中提示 —— **裁决见文末** |
| D4 | 曳光/弹道看得见方向 | 中日双方颜色不同 |
| D5 | 抛壳可见且落地有声 | 桥夹压弹时抛出的空桥夹也要有 |

## E 组 · 动作与重量（权重 ×2）

| # | 项 | 怎么验 |
|---|---|---|
| E1 | 装填是**分阶段**的，不是一段循环 | 中正式/汉阳造/三八式：开栓→取桥夹→压入→抽出空夹→闭锁。每段能读出来 |
| E2 | 装填**可被打断**吗 | 战地允许在特定阶段取消。至少要有明确的"这一发已经进去了"的节点 |
| E3 | 手真的握在它该握的地方 | 左手托护木、右手握把；拉栓时右手真的离开握把 |
| E4 | 换枪有重量 | 收枪→抬枪两段，不是瞬切 |
| E5 | 走动时枪的晃动**滞后于视线** | 且有过冲回弹。这是"有重量"的核心 |

## F 组 · 弹道与命中模型（权重 ×1.5）

| # | 项 | 怎么验 |
|---|---|---|
| F1 | 子弹有飞行时间与下坠 | 战地有。实测三百米下坠应在 0.5—1.0 m |
| F2 | 子弹从**枪口**出膛不是从眼睛 | 视差的物理基础 |
| F3 | 首发精度与连发不同 | 站定首发应显著更准 |
| F4 | 散布受姿态/移动/压制影响且**看得出来** | 不是只有数字在变 |

## 输出格式（审查 agent 必须照此返回）

1. **实测数字**：每一项都要给运行时取证的数字（后坐峰值角度、回落时长、开镜毫秒、
   声音层数、三百米下坠……），不许写"感觉不错"。
2. **逐项打分** + 一句理由。加权总分。
3. **本轮最该改的六件事**，按性价比排序，每条写清楚：
   改哪个文件的哪个函数/常量、**改成什么具体数值**、开枪时会有什么不同、
   为什么这条比别的值。
4. **与战地的差距**：一句话说清楚现在离"接近战地"还差哪一类。

## 冲突裁决（战地 vs Easy Red 2）

这两个基准在几处会打架，按下面定：

| 冲突点 | 战地 | ER2 | 我们 |
|---|---|---|---|
| 准星 | 默认有 | 默认无 | **无**（ER2 优先，这是写实向的定位） |
| 命中提示（hitmarker） | 有 | 可选 | **体验/标准档默认开、写实档关**；听觉回执三档都给（见下） |
| 后坐可视化 | 强、有画面顿挫 | 较克制 | **取战地**（手感优先） |
| 后坐残留 | **零**（回到原瞄准点） | 较克制 | **取战地**，见 Data_BattlefieldNumbers.md |
| 声音分层与远近区分 | 极强 | 强 | **取战地**（这是它最强的一环） |
| 开镜时抢开枪 | 不给 | 不给 | 两边一致，做 |
| 弹道下坠 | 有 | 有（难度可调） | 做，挂难度滑条 |
| 血量与生存 | 快速回血 | 伤口/流血/包扎 | **取 ER2**（史实向） |
| 装填取消 | 允许 | — | 取战地，但要有明确节点 |

一句话：**开枪的那 0.3 秒对标战地，那之后的一切对标 ER2。**

## 命中/击杀回执（2026-08-20 推翻上表原来那一格）

上表原来写的是「默认关，做成难度选项」。实跑之后这条判错了，记在这里免得后人再翻回去。

**为什么错**：本作同时做了三件减法，每一件单看都对 ——

- 没有准星（`Script_Player.mjs` 抬头，ER2 优先）；
- 不显示弹药数（`Script_Hud.SetState`，ER2 的步兵 HUD 也不显示）；
- 结算不打歼敌数（`Data_HistoryQuotes.md` §10，这条不许动）。

三条叠起来，「我这一枪打没打中」就一条出口都不剩了。取证：血雾粒子世界尺寸
0.17 m，一百米外张角 0.097°，1600 px / 55° 视场上折合 **2.8 个像素**；
`impactFlesh` 走 PannerNode 的 inverse 衰减（refDistance 3.5、rolloff 0.9），
八十米上只剩出厂音量的 **4.8%**。也就是说四十米以外，开枪打中人与打空在玩家的
感官里是同一件事。**减法减到玩家读不出因果，减的就不是 UI 而是玩法了。**

**现在的做法**（`Script_Main.ConfirmHit`）：

| 通道 | 命中 | 击杀 | 挂难度吗 |
|---|---|---|---|
| 听觉回执（非空间化，只有开枪的人听得见） | `hitConfirm` 一记干敲击 | `killConfirm` 同一记 + 95 ms 后一记更低的收尾 | **不挂**，三档都给 |
| 屏幕记号（`Hud.Hitmark`，屏幕正中四道短撇） | 骨白、7 px、0.26 s | 干血红、10 px、0.42 s | `DIFFICULTY.hitMarker`，写实档关 |
| 血雾（`Vfx.Blood`） | 按距离补屏幕张角，封顶 3.2 倍 | 同左，量更大 | 不挂 |

**实测响度**（sfx 母线峰值，`?phase=2` 实录采样全部载入之后逐条播、取时域峰）：

| cue | 峰值 | 相对玩家枪声 |
|---|---|---|
| `rifleNra`（玩家自己那一枪） | 0.864 | 0 dB |
| `impactFlesh`（贴脸，零距离） | 0.532 | −4.2 dB |
| `bolt`（拉栓，项目里已认可的"玩法反馈"档） | 0.321 | −8.6 dB |
| `hitConfirm` | 0.261 | −10.4 dB |
| `killConfirm` | 0.258 | −10.5 dB |

回执落在拉栓那一档上：枪声之后听得清，但绝不抢戏。
对照：同一条 `impactFlesh` 在八十米上只剩 0.026（−30 dB），比回执低二十分贝 ——
这就是「远处打中了听不见」的取证。

两条守则：

1. **靠节奏区分命中与击杀，不靠响度。** 只差音量的两个提示音，在几十条枪的底噪里
   等于同一个。所以击杀是"两下"，命中是"一下"。
2. **一次爆炸只回一条。** 一枚手榴弹放倒四个人就响四声的话，那是连杀播报，
   不是命中确认 —— `Data_DesignFirstPass.md` §385 明写不做连杀播报、不做「+1」飘字、
   不做击杀计数。回执里**没有任何数字**。

守着它的：`Script_PlayTest.mjs` 11.6 / 11.7 三条断言（记号序列 + cue 请求计数）。

## 自由瞄准必须看得见，而且不许吃鼠标（2026-08-20）

用户报的原话：「鼠标移动小距离，屏幕的枪没有反应。」实跑取证之后是**两条**毛病叠在一起，
每一条单独都足以让小幅瞄准失灵。

**一、那 2° 从来没画出来。** `Script_Player` 的 `aimYaw/aimPitch` 一直在动，
但相机只读 `yaw/pitch`（`SyncCamera`），视图模型只读**帧间增量**喂 sway 弹簧，
`aimYaw` 的**绝对值**只有弹道在用。加上本作没有准星（这条不动），
于是自由瞄准锥内推鼠标 = 画面上零反馈。锥有多大：`sens = 0.0022 rad/count`，
2° = 0.0349 rad，**16 个鼠标计数以内屏幕上什么都不会发生**。

**二、归位每帧无条件跑，把慢推的鼠标当噪声吃了。** 原来是
`aimYaw *= exp(-dt·2.2)` 每帧无条件执行，稳态偏移 = 鼠标角速度 / 2.2 ——
低于 `0.0768 rad/s`（约 35 count/s）时枪口永远顶不到锥的边界，**视线一步都不会转**。
实测（改前规则的等价复现，`freeAimDeg = 2.0`）：

| 输入 | 鼠标推过的角 | 实际瞄过去的角 | 视线转了 | 枪偏了 |
|---|---|---|---|---|
| 微动 8 计数 | 1.01° | **0.86°**（少 15%） | 0° | 0.86°（但画面上看不见） |
| 60 count/s × 2 s | 15.13° | **7.17°**（少 53%） | 5.24° | 1.93° |
| 120 count/s × 1 s | 15.13° | **11.08°**（少 27%） | 9.15° | 1.93° |

**越慢吃得越狠**，这正是"微调时枪不听话"的来源。

**改法三条**（`Script_Player.Update` / `Script_Viewmodel.Update` / `Script_Main` 的接线）：

1. **把自由瞄准画出来。** `viewmodel.root` 绕相机原点转 `aimYaw/aimPitch`
   —— 原点就是相机原点，转 θ 等于整把枪在画面里挪过 θ 个视场角，
   与弹道的偏离**完全同一个角**。1° ≈ 20 px（55° 视场、1080 p），一个鼠标计数 ≈ 2.5 px。
   它必须挂在 `fovRig` **之上**：`fovRig` 带非等比的深度压缩，转在它下面会把枪拧变形。
   枪口焰、抛壳走的是 `root` 的 world↔local 往返，因此自动跟着偏。
2. **归位只在手停下来之后。** 停 0.10 s 起、0.12 s 拉满。手在动时不归位 ⇒
   **鼠标位移 1:1 全额落在枪口方向（yaw + aimYaw）上**，锥内动枪、锥外动视线，
   但总瞄准角与鼠标永远 1:1。改后同样三档实测：1.01°→1.01°、15.13°→15.13°、15.13°→15.13°。
3. **归位收回来的那一段交给视线。** `yaw += aimYaw·(1-recentre)`。
   不补的话，玩家把枪停在目标上手一松，瞄准点会在 1.5 s 里自己漂掉 2°（一百米上 3.5 m），
   而画面上没有任何提示。补上之后：枪 2°→0.10°（1.5 s），瞄准点漂移 **0.0000°**。

一句话：**自由瞄准是"这一段角度由枪来扛还是由相机来扛"的取舍，不是一个把鼠标吃掉的滤波器。**

守着它的：`Script_PlayTest.mjs` 12.13b 三条断言（枪在画面里真的动了 / 锥内锥外都 1:1 / 归位不漂）。
