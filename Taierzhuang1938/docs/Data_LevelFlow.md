# 第一关 Encounter Designer

入口为高级工具 → 关卡 → Encounter Designer，独立页面 `Tool_LevelFlow.html`。工作区支持单、双、四视口，底部为共用时间轴，右侧为原文与编辑面板。场景 `cover` 标记、`Whitebox/Cover` 材质与工具布设掩体在各视口使用绿色表面、深色轮廓、浅色条纹与盾牌符号，立体标记遵循地形和物件遮挡。布设和标注在右侧对应页签编辑。

## 通路与多视口

空间图统一绘制整个沟岸网络，再统一铺设整个沟底网络，保证支沟口等 T 字交汇处的地面连续。防炮洞、机枪坑、村庄丁字路口等具有独立面积的地点按原始区域画地面。六条折线巷道和村口坡道均接入同一通路网，真实死巷按原始 caps 标记封口。

18 个关键连接点在测试中逐一检查。浏览器测试还在支沟口原误绘位置检查沟底像素，防止后画的沟岸重新封住连接口。

顶部可选单视口、双视口、四视口。每个视口可独立选择空间总览、战斗局部、立体俯视、跟拍或玩家视线，使用同一帧人物和遭遇状态。金色边框表示活动视口，顶部取景按钮与鼠标操作作用于该视口。各视口可独立缩放、平移、复位和选择顺子／冬瓜／班长／头车作为跟随对象。立体视口的旋转按钮每次转 45°，也可选 Scene 自由视角。

立体视口读取场景的原始高度图与沟底基准，调用游戏共用的 `CompileSceneTrenches` 采样实际地面。自适应网格在沟口、弯道与坡道共享边界顶点，远处延伸到场景背景地面。此前遭遇布设新增的凹口按邻近沟底高度开挖，12 条坡道在实际地形端点之间连续插值，统一进入这张地面网格。透视相机远裁剪为 1500 米。地面、建筑与车辆写入同一深度缓冲，人物的遮挡部分以 20% 透明度显示，全遮挡人物的标签透明度为 22%。立体视口的指北方向随视角旋转。

右键拖动转头，按住右键配合 WASD 飞行，Q/E 升降，Shift 加速。中键拖动平移，Alt + 左键环绕，Alt + 右键或滚轮前后移动，F 聚焦所选对象，未选对象时聚焦顺子。左键点选和编辑。手动离开玩家视线或跟拍时，视口切换为 Scene 自由视角。暂停仍可导航，松开右键、取消操作或窗口失焦会清理移动输入。PNG 与工程 JSON 保存自由相机位置、朝向、远裁剪和焦点距离，旧帧包继续可读。

## 编辑与预演

点选地图上的区域或在“布设”页选择对象。选中区域的中心方块可拖动位置，角点可调整范围；选中生成区的路线点可直接拖动，“加路点”后点击地图可延长路线。

触发区支持玩家路线进入矩形／圆形，或从指定拍延迟若干秒触发。区内检查使用连续线段求交，移动触发区后会重算实际触发时刻；路线没有经过该区域时，对应生成组等待触发。

生成区可改阵营、总人数、同时在场上限、补充间隔、存续时长、移动速度、射击目标及行为。支持沿路推进、定点压制、掩体间跃进、绕侧、跟车、撤离和我方驻守。跟车组可选择头车或后车，武器可选择步枪或机枪，投弹间隔设为 0 可关闭投弹。数量为总预算，出兵受结束拍与同时在场上限约束。存续时长是预演中从出现到倒下的示例时间。实际射击命中、掩体遮挡、寻路与难度由玩法白盒验收。

每次有效编辑自动保存到当前浏览器源的 `tengxian1938_encounter_v2`，支持撤销／重做。导出工程 JSON 可跨端口或浏览器保存与分享，导入时校验版本、引用、坐标与数量，失败保留当前草稿。此工具编辑的是自己的遭遇设计草稿。

空间图支持拖动平移、滚轮缩放、本段、全图、跟随战场。跟随按玩家、近敌、战车与接应点的联合范围取景，保留屏幕边距。空格播放，左右键回溯，Shift 配合左右键跳五秒，方括号换拍。阶段、全部 68 拍、滑块和贯穿播放线使用同一条全程时间轴，宽度按真实持续时间分配。镜头动画段用斜纹标记，当前段在播放栏显示拍号与“镜头动画”，悬停可查看每拍原文标题和起始时间。

## 用标注图沟通

暂停在需要的时刻，选择箭头、框或文字并在图上画。右侧可填写文字、删除，标注端点可拖动。标注绑定世界坐标与当前帧，右侧时间书签可返回该帧。

“导出标注图”生成一张 PNG，图下印有拍号、精确秒数、玩家位置、视图中心与比例；PNG 的 iTXt 键 `EncounterFrame` 还保存完整 JSON，包括世界坐标标注、帧定位、当时的遭遇配置及所有视口的类型、独立取景与跟随对象。直接发送 PNG 原文件即可供 agent 回读。“导入”支持这种 PNG 和工程 JSON，能恢复原帧、视图、布设与标注。“复制定位”可复制文字和时间／坐标链接。

Agent 读取用户给的 PNG 时，可用 Pillow 的 `Image.open(path).info['EncounterFrame']`，或调用 `ReadPngFrameMetadata`，再解析 JSON。重新截图或经过图片压缩的文件可能丢掉 iTXt，图下印出的拍号、时间与坐标仍可定位。

## 维护与验证

- `Data_LevelFlow.mjs` 保存剧情拍与玩家路线。
- `Script_LevelFlowMap.mjs` 从真实场景和空间表构建底图。
- `Script_LevelFlowEncounter.mjs` 创建、校验并编译触发／生成组。
- `Script_LevelFlowModel.mjs` 按绝对时间采样人物、战车、触发状态与火力。
- `Script_LevelFlowDocument.mjs` 管理草稿、撤销和 PNG／JSON 帧包。
- `Script_LevelFlowView.mjs` 绘制连通的空间图与编辑手柄。
- `Script_LevelFlowTerrain.mjs` 复用实际地形与壕沟采样，构建共享边界的地面网格。
- `Script_LevelFlowRaster.mjs` 提供三角形深度缓冲和遮挡半透绘制。
- `Script_LevelFlowPerspective.mjs` 绘制立体视口，`Script_LevelFlowViewports.mjs` 管理视口布局与合成导出，`Script_LevelFlowControls.mjs` 管理 Scene 导航。
- `Script_LevelFlow.mjs` 连接编辑、时间轴与标注交互。

`?t=384&x=32&z=106&zoom=5.5` 可传时间与地图视图，`?stage=03` / `?beat=03h` 可按段或拍定位。`window.LevelFlow.Inspect()`、`Seek(seconds)`、`JumpBeat(id)`、`Packet()` 与界面共用入口。

验证运行 `Script_LevelFlowTest.mjs` 和 `Script_LevelFlowBrowserTest.mjs`。检查连续触发、波次上限、追兵和战车衔接、回溯一致性、地图来源、实际 UI 编辑、撤销、刷新恢复与 PNG 回读。验收图保存在忽略目录 `tmp/EncounterEditor/`。
