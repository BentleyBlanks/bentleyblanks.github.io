# ReedSignal1942 ·《苇声：1942》模块契约

## 一句话设计

1942 年冀中反“扫荡”期间，一名十六岁的交通员学徒护送六名失散学童穿过水网封锁。作品借鉴优秀横版电影化解谜的语言，但人物、关卡、视觉与机制均为原创。

主题是：**点名不是数数，是确认每个人都还在。**

## 玩法红线

- 玩家没有攻击键；风险通过观察、遮蔽、声响、队伍纪律和改变环境解决。
- 等待只能提供观察机会，不能自动解决谜题。每章至少有一次主动改变敌情的操作。
- 儿童、平民的苦难不计分、不兑换资源、不用血腥画面刺激玩家。
- 失败回到最近遮蔽点，不反复演出死亡。
- 光与声必须是可读规则：光锥可见，风声窗口可见，队伍移动会增加声响。
- `Data_World.mjs` 与 `Script_Rules.mjs` 必须可由 Node 直接运行，不依赖 DOM、Canvas 或第三方库。

## 历史边界

- 故事锚定 1942 年 5 月至 6 月冀中“五一大扫荡”及其后的封锁环境。
- 苇河县、石桥村、阿苇、周禾与六名学童均为虚构复合创作，不对应真实受害者或真实行动。
- 封锁沟墙、据点网络、水路盘查、群众转移和早期隐蔽地道取材于公开史料；地道不表现为无风险的万能堡垒。
- 侵略责任明确属于侵华日军及其占领体系；不将罪行转化为对现实民族群体的仇恨。
- 玩家只能影响一次虚构的局部转移，不能改写真实战役、真实损失或 1945 年抗战胜利的历史结局。

## 文件职责

- `Data_World.mjs`：历史框架、章节、地形、威胁、互动数据。
- `Script_Rules.mjs`：纯规则、移动、潜行、队伍、存档与关卡图验证。
- `Script_Game.mjs`：DOM、输入、Canvas 绘制、音频与流程集成。
- `Script_SmokeTest.mjs`：纯 Node 冒烟测试，含机器人通关与机制断言。
- `index.html` / `Style_Game.css`：页面结构与响应式界面。

## 交付检查

```text
node ReedSignal1942/Script_SmokeTest.mjs
node --check ReedSignal1942/Script_Game.mjs
```

页面运行时零外部依赖；存档键固定为 `reedsignal1942_campaign_v1`。
