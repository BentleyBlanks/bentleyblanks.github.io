## 一、不可动摇的核心与题材红线（改动前必读）

1. **核心保留项**：「玩家规划并运用地道网络，对抗敌军的侦察、封锁与扫荡」必须是主轴。
   地道必须**有代价、有风险、可被反制**，不是装饰或无风险传送门。
2. 场景是**综合化的冀中平原敌后村落群**，村名一律虚构（枣林庄、柳条峪、石槽村），不伪造真实历史人物原话。
3. **代价账本红线**：群众伤亡、被抓、房屋被焚、粮食被夺只进 `state.ledger`，**绝不转化为资源、分数或奖励**；
   账本项永不为负、永不回落。评级 UI 与文案不得出现绿色/金色/加号/奖励性表述。
4. **歼敌不是计分项**：评级用三勋记制（只奖保全与保网），歼敌只影响敌军撤退（行动力池），超封顶不再显示累计。
5. 文案克制、具体、档案式；不做感官刺激描写，白盒不做血腥表现。特务（平民伪装）未识破时不可被攻击。
6. **不要用堆内容掩盖核心玩法问题**：审查未过的机制先修或删，不添新系统转移注意力。

## 二、玩法规则 v2（定稿 · 实现基线）

> 一句话：敌人在头顶搜庄，你在地下调兵——把整个村庄群变成一件武器。
> 双时钟：敌军每回合都在**积累搜索**、抢走地面存粮（纯缩头会输）；敌军有**行动力池**，
> 伤亡/拖延/破路会加速其撤退（主动袭扰能提前结束扫荡，但每次出手都冒暴露风险）。

### 2.1 回合与阶段

- 关卡 = `平静期（备战）→ 扫荡期（周旋）`，按关卡脚本推进（见 §2.10）。
- 每回合：**玩家阶段**（逐单位操作，任意顺序）→ **敌军阶段**（逐纵队按决策树行动，先算完再按可见性播报）
  → **结算**（烟蔓延→憋闷→被迫出洞→搜索暴露判定→粮食产耗→情报刷新→池扣减→撤退判定→胜负检查，顺序固定）。
- 单位：移动力 MP + 一个「主动作」（用后该单位本回合结束）。免费动作：开关邻接隔断门（每门每回合 1 次）。

### 2.2 地图与地形（11×9 轴向矩形，平顶六角）

| 地形 | 隐蔽(Hide) | 掩护(-1伤) | 可挖地道 | 入口隐蔽上限 | 说明 |
|---|---|---|---|---|---|
| village 村庄 | ✓ | ✓ | ✓(段成本1) | 3 | 有人口/粮仓/组织度；区队部所在为主村 |
| field 农田(青纱帐) | ✓ | ✗ | ✓ | 2 | 隐蔽不减伤 |
| woods 树林 | ✓ | ✓ | ✓ | 3 | 阻挡视线 |
| grave 坟地 | ✓ | ✓ | ✓ | 3 | 经典伏击位 |
| river 河沟 | ✗ | ✗ | ✗ | — | 不可通行（桥格例外）、不可挖穿 |
| open 开阔地 | ✗ | ✗ | ✓ | 1 | — |

- `road` 是格上旗标：敌纵队全路径在路上时 MP 消耗减半；`roadBroken` 后视同越野。
- 视线：距离 ≤ 视野，树林/村庄格阻挡其后延伸。

### 2.3 双层与地道系统

- 每格 = 地表格 + 地下格。地道 = 地下格之间的**边**（段）。挖掘按「工地」推进：
  段 2 进度（村庄下 1）、入口 2、设施 2（门 1）。单位挖掘力/回合：民兵 2、游击 1、联络员 0。
  同一工地同回合只允许 1 个单位施工；组织度≥2 的村庄每回合为村 1 格内的一个工地免费 +1 进度（敌在村 2 格内时停止）。
- **挖掘痕迹（traces）**：每次挖掘动作给对应地表格 +1 痕迹（上限 6，格上明牌显示）。
  扫荡开始时，每个入口的暴露豆初始值 = max(现值, min(本格及相邻格痕迹合计, 阈值-1))。
- **暴露豆全程结算（R2 P0-1，承重墙）**：**每挖通 1 段地道 / 修成 1 处设施 → 该气区所有未被搜出的
  地道口与通风口暴露豆 +1；每开 1 个新口 → 该口自带 +2**。气区按开放门连通计算，所以关门可以把
  「远处动土」与「近处的口」隔开。主动作「掩土」：本格痕迹 -2 **且本格未被搜出的开口暴露豆 -2**，
  **每单位每局至多 3 次**——这是全局唯一的减法。「平静期一锹别动、扫荡期无限开挖」就此作废。
- **入口**：地表↔地下唯一通道，上下穿越花 1 MP。隐蔽等级 conceal 1~3（受地形上限约束），暴露阈值 = conceal×3 豆。
- **通风口 vent**：等效隐蔽 2 的次级开口，可被搜出、可被灌烟；不可通行。
- 设施（挖在已有地道格上）：`storage 储粮洞`（藏粮上限 8）、`shelter 藏人室`（群众容量 6）、
  `vent 通风口`、`fightpost 枪眼`（见 §2.6）、`door 隔断门`（挖在边上：关闭时阻挡烟蔓延与通行）。
- 容量：每地道格至多 2 个单位；群众只能待在藏人室。
- **空气与憋闷（反缩头核心）**：空气分区 = 经开放门连通的地道连通块。分区内有**未被烟熏的通风口或开放入口**
  → 正常呼吸；否则区内每单位/群众批每回合憋闷 +1（烟中 +2）。憋闷 ≥3 → 结算时**一定上地面**（R2 P0-3）：
  ①优先自本分区最近的未封入口涌出；②一个可用口都没有就**在本格正上方刨土钻出**（该地表格 +1 痕迹，
  不产生新入口）；③连正上方都不可通行才退化为每回合 -1 HP。无论地面有没有敌人都要出去；
  出洞时该格有敌 → 群众当场被捕进代价账本。出地面或分区恢复通风 → 憋闷清零。
  **这是地上-地下唯一的强耦合点：把人闷死在洞里不再是可行打法。**
- **自毁封口**：主动作塌毁己方入口（立即生效），断开敌利用；重挖 2 进度。

### 2.5 战斗（确定性，零随机，单一入口 ResolveAttack）

判定顺序：①前置校验（相邻、攻方未行动、我方攻击耗弹药池 1）②伤害 = 攻 ③伏击 +1
④受击方掩护地形 -1（下限：伏击 1 / 普攻 0）⑤扣血、死亡即移除 ⑥反击（仅非伏击且防方存活且防方攻>0）：
反伤 = max(攻-1-攻方掩护, 0) ⑦缴获：我方击杀日军班 +2 弹药、伪军 +1（上限 12；死者不缴获）
⑧攻方隐蔽/伏击状态解除，攻击格留「枪声」目击（置信 2）。

- **伏击（R2 P0-5 改造）**：主动作进入伏击态；敌进入相邻格立即触发先手攻击。
  - 设伏地点：可隐蔽地形 / 未封入口格 / **挖掘力 ≥2 的民兵可在任何可挖地形就地挖散兵坑**（本格 +1 痕迹）。
  - **同一格同时至多 1 个单位处于伏击态**（拆掉「三个班堆一格全砸下去」这个唯一最优解）。
  - **伏击是持续状态**：只有移动、改做别的主动作、开火或被打断才解除，不必每回合重按（Rest 与免费动作不打断）。
  - **打完即暴露**：伏击命中后该单位强制转入 `exposed` 1 回合（可被该纵队当场还击），下个玩家回合开始时清除。
  - **老地方失效**：连续两回合在同一格设伏 → 本次伏击固定只伤 1，且该格获「敌已警戒」标记 2 回合，
    敌寻路对该格附加成本 +4（有路可绕就绕开，绕不开仍会硬过）。
  数学锚点：单伏击 3 伤打不死日军班（4 HP）——残兵会回撤报信；两处不同伏点接力才能全歼。
- **打了就钻**：本回合已攻击且位于**未暴露**入口格且剩 MP≥1 → 花 1 MP 入地，入地后本回合不能再动。
  代价链：枪声目击引来机动队 + 入口使用暴露豆 +2（见 §2.7）——连用两次同一口≈自己交出这个口。
- **枪眼 fightpost**：地下单位在枪眼格可攻击本格/相邻地表格的敌单位（按伏击结算）；使用后该开口立即变为已知。
- 弹药：全局池。L1 开局 6、L2 开局 10，上限 12。攻击（含伏击/枪眼）每次 1。缴获是唯一来源，
  且**收支严格为负**：日军班 +1（打死它要两枪）、伪军/工兵/特务 +0；**反击打死的敌人不缴获**
  （没主动权就没工夫捡枪，否则挨打反而能回血）。

### 2.6 侦察、隐蔽与暴露

- 我方地面单位在敌视野内且未隐蔽 → 产生**置信 2 目击**（被机动队响应）。「隐蔽」主动作：在可隐蔽地形静止时
  敌不可见（相邻除外）；移动解除。地下单位敌军永远不可见。
- **目击两级（防佯动木偶化）**：置信 2 = 敌亲眼所见我方单位/枪声，仅它能让机动队改道（半径内、时效 2 回合）；
  置信 1 = 痕迹/动静，只给该格嫌疑 +1，**绝不拉动任何纵队**。
- **佯动**：联络员/任意单位主动作：现身制造置信 2 目击（自身进入被发现状态，可用剩余 MP 撤离）。
  用真单位承担真风险来牵引敌军——把纵队拖离粮村、拖进伏击口袋。
- **搜索模型**：敌搜索单位把搜索力投给所在格：格内有隐蔽入口/通风口 → 其暴露豆 += 搜索力；
  无 → 该格标记「已搜过」。暴露豆达到阈值（conceal×3）→ 入口**已知（known）**，永久（除非自毁重挖）。
  我方使用入口时：敌视野内 +2 豆、敌 2 格内（无视野）+1 豆、否则 +0；从入口/枪眼开火 = 立即已知。
  暴露豆只由**掩土**减少（每单位每局 3 次，每次 -2；已 `known` 的口不可逆），其余一律只增，
  全程格上明牌（文明式：看得见还剩几回合被搜出）。
- 敌搜索选格（确定性）：嫌疑分 = 2×近 2 回合置信目击 + 2×曾发生袭击 + 1×有明存粮 + 1×挖掘痕迹豆；
  同分按格键字典序。玩家可据此精确预判搜索顺序。

### 2.7 敌军纵队决策树（每纵队每回合按序取首个命中项）

```
0) 波次撤退中 → 沿路网全速退场（在途反地道作业至多再续 1 回合；被打还击不追击）
1) 谨慎整队中 → 原地整队 1 回合
2) 有在途反地道作业且目标口仍已知 → 继续作业
3) 自身为机动队 且 存在时效≤2回合、距离≤响应半径的置信2目击 → 全 MP 逼近，邻接即攻击
4) **已知或暴露豆 ≥4** 的入口在 1 格内 → 反地道四选一（见 §2.8）；工兵队额外会主动奔向全图暴露最高的口
5) 在目标村 → 未搜完则按嫌疑分搜索；有明存粮则征粮 2/回合（进账本+扣我方粮）；否则推进到脚本下一路点
6) 沿脚本路线推进（A*：路 0.5、越野 1、河/断桥不可通）
7) 就地警戒
```

- **谨慎等级 0~2**（遇伏/反地道作业伤亡 +1，连续 3 回合无事 -1）：
  1 级：移动 -1 MP、搜索力 +1；2 级：必须两班同行、禁选攻入、意图箭头只显示下一格。
- **意图明牌**：纵队未来 2 格计划路径箭头 + 当前任务图标，当纵队处于我方单位视野内或
  组织度≥1 村庄 2 格内时显示；机动队响应目击的第 1 回合显示「?」。
- **行动力池（波次时钟）**：每波初值 P。**R2 起两关的基础衰减都归零**，改为
  **扑空衰减**：摸到村 2 格内却一无所获（没搜出开口、没抢到粮、没抓到人、没干成作业）的纵队每支 -1，
  每回合至多 -2。这不是白送——它由「粮藏净、人藏好、口掩住」换来，是地道战本身的胜利。
  我方造成：歼日军班 -3、歼伪军/特务/工兵 -2、
  击伤 -1、破路（敌补给路线上）每处 -2（每波至多 3 处）、敌每次反地道作业自耗（烟 -3/爆 -4/攻入 -4）。
  我方所致扣减每回合合计上限 5。池 ≤0 → 次回合宣布撤退（横幅：「敌军开始收队」）→ 退场。
  硬上限回合数到也撤。**任何池扣减不给玩家任何资源**。
- RNG 仅三处（波次开始时抽取）：路线变体 / 入场格 ±1 抖动 / 嫌疑同分平手。波内一切严格确定。

### 2.8 反地道四选一（敌邻接已知入口时，按序取首个满足项；全部**提前 1 回合电报**给玩家）

1. **烟攻**（需烟具余量>0，工兵在场）：宣布后次回合点烟：烟从该口沿开放边蔓延 1 格/回合，持续 3 回合后 2 回合消散；
   烟中：憋闷 +2/回合、通风口失效；关闭的隔断门阻挡蔓延。烟不直接杀伤——它把人**逼出地面**（被捕进账本）；
   无路可出才掉血。反制：隔断门分区、备用出口、提前转移。
2. **爆破**（需工兵邻接作业 1 整回合，可被击杀打断）：摧毁该入口 + 该地下格设施；格内单位 -2 HP。
3. **攻入**（需 ≥2 步兵班邻接、谨慎<2）：宣布后次回合结算（**不进入地下层**，抽象一回合）：
   若入口正下方格或其相邻枪眼格有我方单位驻守 → 敌 1 个班伤亡（-3 池）且中止，改标记爆破；
   若无人驻守 → 入口被毁，该格藏人室/储粮内容被捕/被夺（进账本）。**在地道里守口有真实价值。**
4. **封堵**（兜底，任一班 1 回合，**每纵队每役至多 1 次**）：入口被填死（我方从地下重挖 2 进度可恢复）。

### 2.9 经济与群众

- **粮食**：村粮仓（明存）+ 地下储粮洞（敌抢不走，除非攻入得手）。平静期每村每回合 +1 明存粮。
  **扫荡期敌到村 2 格内 → 该村明存粮每回合被搜走 `level.sweepGrainLoss` 担（L1 2 / L2 1）进代价簿**
  （当回合已被纵队征过粮的村不重复扣）。敌在村且有明存粮 → 征粮 2/回合；**明存粮净空后改为抓丁 1 批/回合**。
  主动作「藏粮」：**单位所在村格正下方必须有地道格，且该格与还装得下的储粮洞连通、所在气区至少有一个未封的口**
  → 转移 3 粮入洞（R2 P0-4：粮不会隔空入洞）。组织度≥1 的村平静期每回合自动藏 1（同一连通性要求）。
- **群众**：村人口以「批」计（每批≈十余人）。主动作「转移群众」：单位在村格 → 2 批进入邻接入口连通的藏人室。
  扫荡结束敌离场后群众自动返村。群众在地面被敌捕获、在烟/无氧中伤亡 → 全部进代价账本。
- **组织**：主动作「组织」+1 进度，2 进度升 1 级（上限 2）：
  1 级 = 自动藏粮 + 村 2 格内敌纵队意图箭头常显（哨网）；2 级 = 村 1 格内工地每回合 +1 进度（群众参与）。
- **破路**：主动作，路格工地 2 进度 → 永久断路（敌减速 + 若在敌补给线上则扣池）。

### 2.10 关卡（`Data_Levels.mjs` 数据驱动；地图手工摆位，seed 只走白名单）

- **L1《护粮》**（10 回合，教学）：单村（枣林庄）+ **双路轴（北大车路 + 南土路）** + 河 + **石桥（可破）**
  + **浅滩（唯一可涉处，不可破）** + 坟地伏击位 + 树林。
  我方：民兵×2、游击×1、联络员×1；粮 12；起始地道：村内 1 格 + 1 入口。

  L1 自此也有烟攻/爆破/攻入；池 **14、衰减 0（改扑空衰减）**、上限至 T10；征满即离场；
  **征粮队伤亡≥2 → T+1 报复队/追剿队（seed 抽定）进场**。

  即败 = 区队部被驻占 2 回合 / 战斗单位全灭 / 人口 <50%。
  勋记：①**洞存粮 ≥12** ②伤员 4/4 保全**且无战斗单位阵亡** ③主干无被毁段**且群众零损失**

### 2.11 胜负评级（三勋记制）

- 胜利后按勋记数定级：3 枚 = 甲、2 枚 = 乙、≤1 枚 = 丙；失败 = 丁。
- 结算画面：勋记逐条点亮附一句归因 + 代价账本（中性灰白、逐项列出、无任何奖励表述）。
- `state.result.breakdown` 另存数值分（存续/保粮/保网/周旋加权 + 歼敌 min(8, floor(3·log2(1+kills)))），
  **仅供冒烟测试排序断言，不进 UI**。

### 2.12 防退化策略表（独立审查按此逐项攻击）

| 退化策略 | 打败它的规则 |
|---|---|
| 纯缩头（全程躲地道） | 憋闷 3 回合被迫出洞；明存粮被征光；搜索豆只增不减逐口挖出；勋记全丢 |
| 纯莽夫（不挖网对射） | 野战反击 + 敌数值优势；弹药只出不进；民兵不能野战攻击 |
| 无脑全图挖网 | 挖掘占用有限单位回合（预算比率 1.05~1.3）；痕迹结转成搜索起点；裸网无门无口挡不住烟 |
| 单一安全屋 | 单口被封堵/烟攻即全灭风险；容量与空气分区逼多室多口 |
| 佯动风筝遥控 | 置信 1 不拉动纵队；置信 2 需真单位冒险；机动队专责追击；谨慎升级 |
| 同口反复打了就钻 | 枪声目击 + 使用豆 +2：两次即交出该口；重挖需回合与痕迹代价 |
| 同格叠伏击 / 复读伏击 | 同格至多 1 人设伏；打完转「暴露」挨还击；同格连设两回合只伤 1 且该格被敌绕行 |
| 零地道流（不挖不藏） | 胜负只认洞存粮；明存粮在敌到村边后每回合被搜走 |
| 平静期不动土、扫荡期猛挖 | 暴露豆全程结算：每段每设施都记豆，掩土每人每局只有 3 次 |
| 无限伏击刷弹药 | 缴获上限 12 且净收支为负；池扣减每回合上限 5；预备队投放到杀伤最高轴线 |

  map: { hexes: { "q,r": { terrain, road: false, roadBroken: false, bridge: false,   // bridge=桥或浅滩

约定：
- 格键 `HexKey(q,r)`；边键 = 两格键字典序 `a|b` 拼接。所有键名 lowerCamelCase。
- **纯逻辑模块禁止** `window`/`document`/three/`Math.random()`/`Date.now()`；随机一律 `StepRng(state.rngState)` 并写回。
- 对外接口（`PerformAction`/`EndTurn`）一律 `CloneState` 后推进，返回 `{ state, events }`，不改传入 state。
- 渲染/UI 不自己算规则：一切「玩家能看到什么」由 `Script_Visibility.mjs` 的 `DeriveView(state)` 给出

## 六、表现层规范（操作反馈领域裁决稿）

1. **双主态视图**：地上态/地下态，`Q` 互切（200ms 补间）；`Space` 按住=透视窥视（只读，禁下令）。
   选中地下单位自动进地下态；选中地上单位自动回地上态；点击**永不**自动切层（`Alt+点击` 强制选另一层）。
2. 地下渲染：地下层下沉 y=-6；地上态时地下只显 15% 亮度拓扑线（**不显示地下单位**——保护隐蔽感）；
   地下态时地上退化为 25% 透明屋顶线框，入口开洞标环。段=发光管线、入口=色环（绿/黄/红=暴露三档）、
   通风口=白色竖杆（两层可见）、设施=小立方体+字符图标。不做剖面 shader。
3. **格上信息预算**：每格常显徽记 ≤3；数字一律不上格（进左下固定面板）；悬停 300ms 输出到左下面板（不跟鼠标）。
   徽记：暴露豆（灰空心→红实心）、痕迹（土黄小点）、意图箭头（橙虚线）、烟（黄灰染色）、挖掘进度环、伏击紫环。
4. 操作契约（文明式）：左键选中（单位>地物>地形，当前层优先）；右键=移动/下令（悬停预览路径+风险段变橙；
   降低入口隐蔽的操作需二次右键确认——全游戏唯一二次确认）；`Tab` 下一个未行动单位（自动落层跳转）；
   `Enter` 结束回合两段式护栏（未行动/憋闷≥2/工地闲置/入口将暴露 → 首按弹待办清单可点击跳转，二按强制；
   `Shift+Enter` 直通）；`Esc` 栈：目标模式→取消选中→菜单，3 次必达空闲。
5. **敌阶段播报器**：逻辑先算完 → 仅播 `visible=true` 事件：相机 300ms 平移聚焦 + toast 一行（≤14 字）；
   900ms/条，Space 快进 250ms，Esc 跳过（伤亡红条日志强提示）。不可见事件在播报/toast/日志**零泄漏**。
   `L` 日志抽屉（200 条，格号可点击跳转）。
6. 相机：俯角 55° 锁定不可旋转，滚轮 3 档缩放，中键/WASD 平移，无边缘平移。
7. 引导：6 条触发式一次性提示（两层与 Q / 暴露豆是命根子 / 选中右键移动 / 敌意图可预读 / 地道有代价有风险 /
   胜负目标常显顶栏），localStorage 记忆；前 2 回合敌行动脚本固定保证触发稳定。不做教程关。
8. 键位全表与颜色表以 `Data_Keymap.mjs` / `Data_Theme.mjs` 为唯一来源（账本禁绿/金/加号可 grep 验证）。
9. three r152+ 颜色只转换一次（`new THREE.Color(hex)` 已 sRGB→Linear，禁再叠 convert）；
   Instanced/合批；单一渲染路径；改脚本必 bump `index.html` 的 `?v=N`。

## 七、测试与验收

### 7.1 冒烟（`node TunnelFront1942/Script_SmokeTest.mjs`，退出码即成败，<90s）

- 契约：坐标、状态序列化 round-trip、CloneState 隔离、纯度扫描（核心模块无 window/document/three/Math.random/Date.now）。
- 确定性：同 seed 同动作序列 → 终局 JSON 哈希一致；存档读档续跑 = 一次跑通。
- 模糊：乱打 bot L1/L2 各若干 seed 跑满局，零崩溃、零负资源、MP/HP 有界、账本单调不减。
- **策略排序红线**：会玩 > 缩头 且 会玩 > 莽撞（胜负+内部分双排序）；缩头 L1 必不得甲乙（≤丙或败）；
  莽撞 L1 必败；会玩 L1 必胜且 ≥乙。
- 双时钟数学断言（R2 改口径）：纯躲脚本 → 敌满时长离场、明存粮被征 ≥6、**一次也逼不退**；
  袭扰脚本 → **半数以上 seed 把敌逼退，且逼退落在 T9-T10**（取消基础衰减后收队时点不再是平滑函数，
  池与逼退率才是双时钟本体）。
- **R2 承重墙回归**（每条都能单独变红）：暴露豆全程结算（挖段/修设施 +1、开新口 +2）；掩土 -2 且每人 3 次；
  憋闷 3 回合被推到地面（不掉血）；HideGrain 要求正下方连通；同格单伏击 + 打完转暴露；
  同格连设两回合伤害降为 1 且该格获警戒（含 T1 边界不得误判）；伏击持续状态；L1 洞存粮 9 负/10 胜；
  L1 多 seed 终局出现差异；零地道流必输；复读伏击流拿不到甲；只挖不掩土流必然引来烟攻/爆破/攻入/封堵；
  弹药收支为负；代价簿四栏都会动；同格可攻击 / 民兵散兵坑 / 石桥可破且破后敌绕行。
- 佯动木偶化断言：仅置信 1 噪音的脚本 → 敌纵队逐回合路径与基线完全一致。
- 反地道覆盖：烟/爆/攻入/封堵四出口各至少可达一次；攻入遇驻守必中止且敌 -1 班；烟被关门阻断。
