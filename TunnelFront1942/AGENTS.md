# TunnelFront1942 项目入口

《地下长城 · 冀中1942》为 PC 优先的三维双层六角回合制策略白盒，核心是规划和运用地道网络抵抗扫荡。五幕 A1–A5；不扩展为涂色与科技膨胀的 4X。仓库协作与交付见 [根 AGENTS.md](../AGENTS.md)。

## 产品与技术契约

- 地道必须有代价、风险与敌方反制。保留搜索累积、暴露、地面存粮压力及敌行动力池形成的主动袭扰与生存循环。
- 采用综合化冀中村落和虚构村名，不伪造真实历史人物原话；文案克制，白盒无血腥表现。平民伪装的特务未识破时不可被攻击。
- 群众伤亡、被抓、焚屋和失粮只进入 `state.ledger`，账本单调不减且不换取资源、分数或奖励；评级不以绿色、金色、加号表现这些损失。
- 歼敌不计分，评级采用保全与保网的三勋记制；不靠增加内容回避已确认的核心玩法问题。
- 纯逻辑无 DOM、three、Math.random 或 Date.now 依赖；随机走 `StepRng(state.rngState)`，同种子同操作可复现，状态可 JSON 序列化。
- 战斗走 `ResolveAttack`，缴获与敌池扣减走 `KillEnemyUnit`；跨模块状态、动作、HUD 字段遵循参考中的协议。
- 存档键 `tunnelfront1942_v1`、脚本与本地 vendor/three 独立于其他页面。
- 模块职责不是永久人员分工；共享坐标、状态或接口改动同步全部消费方，并扩大回归范围。

## 验证与交付

- 运行时改动执行 `node TunnelFront1942/Script_SmokeTest.mjs`；规则、状态和坐标变化按参考第 7.1 节扩大回归。
- 表现层变化在本任务预览中验证点选、移动、切层、单位切换、结束回合与敌阶段反馈，查看截图。浏览器路径取当前环境，不假定固定 Linux 安装目录。
- 玩法审查可用 `Script_PlayCli.mjs`、`Script_Balance.mjs` 和第 7.4 节的五项判据。
- 按根流程创建本任务分支，验证后快进交付 master；不复用历史 Claude 分支。提交前处理缓存版本；上线核对部署与页面内容。
