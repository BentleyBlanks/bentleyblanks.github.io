# 《地下长城 · 冀中1942》（TunnelFront1942）

抗日战争敌后战场「地道战」回合制策略白盒 Demo。你指挥冀中平原一片村落里的抵抗力量——民兵、游击班与
联络员——在头顶敌军「扫荡」的压力下，把村庄下面挖成一座会呼吸的地下长城：藏粮、藏人、诱敌、伏击，
撑到敌人耗不起为止。

> 白盒阶段：不追求画面，只追求玩法。三维视图仅用色块与线框表达信息。

## 怎么玩

- 线上：<https://bentleyblanks.github.io/TunnelFront1942/>
- 本地：仓库根目录起任意静态服务器（`python3 -m http.server 8000`），访问
  `http://localhost:8000/TunnelFront1942/`。
- **无浏览器完整游玩**（逐回合下指令）：

```
node TunnelFront1942/Script_PlayCli.mjs new   --level L1 --seed 3 --save /tmp/g.json
node TunnelFront1942/Script_PlayCli.mjs show  --save /tmp/g.json [--layer surface|under|both]
node TunnelFront1942/Script_PlayCli.mjs legal --save /tmp/g.json [--unit u1]
node TunnelFront1942/Script_PlayCli.mjs act   --save /tmp/g.json --json '{"type":"Move","unit":"u1","path":["4,1"]}'
node TunnelFront1942/Script_PlayCli.mjs end   --save /tmp/g.json
node TunnelFront1942/Script_PlayCli.mjs run   --level L1 --seed 3 --bot Skilled
```

关卡：`L1`（护粮 · 10 回合 · 教学）、`L2`（合围 · 16 回合 · 完整）。
`legal` 会列出每个单位当前所有合法动作及其 JSON，复制到 `act --json` 即可下令。

## 核心循环

**平静期备战 → 扫荡期周旋 → 逼退敌军。**

敌人在头顶搜庄搜粮，你在地下调兵。两个时钟同时在走：

- **敌军的搜索在累积**——每个地道口都有暴露豆，敌人搜一次涨一次，涨满就永久暴露。纯躲会被逐个挖出来。
- **敌军的行动力池在消耗**——你每次伏击、破路、逼他动用工兵，都在扣他的池。池空了他就撤。
  所以主动出手能提前结束扫荡，但每次出手都在抬高你的暴露。

## 你要做的事

- **挖**：地道是格与格之间的「段」。挖掘会在地表留下**痕迹**——扫荡开始时，痕迹会直接转成
  地道口的暴露豆初始值。挖得越多越容易被搜出来，所以「全图挖网」是陷阱。可以用「掩土」清痕迹。
- **藏**：把明存粮转进地下储粮洞，敌人就抢不走（除非他攻进来）。群众要转进藏人室。
- **喘气**：地道分空气区。区里没有通风口或开放入口，人会憋闷；**憋闷 3 回合就会被迫涌出地面**，
  不管上面有没有敌人。所以纯缩头会把群众送到枪口下。
- **打**：民兵**不能野战对射**，只能伏击或从枪眼开火。游击班是唯一能正面攻击的单位。
  弹药只靠缴获，且收支为负——你打不了几枪。伏击后可以「打了就钻」，但连用两次同一个口
  就等于把这个口交出去。
- **骗**：联络员可以主动现身制造目击，把敌军纵队从粮村引开、引进你的伏击口袋。但只有**真单位
  真冒险**才拉得动敌人——单纯的痕迹和动静不会让敌人改道。

## 敌军会怎么反制你

敌军纵队的下一步意图是**明牌**的（在你视野内或有组织度的村庄附近时显示箭头）。
地道口一旦暴露，工兵会四选一，且**全部提前一回合电报通知你**——你有一个回合窗口去反制：

| 手段 | 效果 | 你能怎么办 |
|---|---|---|
| 烟攻 | 烟沿地道蔓延，把人憋出地面 | 关隔断门分区、留备用出口、提前转移 |
| 爆破 | 炸毁入口与该格设施 | 工兵作业要花一整回合，打断他 |
| 攻入 | 抢入口、夺走洞里的粮和人 | **洞里有人驻守就能把他打回去**（他损一个班） |
| 封堵 | 填死入口 | 从地下重挖 2 进度恢复 |

## 胜负

- **L1**：10 回合内终局存粮 ≥8 且还有战斗单位。
- **L2**：撑到 16 回合、存活村 ≥2、粮 ≥10、伤员 ≥3 批；区队部被驻占 2 回合即败。
- **评级是三枚勋记**（只奖「保住了什么」）：粮、零代价、逼退敌军 / 保网。
  **歼敌不计分。** 群众伤亡、被抓、房屋被焚、粮食被夺只进**代价簿**——
  这本簿子只记损失，不折功劳，永远不会变成你的资源或分数。

## 操作（PC）

`Q` 地上/地下切层、按住 `Space` 透视窥视、左键选中、右键下令、`Tab` 下一个未行动单位、
`回车` 结束回合（有未办事项时会先弹清单）、`Esc` 逐级退出、`L` 事件日志。
