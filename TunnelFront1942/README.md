# 《地下长城 · 冀中1942》（TunnelFront1942）

抗日战争敌后战场「地道战」回合制策略白盒 Demo。你指挥冀中平原一片村落里的抵抗力量——民兵、游击班与
联络员——在头顶敌军「扫荡」的压力下，把村庄下面挖成一座会呼吸的地下长城：藏粮、藏人、诱敌、伏击，
撑到敌人耗不起为止。

> 白盒阶段：不追求画面，只追求玩法。三维视图仅用色块与线框表达信息。

## 怎么玩

- 线上：<https://bentleyblanks.github.io/TunnelFront1942/>
- 本地：仓库根目录起任意静态服务器（`python3 -m http.server 8000`），访问
  `http://localhost:8000/TunnelFront1942/`。
- **无浏览器完整游玩**（逐回合下指令）：

```
node TunnelFront1942/Script_PlayCli.mjs new   --level L1 --seed 3 --save /tmp/g.json
node TunnelFront1942/Script_PlayCli.mjs show  --save /tmp/g.json [--layer surface|under|both]
node TunnelFront1942/Script_PlayCli.mjs legal --save /tmp/g.json --unit u1
node TunnelFront1942/Script_PlayCli.mjs legal --save /tmp/g.json --unit u1 --json
node TunnelFront1942/Script_PlayCli.mjs act   --save /tmp/g.json --json '{"type":"Move","unit":"u1","path":["4,1"]}'
node TunnelFront1942/Script_PlayCli.mjs end   --save /tmp/g.json
node TunnelFront1942/Script_PlayCli.mjs run   --level L1 --seed 3 --bot Skilled
```

关卡：`L1`（护粮 · 10 回合 · 教学）、`L2`（合围 · 16 回合 · 完整）。

## 先记三条，不然会白卡半小时

### 1. 每个单位每回合只能做 1 个「主动作」

这是全游戏最硬的资源约束。挖掘、藏粮、转移群众/伤员、伏击、隐蔽、攻击、佯动、组织、掩土、破路、
自毁封口、休整——**都是主动作，用掉一个，这个单位这回合就结束了**。

不占主动作的只有三类：

| 类别 | 有哪些 | 代价 |
|---|---|---|
| 移动类 | `Move`、`UseEntrance`（上下地道口） | 只花 MP |
| 免费 | `ToggleDoor`（开关隔断门，每门每回合 1 次） | 不花 MP 也不占主动作 |
| 例外 | 「打了就钻」：本回合已开火 + 站在未暴露的口上 + 剩 MP≥1，可再花 1 MP 钻回地下 | 该口暴露豆 +2，入地后本回合不能再动 |

所以一个民兵一回合能做的极限是：**走两格 + 挖一段**，或者 **走两格 + 藏一次粮**。四个单位一回合
一共就四个主动作——「全图挖网」根本排不进日程，这就是设计的意思。

`legal` 的输出按「主动作 / 移动类 / 免费」分好组，还会告诉你哪些动作**为什么**不在列表里。

### 2. 坐标有两套，别搞混

- **动作 JSON 一律用轴向键 `"q,r"`**（例如 `"3,1"`、`"10,-3"`，r 可以是负数）。
- **ASCII 地图用偏移列/行**：列号就是 `q`，行号 `y = r + floor(q/2)`。
- 反过来读图取 r：**`r = y - floor(q/2)`**。地图第二行 `r=y-` 已经把每列要减的数列出来了，
  单位一览与「地道口一览」里的坐标也全是轴向键，直接抄进 `act --json` 即可。

### 3. `legal` 不加 `--unit` 会吐一百多条

L1 第 1 回合 `legal` 一次能列出上百条合法动作（实测 144 条，绝大多数是 `Move` 的可达终点）。
请一律带 `--unit`：

```
legal --save /tmp/g.json --unit u1          # 分组视图 + 「为什么某些动作不可用」
legal --save /tmp/g.json --unit u1 --json   # 原始 JSON，可直接喂给 act
```

## 核心循环

**平静期备战 → 扫荡期周旋 → 逼退敌军。**

敌人在头顶搜庄搜粮，你在地下调兵。两个时钟同时在走：

- **敌军的搜索在累积**——每个地道口都有**暴露豆**，全程明牌显示。豆攒到阈值（隐蔽等级 ×3，
  村庄里的口是 9）就被永久搜出，接着封堵/烟攻/爆破/强攻挨个找上门（敌军盯上一个口只需要 4 豆）。
- **敌军的行动力池在消耗**——你每次伏击、破路、逼他动用工兵，都在扣他的池。池空了他就撤。
  所以主动出手能提前结束扫荡，但每次出手都在抬高你的暴露。

## 你要做的事

- **挖**：地道 = 相邻两个地下格之间的「段」。**开局只有一个地道口**，别的口要单位下到地下用
  `DigEntrance` 自己开。动土是有响动的：**每挖通 1 段、每修成 1 处设施，本空气区所有已开的口
  暴露豆 +1；每开一个新口，该口 +2**。主动作「掩土」（`CoverTraces`）本格痕迹 -2、暴露豆 -2，
  但**每个单位每局只掩得动 3 次**。
- **修**：设施挖在已有的地道格上——储粮洞（藏粮上限 **8 担/洞**）、藏人室（容量 **6 批**，群众与
  伤员合计）、通风口、枪眼。**一格地道只能修一种设施**，要第二种就得先挖出第二格。
  挖掘力：民兵 2、游击班 1、**联络员 0——联络员挖不了任何东西**。
- **藏**：主动作「藏粮」每次转 3 担入洞，前提是**村 1 格内有连通到还有余量的储粮洞的地道口**。
  「转移群众」每次 2 批进藏人室。
- **喘气**：地道按空气区算。区里既没有未被烟熏的通风口、也没有未封且无烟的地道口 →
  区内每人每回合憋闷 +1（在烟里 +2）。**憋闷满 3 就被迫涌出地面**：有口就从最近的口涌出，
  一个口都没有（自己塌了口 / 被敌封死）就地刨土钻出去——总之留不住。出到地面的群众若与敌同格即被捕，
  进代价簿。
- **打**：民兵**不能野战对射**，只能伏击或从枪眼开火；游击班是唯一能正面攻击的单位。
  设伏位只有三种：可隐蔽地形（村庄/农田/树林/坟地）、地道口格，或者**挖得动散兵坑的可挖地形**
  （会给本格留 1 点痕迹）。伏击是**持续状态**（移动或被打断才解除，不用每回合重按），
  但**同一格同时只容 1 处伏点**，伏击打完当回合会转入「暴露」态可被还击，
  **连着两回合在同一格设伏第二次只伤 1**，而且该格会被敌标记「已警戒」绕行。
- **弹药是真会打光的**：全局池，L1 起手 6 发、L2 起手 10 发，上限 12。每次开火（含伏击、枪眼）扣 1；
  缴获**只有击杀日军班 +1、工兵班 +1，打死伪军和特务一发都不给**——而一次伏击只打 3 伤，
  打死一个 4 HP 的日军班通常要两枪。**收支严格为负。** 实测一局 L1 打了 4 枪、歼灭 1 队伪军，
  池子 6 → 2；每一枪都得挑值不值。
- **骗**：联络员可以主动现身制造目击，把敌军纵队从粮村引开、引进你的伏击口袋。但只有**真单位
  真冒险**才拉得动敌人——单纯的痕迹和动静不会让敌人改道。

## 敌军会怎么反制你

敌军纵队的下一步意图是**明牌**的（在你视野内或有组织度的村庄附近时显示箭头，CLI 里另有
「敌纵队意图」文字列表）。地道口一旦被盯上（暴露豆 ≥4），敌工兵会四选一，且**全部提前一回合
电报通知你**——你有一个回合窗口去反制：

| 手段 | 效果 | 你能怎么办 |
|---|---|---|
| 烟攻 | 烟沿地道蔓延，把人憋出地面 | 关隔断门分区、留备用出口、提前转移 |
| 爆破 | 炸毁入口与该格设施 | 工兵作业要花一整回合，打断他 |
| 攻入 | 抢入口、夺走洞里的粮和人 | **洞里有人驻守就能把他打回去**（他损一个班） |
| 封堵 | 填死入口 | 从地下重挖 2 进度恢复 |

> 电报里的「明日有敌一部自 X 入境」只保证**敌确实会入境**，不保证你看得见：如果入境点在你视野之外，
> 次回合的敌军阶段可能一条相关事件都不播报（不可见的事不会泄漏给你）。想确认就派联络员去看。

## 胜负

- **L1《护粮》**：10 回合内 **洞存粮 ≥10 担**（明存粮不算数）且还有战斗单位。
  扫荡期敌进村每回合刮走 2 担明存粮，粮不入洞就是别人的。
- **L2《合围》**：撑到 16 回合、存活村 ≥2、洞存粮 ≥8、伤员 ≥3 批、战斗单位 ≥1；
  **区队部（枣林庄，格号常显在顶栏与「关键地点」里）被驻占 2 回合即败**，人口跌破 50% 亦败。
- **评级是三枚勋记**（只奖「保住了什么」）。终局画面与 CLI 都会**逐枚列出勋记名称、条件、
  达成与否，以及具体是哪个数没够**。三枚全中评甲、两枚乙、一枚及以下丙，失利一律丁。
  **歼敌不计分。** 群众伤亡、被抓、房屋被焚、粮食被夺只进**代价簿**——
  这本簿子只记损失，不折功劳，永远不会变成你的资源或分数。

## 读 ASCII 地图

地上、地下并排，**每格 3 个字符**，各司其职（这样站在地道口上的单位不会盖住自己的暴露豆）：

```
地上 = [地形][开口位][单位位]        地下 = [设施][内容位][单位位]
       V  3  M                             S  g  M
       村 暴露豆3 民兵                     储粮洞 有粮 民兵在此
```

- 地形位：`V`村 `F`农田 `W`树林 `G`坟地 `R`河 `B`桥 `=`路 `x`断路 `.`开阔
- 开口位：`0-9` 该地道口当前暴露豆、`!`已被搜出、`#`已封堵、`o`通风口、`*`通风口被烟、
  `,`挖掘痕迹、`_`敌已搜过
- 单位位：`M`民兵 `G`游击 `R`联络 `+`我方多单位｜`J`日军 `P`伪军 `B`工兵 `S`特务 `?`身份不明
  `&`我敌同格｜`> < ^ v` 敌意图箭头
- 地下设施位：`o`普通地道格 `S`储粮洞 `H`藏人室 `O`通风口 `X`枪眼 `·`尚未挖通；
  内容位：`g`存粮 `c`群众/伤员 `*`烟

地图下面还有四张随时可查的表：**关键地点**（各村格号、区队部）、**地道口一览**（每个口的
暴露豆/阈值/被搜出与否/谁在上面）、**存粮分账**（各村明存粮 + 各洞洞存粮 + 距胜利线还差多少）、
**敌纵队意图**。

## 操作（PC）

鼠标习惯对标文明VI，直接上手即可：

| 鼠标 | 作用 |
|---|---|
| 左键单击 | 选中（单位 ＞ 地物 ＞ 地形，当前层优先）；`Alt+左键` 强制选另一层 |
| **右键单击** | 对该格下令：移动 / 上下地道口 / 攻击（会降低入口隐蔽的操作需**二次右键确认**） |
| **悬停** | 选中单位后，鼠标移到哪，哪就实时出路径预览：粗白管线 + 方向箭头 + 落点环，落点上方挂一块牌子写「几步 · 还剩多少 MP」；风险段整段变橙，同一份数字也在左下「移动预览」条里 |
| 任意键按住拖动 | 平移地图（左/中/右键皆可；越过 5px 才算拖拽，所以拖完不会误下令） |
| 滚轮 | 缩放（3 档；触控板的小增量会累加，不用使劲滚） |
| 光标形状 | 停在能下令的格子上会变成手型；拖地图时变抓手 |

选中单位后，**能去的格子会整片描上青色六边形边框**，并分两档：

- **亮青** = 走到那儿还剩行动力（还能接着走）；
- **深青（压暗）** = 走到那儿正好走满，本回合到此为止。

进入挖掘目标模式（`B`）时候选格改用**琥珀色**边框，与「能走到」区分。地下层同样有这套提示；
执行完上下地道口的动作后，视角会自动跟着单位换层，不会把人跟丢。

键盘：`Q` 地上/地下切层、按住 `Space` 透视窥视、`Tab` 下一个未行动单位、
`B` 挖掘、`V` 伏击、`F` 佯动、`G` 隐蔽、`W A S D` 平移、
`回车` 结束回合（有未办事项时会先弹清单，`Shift+回车` 直通）、`Esc` 逐级退出、`L` 事件日志。
右上面板常显明存粮/洞存粮分账与区队部坐标；下令被拒时会直接告诉你真实原因。

> 相机是**锁定俯角、不可旋转**的，也**没有边缘平移**（鼠标推到屏幕边不会滚屏）——要挪视角请拖拽或 `WASD`。
