# 《地火线》（TunnelFront1942）

抗日战争敌后战场「地道战」回合制策略白盒 Demo。冀中平原，一九四二年五月：
敌人正在收紧封锁圈，你有十一个回合，要在头顶的扫荡开始之后，把三批共八名群众从地道送出去。

> 白盒阶段：不追求画面，只追求玩法。三维视图仅用色块与线框表达信息。

## 怎么玩

- 线上：<https://bentleyblanks.github.io/TunnelFront1942/>
- 本地：仓库根目录起任意静态服务器，如 `python3 -m http.server 8000`，
  访问 `http://localhost:8000/TunnelFront1942/`。
- 无浏览器完整游玩（供人或 Agent 逐步下指令）：`node TunnelFront1942/Script_PlayCli.mjs`，
  子命令 `new / show / legal / act / path / end / survey`，输出双层 ASCII 地图与完整事件流。
  `path <unitId> <Move|Dig> <targetKey...>` 可一次确认当前回合的连续移动或开挖。
  `legal` 会给每个开挖目标和完整路径持续标出 `Shared / Fast / Quiet / Off-plan`，并列出 AP、工具、
  暴露与改线身份；未勘土层只显示公开的预留值/实付范围，不泄漏实际土层。复制对应 route 即可明确下令。

## 你要做的事

**一句话**：敌人在头顶搜庄封路，你在地下把三批群众一批一批送出去——挖得快会被听见，挖得稳来不及。

- **第 1~4 回合（准备）**：交通员先做**规划侦察**，勘察走廊土层，再决定主干道从哪挖。
  地道不是画线就通——每格有土层（夯土/黏土/树根层/返沙层），各有挖掘成本、稳定度与噪音：
  树根层开挖声大会留地表证据，返沙层下回合就开裂必须支护，黏土费工具但能显著减缓烟流。
- **快掘/静掘是整局可追踪的主线选择**：勘线只把两条最优带的土层视为已知；从第一个分流格开挖后，
  HUD、CLI 和终局会持续记录主线身份、累计施工次数、实际工具、土层噪音、挖掘暴露、接通回合与标线外段数。每段开挖的 AP 等于工具成本，
  因此快掘在北/南都早一个施工回合接通；静掘少噪音但黏土更费工。标线外应急改线仍合法，不过必须预留
  2 AP 与 2 工具、每次只挖一段，并按未知土层额外增加 3 暴露。第一条接通主出口的主线会冻结为撤离优先路径；
  后补支线可救急，但不会静默改写本局身份。若冻结主线塌方而同一出口仍有支线可走，转移预览、在途卡、CLI 与事件日志都会明确标成“同出口应急改线”。
- **第 4 回合起**：可以开始送群众。每批群众进地道后要走若干回合才能抵达出口，
  路上会遇到塌方、烟流、被封堵的出口。
- **发车前先看排班**：网页预览和 CLI `legal` 会按真实通行规则列出本批预计到口回合、
  容量等待和第一个冲突。若当前选择会把剩余慢批挤到期限外，还会在确认动作前报警；
  这条报警固定**当前已通路线**，并假设下一批前不再开路或抢通，所以你也可以及时接通更短支线来改写排班。
- **发车后仍可救车**：点击网页中的在途/被困批次，或在 CLI 运行 `show` / `legal`，会看到当前位置、
  预计到口、能否按当前条件安全出洞、下一处公开阻断，以及**此刻真正合法且有效**的支护、复查、抢通、重挖、
  设陷、伏击或地面压制；动作若会让本批经过烟段或承受其他不可逆代价，也会直接列出群众安全损失。
  “到口”不等于“已安全”；只读时刻表不自动下令，也不会预测未揭示敌情。若恢复动作还需移动、AP、工具或组织，
  界面只列条件，不会虚构一个必然获救的时间。
- **第 5 回合起（扫荡）**：敌军进圈。他们会侦察、搜庄、**封堵出口**、**向地道灌烟**。
  你可以用假迹诱敌、洞口伏击、陷阱、正面阻击来争取窗口，但每一次出手都在抬高暴露度。
  工兵会在多个已确认洞口间优先追踪未过期的较强线索；假迹只会浪费一次调查行动，
  真正的封洞或灌烟仍会提前一回合公开预警。
- **胜利**：三批共八人全部安全撤出，且你确实是在扫荡开始之后完成的转移（不能抢在敌人来之前跑光）。
- **失败**：群众安全度跌到 45 以下（转移秩序崩溃），或行动骨干损失到不足两人。

## 五项资源

| 资源 | 含义 |
|---|---|
| 工具 | 挖掘与支护的燃料，用一点少一点 |
| 组织 | 组织群众转移与维持秩序的能力 |
| 情报 | 侦察所得，用于预读敌军意图 |
| 暴露 | 你的动静有多大——挖掘噪音、开火、地表痕迹都会推高它 |
| 群众安全 | 核心指标，跌破 45 即告失败；只会因你的失误下降，不会因战果上升 |

群众的伤亡、被抓、房屋被焚只会进入代价账本，**永远不会变成你的资源或分数**。

## 操作（PC）

`Q` 地面/地下切层、左键选中、右键下令、`Tab` 下一个未行动单位、`回车` 结束回合、`规则` 按钮查看完整规则。
移动或开挖时可以直接选择本回合内高亮的远端格：规划侦察会标明两条候选走廊的逐格土层，预览再用序号标出路线，
一次确认后仍逐步结算 AP、工具、暴露、烟害与证据。连续命令不会跨回合、自动结束回合、自动支护，
也不会越过新裂缝、烟段、敌军视线或走廊外的未知土层。走廊外目标在合法列表中按最坏情况预留 2 AP/工具，
不会用“能不能点”泄漏真实土层；实际开挖后才揭示并支付真实 1~2 点成本。
