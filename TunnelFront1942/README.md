# 《地下长城 · 冀中1942》（TunnelFront1942）

抗日战争敌后战场「地道战」回合制策略白盒 Demo。你指挥冀中平原一片村落里的抵抗力量——区小队、民兵与群众，
在头顶敌军反复「扫荡」的间隙里，把村庄群下面挖成一座会呼吸的地下长城：藏人、藏粮、转移、诱敌、伏击，
撑到敌人耗不起为止。

> 白盒阶段：不追求画面，只追求玩法。三维视图仅用色块与线框表达信息。

## 怎么玩（当前版本）

- 线上（master 部署后）：<https://bentleyblanks.github.io/TunnelFront1942/>
- 本地：仓库根目录起任意静态服务器，如 `python3 -m http.server 8000`，
  访问 `http://localhost:8000/TunnelFront1942/`。
- 无浏览器完整游玩（供人/Agent 逐步下指令）：见 `AGENTS.md` §7.3 的 `Script_PlayCli.mjs`。

## 规则速览

（实现落地后由每轮迭代同步维护——以游戏内提示与本节为准。）

- 回合制双层六角战场：每格既是地表也是地下。平静期挖地道、藏粮、组织群众；扫荡期敌军纵队进村
  搜粮、搜地道口，你在两层之间转移、隐蔽、诱敌、伏击。
- 地道不是安全屋：入口会被搜出，网络会被烟攻、灌水、爆破、攻入；没有通风口的地道会把人闷出去。
- 敌军有行动力池：拖延、破路、伤亡都在消耗它——把它耗空，扫荡就提前结束。
- 群众的伤亡只会进「代价账本」，永远不会变成你的资源或分数。

## 操作（PC）

实现后同步：鼠标选中/下令、滚轮缩放、`Tab` 下一个未行动单位、`1/2/3` 地上/地下/透视视图、
`回车` 结束回合。
