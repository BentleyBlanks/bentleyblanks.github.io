# 《地下长城 · 冀中1942》（TunnelFront1942）

抗日战争敌后战场「地道战」回合制策略白盒 Demo。你指挥冀中平原一片村落里的抵抗力量——民兵、游击班与
联络员——在头顶敌军「扫荡」的压力下，把村庄下面挖成一座会呼吸的地下长城：藏粮、藏人、诱敌、伏击，
撑到敌人耗不起为止。

> 白盒阶段：不追求画面，只追求玩法。三维视图仅用色块与线框表达信息。
>
> 本文所有数字都用 CLI 实测过（`--seed 3`、第 1 回合、默认继承档）。**数值仍在频繁调整**，
> 每张表下面都写了「这一格去 CLI 的哪一行核对」；发现对不上时**一律以 CLI 输出为准**。

## 这是一条五幕战役，不是两个关卡

**关卡不是难度递增，是认知递增**：每一幕教一件事，后一幕的动作集是前一幕的超集。
本幕没解锁的动作**根本不会出现在 `legal` 里**，直接下令也会被拒绝并回一句「本幕尚未开放」。

| 幕 | 名 | 回合 | 本幕新解锁 | 这一幕要学会什么 |
|---|---|---|---|---|
| **A1** | 单口洞 | 8 | （只有藏粮/转移群众（含地面换格）/隐蔽/佯动/组织/掩土/破路/塌口/休整——**挖不了**） | 洞不通，人就没处去；**人站在哪一格**决定谁被抓走 |
| **A2** | 户户相通 | 10 | 连通挖掘 `Dig`、开新口 `DigEntrance`、修设施（储粮洞/藏人室）、伪装口、**带路 `GuideCivs`** | 网络的价值不是长度，是出路的条数 |
| **A3** | 能打的地道 | 10 | 射击孔、翻板、伏击 `Ambush`、野战 `Attack` | **打一枪换一个地方** |
| **A4** | 毒烟与水 | 12 | 通气孔、**隔断门 `DigDoor`/`ToggleDoor`**、高低差（敌烟/水/刨口全开） | 反制来自结构，不是数值；水从**被灌的那个口**往同高或更低处走 |
| **A5** | 反扫荡 | 14 | 三村相连、跨村地道网、多射击孔协同 | 把整片村庄变成一件武器 |

### 胜负与勋记（每幕各不相同）

| 幕 | 胜利线 | 即败 | 三枚勋记 |
|---|---|---|---|
| A1 | 群众保全 ≥3 批、战斗单位 ≥1 | 战斗单位全灭 | 窖满（洞存粮 ≥4）· 五口（保全 ≥5）· 周旋（把敌逼退） |
| A2 | 保全 ≥5、**洞存粮 ≥10**、战斗单位 ≥1 | 同上 | 户户相通（最大连通块 ≥5 格）· 六口（保全 6/6）· 多口（未搜出的口 ≥2 且伪装口 ≥1） |
| A3 | 保全 ≥5、**洞存粮 ≥12**、战斗单位 ≥1 | 同上 | 换地方（从 ≥2 个不同射击孔开过火）· 六口（保全 6/6）· 逼退 |
| A4 | 保全 ≥6、洞存粮 ≥12、战斗单位 ≥1 | 同上 | 换气（通气孔 ≥2 **且**零逼出地面）· 一个不落（保全 8/8）· 高处（洞存粮 ≥12） |
| A5 | 保全 ≥8、**存活村 ≥2**、**洞存粮 ≥15**、战斗单位 ≥1 | 战斗单位全灭 / **区队部被驻占 2 回合** | 村村相连（同一片网串起 3 个村）· 一个不落（保全 10/10 且零逼出）· **多孔协同**（3 个不同射击孔都开过火） |

> 洞存粮那条线**每幕都高于两个满仓**（A2 10>6、A3/A4 12>5×2、A5 15>6×2）——两个储粮洞也装不下，
> 所以「挖出第三间窖」是每幕都躲不掉的账，粮还得分几个洞放（藏粮会自动先往最空的窖装）。
> **这几个门槛正在被反复调**：`show` 的「幕目标进度」与终局的「勋记逐枚」都会给出
> 「当前值 / 门槛 / 还差几」，看那里，别看这张表。

胜利线随版本调整，**每回合的 `show` 里都有一段「幕目标进度」逐条给出「当前值/门槛（还差几）」**，
以那一段为准。

- **洞存粮才算数，明存粮不算**（A2 起）。明存粮敌一进村就搜得走。
- 三枚全中评甲、两枚乙、一枚及以下丙；**失利一律丁，且三枚勋记一概不计**。
- **歼敌不计分。** 群众伤亡、被抓、房屋被焚、粮食被夺只进**代价簿**——只记损失，永远不折功劳。
- 终局逐枚列出勋记，**并给出「实测值 vs 门槛」**，例如
  `○ 换气……：通气孔 1 处（需 ≥2）；被烟/水/憋闷逼出地面的群众 6 批（需 ≤0）`。

## 怎么玩

- 线上：<https://bentleyblanks.github.io/TunnelFront1942/>
- 本地：仓库根目录起任意静态服务器（`python3 -m http.server 8000`），访问
  `http://localhost:8000/TunnelFront1942/`（可加 `?level=A4&seed=3`）。
- **无浏览器完整游玩**（逐回合下指令）：

```
node TunnelFront1942/Script_PlayCli.mjs new   --level A4 --seed 3 --save /tmp/g.json [--carry default|full|<存档>]
node TunnelFront1942/Script_PlayCli.mjs show  --save /tmp/g.json [--layer surface|under|both]
node TunnelFront1942/Script_PlayCli.mjs legal --save /tmp/g.json --unit u1
node TunnelFront1942/Script_PlayCli.mjs legal --save /tmp/g.json --unit u1 --json
node TunnelFront1942/Script_PlayCli.mjs act   --save /tmp/g.json --json '{"type":"Move","unit":"u1","path":["4,-1","4,0"]}'
node TunnelFront1942/Script_PlayCli.mjs end   --save /tmp/g.json
node TunnelFront1942/Script_PlayCli.mjs next  --save /tmp/a1.json --save-to /tmp/a2.json     # 战役串联
node TunnelFront1942/Script_PlayCli.mjs carry --save /tmp/a1.json [--out /tmp/carry.json]
node TunnelFront1942/Script_PlayCli.mjs run   --level A4 --seed 3 --bot Skilled [--verbose] [--save /tmp/g.json]
node TunnelFront1942/Script_PlayCli.mjs fixture --level A4 --seed 3 --turns 6 --write
```

- **`--level` 只认 A1 / A2 / A3 / A4 / A5**。写别的（包括早已停用的 `L1` / `L2`）会**直接报错退出**，
  不会再像以前那样悄悄回落到 A1。
- **未知参数一律报错退出**。以前 `--from`、`--carry`、`--bogusflag` 都被**静默吞掉**，
  于是「我明明接上了上一幕」这种误会没有任何一处会告诉你。现在每条子命令都有自己的参数白名单，
  写错的 flag 当场报错并列出这条命令认哪些参数。
- `fixture` 用来生成渲染夹具，**会覆写仓库里的 `Data_FixtureState.mjs`**。
  因此它默认只空跑并打印将要写入的目标；真要落盘得显式加 `--write`（或 `--out <别处>`）。
- `run` 的 bot 只认 **`Random` / `Turtle` / `Rambo` / `Skilled`**（`--bot`），整局跑完输出总结 JSON；
  加 `--save` 就把终局落盘，可以直接接 `next` 串下一幕。写别的名字（例如旧文档里的 `Reckless`）会报错。

## 战役是串起来的：你挖下的东西真的会跟着走

**A2 起，每一幕的开局盘面都是继承来的**，不是关卡写死的。带得走的东西只有一样东西的清单：

| 带得走 | 带不走 |
|---|---|
| 地道格、地道段、地道口（含被填死的口，仍是堵着的）、伪装、设施（**翻板除外，要重新支**） | 暴露豆（新的一幕从 0 记） |
| 洞里剩下的粮（按新幕仓容一洞一洞地填，**装不下的就是上一幕白藏了**） | 已知标记、敌军记忆 |
| 剩下的弹药（本幕照例配发，**上一幕省得更多就按省下的算**——认真打永远不吃亏） | 代价簿（新的一幕从头记账） |

三条路子，**开局横幅会明确打印用的是哪一条、继承了什么、对照满配还欠什么**：

```
# ① 战役串联：打完上一幕，带着战果直接开下一幕（推荐）
node TunnelFront1942/Script_PlayCli.mjs new  --level A1 --seed 3 --save /tmp/a1.json
#   …… 打到终局 ……
node TunnelFront1942/Script_PlayCli.mjs next --save /tmp/a1.json --save-to /tmp/a2.json

# ② 显式指定继承源
node TunnelFront1942/Script_PlayCli.mjs new --level A3 --seed 3 --carry /tmp/a2.json   # 拿某份存档当继承源
node TunnelFront1942/Script_PlayCli.mjs new --level A3 --seed 3 --carry full           # 满配档（上一幕该挖的都挖到了）
node TunnelFront1942/Script_PlayCli.mjs new --level A3 --seed 3 --carry default        # 默认继承档（=不写 --carry）

# ③ 看/导出一份存档折出来的继承档
node TunnelFront1942/Script_PlayCli.mjs carry --save /tmp/a1.json --out /tmp/carry.json
```

**不接前作是有账的。**不写 `--carry` 就用该幕的**默认继承档**：一份「别人替你挖了一半」的网，
它在格数／活口数／伪装数里至少有一项严格劣于满配档，弹药也配得更少。例如 A2 的默认档把
村西青纱帐那个口（`2,1`）填死了、洞里一担粮也没有、弹药只配 4 发。

实测对照（同 seed 3，同一幕 A2 的第 1 回合）：

| | 直接开 A2（默认继承档） | 打完 A1 再 `next` 进 A2 |
|---|---|---|
| 弹药 | 4 | **5**（A1 剩 4 发，本幕配发 5 发，取大） |
| 洞存粮 | 0 担（离胜利线还差 10） | **4 担**（A1 藏进窖里的四担跟着来了） |
| 地道口 `2,1` | 地图上是 `#` 已封堵，那一间藏人室**没有出口**、气区「通风：无」 | A1 里没塌掉它，进 A2 就还是活口（暴露豆 0/6），气区「通风：有」 |
| 顶栏「本局继承自」 | 默认继承档（未打第一幕） | 【上一幕的战果】…… |

（复现命令：`run --level A1 --seed 3 --bot Turtle --save /tmp/a1.json` →
`next --save /tmp/a1.json --save-to /tmp/a2.json` → 与 `new --level A2 --seed 3` 的 `show` 输出对比。）

`show` 的顶栏常显一行「本局继承自：X ｜ 对照满配还欠：Y」，全程看得见这盘网是自己挣的还是系统送的。

**网页侧**：终局画面的按钮就是「进入下一幕 A2（带着这一幕的战果）」，
下面写清这一幕交出去的是几格网、几个活口、几担洞存粮、几发子弹。

## 先记三条，不然会白卡半小时

### 1. 每个单位每回合只能做 1 个「主动作」

这是全游戏最硬的资源约束。挖掘、藏粮、转移群众、带路、伏击、隐蔽、攻击、佯动、组织、掩土、破路、
自毁封口、休整——**都是主动作，用掉一个，这个单位这回合就结束了**。

不占主动作的只有三类：

| 类别 | 有哪些 | 代价 |
|---|---|---|
| 移动类 | `Move`、`UseEntrance`（上下地道口） | 只花 MP |
| 免费 | `ToggleDoor`（开关隔断门，**每门每回合 1 次**，A4 起） | 不花 MP 也不占主动作 |
| 例外 | 「打了就钻」：本回合已开火 + 站在未被搜出的口上 + 剩 MP≥1，可再花 1 MP 钻回地下 | 该口暴露豆 +2，入地后本回合不能再动 |

所以一个民兵一回合能做的极限是：**走两格 + 挖一段**，或者 **走两格 + 藏一次粮**。四到六个单位一回合
一共就四到六个主动作——「全图挖网」根本排不进日程，这就是设计的意思。

`legal` 的输出按「主动作 / 移动类 / 免费」分好组，还会告诉你哪些动作**为什么**不在列表里，
以及关键动作**到底有什么用**（「这些动作到底有什么用（速查）」一节）。

### 2. 坐标有两套，别搞混

- **动作 JSON 一律用轴向键 `"q,r"`**（例如 `"3,1"`、`"10,-3"`，r 可以是负数）。
- **ASCII 地图用偏移列/行**：列号就是 `q`，行号 `y = r + floor(q/2)`。
- 反过来读图取 r：**`r = y - floor(q/2)`**。地图第二行 `r=y-` 已经把每列要减的数列出来了，
  单位一览、「地道口一览」「地道段一览」里的坐标也全是轴向键，直接抄进 `act --json` 即可。

### 3. `legal` 不加 `--unit` 会吐两百条

第 1 回合 `legal` 一次能列出的条数（seed 3、默认继承档实测）：
**A1 166 / A2 162 / A3 204 / A4 236 / A5 203**，绝大多数是 `Move` 的可达终点。
带上 `--unit` 就只剩二三十条：

```
legal --save /tmp/g.json --unit u1          # 分组视图 + 用途速查 + 「为什么某些动作不可用」
legal --save /tmp/g.json --unit u1 --json   # 原始 JSON，可直接喂给 act
```

**`legal` 里的每一行 JSON 都是完整的，可以整段复制进 `act --json`**——`Move` 也带全 `path`
（`{"type":"Move","unit":"u1","path":["4,-1","4,0"]}`），不用自己拼路径。

分组视图右边还会逐条给出**下令前你需要知道、但盘面上看不出来的那一句**：

- `Move`：**「到那儿还剩几 MP」**，以及「脚下有地道口，再花 1 MP 就能钻下去（钻完剩 0 MP）」——
  「移动到村格 + UseEntrance 要 2 MP 而民兵只有 2 MP」这种边界，在下令前就看得见。
- 挖掘类（`Dig` / `DigEntrance` / `DigFacility` / `DigDoor`）：**「挖通后你仍站在原格」**。
  `Dig` 只挖**相邻**那一段，人不会跟着过去；设施只修得在**你所在的这一格**。
- `MoveCivs`：**人会进哪个窖、那个窖还剩几铺**（见下节）。

### 动作 JSON 速查（照着 `legal` 抄就行，这里只是备查）

| 动作 | 形状 | 备注 |
|---|---|---|
| `Move` | `{"type":"Move","unit":"u1","path":["4,-1","4,0"]}` | `path` 是**逐格**的轴向键，每步 1 MP |
| `UseEntrance` | `{"type":"UseEntrance","unit":"u1"}` | 1 MP；加 `"dive":true` 是「打了就钻」 |
| `Dig` | `{"type":"Dig","unit":"u2","target":"5,0"}` | `target` 是**相邻格**，挖的是两格之间的段 |
| `DigEntrance` | `{"type":"DigEntrance","unit":"u2","at":"3,1"}` | `at` 只能是**本格** |
| `DigFacility` | `{"type":"DigFacility","unit":"u4","cell":"3,1","facility":"storage"}` | **是 `cell`+`facility`，不是 `kind`**；`facility` ∈ storage/shelter/vent/fightpost/trapdoor；翻板重支再加 `"rearm":true` |
| `DigDoor` | `{"type":"DigDoor","unit":"u4","edge":"3,0\|4,-1"}` | `edge` 是**段键**，两个格键用 `\|` 连起来 |
| `ToggleDoor` | `{"type":"ToggleDoor","unit":"u4","edge":"3,0\|4,-1"}` | 免费动作，每门每回合 1 次 |
| `Disguise` | `{"type":"Disguise","unit":"u1","at":"3,0","disguise":"stove"}` | `disguise` ∈ stove/well/kang/trough |
| `MoveCivs` | `{"type":"MoveCivs","unit":"u1","to":"2,1"}` | `to` = **进哪个藏人室**；`"kind":"old"` 只送某一类 |
| `MoveCivs`（地面） | `{"type":"MoveCivs","unit":"u1","to":"3,1","ground":true}` | 人不进洞，只挪到本村**相邻**的另一个村格 |
| `GuideCivs` | `{"type":"GuideCivs","unit":"u2","to":"3,0","count":2,"path":["3,0"]}` | `path` 与 `to` 都要给（照抄 `legal`） |
| `HideGrain` / `Organize` / `Hide` / `Feint` / `Rest` | `{"type":"HideGrain","unit":"u1"}` | 只要 `unit` |
| `Ambush` | `{"type":"Ambush","unit":"u1"}` | `site` / `stale` 是 `legal` 给的提示，不必回填 |
| `Attack` | `{"type":"Attack","unit":"u3","target":"e1"}` | 射击孔开火时 `legal` 会带 `"fightpost":true` |
| `CoverTraces` / `BreakRoad` / `Collapse` | `{"type":"Collapse","unit":"u1","at":"3,0"}` | `Collapse` 只塌**脚下**这个口 |

## 核心循环

**平静期备战 → 扫荡期周旋 → 逼退敌军。**

敌人在头顶搜庄搜粮，你在地下调兵。两个时钟同时在走：

- **敌军的搜索在累积**——每个地道口都有**暴露豆**，全程明牌显示。豆攒到阈值就被永久搜出，接着
  封堵/刨口/爆破/攻入/烟攻/灌水挨个找上门（敌军盯上一个口只需要 4 豆，伪装口更多）。
  **阈值各幕不同、甚至逐口不同**（关卡可以逐口覆写）：A1 三个祖辈挖的土窖 3~4 豆就被搜出，
  A2 起同样的口涨到 6~9 豆，A4/A5 的灶台伪装口要 12 豆。实际数字看「地道口一览」，那儿是明牌。
- **敌军的行动力池在消耗**——你每次伏击、破路、逼他动用工兵，都在扣他的池。池空了他就撤（＝「逼退」）。
  所以主动出手能提前结束扫荡，但每次出手都在抬高你的暴露。

平静期每村每回合 **+1 明存粮**；扫荡期敌摸到村 2 格内，每回合刮走 1~2 担（各幕不同，见上表）进代价簿。

## 你要做的事

- **挖**（A2 起）：地道 = 相邻两个地下格之间的「段」。进度：段 2（村庄下 1）、开口 2、设施 2、
  **隔断门 1**、伪装 1、破路 2、破桥 4。挖掘力：民兵 2、游击 1、**联络员 0——联络员挖不了任何东西**。
  动土是有响动的：**每挖通 1 段、每修成 1 处设施，本气区所有已开的口暴露豆 +1；每开一个新口，该口 +2**。
  主动作「掩土」（`CoverTraces`）本格痕迹 -2、暴露豆 -2，但**每个单位每局只掩得动 3 次**——
  这是全局唯一的减法。
- **修**：设施挖在已有的地道格上，**一格只能修一种**，且**按幕解锁**：

  | 设施 | 首次开放 | 作用 |
  |---|---|---|
  | 储粮洞 storage | A2 | 藏粮上限见上表（A1 4 / A2 6 / A3~A5 8 担·每洞） |
  | 藏人室 shelter | A2 | 铺位见上表（A1 2 / A2 4 / A3~A5 6 铺·每间）；老弱与青壮各占 1 铺，**伤员占 2 铺** |
  | 通气孔 vent | **A4** | 气区有它就不憋闷；**修够（≥ 该气区地道格数 ÷ 3）敌工兵的烟就用不上** |
  | 射击孔 fightpost | **A3** | 从地下打地面的相邻敌人；**同孔连打会被锁定**（伤害降为 1 + 该格被敌警戒） |
  | 翻板 trapdoor | **A3** | 压在有口的格上：拦敌一回合、挡烟挡水；**用过要重修** |
  | 隔断门 door | **A4** | 挖在**段**上（1 进度）；关上挡烟、挡水、断通行，并把气区切成两半 |

- **藏**：主动作「藏粮」每次转 **3 担**入洞，前提是**单位所在村格正下方有地道格，且该格连通到还装得下的
  储粮洞、所在气区至少有一个未封的口**。「转移群众」`MoveCivs` 每次 **2 批**从村口进**藏人室**
  （走廊装不了人，只能在带路途中临时容身，每格 2 铺）。
  **进哪个窖由你决定**：`"to":"2,1"` 指定藏人室，`legal --unit` 的「转移群众会把人放进哪个窖」一节
  逐窖列着「住着几批 / 还空几铺 / 从哪个口下去」，还附上可直接复制的 JSON。
  同一个动作加 `"ground":true` 就是**地面换格**——人不进洞，只挪到本村相邻的另一个村格，
  用来把人从敌纵队踩着的那一格挪开（抓丁按格判定）。
  排队顺序：**与下令单位同格的批先走**，其余按批号。老弱/青壮各占 1 铺、**伤员占 2 铺**。
- **带路**（A2 起）：**地道里的群众没有单位同格就一步也动不了**。`GuideCivs` 是主动作，单位须与群众同格，
  一次带的批数 = 联络员 3 / 民兵 2 / 游击 1（牲口槽伪装口 +1），走的格数 = min(单位 MP, 最慢一批的速度)，
  **单位跟着一起走**。速度：青壮 2 格/回合，老弱与伤员 1 格/回合。
- **恐慌**（A2 起，A1 不积）：地道里的群众每回合 **恐慌 +1**（扫荡期且同格没有我方单位）、
  +1（气区无风）、+2（烟中）、+2（水中）；**同格有我方单位且无烟无水有风则 -1**（安抚不花主动作，人在那儿就行）。
  **恐慌满 3 就自己冲出地面**：走本气区最近的、群众过得去的未封口（**水井伪装口不算，口窄群众上不来**），
  没有口就在本格正上方刨土钻出，连正上方都不可通行才罹难。**地面有敌 → 当场被抓进代价簿。**
- **喘气**：地道按**空气区**算（＝经**开放的门**连通的地道连通块）。区里既没有未被烟熏的通气孔、
  也没有未封且无烟的地道口 → 区内每人每回合憋闷 +1（烟里 +2、水里 +2）。**憋闷满 3 就被迫涌出地面**，
  规则同上。出地面或分区恢复通风 → 憋闷清零。
  **这是地上-地下唯一的强耦合点：把人闷死在洞里不是可行打法。**
- **打**（A3 起）：民兵**不能野战对射**，只能伏击或从射击孔开火；游击班是唯一能正面攻击的单位。
  设伏位只有三种：可隐蔽地形（村庄/农田/树林/坟地）、地道口格，或者**挖得动散兵坑的可挖地形**
  （只有挖掘力 ≥2 的民兵挖得动，会给本格留 1 点痕迹）。伏击是**持续状态**（移动或被打断才解除），
  但**同一格同时只容 1 处伏点**，伏击打完当回合转「暴露」态可被还击，
  **连着两回合在同一格设伏第二次只伤 1**，而且该格会被敌标记「已警戒」绕行 2 回合。
- **弹药是真会打光的**：全局池，起手 4~8 发（见上表），上限 12。每次开火（含伏击、射击孔）扣 1；
  缴获**只有击杀日军班 +1、工兵班 +1，打死伪军和特务一发都不给**——而一次伏击只打 3 伤，
  打死一个 4 HP 的日军班通常要两枪。**收支严格为负**，每一枪都得挑值不值。
- **骗**：`Feint`（佯动）让单位主动现身制造目击。**只有真单位在敌纵队 2 格内现身才拉得动人**——
  拉动的效果是：**最近的那一支纵队下一个敌回合朝你现身的那一格来**（只钉 1 个敌回合，只钉 1 支纵队）。
  离敌超过 2 格，CLI 会当场回一句「离敌太远，这一嗓子没人听见」，那一下就是白花一个主动作。
  代价是该单位当场转「暴露」态、被记一次置信 2 的目击，可被还击；佯动后本回合仍可移动/上下口撤离。
- **组织**（见下节）。
- **破路**（`BreakRoad`：路格 2 进度、桥 4 进度，永久断路——敌减速，若在补给线上还扣他的池；
  **村里的街不能刨**）。**它不是免费的**：刨路的那一格痕迹 +2，刨路的人当场被看见（置信 2 目击）。
- **自毁封口**（`Collapse`，立即断开敌利用，重挖 2 进度恢复）。

## 组织度到底有什么用

每个村都有一个 **0~2 级**的组织度（`Organize` 是主动作，每按一次 +1 进度，**2 进度升 1 级，上限 2 级**）。
它在报表里一直显示着，作用是：

| 级 | 效果 |
|---|---|
| **≥1 级** | ① **平静期**该村每回合**自动藏 1 担粮**进储粮洞（要求跟手动藏粮一样：村下得有连通的储粮洞）；<br>② **哨网**：该村 2 格内的格子**永远可见**——敌纵队进到村边你不派人也看得见，意图箭头常显 |
| **2 级** | 在 1 级的基础上，**村 1 格内每回合免费给一个工地 +1 进度**（群众来帮工） |

**「敌进到村 2 格内即停」停的是这份免费进度，不是敌人。** 这句话过去三轮复审都被读成
「敌军会在村外停下」，然后逐幕判它「未观察到」——敌人该进村照样进村。真实规则是：
**敌一摸到村 2 格内，2 级的免费工地进度就停发**（乡亲不敢出门帮工），结算里会播报
「敌已摸到村边（2 格内），乡亲不敢出门帮工——本回合没有免费进度」；给了也播报
「组织度 2 级：乡亲来帮工，工地免费 +1 进度」。两头都说话，不再是暗规则。

**组织本身也有代价，而且有窗口期**：`Organize` 是主动作，每按一次 +1 进度、2 进度升 1 级；
按一次会在本格留下痕迹（一屋子人进进出出，村口踩出新土），而且**敌一进到村 2 格内就聚不起人**——
那时 `Organize` 直接从 `legal` 里消失。想升级就得趁平静期。

各幕起手：A1~A4 的高家庄自带 1 级；A5 只有高家庄 1 级，**李庄与马家河都是 0 级**（要自己发动）。

`legal --unit <某个站在村格上的单位>` 的「这些动作到底有什么用（速查）」一节会把上面这张表、
本村当前级数与进度、以及「本村地下还没有连通的储粮洞，自动藏粮现在一担也藏不进去」这类实况一并打出来。

## 第一幕另有三条只在 A1 出现的规则（简报里有，但值得单列）

A1 挖不了、打不了、带不了路，它教的是**「人站在哪一格」比什么都重要**。三条机制合起来构成整幕：

1. **抓丁**：**敌军阶段结束时，还站在敌纵队所占村格上的群众批被抓**。
   老弱与伤员一个也跑不掉；青壮**头一回能走脱、第二回就没跑掉**（每批各记一次 `levyMisses`）。
   判定看的是**人站在哪一格**，不是村里还有没有粮——所以「把人往敌人还没踩到的村格挪」
   （`MoveCivs` 加 `"ground":true`）是这一幕的主要操作之一。
2. **敌踩在口上**：敌纵队占住哪一格，那一格**未被搜出的地道口与通气孔每回合暴露 +2**——
   他不用翻检，光是来回踩就把土色踩出来了。A1 三个祖辈挖的土口阈值只有 **3~4 豆**
   （村北粮窖 4、村南人窖 4、村西青纱帐人窖 3），敌在口上站两回合就够。
3. **第六日撬窖**：关卡硬脚本。**第 5 回合电报预告、第 6 回合必然发生**，
   敌认准**藏人最多的那个窖**撬开。三件事决定这一下有多疼：
   **早藏**（人在地面就被抓丁抓走）、**分窖**（他只撬人最多的那一个）、
   **留守**（窖里有我方单位就被打退，付前述四项代价）。没人守时他**最多带走 1 批**，
   但窖里的粮全被夺、口被填死——那个口在下一幕的继承档里也还是堵着的。

## 敌军会怎么反制你

敌军纵队的下一步意图是**明牌**的（在你视野内、或组织度 ≥1 的村庄 2 格内时显示箭头，CLI 里另有
「敌纵队意图」文字列表）。地道口一旦被盯上，敌工兵会按**本幕开放的手段**挑一个，且**全部提前一回合
电报通知你**——你有一个回合窗口去反制：

| 手段 | 首次出现 | 效果 | 你能怎么办 |
|---|---|---|---|
| 封堵 seal | A1 | 填死入口 | 从地下重挖 2 进度恢复；先留好第二个口 |
| 攻入 breach | A1 | 抢入口、夺走洞里的粮和人 | **守洞能把他打回去**（他损一个班），但守洞不是免费的——见下 |
| 刨口 excavate | A2 | 不用工兵，直接往下刨 | 塌口自毁、或提前把人和粮挪走 |
| 爆破 blast | A3 | 炸毁入口与该格设施（粮埋在土里进代价簿） | 工兵作业要花一整回合，打断他 |
| **烟攻 smoke** | **A4** | 烟沿地道蔓延（直巷 1 格/回合，**拐弯要多花一回合**），把人憋出地面 | **通气孔修够（≥格数÷3）他就用不上这一手**；关隔断门分区；翻板挡烟 |
| **灌水 flood** | **A4** | 自河沟架水车灌进他盯上的那个口；**水只往同高或更低的相邻格漫** | 人和粮放得**比会被灌的那个口更高**；关隔断门；翻板挡水。被淹的储粮洞每回合泡毁 2 担进代价簿 |

A4/A5 的敌人各带 **2 次烟具 + 2 次水车**（顶栏「敌烟具/敌水车」是余量计数，用一次少一个）。
敌不会把同一手用到底：可做的几手里，他先挑**本役用得最少**的那一手。

**守洞要付四样代价**（`Collapse` 一样，「有人驻守就能把他打回去」这句话过去只写了一半）：
入口正下方那一格、或相邻的射击孔格上有我方单位时，敌攻入被打退、他折一个日军班；同时你付出

1. **弹药 −1**（弹药池空就守不住，敌照样踩进来）；
2. **守洞的人被压制 1 回合**（下一回合动不了）；
3. **这个口从此永久转为「已知」**——明摆在敌人眼里；
4. 该口从此被敌标记 `breachDenied`，他改用别的手段对付你。

**注意区分两件事**：上面说的是「攻入 breach」。第一幕第六日那次**撬窖**是关卡硬脚本，
提前一回合电报、不可避免；它现在也认同一套守洞判定——**窖里有我方单位驻守就被打退**
（同样付上面四项代价），没人驻守时**最多带走 1 批**（不再是一锅端），窖里的粮一并被夺、口被填死。

> 电报里的「明日有敌一部自 X 入境」只保证**敌确实会入境**，不保证你看得见：如果入境点在你视野之外，
> 次回合的敌军阶段可能一条相关事件都不播报（不可见的事不会泄漏给你）。想确认就派联络员去看。

### 高程与水（A4/A5）

`hex.elev` 有 0（低）/ 1（中）/ 2（高）三档，A4 与 A5 的地图有明确高低差
（A4：西岗 `2,2` 高程 2 / 村 高程 1 / 东洼 `5,2` 高程 0）。规则只有一句：
**水从敌人灌的那个口进来，只往同高或更低的相邻格漫。**

**「高处的巷子永远淹不着」是错的**，别照这句话摆粮。水不是从地图最低点冒上来的，
是从**敌人当下盯上的那个口**灌进去的——如果他灌的是高程 2 的 `2,2`，那么同气区里
**所有高程 2 的格子照样进水**（实测：高程 2 的储粮洞被从高程 2 的口灌进的水泡毁 2 担）。
正确的说法是：

- 只有**比会被灌的那个口更高**的格子才淹不着；跟那个口**同高**的格子一样淹。
- 想让高处真的安全，就得让高处那一片**没有口可灌**，或者用**隔断门把它切成单独的气区**
  （关上的门挡人也挡水），或者在门那一段支**翻板**。
- 每个口的暴露豆是明牌的：敌人会先盯上豆最多的口。**你把哪个口养到被盯上，水就从那儿进来。**

### 隔断门与空气分区（A4/A5）

- 门挖在**段**上（`DigDoor`，1 进度），开关是**免费动作**（`ToggleDoor`，每门每回合 1 次）。
- **关上的门同时挡住烟、水、人**，并把一个空气区切成两个。
- **通气孔按空气区算**：某区要 `≥ 该区地道格数 ÷ 3` 个通气孔，敌工兵才用不上烟。
  所以关一道门是把 1 个区变成 2 个区，**两边各自都得够数**——
  同理，**你自己往外扩两格网，就得再修一个孔**，否则比例被自己破坏。
- 顶栏常显 `通气孔 X/需 Y`，`show` 里的「空气分区」逐区给出格数、通气孔/门槛、通风有无与出口。

## 读 ASCII 地图

地上、地下并排，**每格 3 个字符**，各司其职（这样站在地道口上的单位不会盖住自己的暴露豆）：

```
地上 = [地形][开口位][单位位]        地下 = [设施][内容位][单位位]
       V  3  M                             S  g  M
       村 暴露豆3 民兵                     储粮洞 有粮 民兵在此
```

- 地形位：`V`村 `F`农田 `W`树林 `G`坟地 `R`河 `B`桥 `=`路 `x`断路 `.`开阔
- 开口位：`0-9` 该地道口当前暴露豆、`!`已被搜出、`#`已封堵、`o`通气孔、`*`通气孔被烟、
  `,`挖掘痕迹、`_`敌已搜过（`o`/`*` 是通气孔，与地下设施位的 `O` 同一个东西）
- 单位位：`M`民兵 `G`游击 `R`联络 `+`我方多单位｜`J`日军 `P`伪军 `B`工兵 `S`特务 `?`身份不明
  `&`我敌同格｜`> < ^ v` 敌意图箭头
- 地下设施位：`o`普通地道格 `S`储粮洞 `H`藏人室 `O`通气孔 `X`射击孔 `T`翻板 `·`尚未挖通；
  内容位：`g`存粮 `o`老弱 `y`青壮 `w`伤员 `!`群众恐慌将满 `*`烟 `~`水

**格与格之间画的是「段」**（有段才走得通）：

| 记号 | 含义 |
|---|---|
| `-` `\|` `/` `\` | 这两格之间**已挖通**（人、烟、水都过得去） |
| `D` | 这一段上装了**隔断门，现在开着**（通） |
| `#` | 这一段上装了**隔断门，现在关着**（人、烟、水都不通） |
| 空白 | **未挖通** |

地图下面还有七张随时可查的表：

1. **关键地点**（各村格号与组织度、区队部、地标高程与用途）
2. **地道口一览**（每个口的暴露豆/阈值/被搜出与否/伪装/翻板状态/谁在上面，以及通气孔与挖掘痕迹）
3. **地道段一览**（逐条列出哪两格通着；每道隔断门是开是关，并直接给出可复制的 `ToggleDoor` JSON）
4. **空气分区**（每个区的格数、通气孔/门槛、通风有无、出口、区内群众与洞存粮）
5. **存粮分账**（各村明存粮 + 各洞洞存粮 + 距胜利线还差多少）
6. **群众一览**（每批的类型、位置、有没有人带路、恐慌值；**地面群众给真实村格号**，
   并在村格上出现可见敌军时点名「这些人正贴着敌人」）
7. **敌纵队意图**（只列你看得见的）

## 操作（PC）

鼠标习惯对标文明VI，直接上手即可：

| 鼠标 | 作用 |
|---|---|
| 左键单击 | 选中（单位 ＞ 地物 ＞ 地形，当前层优先）；`Alt+左键` 强制选另一层 |
| **右键单击** | 对该格下令：移动 / 上下地道口 / 攻击（会降低入口隐蔽的操作需**二次右键确认**） |
| **悬停** | 选中单位后，鼠标移到哪，哪就实时出路径预览：粗白管线 + 方向箭头 + 落点环，落点上方挂一块牌子写「几步 · 还剩多少 MP」；风险段整段变橙，同一份数字也在左下「移动预览」条里 |
| 任意键按住拖动 | 平移地图（左/中/右键皆可；越过 5px 才算拖拽，所以拖完不会误下令） |
| 滚轮 | 缩放（3 档；触控板的小增量会累加，不用使劲滚） |
| 光标形状 | 停在能下令的格子上会变成手型；拖地图时变抓手 |

选中单位后，**能去的格子会整片描上青色六边形边框**，并分两档：

- **亮青** = 走到那儿还剩行动力（还能接着走）；
- **深青（压暗）** = 走到那儿正好走满，本回合到此为止。

进入挖掘目标模式（`B`）时候选格改用**琥珀色**边框，与「能走到」区分。地下层同样有这套提示；
执行完上下地道口的动作后，视角会自动跟着单位换层，不会把人跟丢。

键盘：`Q` 地上/地下切层、按住 `Space` 透视窥视、`Tab` 下一个未行动单位、
`B` 挖掘、`V` 伏击、`F` 佯动、`G` 隐蔽、`W A S D` 平移、
`回车` 结束回合（有未办事项时会先弹清单，`Shift+回车` 直通）、`Esc` 逐级退出、`L` 事件日志。
顶栏常显回合/波次/敌行动力池与**地道网摘要（几格几段 · 通气孔 X/需 Y · 隔断门 开几关几）**；
右上面板常显明存粮/洞存粮分账与区队部坐标；点开一个地下格，左下面板会列出它**通向哪几格、
每道门开着还是关着、所在气区的通气孔够不够**。下令被拒时会直接告诉你真实原因。

> 相机是**锁定俯角、不可旋转**的，也**没有边缘平移**（鼠标推到屏幕边不会滚屏）——要挪视角请拖拽或 `WASD`。
