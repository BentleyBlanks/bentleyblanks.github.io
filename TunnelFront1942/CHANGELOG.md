# TunnelFront1942 轮次记录

每轮 = 设计 → 实现 → 完整游玩 → 独立审查 → 修改或删除 → 再次验证 → 提交 + 部署。
独立审查的五项标准与 verdict 逐轮记录于此。

## R6（2026-07-31）玩法内核修复 —— 把第一幕的激励掰回来，把死代码变成工具

R6 独立复审（只读 README + CLI，五幕各打通 + 多组 A/B 对照实验）判词：
**A2~A5 已经是紧张、清晰、可重复游玩的完整循环**（这部分本轮一处也没动坏），
**但剧情推进不成立**——A1 教反了、Feint 是死代码、组织度 2 级的停止条件观察不到、胜利线仍在前半局。

本轮按复审逐条修，**没有新增任何单位/资源/子系统**——全部落在既有规则、既有动作与数值上。

### P0-1 把第一幕的激励掰回来（复审：「最严重；其余免谈」）

复审 A/B 硬数据：同 seed 同开局只改「藏不藏人」，**不用地窖比用地窖评级更高**
（seed 7 不用窖拿乙、seed 11/19 用窖直接失利），而简报第一条写的是「粮与人即刻转入窖中」，
失利提示写的是「①先送老弱与伤员进窖」。**教什么就罚什么。**

- **撬窖从「一锅端」改成「最多带走 1 批」**（`level.scriptedBreachHaul`），
  且**窖里有我方单位驻守就被打退**——走「攻入」同一套结算：
  弹药 -1 + 守洞单位压制 1 回合 + 该口永久转为已知（弹药池空则守不住）。
- **`MoveCivs` 加目的地参数 `to`**：写地道格键 = 送进指定的那一个藏人室
  （`LegalActions` **逐窖**给出 `roomLeft` 剩余铺位与 `here` 已有批数）；
  写相邻村格键 + `ground:true` = 把人挪到**敌人还没踩到的**那一格。
  失利提示里的「人分两个窖放」与「地面上剩下的人往敌人还没踩到的村格挪」两条，
  在此之前**在动作集里物理上做不到**（窖由系统自动挑；A1 全部主动作里没有任何一个能挪动地面群众）。
- 「五口（保全 ≥5）」从「别碰地窖」的考试改回**「早藏、分窖、留守」**的考试（勋记提示逐条写明怎么做）。
- **A/B 实测（修后，7 个 seed 全成立）**：

  | seed | ①早藏+分窖+留守 | ②全挤一个窖·无人留守 | ③一个人也不藏 |
  |---|---|---|---|
  | 3 | 乙 保全 6/6 | 丙 保全 4/6 | **丁·失利** 保全 2/6 |
  | 5 | 乙 保全 5/6 | 丙 保全 4/6 | 丙 保全 3/6 |
  | 7 | 乙 保全 6/6 | 丙 保全 4/6 | 丙 保全 4/6 |
  | 11 | 乙 保全 5/6 | 丙 保全 4/6 | 丙 保全 3/6 |
  | 19 | 乙 保全 6/6 | 丙 保全 4/6 | **丁·失利** 保全 2/6 |
  | 23 | **甲** 保全 6/6 | 丙 保全 4/6 | 丙 保全 3/6 |
  | 31 | 乙 保全 6/6 | 丙 保全 4/6 | 乙 保全 5/6 |

  修前同一张表是「①与③打平甚至更差」。修后 ① > ② > ③ 在 7/7 个 seed 上严格成立。

### P0-2 让 Feint 真的拉得动敌人

复审 A/B：连续佯动 4 回合 vs 完全不佯动，**敌军移动逐格相同**，四支纵队终局意图完全一致。
它占一个主动作、把单位暴露出去，换来零收益。

- **真单位在敌纵队 `CFG.feintPullRange`(=2) 格内佯动 → 强制最近的那一支纵队下一个敌回合
  把意图指向佯动格**（`column.lureAt`，`CFG.feintLureTurns`=1 回合），代价是该单位转入 `exposed`
  ——被拉过来的那一支就是冲着他来的，邻接即挨枪。
- 决策树位置：排在「在途反地道作业」之后、「机动队响应 / 反地道四选一 / 进村搜索征粮」之前。
  已电报的作业撤不掉（电报一发就作数），但**还没动手的那一下可以被引开**。
- **防木偶化红线原样保住**：置信 1 的痕迹/动静仍然绝不拉动任何纵队；
  超出 2 格的佯动明确播报「这一嗓子没人听见」。冒烟里既有的「佯动木偶化」用例仍绿。
- **A/B 实测（修后）**：A1 seed3 T4 / A1 seed7 T5 / A3 seed3 T5 / A5 seed5 T6 四组同存档分叉，
  被拉的那一支纵队**全部改道走到佯动格上**（修前四组逐格相同）。

### P0-3 组织度 2 级的「敌进到村 2 格内即停」

引擎里这条规则一直是对的（`PlayerWrapUp` 的 `EnemyNearVillage` 判定），
但它**给了不播报、停了也不播报**——三幕独立复审因此都判它「未观察到 / 不生效」。
**规则不播报就等于不存在。** 现在两头都说话：
「乡亲来帮工，工地免费 +1 进度」/「敌已摸到村边（2 格内），乡亲不敢出门帮工——本回合没有免费进度」。
语义不变：**停的是免费工地进度，不是敌人**（与并行文档 Agent 的 README 措辞一致）。

### P0-4 把胜利线搬到后半局

- **洞存粮本来就是终局判定值**（`Evaluate` 只在终局跑一次），本轮新增回归把它钉死：
  中途攒够、被攻入搬走 → 终局判负。
- **门槛改成「两个满仓也不够」**：不是靠抬绝对担数（各幕的粮总量顶不住），
  而是**把单洞容量压小**——A3 8→**5**、A4 8→**5**、A5 8→**6**（A2 维持 6/线 10 不动）。
  于是 A3/A4 的 12 担线要**三间窖**、A5 的 15 担线也要**三间窖**，第三间从此是必修课。
- **久占加压**（`OccupationToll`）：全幕过了 `CFG.occupationTollFrom`(=2/3) 之后，
  敌若**连着两个回合**还踩着村格不走 → 每村每回合烧一处房 + 把他脚下那一格的人再拉走一批
  （这时青壮也跑不掉）。反制是这套规则本来就有的两条：把人送到地下去，或者把他赶走/引走。
- **实测：会玩 bot 首次达标回合（修前→修后）**
  A2 **T5.0→T6.0**（幕长 10）、A3 **T4.0→T5.0**（10）、A4 **T7.1→T9.7**（12）、A5 T6.7→T6.7（14）。
  冒烟门槛同步从 `maxTurns × 0.4` 抬到 `× 0.45`。

### P1 其它

- **BreakRoad 不再零代价**：本格痕迹 +1（与一次普通挖掘同价），且这一回合藏不住身形。
- **Organize 不再「站村格按两下白拿」**：要赶在敌摸到村 2 格内之前做（之后动作直接不可用），
  每做一次本格痕迹 +1。它唯一写明的代价（2 级要求把敌人挡在村外）现在对动作本身也成立。
- **A4「换气」的判据口径写给玩家看**：只有**未被搜出**的通气孔才算（`VentCount` 一直是这个口径，
  但文案只写「通气孔 N 处」，于是「保全 8/8、逼出 0 批却判通气孔 1 处」看上去像 bug）。
- **A5「一个不落」与 A4「换气」同价**：加 `forcedOutAtMost: 0`——同一件失误不能一幕扣章一幕不扣。
- **A5 的第三课有了机制承接**：第三枚勋记「逼退」→ **「多孔协同」（从 3 个不同射击孔开过火）**。
  原来三枚勋记没有一枚挂钩射击孔，只用起手那一个孔照样拿甲。
- **开局脚本逐幕不同**：A3 的高家庄**开局就是组织度 2 级**（同一个村打到第三幕，乡亲早组织起来了），
  「Organize×2」从此不是每一幕的开局必答题；A1 压根没有工地（挖不了），2 级红利在那一幕是零。
  各幕 `openingChecklist` 末尾新增一行「※ 本幕开局与别幕不同的地方」。
- **藏粮改成先往最空的那个窖装**：「粮分几个洞放」这句话第一次在动作里成立
  （原来按格键顺序把第一个窖灌满才动第二个，一次灌水泡的就是那一整窖）。

### 并行 CLI/文档 Agent 转来的两条（都落在内核文件里）

- **战役续承方向搞反了**：`ApplyCarry` 直接照搬上一幕的格/段/口/伪装，于是**手打输掉的 A2
  （两个口都被搜出）串进 A3 得到 0 个活口，而直接开 A3 的默认档有 2 个活口**——打过前作反而更惨。
  现在落地时取 **`carry ∪ carryDefault`**（保底不低于默认继承档），继承**只增不减**。
- 撬窖断言与实现对不上：两边统一到「**有驻守就打退，一批也带不走**」。

## R5（2026-07-31）玩法内核返工 —— 把「叙事进化线」补成「机制进化线」

R5 独立盲审（只读 README + CLI，五幕各打满 + 多 seed 半局 + 3 个专项实验 + 50 局 bot 对照）判词：
**「还不是一个紧张、可重复游玩的循环。」** Skilled bot 50 局赢 49 局；胜利线普遍 T3-T4 就达标；
唯一支配线是「藏粮→下地→Rest」。八项判定里 ③敌军合理反制 / ⑤无唯一最优解 / ⑦跳过前两幕体验垮掉 全 FAIL。

本轮按盲审逐条返工，六条 P0 + 四个必修 bug。**没有新增任何单位/资源/子系统**——全部落在规则与数值上。

### P0-1 让第一幕真的把你打疼（招牌失败原本在 8 回合内数学上不可能发生）

- 逐口暴露阈值覆写 `level.entranceThresholds`：A1 的三个窖口 9/9/6 → **4/4/3**（祖辈挖的土口没有伪装）。
- **敌纵队踩在哪一格，该格未被搜出的口与通气孔每回合暴露 +2**（`CFG.occupiedExposePerTurn`，全战役生效）。
  盲审实测「seed 7 的 T6 敌人站在 2,1 这一格上，暴露豆纹丝不动」——翻检是断续的，脚是一直踩着的。
- `level.scriptedBreach`：**第六回合必然撬开人最多的那个窖**，窖内群众全部进代价簿（提前一回合电报）。
  玩家能改变的是「把人分散在哪几个窖里」，不是这一下会不会来。
- 实测（修前→修后）：会玩 bot 8 seed 评级 **5 甲 3 乙 → 0 甲 0 乙 8 丙**，群众保全 **5.4/6 → 4.0/6**；
  新增「认真打的新手线」8 seed 平均保全 **3.00/6、5 丙 3 丁**——正是审查员要的手感。

### P0-2 抓丁改挂群众暴露（原规则有反向激励：藏粮越快死人越多）

- 删除「村中无粮可征即抓丁」。改为 **敌军阶段结束时，站在敌纵队所占村格上的群众批被抓**：
  老弱与伤员一个也跑不掉，青壮每批有一次走脱机会（确定性的「一半」，不消耗 rng）。
- 地面群众带**格号** `civ.hex`；被迫出洞的人落在本村离敌最远的一格，**不再一句「散回村中」**。
- **终局就地结算**：删掉「把幸存群众一律传回地面」——那一步把地上/地下的区别在结算那一刻全抹平了。
- 实测（A3 seed 21，修前→修后）：
  什么都不做 4/6→2/6、全塞进地道后不管 4/6→5/6、疯狂藏粮 2/6→2/6（被抓 4→4，**不再多于「什么都不做」**）。
  三条线**不再给出相同终局**，反向激励消失，「谁去带路」在五幕里都成了真取舍。

### P0-3 战役续承（原本 `new --level A3` 无论是否打过前作永远同一盘面）

- 新接口：`ExtractCarry(state)` / `CreateGame(levelId, seed, { carry })` / `BuildFullCarry(levelId)` / `CarryWeight(carry)`；
  `state.meta.carry` 记录本局用的是哪一份档，`DeriveView().carry` 原样透出。
- 每幕新增**明确标注的默认继承档** `level.carryDefault`（`isDefault:true` + `label` + `notes[]` 写清差在哪儿）：
  A2 少一个口（上一幕被填死）、A3 少两格且一处伪装也没有、A4 **整张网都在低处**（西岗那一段没挖）、
  A5 少一个口且马家河的牲口槽口没做成；四份档都**洞里没粮、配发弹药少两发**。
- 冒烟逐幕断言：默认档在格数/活口数/伪装数里至少一项严格劣于满配档，且配发弹药更少；
  同 seed 同 bot，满配档的终局分不劣于默认档（A3/A4/A5 各 ≥3/4 个 seed）。

### P0-4 守洞 Rest 不再是无惩罚的支配解

- 打退攻入仍折敌一个班（现在还会**计入战果与行动力池**——原来这一刀连账都不记），但：
  花 1 发弹药、守洞单位**被压制一回合**（当回合零合法动作）、那个口**立刻转为已知**；
  **弹药池为 0 时视同无人驻守**（洞口只剩人，堵不住枪）。它仍然是一手好棋，只是不再免费。

### P0-5 水必须真的出现（A4 打满 12 回合 0 次、水车 2/2 从没动过）

四条改动：作业**轮换**（先挑本役用得最少的那一手）、工兵**在手**判定放宽到 1 格内、
工兵**闻着新土走**（豆 ≥2 就专程摸过去，摸到就踩住不走）、**驻剿队照样做反地道作业**；
另把 A4/A5 的工兵波提前、A5 给两班工兵，并让伏击优先打前头的步兵班（工兵夹在队伍中间）。

- 实测「只挖不掩土」线 8 seed 至少发生一次的 seed 数（修前→修后）：
  A4 水 **0/8 → 8/8**、A4 烟 8/8→8/8、A5 水 **3/8 → 5/8**、A5 烟 8/8→8/8、A5 爆破 **1/8 → 4/8**、
  A4 攻入 3/8→1/8（被守洞打退的次数上升，成功攻入相应下降）。
- **保住了 A4 通气孔比例的涌现**：通风口修够（≥地道格数 ÷ 3）敌就不再选烟攻——冒烟里有确定性断言锁着。

### P0-6 胜利线不能第三四回合就达标

- 各幕洞粮线一律抬到**高于单个储粮洞的容量**：A2 8→10（洞容 6）、A3 8→12（洞容 8）、
  A4 8→12（洞容 8）、A5 8→18（两个起始窖合计 16）。一个窖装不下，必须再挖一间。
- **敌人能真的夺走洞存粮**：爆破埋掉 4 担、攻入把该格全拿走**再顺着巷子搬走 4 担**、灌水每回合泡毁 2 担。
- 实测会玩 bot 首次达标回合（修前→修后）：A2 **T5→T5**（幕长 10）、A3 **T2→T5**、A4 **T2→T7.1**、A5 **T2→T6.7**；
  且最后三分之一仍有敌情（或已被提前赶走）的 seed ≥半数。

### 必修 bug

1. **平静期静默造粮** → 明存粮 +1 与组织度自动藏粮**都会播报**；A1 开局明存粮 8→7，
   使「开打时正好八担、粮窖只装得下四担」与复盘文案的算术对上。
2. **BreakRoad 可作用于村庄格** → 禁止（`hex.villageId` 非空一律拒绝，并给出理由）。
3. **缴获恒为 0** → `loot` 改为日军班 +1、**工兵班 +1**；守洞折敌改走 `KillEnemyUnit`（计战果与池）；
   缴获与「没能缴获」都有事件。收支仍严格为负（反击打死的不缴获）。
4. **非法动作附带无关提示** → `PerformAction` 改回 `{ illegal, illegalAction, hints }`，
   `hints` 只针对被拒的那一个动作；另在关卡数据里给出「这个动作为什么不可用」自查表。

## R3（2026-07-31）五幕战役重构 —— 按电影《地道战》的进化线重写关卡

用户判词：「没有剧情、没有推进，两张关卡之间没有因果。」本轮把两张抽象关卡换成**五幕战役**：
地道从「各家的藏身地窖」一步步变成一件武器，每一幕都由**上一幕的失败**推动。
**关卡不再是难度递增，是认知递增**——`level.unlocks` 是它在代码里的落点。

- **五幕（A1~A5）替换 L1/L2**（L1/L2 保留为别名 `L1→A1`、`L2→A5`，旧链接不断）：
  A1《单口洞》8T → A2《户户相通》10T → A3《能打的地道》10T → A4《毒烟与水》12T → A5《反扫荡》14T。
  A1~A3 共用高家庄同一张图——同一个村子，一幕比一幕会打，玩家能亲身比较
  「同样被搜出，第一幕跑不掉，第二幕跑得掉，第三幕还能还手」。
  每幕带档案式开场简报 + 三行「这一幕你要学会什么」+ 本幕新解锁清单 + 终局复盘三段
  （付出了什么代价 / 学到了什么 / 解锁了什么）。
- **`level.unlocks` 解锁过滤真的生效**：`LegalActions` 与 `PerformAction` 双向按幕过滤，
  后一幕的动作集必须是前一幕的超集。**第一幕挖不了连通段、开不了口、修不了设施**——
  它只有藏粮、转移群众、掩土、破路四件事，而这四件事注定不够。
- **第一幕注定要付代价（设计，不是失衡）**：明存粮 8 + 平静期 1 > 粮窖上限 4；
  群众 6 批（7 个铺位）> 两个人窖合计 4 个铺位；搜庄队 `levyAlways` 搜粮抓人一起来。
  胜利线放宽到「保住半数群众」，但**代价簿结构性不为零**（冒烟里既有结构断言也有多 bot 多 seed 实测）。
  终局复盘点破：「洞是死的，人是活的。洞不通，人就没处去。」
- **带领百姓躲避（用户明确要求的第二条主线，第二幕起贯穿到底）**：
  `state.wounded` 与 `village.pop` / `cell.civs` 全部删除，改为 `state.civs` 群众批注册表，
  分老弱（1 格/回合，1 铺）/ 青壮（2 格/回合，1 铺）/ 伤员（1 格/回合，2 铺）。
  **地道里的群众必须有单位同格带路才能移动**（`GuideCivs`，主动作；一次带 3/2/1 批，
  走的格数按最慢一批算）；无人带路每回合恐慌 +1，无风 +1、烟 +2、水 +2，同格有人则 -1。
  **恐慌 ≥3 → 自行冲出地面**，与「憋闷被迫出洞」合并为同一套压力，地面有敌当场被抓。
  终局按**群众保全率**评定。带路占主动作 →「谁去带路、谁去挖、谁去打」成为每回合的真取舍。
- **逐幕新机制**：A2 连通挖掘/多口/伪装口（灶台+1、炕洞+1、水井+2 但群众上不去、牲口槽带路 +1 批）；
  A3 射击孔 + 翻板 + **打一枪换一个地方**（同孔 1 回合内再开火只伤 1，且该格获「敌已警戒」）；
  A4 敌烟/水/刨口全开，反制全部来自结构（翻板挡烟挡水并拦敌一回合、拐弯让烟多花一回合、
  通气孔、**高低双层：水只往同高或更低处漫**、隔断门分区）；A5 三村相连 + 跨村地道网 + 全员转移 + 多孔协同。
- **敌反地道四选一 → 六选一**：新增**刨口**（不需工兵，A2 起）与**灌水**（需工兵与水车，A4 起）。

  unlockedFacilities / unlockedDisguises / civGuidance / objectiveProgress / civs / civSummary /

## R2（2026-07-31）玩法内核修复 —— 独立盲审五项全 FAIL 的逐条返工

盲审（只读 README + CLI，L1 三局 + L2 两局逐回合游玩 + 32 局 bot 对照 + 2 组定向实验）判定五项标准全 FAIL。
本轮不加新单位、不加新资源、不加新子系统，只改规则与数值。修前/修后同口径实测：

- **P0-1 暴露豆全程结算**：原本只在扫荡开始那一瞬结算（定向实验：扫荡期挖 5 段开 2 口，所有口仍是 0 豆）。
  现在每挖通 1 段 / 修成 1 设施 → 同气区各口 +1，每开新口 → 该口 +2；掩土 -2 但**每人每局 3 次**。
  实测「只挖不掩土」流的口最高暴露从 0 → 30~46 豆。
- **P0-2 烟攻/爆破真的会发生**：作业门槛从「已被搜出（9 豆）」降到「暴露豆 ≥4」；烟攻加条件
  「该气区通风口 < 地道格数/3」；封堵改为每纵队每役至多 1 次；工兵队会主动奔向全图暴露最高的口，
  走到即在同回合下电报。L1 补入工兵组（烟具 1）。**25 局 0 次 → 10 seed 实测 L1 烟 4/爆 3/封堵 11，
  L2 烟 13/爆 3/攻入 10/封堵 19。**
- **P0-3 憋闷改成真的「被迫出洞」**：原实现是原地掉血直到窒息阵亡（与 README 相反）。现在憋满 3 回合
  **一定上地面**：先走分区最近的未封口，没有口就在本格正上方刨土钻出（留痕迹），连正上方不可通行才掉血；
  地面有敌 → 群众当场被抓进代价簿。这是地上-地下唯一的强耦合点。
- **P0-4 HideGrain 要求物理连通**：本村格**正下方**必须有地道格且连着还装得下的储粮洞、气区还有未封的口。
  盲审「头顶一格地道都没有的村里成功储粮」的复现用例现在被拒绝。
- **P0-5 拆同格叠伏击 + 消灭重复劳动**：同格至多 1 人设伏；伏击改为**持续状态**（不必每回合重按）；
  打完强制转「暴露」并当场吃一次还击；同格连设两回合 → 伤害 3→1 且该格获「敌已警戒」2 回合（敌寻路 +4 绕行）；
  民兵可在任何可挖地形挖散兵坑设伏（+1 痕迹）——民兵在开阔地不再瘫痪。
- **P0-6 修好 L1**：胜利线「总粮 ≥8」→「**洞存粮 ≥10**」，明存粮在敌到村 2 格内每回合被搜走 2 担；
  池 10→14 且**取消每回合白送的 -1**，改为**扑空衰减**（摸到村边却一无所获的纵队每支 -1，每回合至多 -2）；
  地图补南土路、浅滩，石桥改为可破；seed 给到真变量（轴线 9 × 配比 3 × 到达 T5±2 × 斥候 6 × 报复队 2）。
  **12 个 seed 的终局从「逐字节相同」→ 9 种不同终局；逼退时点从 T7-T8 → T9-T10（10/12 seed）。**
- **P1**：同格敌人可攻击；石桥可破且破后敌走浅滩/南土路绕行；弹药收支改为严格为负（日军班缴获 2→1，
  伪军/工兵 →0，反击致死不缴获）；敌在无粮可征的村里改为抓丁（civCaptured 活了）；
  L2 三枚勋记各加一条「全须全尾」判据（丢 8 担粮 + 死一个班的一局不再与全须全尾同评）。
