## R1（2026-07-30）v0.1 可玩白盒落地

- **引擎**（纯逻辑约 3900 行）：`Script_State/Actions/Visibility/EnemyAi/Turn/Bots` +
  `Data_Rules/Data_Levels`。全确定性、零 `Math.random`、CloneState 推进、事件带 `visible` 标记。
- **表现层**（约 2900 行）：`Script_Renderer/Ui/Main` + `Data_Theme/Data_Keymap` + `index.html/Style_Game.css`。
  双主态视图（Q 切层、Space 窥视）、格上徽记预算、两段式结束回合护栏、敌阶段按可见性播报、三勋记结算。
- **审查接口**：`Script_PlayCli.mjs`（new/show/legal/act/end/run/fixture）+ 双层 ASCII 地图。
- **冒烟 26/26 全绿**（2.6s）：契约/确定性/乱打模糊/策略排序红线/双时钟/佯动木偶化/反地道四出口/
  憋闷链/预算比率/账本红线/kills 封顶/页面装配。
- **Balance**（4 bot × 2 关 × 8 seeds）：L1 Skilled 100%(8甲) / Turtle 0% / Rambo 0%；
  L2 Skilled 100% / Turtle 0% / Rambo 63% / Random 25%。
- 浏览器实测：真引擎 `?level=L1&seed=3` 零控制台错误，回合推进正常，双层渲染与 HUD 可辨认。
- 引擎侧关键裁决：纵队整体制（同格同进退）；邻接接火只打得动的目标（防止征粮队被隐蔽民兵空转）；
  受创斥候回撤报信；L2「占村」需有可剿之物（藏净粮+塌已知口 = 让敌扑空，核心策略闭环）；
  `DeriveView` 改为纯函数（原写 `enemy.lastSeen` 会让调用视图与否的哈希分叉）。
- 已知问题（下轮）：L1 对 Random 过宽（乱打也能拿丙）；Rambo 在 L2 仍有 63% 胜率。

## R-设计（2026-07-30）七领域设计委员会 → 规则 v2 裁决

- 七个领域 Sub-Agent（核心玩法/双层地图/单位战斗/敌军AI/关卡任务/操作反馈/数值平衡）并行评审。
  （工作流权限层故障导致其文件读取与结构化输出被剥参，全部结论自转写抢救合并；各 Agent 按简报独立推导。）
- 关键裁决（详见 AGENTS.md §二 v2）：
  - 保留文明式逐单位 MP+主动作操作；否决抽象共享行动池。
  - **敌军不以单位进入地道**：攻入改为提前电报的一回合抽象结算（有驻守=敌损1班中止；无=毁口夺物）。
    删陷阱/休息室/地道内逐格战斗（-500 行）。
  - v1 反地道 = 搜索暴露 + 烟攻(逼出而非杀伤) + 爆破(可打断) + 封堵；灌水推迟 v2（河仍为地形约束）。
  - 入口暴露 = 隐蔽等级×3 暴露豆，确定性、全明牌、只增不减；掩土只作用于挖掘痕迹。
  - **挖掘痕迹结转**：平静期每次挖掘 +1 痕迹，扫荡开始转为入口暴露豆初值——反无脑挖网的账。
  - 佯动防木偶化：目击置信两级，置信 1 绝不拉动纵队；机动队专责响应置信 2。
  - 敌撤退 = 行动力池（歼敌/破路/反地道自耗扣池，单回合上限 5，绝不产生玩家资源）。
  - 评级 = 三勋记制（只奖保全与保网），歼敌不进 UI 计分；数值分仅供冒烟排序断言。
  - 民兵不能野战攻击（仅伏击/枪眼）；弹药只靠缴获且净收支为负；无征募，损失永久。
  - 憋闷 3 回合被迫出洞且先于敌行动结算——反缩头的确定性机制。
  - L1《护粮》10 回合单村教学（含条件触发报复队）；L2《合围》16 回合三村三阶段脚本；seed 白名单只变敌不变图。
