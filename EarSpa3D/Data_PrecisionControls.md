# EarSpa3D 精细操作与对标

2026-10-13 用户确认：参考 Surgeon Simulator 的自由工具与物理反馈，采用“精细器具控制、一个按键夹持”，以电脑键鼠为主。

## 对标依据与选择

原作由鼠标控制手的位置、深度和手腕，各手指使用 A/W/E/R/Space 独立操作；物体抓取、碰撞和掉落是其核心体验。依据：[Bossa 开发者访谈](https://www.gamedeveloper.com/business/the-blissfully-awkward-controls-of-i-surgeon-simulator-2013-i-)、[官方演示](https://www.youtube.com/watch?v=ZO10bAn_8M8)。

本项目将位置、深度、倾角与夹持分开，把控制对象放在器具工作端；用户选择了精细方案，因此保留快捷栏选工具和单键夹持。模型、经营存档和已验收声音继续使用现有资产与系统。当前使用几何接触、XPBD 材料、有限夹持和重力，不能称为复刻原作引擎或医学模拟。

## 当前键位

| 输入 | 行为 |
| --- | --- |
| 鼠标移动 | 按指针位置直接定位实际工作端，不需要先点击耳垢 |
| 滚轮向前／向后，W／S | 深入／撤出；碰到实体后输入不累积反向死区 |
| 按住右键拖动 | 调整手腕两个方向的倾角 |
| Q／E | 绕器具杆转动，调整凹面与夹口方向 |
| 按住左键或 Space | 闭镊夹持、耳勺施力、刷扫、滴液或吸引；松开释放 |
| Shift | 以四分之一速度精细移动、进退和转腕 |
| 方向键 | 平移工作端，不选择或自动处理目标 |
| 1–6 | 耳勺、镊子、滴管、毛刷、吸引管、鹅绒掸；仍受营业库存限制 |
| T | 撤到耳口外后查看盘面；放下材料后返回耳道，空器具复位 |
| Esc／松手 | 清除平移队列、转腕、进退和夹持，原地释放材料 |

Space 与左键是同一作用的两个输入源，按住两者时松开其中一个仍保持夹持。键盘输入不会拦截设置表单或按钮的正常操作。触屏仅提供基础拖动，完整精细操作需要电脑键鼠。

指针定位修正：普通移动将屏幕指针投射到工作端的当前深度，进退仍保持该屏幕位置。操作区只显示勺头／镊尖中心的光标，不再同时显示一个有偏移的系统箭头。转腕、精细慢移与碰撞采用工作端位置重新建立控制基准，松开修饰键不会跳回另一位置，碰壁后反向移动立即生效。实际工具仍受完整几何碰撞限制，不会为追随指针穿过耳壁。UI 使用正常系统指针。

## 工作端与材料

- 耳勺：从真实薄片边缘接触，凹面与运动方向参与传力，逐点反力释放附着。受力可造成弯曲和真实碎裂，勺背不工作。松脱后由有限勺面支撑，翻到凹面向下会滑落。
- 镊子：材料必须实际进入两尖之间；两侧独立的有符号止点决定闭合姿态，包括偏心夹持。空处也能闭合，但不会吸附远处目标。静止夹持无自动取出，过大的工具与材料分离量会滑脱。
- 黏性耳垢和硬结：可先软化或先刮松边缘，再夹取，强拉可能导致不适或碎裂。手动输入沿用已验证的干片 .20、湿层 1.4 附着倍率，硬结仍随软化改变阻力。
- 毛刷／鹅绒掸：使用真实刷毛接触和工具位移／旋转，保留粒数、容量、独立质量与材质门槛；松手不执行自动带出。
- 滴管／吸引管：在实际管口接触处作用；吸入滤芯沿用现有结算，不进入收集盘。

## 取出与掉落

亲手解除附着后，继续保持夹持，滚轮向后撤到耳口外，再按 T。镜头切换期间保持材料的世界位姿。盘面视角下移动器具到真实盘上方，松开后以 9810 mm/s²、240 Hz 子步下落，接触盘面才计分。掉在盘外工作垫上的耳垢不计清洁度，也不删除质量，可以重新夹取。

耳道内与盘面上的器具都使用完整几何接触。松脱材料的碰撞使用实际变形网格；实体盘面与工作垫负责落地支撑。薄壳、油耳体积和碎裂质量守恒继续使用原求解器。原 `Approach`／`ClickSweep`／`Release` 自动路径仅保留给历史检查和吸引管兼容，主输入不调用自动取出路径。

普通营业给 600 秒，油耳仍为 900 秒；练习不限时。时长增加用于手动定位、撤出和放盘，不改变营业收益及存档键。

## 验收

从本 worktree 启动预览，然后运行：

```powershell
node EarSpa3D/Script_PrecisionPlayTest.mjs --url=http://127.0.0.1:8096/EarSpa3D/
node EarSpa3D/Script_PrecisionPlayTest.mjs --url=http://127.0.0.1:8096/EarSpa3D/ --width=1000
node EarSpa3D/Script_PointerAlignmentTest.mjs --url=http://127.0.0.1:8096/EarSpa3D/
```

脚本仅控制动画时间，使用自然种子耳垢和真实鼠标／键盘事件，不修改材料、锚点或工具位姿来取得成功。检查空夹、自由平移、转腕、进退、接触软化、静止夹持、逐点松脱、手动撤出、盘外掉落、重夹、落盘、质量与收益隔离、耳勺弯曲、取消恢复和渲染预算。报告与原始截图保存到本地 `_dev/`。
