# EarSpa3D 辅助贴合与物理操作

默认采用辅助贴合：玩家负责选择接触处、刮动／夹持和松手；系统负责贴合工作面与取出后的托送。深度、转腕仍可微调，但不再作为入门必需步骤。

## 怎么操作

| 工具／动作 | 操作与结果 |
| --- | --- |
| 小勺 | 指向薄片翘边，按住左键小幅划动；逐点刮开附着，松脱后松手，播放托出与落盘 |
| 镊子 | 指向露出的块体，按住左键让两尖闭合，再缓慢移动；只有双侧真实接触才夹住，松脱后松手送盘 |
| 软化滴管 | 接触黏块后按住滴液；可先处理旁侧干片，等软化后再夹 |
| 柔毛刷 | 按住沿壁来回扫，刷毛弯曲推动真实接触的小颗粒，刷拢本身不算收集 |
| 鹅绒清屑掸 | 按住扫过颗粒，容量内托住它们，松手后逐件送入盘中 |
| 吸引管 | 管口接触已软化的合格碎片后按住，滤芯回收按实际完整度估价 |
| 调灯 | 点「调灯」或 L，再点要照亮的位置；基础台灯固定在耳口，鼠标移动不会带着灯跑 |
| 查看盘子 | T 或「收集盘」，属于可选观察操作；正常取出无需切盘 |
| 取消 | Esc／取消／失焦／打开面板：停止输入并原地释放，不替玩家收集 |

触屏使用点住目标并短距离移动，抬手完成托送。数字 1–6 切换已拥有工具；滚轮／W、S、右键和 Q、E 保留精细微调。静止按住不会自动刮下材料；过大载荷可能碎裂、滑脱或疼痛。

## 自动辅助的边界

可见表面射线和有限屏幕容差只用于定位工具，不代替实体接触。小勺必须由工作面触及边缘；镊子先在有限局部范围调整张开的双尖，再按实际接触宽度闭合。空夹不能吸住远处耳垢。完整器具、变形毛簇、耳壁和盘面仍参与碰撞。

玩家解除附着后普通松手，工具连续托送出耳口，再在盘上释放。只有自然下落真正触盘后计清洁质量；托送中不计分，取消也不会凭空收集。游离质心采用 9810 mm/s² 向下重力、240 Hz 子步；薄壳和油耳内部继续使用原 XPBD 约束。

刷毛采用有阻尼的弹性毛簇，运动产生滞后、接触使其弯曲，停下后回弹；每次变形后再投影到完整管壁约束。根部固定，实际变形后的毛簇参与颗粒接触。粒数和清扫质量不会由视觉抖动增加。

## 验收

`Script_AssistedPlayTest.mjs --url=<本任务预览URL>` 使用自然耳垢与真实鼠标／触控验证默认输入。`Script_CareerEffectsPlayTest.mjs` 检查灯光、刷毛碰壁和最高等级闪光；其中灯光升级与闪光是受控渲染夹具，实际挣钱与购买另由经营／商店检查覆盖。旧 `Script_PrecisionPlayTest.mjs` 保留精细底层检查，旧自动点击和拖拽轨迹仅作历史参考。
