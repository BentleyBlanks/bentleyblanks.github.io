# EarSpa3D 当前契约

本文件约束 `index.html` 装配的拟物采耳入口；跨模块修改时读取涉及章节，并同步数据、实现和消费方。模块职责不代表永久人员分工，未登记的必要接口可随本次任务一起补充。

## 0. 当前玩法

查看病例 → 选择工具与路线 → 自由控制工作端位置、深度和倾角 → 实际接触、手动刮取或闭镊夹持 → 松脱或真实碎裂 → 亲手撤出与放盘／吸入 → 达标后主动交单或继续精清 → 结算与器具经营。主平台为电脑键鼠，采用用户确认的精细器具控制。

- 主入口为 `controlScheme='precision'`，旧点击／拖拽偏好迁移，营业存档不变。鼠标移动器具，滚轮／W、S 控制进退，右键拖动转腕，Q、E 绕杆转动，左键或 Space 持续夹持／施力，Shift 慢移，方向键移动工作端，1–6 切换已拥有器具。输入不选择耳垢，不自动对齐或执行取出路径。
- 普通鼠标位置投射到器具当前深度平面，无阻挡时工作端与指针位置对齐；耳道操作区仅显示工作端光标，UI 保留系统指针。转腕、Shift 慢移、键盘移动和碰撞后重新建立指针基准，避免释放后的跳跃与碰壁后的反向空行程。镜头切换保持已有夹持，指针离开／返回 UI 时不搬运所持材料。
- Esc、「松手」、失焦、取消指针、打开设置／小铺、换工具及换客清除全部输入并释放材料。工作端实际接触才可施力；空夹、单侧接触、错误勺面和工具长度限制继续有效。静止夹持不按时间增加剥离进度，过度拉扯会滑脱或碎裂。
- 松脱后保持夹持并亲手撤出耳口，按 T 切换盘面视角，再移动到盘上松手。视角变化不搬运所持耳垢；盘外落在真实工作垫上，可重新夹取。返回耳道前先放下耳垢，空器具回到可操作位置。
- 柔毛刷按住扫动，只推动实际刷毛接触的合格微屑，刷拢不计清洁度；鹅绒掸按住移动／旋扫，携带容量内实际接触的微屑，松手原地掉落。滴管接触处按住滴液，吸引管真实接触后吸入合格碎片。触屏保留基础拖动，完整深度和转腕以键鼠为准。
- 清洁度按实际收集质量增加；碎裂、刷拢、尚未落盘或吸入的物体不计收益。断口闭合，子块继承材料、运动与尚存附着，总质量守恒。
- 病例仅新增已选择的 1「干片练手」、2「黏块软化」、5「弯道深部」。指定原生耳垢及其所有代碎片实际收齐后才可交单，其他材料为可选精清；整片与软化挑战不阻止碎片补救。病例交单不把部分清洁伪装成 100%。原油耳服务与自由练习保留全耳完成条件。细节见 [病例说明](Data_CareCases.md)。
- 普通营业为 600 秒，油耳为 900 秒，练习不限时；手动定位、撤出与放盘增加了操作时长。练习隔离营业进度，退出恢复进入前局面和盘面视角。小铺与设置暂停操作。
- 经营键保留 `earspa3d.shop.v1` 及现有旧档迁移；换客、跨日与小铺保留盘内物品，刷新重新开始收集。清盘不回退已结算收益，不改变新客初始质量。

## 1. 跨系统约定

- 1 世界单位 = 1 毫米，Y 向上、右手系；灯光按毫米尺度标定。空间查询返回缓存向量时立即复制，再进行下一次查询。器具显示几何与碰撞使用同一位姿。
- 耳道视角隐藏外部房间与角色，照明由相机头灯承担；取出视角由实时头部和耳廓承接。当前入口的探针与空间实现以 `Script_ImmersiveScene.js` 为准。
- 游离块体的质心统一使用 9810 mm/s² 向下重力与 240 Hz 子步碰撞；薄片厚度与朝向通过空气阻力影响落速。托送由器具支撑，凝胶内部柔变仍沿用原求解标度。物理保留真实碰撞和独立质量约束；画质与性能优化不降低工具采样、扫掠精度或改变结算。具体薄壳／凝胶求解器边界见分项契约。
- 当前 UI 为暖黑半透明、米白文字、细衬线标题和米金选中态；模型和器具继续写实拟物。详情见分项契约“美术与声音”。
- 离线声音遵循根 Volcengine 规则。女声对白与叹气停用且不再生成；已试听的落盘三档及干／湿短刮保留原波形与音调。现场连续接触声按实际接触、位移与载荷门控，不能用旧接口中的“只能合成”覆盖已批准的采样通道。
- 普通页只提供只读 `__EarSpaProbe()`；仅 `?debug=1` 暴露可写 `__EarSpaDebug`。可选材质和音频缺失不得阻塞游戏；材质、几何与异步准备在取消或销毁时释放。
- 客人生成和物理输入使用传入的确定性种子，公共随机工具为 `Script_Util.MakeRng`；保持同种子可复现。当前渲染检查保留三角形 ≤180k、draw calls ≤120 的预算，不能通过删掉实际模型或降低碰撞精度达标。
