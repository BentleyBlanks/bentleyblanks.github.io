# EarSpa3D 当前契约

本文件约束 `index.html` 装配的拟物采耳入口；跨模块修改时读取涉及章节，并同步数据、实现和消费方。模块职责不代表永久人员分工，未登记的必要接口可随本次任务一起补充。

## 0. 当前玩法

查看病例 → 调整固定台灯 → 选择工具和接触处 → 辅助贴合后亲手刮取／闭镊夹持 → 松脱后松手托出、自然落盘 → 达标交单 → 服务费与舒适小费 → 小铺出售收藏、升级器具 → 下一位顾客。

- 主入口为 `controlScheme='assisted'`，旧输入偏好迁移。鼠标／单指指向可见表面，系统帮助调整深度、工作面与有限范围入尖；按住短距离移动供给真实载荷，静止不增加剥离进度。微调与可选看盘仍可用，详见 [操作说明](Data_PrecisionControls.md)。
- 小勺工作面、真实边缘及镊子双侧接触决定抓取；单侧／空夹不抓住目标。有限辅助不绕过全工具碰撞、长度、材料门槛和质量约束。
- 普通松手将已松脱材料连续托出、逐件落盘；实际触盘或吸入滤芯才计清洁质量。Esc、失焦、取消指针、面板与换工具原地释放，不自动收集。碎裂、刷拢与尚在托送的物体不计收益。
- 刷毛按住扫动，带阻尼毛簇弯曲和回弹，推动实际接触的微屑；鹅绒掸按容量托住微屑，普通松手逐件托送。软化和吸引仍要求真实管口接触。
- 新档 0 币、仅基础小勺、一级弱固定灯。台灯必须明确调向，升级亮度后仍固定；达到等级并购买器具照明后才随该工具运动。练习临时开放器具与明亮台灯，退出恢复营业状态。
- 附着难度、原始质量和最大完整片决定五级收藏；同一来源碎片合并估价，最高级取出时闪亮。每位顾客只付一次服务费和小费，有疼痛则小费为零；售卖收藏才兑币。详见 [经营策划](Data_ProgressionDesign.md)。
- 基础器具阶段只安排可用小勺完成的干片病例；滴管与镊子齐备后再解锁黏块／深部路线。指定原生块及多代碎片实际收齐后才可交单，不将部分清洁伪装成全耳完成；油耳和自由练习保留相应目标。
- 普通营业 600 秒、油耳 900 秒，练习不限时并隔离营业。经营键保留 `earspa3d.shop.v1`，旧资产保留迁移；待售收藏持久化，场景盘内几何仅在同次会话跨客保留。

## 1. 跨系统约定

- 1 世界单位 = 1 毫米，Y 向上、右手系；灯光按毫米尺度标定。空间查询返回缓存向量时立即复制，再进行下一次查询。器具显示几何与碰撞使用同一位姿。
- 耳道视角隐藏外部房间与角色，照明由手动固定台灯或已购器具灯承担；取出视角由实时头部和耳廓承接。当前入口的探针与空间实现以 `Script_ImmersiveScene.js` 为准。
- 游离块体的质心统一使用 9810 mm/s² 向下重力与 240 Hz 子步碰撞；薄片厚度与朝向通过空气阻力影响落速。托送由器具支撑，凝胶内部柔变仍沿用原求解标度。物理保留真实碰撞和独立质量约束；画质与性能优化不降低工具采样、扫掠精度或改变结算。具体薄壳／凝胶求解器边界见分项契约。
- 当前 UI 为暖黑半透明、米白文字、细衬线标题和米金选中态；模型和器具继续写实拟物。详情见分项契约“美术与声音”。
- 离线声音遵循根 Volcengine 规则。女声对白与叹气停用且不再生成；已试听的落盘三档及干／湿短刮保留原波形与音调。现场连续接触声按实际接触、位移与载荷门控，不能用旧接口中的“只能合成”覆盖已批准的采样通道。
- 普通页只提供只读 `__EarSpaProbe()`；仅 `?debug=1` 暴露可写 `__EarSpaDebug`。可选材质和音频缺失不得阻塞游戏；材质、几何与异步准备在取消或销毁时释放。
- 客人生成和物理输入使用传入的确定性种子，公共随机工具为 `Script_Util.MakeRng`；保持同种子可复现。当前渲染检查保留三角形 ≤180k、draw calls ≤120 的预算，不能通过删掉实际模型或降低碰撞精度达标。
