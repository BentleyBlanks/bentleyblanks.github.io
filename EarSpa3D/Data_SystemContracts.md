# EarSpa3D 分项现行契约

按 [当前契约](Data_Contract.md) 的路由读取涉及章节。本文件保存仍有效的实现边界；旧方案与原始更新顺序见 [历史快照](Data_ContractHistory.md)。数值是当前实现的验收基线，修改时同步实现、消费方与对应说明。

## 工具与接触

器具直接操控（取代下方可选拖动与鼠标选块约定）：六种工具统一按住左键／触屏施力才平移，松手原地停留；旧设置中的 toolDrag=false 自动迁移，移除旧跟随模式开关。鼠标位置只提供相对位移，选块、抓点和施力均来自碰撞修正后的真实工作端；点击远处不吸附、不挪动工具，空划和静止不加载。碰壁丢弃受阻位移，反向立即响应。滚轮向上推进、向下退出，触屏「进退」模式向上拖推进、向下拖退出，二者保留整件扫掠与工具长度。右键按住原地旋转不变。键盘方向键移动工具、W/S 进退、空格按住接触并施力、Q/E 转向；不再按键选块后自动贴过去。新增 AdvanceTool / QueueToolDepth，接触探针增加 toolScreen / toolDepth；Script_ToolDragPlayTest.mjs 验证新用户、旧设置迁移、四种视口、实际工作端命中、空点不抓、受阻反向、进退、松手与落盘。

耳勺侧边接触：薄壳外轮廓的任意一侧均可进勺，`Script_WaxEdgeContact.mjs` 从当前形变节点的外边界计算局部向内方向，内部三角边不算边缘。凹口朝向局部材料的侧刃可以推刮，不再仅用整块耳壁法线否决；中心托举仍沿用原勺面条件。鼠标中心未命中时，在真实勺碗的有限范围内用开口射线检测耳垢网格，仍检查耳壁遮挡与工具长度。向外撤离边缘停止传力，保留真实接触范围、静止不加载、勺背无效、整件工具碰撞及碎裂质量守恒。新碎片用自身重建的外边界，边界缓存不跨物体复用。

鼠标刮取与黏聚断裂：耳勺左键建立相机平面的位移基准，按住后真实器具位置随鼠标／触点位移，仍做整件器具扫掠碰撞；静止按住不自动施力。凹口朝向、局部接触距离及单向支撑共同决定是否传力，勺背和离开材料的勺子不能远程拉扯。右键保持已有转向操作。薄壳保留 240 Hz XPBD 拉伸与弯曲求解，壁面黏附与内部黏聚区分别计算；裂纹由截面反力和弯矩驱动，损伤取历史最大载荷包络，不按按住时长累计。切面来自受力截面，沿真实形变网格封口分离；子块继承该侧尚存的耳壁锚点与运动，固定残片留在原位，游离块按重力和接触落下，不全部重新铺回耳壁。质量及落盘计分不变。

耳勺朝向修正：耳勺首次摆放建立握持朝向，此后移动、贴壁、切换目标和镜头进深只自动修正位置，不重新对齐表面法线或镜头。只有玩家的转向输入改变旋转；转向仍保留固定安全支点与碰撞角度限制。新客人重置初始朝向；自动落盘展示不改写玩家握持角度。其他器具沿用各自现有姿态逻辑。

刷拢微屑：柔毛刷按住拖动时，碰撞修正后的真实刷毛沿管壁推动接触到的原生微屑和合格细碎片，向刷头前沿聚拢；空划、静止、转向和未按住移动不聚拢。碎屑停留在扫到的位置，保留独立几何、质量与工具门槛，刷拢不取出、不计清洁度。较大碎片仍走原刷松流程。鹅绒掸五级容量更新为 1／3／6／9／12 组，实际绒羽接触才收集，松手托送、落盘逐件结算；沿用既有等级存档与工作面宽度。新增 SweepBrush / BrushSweepProbe 及 Script_BrushGatherPlayTest.mjs，验证真实鼠标／触屏、停手留堆、壁面、质量和升级批量落盘。

鹅绒柔顺修订：羽枝按连续的径向下垂场梳向末端，共享接触网格同步更新，贴壁时完整细小截面一同弯折，保留截面厚度与安全间隙；工作面宽度与等级容量不变。外层改为沿每根羽枝的局部方向连续延伸的细丝，厚度收至 .024 mm，根梢淡出、表面高光柔化，保留六层绘制及完整贴壁约束。

鹅绒旋扫：五级单次容量为 1／3／6／9／12 组微屑（每个原生微屑物体仍是 9 粒，质量与总粒数不变）。右键或触屏转向模式旋转时，按碰撞修正后实际绒羽接触选择微屑；按下或静止不清理，松开沿现有托送路径带出，实际落盘才计分。左键剥离仍可用，松手不再自动吸附附近未接触微屑。只接受原生微屑或满足既有质量与尺寸门槛的碎片。羽毛新增共享变形网格的六层稀疏 shell fur，当前厚度 .024 mm，安全间隙包括外层；商店使用相同材质并独立释放资源。实时着色近似，不改变其他工具和物理求解器。

## 物理与油耳

本体弯折：原生块和可见碎片采用有厚度的 XPBD 薄壳，低分辨率物理网格驱动原有完整表面。拉伸／剪切、跨边弯曲、工具抓点与耳壁附着分别求解，附着按局部反力逐点失效；未脱开的区域留在耳壁，受力边缘可逐步掀起，松手按弹性与阻尼回落，回落过程中也可继续抓取。干片、湿层与硬结使用不同柔度，滴液同时降低弯曲刚度和附着强度。不再绘制耳壁连接柱或碎片间假拉丝，也不以进度驱动顶点形变。微屑继续使用轻量刚体；质量、工具适配、三代碎裂及落盘计分保持原契约。实现与定量验收见 Script_SoftWaxPhysics.mjs、Script_SoftWaxPhysicsTest.mjs。

油耳碎裂性能：`Script_SlimeConstraints.mjs` 将原有顺序 XPBD 投影放进每个凝胶独立的 Float64 暂存区，每个子步从真实节点、材料记忆与体积约束同步，求解后写回。仍为 240 Hz、覆盖层 16 轮／旧凝胶 8 轮，完整碰撞、反翻转、抓点反力、质量与材料参数不变。撕开两侧继承当帧已求解的状态，母体下一帧才继续推进，避免断裂当帧额外执行一次物理。断口拓扑使用 Uint16 节点范围内无冲突的数值键，闭合网格、细分外观与逐点附着不变。新增 `Script_OilyFracturePerformanceTest.mjs` 检查真实鼠标／触屏施力、断裂帧子步数、握持不重复取垢、落盘与帧耗时。

深部油垢与局部黏性挖取：油耳营业服务时长改为 900 秒，为大量局部清理与落盘留出可完成的操作时间；其他客人仍为 210 秒，练习仍不限时。三片连续覆盖层延伸到 22–23.1 mm，前段形态保留，深部各增加三处厚积垢；每片 594 节点、1536 四面体，297 个底层节点逐点黏壁。工具接触附近先黏软拉伸，实际抓点位移与反力产生的撕取功达到阈值后，仅分离邻近体积单元，单团清洁质量最多 .32（全耳质量 9）；持续握持只带走这团，母体留壁，需再次接触挖取。断口从四面体边界封闭重建，两侧继承体积、速度、材料坐标及尚存附着，不重置损伤、不删质量。离壁小团以表面积梯度的表面张力缓慢收拢，仍保留体积约束、黏性阻尼和真实工具接触。短勺仍需实际刮动，静止不加载；长镊实际夹臂与握柄位置加长 6.3 mm，碰撞使用相同模型，基础可达深度 23.8 mm。油耳缩放按钮在标准、深部、入口全景三种镜头间循环，入口全景后退到耳口外，保证局部清理后边缘材料仍能实际点取；其他客人保留原两档。240 Hz／16 轮体积约束、防翻转回溯、法线细节、非金属油膜、落盘计分与营业隔离继续适用。

蜡体与油膜高光使用随材料变形的三尺度细节法线，按屏幕足迹滤掉亚像素细节；metalness 仍为 0，蜡体 roughness 为 .10–.21，clearcoat roughness 为 .16。透明体积恢复深度写入，避免背面折边叠到近侧形成交叉黑线；壁面底层间隙增至 .035 mm。显示中心与诊断抓点来自实际细分曲面。体积求解、附着点数、总清洁质量、工具接触与营业隔离保持不变。新增 Script_OilyDetailTest.mjs 检查所有覆盖层的真实管壁间隙、三种视角的细节像素与三角形绘制顺序独立性。

油耳形态修正：用三片不规则连续覆盖层取代九个分离扁块。每片沿真实管壁从入口延伸到深处，薄层与局部厚积垢共享棱柱四面体网格、受力和质量；拉厚部会牵动周围贴壁薄层，清除后露出原管壁。覆盖层的厚薄与褶皱改变可见管腔轮廓，不能只改颜色或把扁球重新排布。总清洁质量仍为 9，每片质量 3。连续覆盖层使用 16 轮体积迭代，保留 240 Hz 子步，并响应既有物理参数设置。黏附法线逐点来自实际耳道，材质 metalness=0，roughness 依厚度在 .10–.21 之间变化；吸收光程直接使用模拟薄层厚度。

油耳 `oily` 是独立客人类型，整耳全部使用黏弹凝胶，不混入干片、硬结或干微屑；总清洁质量仍为 9。`Script_SlimePhysics.mjs` 以四面体体积、可松弛的剪切/拉伸、黏性阻尼、局部附着与实际抓点约束求解，连续曲面由同一物理节点细分；允许颈缩、缓慢回缩、逐点剥离和落盘摊软，不能用预设拉丝动画代替。透明油膜、厚度吸收和柔和内部散射是实时材质近似，不宣称医学测量或无限精度流体。

## 经营与收集盘

设置提供混合、干耳、黏耳、硬结、油耳的确定性练习入口、重置和返回营业。练习不计时、不结算金币或声望，临时可用全部工具；营业进度单独保留，退出恢复进入前的实际局面。普通营业名单包含油耳。新求解器、客人生成和场景接口按本节扩展，原有干/湿/硬壳、工具碰撞、毫米坐标及质量守恒继续适用。

盘面整理：服务完成或到时后，镜头平滑进入独立盘面特写。Script_CollectionTray.js 持有已落盘耳垢的几何与质量，独立于每位客人的 chunks；同一游戏内换客、跨日及打开小铺均保留，刷新页面重新开始收集。吸入滤芯的耳垢不进入盘子。结算时免费提供清盘耳勺，鼠标／单指按住拖动可将耳垢拨过盘沿；按住倾倒按钮使盘子倾斜并让碎屑滑落，松手回平。仅实际越过盘沿的耳垢被移除；清盘不改变已结算收益、清洁度或下关初始质量。失焦、取消触控、打开面板、换客均停止清盘输入。盘内模型按材质合批，清除后释放几何，验收覆盖四种视口、真实输入、跨关保留与质量隔离。

倒盘盘壁碰撞：收集盘的内壁按 `Script_BuildImmersiveEar.BuildTray` 的真实剖面参与盘内耳垢运动——耳垢贴壁面爬升，壁面法线把它顶回盘心，只有真的翻过唇口（盘沿最高处）才离盘下落，不再在盘底高度直接穿出盘壁；倾角不足时滑回盘心，清盘耳勺拨出去的也先沿壁抬升再越沿，凝胶耳垢的落地面同步抬到壁面高度。倒空判定、质量、结算与跨客保留不变；盘内诊断新增 `exitHeight`（最近一次离盘处的盘沿高度），验收见 `Script_DirectionalPlayTest.mjs` 按真实盘子网格的倒盘取样。

清盘耳勺比例：清盘器具独立按盘长轴的 68% 标定（约 37 mm），浅角度斜向盘面，勺面最低点贴近盘底、工作端原点跟随触点。耳道操作器具与约 55 × 33 mm 收集盘继续使用原尺寸；清盘碰撞、质量、结算和倾倒规则不变。

## 设置与性能

通用 → 画质提供模拟渲染总开关、默认／流畅／均衡／精细预设及分项等级：分辨率、动态阴影、接触遮蔽、皮肤散射、湿润油膜、表面细节、环境反射和绒羽细丝。默认延续当前设备自适应分辨率／阴影及完整材质效果；手动分辨率和阴影不被自动降级覆盖。`Data_RenderQuality.mjs` 校验配置，`Script_RenderQualitySettings.mjs` 使用独立本机键 `earspa3d.render.settings.v1`，`core.SetRenderQuality` 与 `view.SetRenderQuality` 即时应用；关闭总开关保留分项选择。只改渲染分辨率、采样、材质与细丝显示，不改碰撞网格、240 Hz 物理、质量、工具能力或营业存档。当前、新客人、练习、升级后的器具均继承设置。

Debug → GamePlay 提供「跳转下一个顾客」，首屏、服务中、结算后可用；练习中禁用，准备中防重复触发。`shop.SkipCustomer()` 只将未完成顾客标为已跳过，不结算金币、声望或完成数。换客复用异步准备流程，保留已落盘物品；末位后进入次日，失败时可重试同一顾客，不再次跳号。验收入口 `Script_RenderQualityPlayTest.mjs` 覆盖四种视口、真实设置输入、刷新持久化、存储异常、渲染探针及换客边界。

设置中的 Debug → 物理模拟默认折叠，普通页面可用。`Data_WaxPhysicsSettings.mjs` 集中定义四种材质的参数范围、默认值和校验；薄壳与凝胶求解器每帧读取同一份只读配置，当前物体、碎片、新客人和盘内凝胶均使用更新后的参数，不重建物体或重置锚点损伤。薄壳默认拉伸／弯曲弹性为原基准的 85%，速度阻尼由 12 增至 16 /秒；凝胶拉伸弹性为 85%，阻尼由 8 增至 10 /秒，形状恢复由 .15 降至 .12 /秒。240 Hz 子步、8 次迭代、体积约束及真实碰撞不变。

`Script_PhysicsSettings.mjs` 在现有设置内创建材质选择、带数值和说明的滑块及全部恢复默认按钮；使用独立的 `earspa3d.physics.settings.v1` 本地键，不写入营业存档。输入钳制到已验证范围，损坏／不可用的存储回退默认并允许本次会话调节。设置打开时游戏继续暂停，关闭后生效；只读探针增加 `physicsSettings`，普通页仍无可写调试全局。验收入口为 `Script_PhysicsSettingsTest.mjs` 与 `Script_PhysicsSettingsPlayTest.mjs`。

接触与加载性能：保留完整工具采样、扫掠步长、240 Hz 物理、模型和材质效果。最小间隙查询仅计算胜出点法线，按几何版本与夹爪局部矩阵复用采样；完全相等的受管采样/位姿才缓存间隙，自定义可变采样不缓存。首屏客人直接进入服务，不重复 Reset。`PrepareCustomer(seed)` 在独立暂存中分批生成同样的块体、薄壳物理绑定与接触轮廓，最多保留一位；薄壳绑定按轮廓射线、物理节点和顶点权重批次让出主线程，同步碎裂仍使用相同的完整绑定；`Reset(seed)` 消费已完成结果，未准备时仍支持同步重建；取消、替换和 Dispose 释放暂存。结算时预备同日下一位，跨日按原经营逻辑生成名单后显示短暂准备状态，此时不计服务时间；不得提前消费经营 RNG 或改变存档。切换时复用同类独立材质的 shader program，并重置湿度和裁切状态。GLB、PBR、解剖 profile 并行加载，音频提前准备；不降低画质、不省略首次工具预热。回归入口增加 `Script_ContactLoadingTest.mjs`，覆盖暂存隔离、取消、真实跨客流程和缓存失效；可加 `--compare=<commit>` 核对逐种子几何与像素。整局脚本只由 StepFrames 推进游戏，用真实转向满足工作面条件，等待异步接待完成再开始下一局；不改变碎裂、落盘、清洁度和超时断言。

第二天操作性能：悬停移动每帧只处理最新位置，按下、旋转和施力保留现有入口，取消操作时清空待处理移动。管壁查询缓存 0.25 mm 格内可能最近的中心线段（最多 8192 格），真实位置仍精确计算；完整工具采样、扫掠步长和安全间隙保持原值，收敛位姿复用已有间隙结果。验收增加第二天存档、跨日换客资源稳定性、输入合并及独立全段搜索比对，不改模型、画质或存档格式。

## 美术与声音
