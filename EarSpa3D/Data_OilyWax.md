# 油耳与耳道练习

入口：设置 → 客人耳道测试 → 油耳。混合、干耳、黏耳、硬结、油耳可直接切换；同种练习使用固定种子。练习不限时、开放六种器具，不发金币或声望；进入前的实际耳道、清理质量、计时和收藏盘独立暂存，返回营业时恢复。

## ear029 连续薄层与厚积垢

根据用户参考修正 ear025 的九个独立扁块：`Script_OilyCoating.mjs` 生成三片不规则连续覆盖层，沿真实管壁延伸约 0.65–15.3 mm。每片包含贴壁薄膜、连续褶皱与多个局部厚积垢，薄厚区域属于同一个封闭网格与体积格架。覆盖层改变可见管腔轮廓；清除后露出原管壁，不永久改动解剖坐标和器具碰撞模型。三片各质量 3，总清洁质量仍为 9，无干微屑或硬结。

每片 378 个材料节点、960 个四面体、21 个分布式附着点；十六轮 XPBD、240 Hz 子步。沿用最新物理设置的弹性、阻尼、黏附与松弛参数，设置调整对当前薄膜即时生效。采用棱柱网格的体积划分，不使用不能适配弯曲薄层的中心点放射划分。厚部拉取时，材料边约束将载荷传到周围薄层，按各处真实管壁法线逐点脱黏。体积屏障和位移回溯防止薄层翻转；不改静止体积来修复数值，也不删除材料。松手保留原形变并黏弹回缩，落盘后继续短暂摊软，清盘接触会唤醒休眠体。

显示曲面由同一组物理节点细分。厚度约 0.022–1.2 mm，局部拉伸影响光程；薄层保留皮肤纹理，厚部呈金黄褐色。`metalness=0`、`ior=1.46`、厚度驱动 `roughness=0.10–0.21`，清漆粗糙度 0.095。使用器具已有的检查环境反射，亮度随检查灯和取出镜头变化。极薄边缘按光学覆盖率淡出，避免不透明硬边；不再把透明弯曲薄层作为不透明投影轮廓遮蔽物。工具的真实阴影保留。

镊子按真实抓点和双侧接触拉取；局部薄层法线参与握持朝向。耳勺沿用指针刮动、有限工作区与滑脱，静止长按不代替刮取。落盘和营业计分各只发生一次。任意两片后续接触不会自动合并拓扑；这是实时黏弹体积近似，未做实物材料参数拟合。
