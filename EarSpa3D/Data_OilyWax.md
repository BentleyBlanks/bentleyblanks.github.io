# 油耳与耳道练习

入口：设置 → 客人耳道测试 → 油耳。可选混合耳、干耳、黏耳、硬结耳、油耳；相同练习种子重开得到相同耳道。练习不限时、临时开放六种器具，不发放金币或声望。进入前的耳道、已清理质量、营业计时与收藏盘暂存，返回后恢复；练习藏品不会进入营业收藏盘。营业名单也会按天数与客人顺序安排油耳，不需要调试参数。

油耳九块均是凝胶，每块质量 1，总质量 9，不生成干微屑或硬结。镊子对准后按住，局部先拉长、变细，再逐点脱黏；中途松手保留已松开的附着点并黏弹回缩。耳勺沿用实际指针刮动、有限勺碗接触与滑脱，不能靠原地长按完成。松脱后沿既有器具路径送出，落盘只计数一次，收藏盘继续短暂的体积求解，使凝胶摊软后休眠；接触清盘耳勺会重新唤醒。

`Script_SlimePhysics.mjs`：每块 163 个材料节点、320 个四面体、13 个离散附着点。240 Hz 子步、每子步八轮 XPBD 投影，四面体体积与黏弹边约束分别求解，沿边交换速度以产生黏性阻尼，材料静止长度缓慢松弛。附着按局部反力与作用时间失效。活动凝胶每个子步查询真实耳道碰撞场，已落盘的凝胶约束在盘面上。热循环使用标量梯度，避免反复分配临时向量。

显示曲面是材料节点的 Loop 细分，642 顶点 / 1280 三角面；没有独立假拉丝、缩放消失或按进度播放的形变动画。黏性牵连由未脱开的凝胶本体产生。材质使用介电高光、油膜、透射、按形变估计的光程和已有蜡质图集的微弱内部色差；薄处与颈缩处更透光。油耳不投射不透明硬阴影，近壁遮蔽沿用实际三角轮廓，保留透射与工具的真实阴影。油耳拉取场景约 170432 个提交三角面、21 次绘制，保持原 180k / 120 预算。

这是面向毫米级实时交互的黏弹体积近似，尚未做实物材料参数拟合，不把它表述为医学测量或完整流体 CFD。各块独立求解，不承诺任意两块接触后融合成同一个流体拓扑。薄层光程与内部散射也是实时近似。

验证命令（本地预览端口以实际输出为准）：

```powershell

node EarSpa3D/Script_OilyWaxPlayTest.mjs --url=http://127.0.0.1:8110/EarSpa3D/
node EarSpa3D/Script_OilyRenderingTest.mjs --url=http://127.0.0.1:8110/EarSpa3D/
```

物理测试覆盖静止、压入耳壁、拉伸、附着点误差、松手回缩、重夹、四组种子、落盘、正体积与暂停。四组种子的局部边伸长峰值 3.22–3.77 倍，总体积误差峰值低于 0.3%。交互测试使用真实鼠标和 CDP 触屏，尺寸 1000×900、390×844、320×568、844×390，包含全部九块清理、深处转向、重开、五种耳道、存档隔离和非空收藏盘恢复。渲染测试另外以实际耳道网格射线检查凝胶穿透，并测量包括 GPU 完成等待的帧耗时；此为本机浏览器测量，不代表实体手机性能。截图与 JSON 报告仅留本地 `_dev/`。
